## 规则

1. 优先引用论文原文、官方代码和官方数据页面。
2. 论文报告值与本项目实测值必须分开，不将不同 benchmark 的数字横向混用。
3. 对尚未独立复现的预印本明确标注，不能直接作为模型切换依据。
4. 调研结论必须落到可证伪实验，不能只给架构名称或笼统建议。
