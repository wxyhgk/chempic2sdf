# v0.8.26 Junction Pair 投影一致性

> 状态：工程协议 GO；模型能力 NO-GO  
> 日期：2026-07-21

## 目标

v0.8.21 训练评估先按 selector keep score 删除同一预测 Junction pair 的重复候选，
再计算 Junction 坐标；v0.8.22 正式推理则先让全部重复候选参与坐标聚合，之后按原始
detector score 选择代表。该错位会同时改变代表候选的键型、方向和 Junction 坐标。

本轮不训练新权重，只统一投影协议，并用显式 A/B 开关验证实际收益。

## 实现

新增公共投影：

```text
project_unique_junction_pairs(
    bond_objects,
    endpoint_groups,
    ranking_scores=selector_probability,
)
```

协议为：

- threshold 后的候选按预测无向 Junction pair 去重；
- self-loop 删除；
- 重复 pair 保留 selector probability 最高者；
- 同分按原局部索引稳定决胜；
- 只有保留对象参与 Junction 坐标计算；
- 对象原始 `score` 仍保留为 detector confidence，不被 selector score 覆盖。

推理新增 `junction_projection_score_source={detector,selector}`。`detector` 完整保留
v0.8.22 历史行为，`selector` 启用训练/推理一致协议。稳定默认不变。

评测器同时完成两项加固：

- 使用 `structure_labels()`，统一支持 ChemVision pilot 和 full WebDataset；
- 新增纯骨架 topology exact、Edge precision/recall/F1 和 stress 分桶。

## 结论

训练/推理投影错位是真实工程问题，公共协议和显式 A/B 开关应保留。但 v0.8.21 当前
候选中，detector 与 selector 只在极少数重复 pair 上选择不同代表，因此整图 exact
净提升为零，没有通过预设 `+3pp topology` 门槛。

本轮结论：

- 公共 projection、统一坐标路径、评测口径和对照开关：GO；
- 将 selector-score projection 作为能力升级或替换稳定默认：NO-GO；
- v0.8.25 的 `77%` GT-pair 去重上限不能外推到 v0.8.21 线上链路；
- 下一阶段不再调 winner score，而是在全候选预测 pair 上训练 pair-level
  existence/ranking/cardinality；
- crossed 和 near-nonbonded 继续归入 candidate/query 表示专项。
