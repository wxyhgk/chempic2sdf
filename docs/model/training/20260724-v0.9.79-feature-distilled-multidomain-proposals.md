# v0.9.79 特征蒸馏的多域 Proposal

## 目标

v0.9.76 证明全解冻可显著提高 MolGrapher proposal recall，但会破坏下游特征；v0.9.78
证明全冻结可保护接口，但几乎无法适配新域。本轮使用冻结 v0.9.72 教师约束可学习学生的
`object_features`，在两者之间寻找可用解。

## 方法

- 教师 Atom/Bond：v0.9.72，完全冻结；
- 学生 Atom/Bond：同一初始化，允许全量训练；
- 原 proposal detection loss 保持不变；
- 增加 Atom/Bond 全空间 object feature MSE；
- 初始蒸馏权重为 `10.0`。

训练和验证仍为 ChemVision、full-v0、MolGrapher 三域严格等量，MR-TADF/USPTO 不参与选择。

## 门控

第一个 4,500 总样本必须同时看到：

- MolGrapher proposal recall 明显优于 v0.9.78；
- ChemVision/full-v0 的 Bond deployed exact 不得再次整体归零；
- 若 coverage 与接口稳定性仍不可兼得，再改为显式 feature adapter，而不是继续调同一损失权重。

输出：

`outputs/checkpoints/chemvector-v0979-feature-distilled-multidomain-proposals-balanced18k/`

## 第一检查点结果

4,500 总样本时：

- MolGrapher Atom proposal recall：85.73% → 92.80%；
- MolGrapher Bond proposal recall：78.76% → 86.55%；
- Atom/Bond feature MSE 约为 0.0032/0.0143；
- 但三个域 Bond deployed exact 仍为 0。

阈值扫描的最佳 pooled full exact 仅 1.61%，因此失败不是单一 decision threshold 偏移。
本轮在 4,500 后停止，继续审计 proposal score、type 和 representation 接口。
