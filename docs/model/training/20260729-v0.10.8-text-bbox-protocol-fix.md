# 2026-07-29 v0.10.8 文字框与原子身份协议修复

> 状态：bbox 组件 GO，最终组合门仍差 1.1pp  
> 输出：`outputs/checkpoints/chemvector-v0108-direct-atom-text-bbox-style10k`  
> 评测：`outputs/evaluations/chemvector-v0108-direct-atom-text-bbox`

## 根因

v0.10.6/0.10.7 使用 ChemScene 的空间顺序 `target_index`，却用它索引按源 SDF `atom_id`
建立的 `rendered_atom_labels`。fresh calibration 500 上，全原子标签只有 56.32% 碰巧相同，
真实 TEXT 字符串只有 10.14% 碰巧相同；这精确解释了旧结果的 state 约 56% 和 TEXT 约 10%。

此外，旧训练虽然调用 `requires_grad_(True)`，CTC forward 仍按 checkpoint 配置进入
`no_grad()`，Pixel Encoder 权重实际没有变化。

本版统一从 ChemScene AtomObject 读取字符串，并增加原子重排回归测试；v0.10.6/0.10.7
checkpoint 均受错误监督污染，不再用于能力判断或续训。

## Oracle 审计

同一 v0.8.8 CTC、同一 fresh calibration 500，只修正标签协议：

| crop | TEXT raw | state accuracy | 整图 exact |
|---|---:|---:|---:|
| anchor + predicted extent 1.5x | 69.34% | 91.59% | 8.0% |
| 完整 GT bbox | 85.23% | 95.86% | 23.2% |

GT center 加当前 predicted extent 已达到约 82.0% TEXT，而 anchor 加 GT size 只有约 72.7%；
中心偏移是主缺口。旧 `geometry[4:6]` predicted center 直接接入仅约 26.8%，不能复用。

## 模型

- 冻结 v0.10.4 结构、v0.10.5 role gate 和 v0.8.8 CTC。
- 对预测 Atom anchor 读取 16/32/48px 三尺度 RGB patch。
- 274,148 参数的小 CNN 只回归 bbox 中心偏移与半宽/半高。
- 三域 10k：style/ChemVision/font-v2 = 6,668/1,666/1,666。
- fresh calibration 500 只用于选模；fresh evaluation 1,000 只在训练结束后读取。
- sealed test 未读取，MR-TADF/USPTO 未参与训练或选模。

## 决策

bbox 组件通过预设门槛 `TEXT >= 78%`、`state >= 95%`、`exact >= 15%`，正式 GO。
最终组合目标仍是 exact >= 20%，当前 18.9%，不宣布完整 OCR 已解决。

下一步从干净 v0.8.8 初始化，在正确 ChemScene 标签与 learned bbox 上真正解冻 Pixel Encoder。
先做固定小集合过拟合并验证卷积权重变化，再做 10k/20k pilot；不 resume v0.10.6/0.10.7。
