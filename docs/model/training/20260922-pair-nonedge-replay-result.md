# 单次非边回放试训：抑制新增假键有效，但仍未通过完整保护检查

## 结论

用户确认“开始启动训练”后，完成一次事前固定的自研 pair 修复试训：
从原始 initial 出发，RTX 5090 单卡，**50 次更新／54 次尝试，进程总耗时 23.045 秒**。
4 次空监督跳过；回放覆盖全部 32 张旧完整分子图，共 1,600 条次确认非边。
没有第二条训练轨迹、调参扫描、自动重试或部署。当前单次许可已消费。

相同初始条件下，与不加回放的历史 50 步对照相比，确认假边从 3 降到 1，
两条重点假键均未跨过固定 0.85 阈值，有效 SDF 从 52 恢复到 53。
正确类型键总数仍为 1,049，完整 SDF 正确仍为 21 / 58。

这是单变量回放方案在本训练池中的正面证据，但**不是完整修复成功**：
仍有一处新增 fallback、一处初始正确类型键丢失，原保护检查返回 `stop_regression`。
默认模型仍为原始 initial，不能用本次权重替换。

## 两条重点假键

| 探针 | initial 概率 | 原目标 50 步 | 回放 50 步 | 本次跨 0.85 |
| --- | ---: | ---: | ---: | --- |
| `4ef / bond_short`，GT (31,34) | 35.1084% | 95.0123% | 70.3770% | 无 |
| `08d / font_large`，GT (7,14) | 6.9670% | 96.3315% | 76.7696% | 无 |

它们通过通用“初始分数最高的确认非边”规则进入回放池，分别在第 22、25 步直接接受回放监督。
没有为它们硬编码训练行，但它们也不是未见样本，不能把改善称为未见错误上的泛化。
最终分数仍高于 initial，说明是抑制了上涨／越阈值，不是彻底消除了跨样本干扰。

注意：本轮两次本图更新的总 logit 变化分别为 +0.001461、+0.068165，
不能沿用旧试验中“本图更新必然下降”的说法。本轮每次更新包含主图和另一图片回放，
Adam 状态也已改变；日志明确区分主图监督和回放监督，不作单分量因果占比解释。
