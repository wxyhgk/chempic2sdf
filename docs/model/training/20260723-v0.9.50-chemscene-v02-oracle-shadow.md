# v0.9.50 ChemScene v0.2 Oracle Chemistry Shadow

> 状态：ChemScene/SDF shadow GO，当前 Bond chemical type NO-GO  
> 模型：v0.9.49 best  
> 数据：固定 internal_test 前 100 张  
> OCR/原子化学状态：Oracle，仅用于隔离结构能力  
> 外部数据：未使用 USPTO 或 MR-TADF

## 目标

首次把 v0.9.49 选择出的 AtomObject、BondObject 和 incidence 编译成 ChemScene v0.2，
再实际生成 SDF 与渲染图。必须保存：

- 正确预测 SDF 和渲染；
- 错误但有效的 SDF 和渲染；
- 无效预测的诊断 SDF 和渲染；
- 原图、GT SDF、GT 渲染和预测 scene JSON。

当前 AtomObject 还没有开放字符串/OCR 输出，因此本轮明确使用 Oracle chemistry：模型只决定
对象集合、坐标、Bond incidence 和键型；匹配到 GT AtomObject 的元素、电荷、同位素、芳香性、
氢、手性和文字值由 GT 复制。未匹配的额外原子固定为普通隐式 C。

本轮结果不能写成端到端化学 OCR 准确率。

## 实现

- Shadow 与产物保存：`chemvector/shadow_chemscene_v02_oracle.py`；
- 输入：v0.9.49 frozen proposal cache + best set checkpoint；
- 全局阈值：Atom `-0.25`、Bond `-0.5`；
- 测试：`tests/chemvector/test_shadow_chemscene_v02_oracle.py`。

确定性编译规则：

1. Atom presence 过阈值后按量化 anchor 去重；
2. Bond endpoint incidence 必须指向两个已选 AtomObject；
3. self-bond 直接拒绝；
4. 同一 AtomObject pair 的多个 BondObject 只保留最高 presence；
5. 文字端口在所属 AtomObject bbox 内确定性裁剪；
6. 不使用键长删除、不使用最近邻附着；
7. 当前 direction/stereo 固定为 `NONE/STEREONONE`，主指标使用非立体 SDF graph match。

## 运行

```bash
  --samples 100 \

```

| ChemScene v0.2 valid | 100% |
| SDF valid | 56% |
| Atom count match | 42% |

对象集合阶段的 full object exact 为 24%，SDF 非立体 exact 为 30%。后者较高是因为确定性
编译会删除指向未选原子、自连接和重复 pair 的 BondObject；这是显式的一致性编译，不读取
GT 拓扑。

## 无效分析

44 个 invalid：

| 原因 | 数量 |
|---|---:|
| non-ring atom marked aromatic | 26 |
| kekulize 失败 | 12 |
| 显式价态失败 | 6 |

100 张中确定性删除：

- endpoint 指向未选 AtomObject：86 根；
- duplicate AtomObject pair：47 根；
- self-bond：5 根；
- duplicate quantized Atom anchor：0 个。

这说明当前第一化学瓶颈已经不是 OCR：即使使用 Oracle 原子化学状态，错误的 aromatic/
single/double Bond chemical type 仍会制造 non-ring aromatic、kekulize 和价态失败。
