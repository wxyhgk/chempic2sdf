## 固定阈值目标：区别于只看相对排序

实现：`tools/selector_threshold_contract.py`。
使用既定threshold `tau=-0.25`，只诊断原8个单候选节点：

```text
L = mean_node 0.5 * (
    softplus(tau - z_valid)
    + mean_owned_fragment softplus(z_fragment - tau)
)
```

这是按节点等权、节点内部正负类别等权的阈值平移BCE。
没有叠加rank/count/retention损失、没有搜索权重或重新接入原full loss。
它是一个局部判别诊断目标，不是完整分子图训练配方，也不是新颖损失的性能证明。

验收同时检查`z_valid >= tau`与全部`z_fragment < tau`；负例恰好等于阈值仍判为失败。
整体分数平移不再对目标完全不可见，但损失下降本身仍不保证有限步选择正确。
未知归属片段不监督，多候选节点直接拒绝，不恢复此前失败的exactly-one目标。

配对依据核对包括：唯一空间合格候选与原raw正标签一致，负候选不属于任何目标6px范围，
不在23个坐标敏感排除项内，767逆投影与保存值一致，字形或多重键外侧端头的归属证据一致。
**这不是人工语义复核或正式训练标签发布**；`training_authorized`保持false。
原39个替代正确候选及其他未聚焦节点均未被改成负标签。

四个历史阶段的直接logit导数都满足8个真点向上、25个片段向下，
但保存分数下同时满足真/伪选择条件的节点均为0/8。没有修改这些分数或生成新预测。

合成反例还验证：若真点和伪点的隐藏特征完全相同，虽然独立logit导数方向正确，
共享末层参数梯度仍可完全抵消，且任何共同分数都无法把二者放在阈值两边。
这正是不能把数学原型通过当作训练成功的原因。

计划固定58张既有训练/回放图，CPU两线程、总墙钟上限240秒、每图最多一次前向、零重试。
不读取64张开发图逐图产物或封存测试，也不新增身份查询。

只分析`set_head.atom_presence_residual.2.weight/bias`的128个权重和1个偏置。
末层输入与加性的`atom_pre`固定时，原子selector分数对这129个参数是精确仿射函数。
因此可用链式法则检查8节点联合方向，并解析求出是否存在同时修好真/伪选择、
保护58图原有正确候选的步长区间，无需实际更新权重或扫描学习率。
这不会代表整个178,565参数selector的能力，也不能替代连键/SDF验收。

执行前固定复现条件：候选slot/grid顺序完全一致，目标6px合格关系及筛选决策完全一致，
候选坐标误差不超过0.01px，selector分数误差不超过0.001。
实际在第一条候选slot/grid检查就退出，没有放宽这些条件继续执行。

## 停止状态与下一优先项

本次状态是`STOPPED_CANDIDATE_PARITY`，不是判别目标或共享参数方向的`NO_GO`。
预定58次前向实际完成1次，其余57次未执行；没有自动重试，也没有用旧slot强行套新候选。
worker退出在最终模型state摘要检查之前，故不声称该摘要已完成。
执行路径没有优化器、没有参数写入，所有模型参数在前向前已冻结。
独立复核已用保存的末层权重、输入和`atom_pre`重建CPU logits，最大误差约4.47e-7。

下一步优先处理**候选身份与同分选取的可复现约定**：

1. 在合成输入上为完全同分峰规定明确的grid次序；只处理真正相等的分数，
   不用epsilon改分数，也不悄悄合并近似同分项、调阈值或删除边缘候选。
2. 固定缓存必须包含实际raw/bond候选的索引、mask、几何和特征，而不只是最终分数。
   对比时先检查整个候选集合，再按grid身份解释；仅最终入选集合相同不足以复用中间监督。
3. 若约定会改变实际候选，必须建立单独的新基线并重核配对及旧图保护，
   不能当作历史initial数值复现，也不能覆盖本次失败记录。
4. 候选基线稳定后再回到固定阈值目标的共享参数检查。当前不继续129参数分析、不启动新GPU试训。

这个顺序解决的是实验可比性，不保证识别率提升，也不解释所有历史训练退步。
原8/7/6筛选缺口、10个raw缺口和旧图连键保护仍保持原定义。
