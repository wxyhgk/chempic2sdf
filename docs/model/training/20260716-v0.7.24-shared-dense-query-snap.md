# 2026-07-16 v0.7.24 共享 Dense 顶点吸附

## 目标

验证 v0.7.23 剩余顶点错误是否主要来自局部精定位，并在不增加第二套视觉主干、
不限制候选边长度的前提下，把 MolGrapher 式 stride-4 dense 峰作为 query 坐标的
局部证据。

## Ranking 零训练消融

使用 v0.7.23 最终 checkpoint，在 MolGrapher scaffold 独立 validation 1k 上只替换
排名 logits，不更新任何权重：

| 排名组成 | known-count 6px F1 | set-count 6px F1 |
|---|---:|---:|
| 冻结 ranking prior | 41.03% | 40.82% |
| local + context | 47.93% | 47.69% |
| ranking prior + local + context | **55.12%** | **54.79%** |

旧 prior 虽来自 refinement 前的 hidden，但仍提供有效全局语义；当前不能直接删除。
它应被表述为冻结旧 prior，而不是完全基于最终坐标的新 ranking head。

## Dense 吸附零训练实验

使用 v0.7.15 dense head，阈值 `0.2`。Atom Query 仍负责集合、计数与一对一选择，
dense head 只提供局部峰；`snap_queries_to_dense_candidates` 做 query 与峰的一对一匹配。
64px 只限制顶点坐标吸附范围，不参与边候选建立或删除。

MolGrapher validation 1k：

| 方案 | set-count 6px F1 | selection Oracle | coordinate Oracle | Oracle exact |
|---|---:|---:|---:|---:|
| v0.7.23 query | 54.79% | 55.12% | 65.39% | 1.8% |
| 当前 base 自带 dense head | 62.59% | 63.17% | 74.09% | 6.2% |
| 共享主干 + v0.7.15 dense head | 75.64% | 76.27% | 92.09% | 33.0% |
| 双主干机制上限 | 77.00% | 77.54% | 94.17% | 40.9% |

吸附半径 `16/32/64px` 的 set-count 6px F1 分别为 `71.99%/74.44%/77.00%`；
64px 在当前 768 输入上最好。固定半径尚未完成任意分辨率门控，因此只作为显式参数。

## 共享 Head 9k Pilot

固定 v0.7.23 的 query 视觉主干，只训练 92,678 个 dense head 参数；query、relation、
OCR 和视觉层全部冻结。训练集为 MolGrapher train 9k，单 seed、单 epoch：

```bash
.venv-train/bin/python -m chemvector.pretrain_vertex \
  --init-checkpoint outputs/checkpoints/chemvector-v0715-dense-unfreeze1-9k-45k/best.pt \
  --atom-query-checkpoint outputs/checkpoints/chemvector-v0723-independent-count-16k/best.pt \
  --train-shards 'Data/sdf/molgrapher_synthetic_v0_1/pilot_10k/shards/train-*.tar' \
  --validation-shards Data/sdf/molgrapher_synthetic_v0_1/pilot_10k/shards/validation-000000.tar \
  --output-dir outputs/checkpoints/chemvector-v0724-shared-dense-head-9k \
  --train-samples 9000 --epochs 1 --batch-size 8 \
  --learning-rate 2e-5 --weight-decay 0 --threshold 0.35
```

最佳 head 来自 4k 曝光。打包后的最终 query checkpoint：

```text
outputs/checkpoints/chemvector-v0724-shared-dense-snap/best.pt
SHA256 9fbc50c9db002558fd4dcc464c80d2f789ddde23cdff06076020afef4e8f48cd
```

打包只增加 92,678 个参数；dense head 与 query、relation 共享同一 stroke feature，
推理不增加第二套 backbone。

## 骨架评测

共享 dense snap 接入现有全点对 relation，在 MolGrapher validation 1k 上：

- vertex precision：74.37%；
- vertex recall：72.38%；
- edge threshold 0.30 时 precision/recall：49.38%/53.81%；
- edge threshold 0.60 时 precision/recall：54.41%/48.96%；
- skeleton exact：0。

同一固定 100 图、edge threshold 0.50 的无吸附/吸附 A/B：edge precision
`23.06%→52.63%`，edge recall `22.57%→54.46%`。坐标修正明显帮助 relation 读取
真实线条，但旧 relation 仍未适配新的检测顶点分布。

## 工程改动

- `evaluate_atom_query` 增加 ranking 组件消融和 dense top-k 吸附指标；
- query checkpoint 可内嵌 `dense_vertex_head`；
- `pack_atom_query_dense_head` 负责原子化打包；
- evaluator 可复用 query stroke feature，不重复运行视觉主干；
- skeleton evaluator 默认使用 set-count，并支持 packed shared dense head；
- vertex trainer 可加载 Atom Query 的视觉更新后只训练 dense head。

## 决策

- 冻结 ranking prior：保留；
- 共享 dense head 局部吸附：顶点组件 GO；
- 第二套 dense backbone：NO-GO，没有必要；
- v0.7.24 替换稳定端到端推理：NO-GO；
- 下一步：在吸附后的检测顶点上重训 relation，并单独提高 Count exact。

全流程仍对所有预测顶点点对读取真实线条，不使用最近邻边、估计键长、长键预删除
或固定边长阈值。
