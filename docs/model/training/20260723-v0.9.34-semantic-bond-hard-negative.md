# v0.9.34 Semantic Bond Hard Negative

## 目标

v0.9.33 在 sampled pair 上接近 99% F1，但 dense 全点对整图 exact 只有 70%/66%。本实验不增加
长键样本，而是让模型扫描训练图的全部 non-bond pair，选择自身分数最高的视觉误判作为 hard
negative。

选择协议：

- 所有 GT 键完整保留；
- 每张图枚举全部无序 GT Junction pair；
- hard negative 只按 v0.9.33 existence 视觉分数排序；
- 不读取键长，不按键长过滤或过采样；
- 每条正键最多配 1.5 条 hard non-bond。

## Pilot

- hard-negative mining：500 张训练图；
- 初始化：v0.9.33 best；
- 总曝光：10,000 张；
- dense gate：固定内部跨字体 100 张、全部点对。

结果：

| Dense relation set exact | v0.9.33 | v0.9.34 |
|---|---:|---:|
| Clean | 70% | 73% |
| Degraded | 66% | 73% |

固定阈值 0.5 下，clean FP 从 133 降到 42，degraded FP 从 117 降到 41。模型精度明显改善，
但 500 张唯一图续训一度损伤最长四分位召回，说明 hard-negative 方向成立、视觉覆盖仍不足。

## 决策

- 模型分数驱动 hard-negative mining：GO；
- 500 张 checkpoint 直接接整图：NO-GO；
- 下一步扩大唯一训练图数量，不改变目标、不增加长度规则。
