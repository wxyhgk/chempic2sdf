# v0.7.38 端点偏移稳健 Bond Object

## 问题

v0.7.37 把角色严格 vertex exact 提高到 56.02%，接入 v0.7.36 Bond Object 后
strict skeleton exact 达到 41.37%。但按 GT 键长分桶发现，`>96px` 长键在端点已
匹配的前提下 recall 只有 92.84%。

同一个 Bond Object、同一批 498 张的真实端点对照为：

```text
bond=0.80                  真实端点 recall   预测端点条件 recall   回退
<=48px                         99.88%              98.78%       1.11pp
48-96px                        99.78%              98.81%       0.97pp
>96px                          97.04%              92.84%       4.20pp
```

预测顶点误差实际很小：距离中位数 0.38px，P95 1.21px，P99 2.13px。问题不是顶点
严重错位，也不是长键被候选规则删除，而是 v0.7.36 只在精确 GT 端点上训练，宽线带
读取器对亚像素到 2px 的端点分布偏移过于敏感。

## 方法

从 v0.7.36 checkpoint 初始化，只改 Bond Object 训练输入：

```text
每个 GT 端点以 75% 概率加入二维高斯偏移
sigma = 0.5px
最大半径 = 3px
坐标限制在图片范围
键标签、全点对协议和模型结构不变
```

该增强来自通用 9k 训练集的 v0.7.37 预测误差分布，不使用 MR-TADF，不按键长或
键类型采样，也不增加长键专属规则。验证同时保留干净 GT 端点和固定随机种子的
jitter 端点两套指标。

训练命令：

```bash
.venv-train/bin/python -m chemvector.pretrain_node_conditioned_bond \
  --init-checkpoint outputs/checkpoints/chemvector-v0736-node-conditioned-bond-9k-45k/best.pt \
  --train-shards 'Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/train-*.tar' \
  --validation-shards Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/validation-000000.tar \
  --output-dir outputs/checkpoints/chemvector-v0738-node-conditioned-bond-jitter-9k-15k \
  --train-cache-samples 8974 --validation-samples 100 \
  --train-samples 15000 --epochs 2 --batch-size 4 --learning-rate 1e-4 \
  --validate-every 5000 --endpoint-jitter-sigma-pixels 0.5 \
  --endpoint-jitter-max-pixels 3.0 --endpoint-jitter-probability 0.75
```

## 结果

三个 checkpoint 均接入同一个 v0.7.37 Group selector，在完整 498 张 validation 上
做端到端扫描。平衡严格骨架和长键后选择 15k checkpoint、`bond=0.80`：

| 指标 | v0.7.37 Bond 基线 | v0.7.38 jitter | 变化 |
|---|---:|---:|---:|
| Role-aware vertex exact | 56.02% | 56.02% | 0 |
| Edge F1 | 94.97% | 95.46% | +0.49pp |
| 匹配端点条件 Edge recall | 98.60% | 99.56% | +0.96pp |
| Strict skeleton exact | 41.37% | 51.00% | +9.64pp |
| DOUBLE edge recall | 93.24% | 94.03% | +0.79pp |
| TRIPLE edge recall | 35.00% | 35.00% | 0 |
| `>96px` 端点条件 recall | 92.84% | 96.08% | +3.24pp |
| 真实端点 skeleton exact | 77.11% | 77.31% | +0.20pp |
| 真实端点 `>96px` recall | 97.04% | 97.19% | +0.15pp |

15k checkpoint 在阈值 0.90 的 strict skeleton exact 为 51.20%，但长键端点条件
recall 降到 94.21%。因此 shadow 协议选择 0.80，不为了额外 0.20pp 整图 exact
牺牲 1.87pp 长键召回。

## 决策

- 按真实误差分布做端点 jitter：GO；
- strict skeleton exact `41.37% -> 51.00%`：GO；
- 长键端点条件 recall `92.84% -> 96.08%`：GO；
- 干净真实端点无回退：通过；
- shadow 键阈值：`0.80`；
- 不引入键长删除、最近邻截断或长键专属采样；
- 下一步处理环级芳香/Kekule 表示和剩余假边，不继续单独增加 jitter 强度；
- 稳定推理仍为 v0.7.10，不打 tag、不自动替换默认模型。
