## 已有预测能支持的线索

只读比较完整预测 SDF，不额外运行 GPU。以下统计描述错误现象，不是具体模型头的因果归因。

| 最后一步改错的 111 图：互斥首要观察 | 图数 |
| --- | ---: |
| 原子数相同，但元素/电荷/同位素的组成计数不同 | 65 |
| 输出无效 | 29 |
| 原子数减少 | 10 |
| 原子组成计数相同，但键数不同 | 4 |
| 其他连接/键变化 | 2 |
| 原子数增加 | 1 |

65 张组成变化的图中，**50 张在忽略原子属性与立体信息、保留键级后，预测图仍与真值同构**。因此主要回归现象并非都能解释为“漏了很多原子或线”。第 600 步也有相同信号：88 个改错中 51 个原子数相同但组成变了，其中 35 个保留无原子属性的键级图。

第 600 步常见组成差量包括 N 少 1/C 多 1（13 图）、S 少 1/C 多 1（5 图）、O 少 1/C 多 1（4 图）。这是分子整体计数差，不冒称已经定位到了某一个原子的替换。另有 10 图的元素总数相同而电荷/同位素组成不同。

OCR 转写权重本身冻结，但 atom 候选、文字角色判断、文字框预测会改变 OCR 收到的区域和字符附着位置；角色或裁框漂移是值得优先验证的假设。仅凭同构和计数还不能区分 atom 锚点、role、bbox、OCR 裁剪、化学编译/fallback 的贡献，也不能保证几何坐标正确。
