## 文字兼容候选的结果

新增隔离模块 `chemvector/components/ocr/display_label_candidate.py`，不接入默认调用链。
它只接受字符串，不接受真值图、像素归属或化学身份作为解码输入。
支持明确的 H 前置和电荷前置语法，保留元素/电荷/同位素/氢数/自由基字段；不把字符串中
出现字母 H 当作“附着氢”，因此 H、He、Hf、Hg、Ho、Hs 的元素符号不会产生虚假的附着氢。

基于前轮已审计 12,239 张图的全部 40,789 个可见标签，仅作正确字符串接口比较：

| 指标 | 默认解析器 | 候选解析器 |
| --- | ---: | ---: |
| 能解析的标签实例 | 36,183 | **40,781** |
| 不接受／有歧义 | 4,606 | **8** |

新增支持七类，共 **4,598** 次：H2N 947、HN 880、HO 2,532、N+H2 4、H2N+ 4、H3N+ 71、HS 160。
`H215N` 和 `H18O` 各 4 次继续拒绝。上下标压平后氢数与同位素数字不能可靠分开，
不能借助真值身份猜测，也不能通过任意改字序提高通过率。

已解析结果的元素、电荷、同位素、自由基检查为 0 差异；11,757 次正的可见氢声明
与图中总 H 对照为 0 差异。没有可见 H 不等于总 H 为 0，此种隐式 H 语义未在接口检查中证明。
本批原先能解析的标签，候选解析字段全部保持一致。

这是正确字符串兼容性，不是 OCR 识别准确率或端到端图准确率；未检验真实错误 OCR 的
误接受风险，未在默认装配链路重编译分子图。因此当前保持候选模块，不自动替换默认解析器。
