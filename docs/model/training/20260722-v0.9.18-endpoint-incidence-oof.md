# v0.9.18 Endpoint-Incidence Safe Residual OOF

> 状态：正式 3-fold OOF 已完成，结论为 `FIT-OOF-ENDPOINT-SAFE-RESIDUAL-NO-GO`。
> v0.9.18 P0 candidate-pool oracle 已通过，但 learned endpoint scorer 未达到每折 cross=0。
> 本轮永久禁止读取 v0.9.17 dev900、原 calibration、fresh、sealed、internal test 和 MR-TADF。

## 目标

v0.9.17 的 scorer 只看 21D pair token 和全图 mean/max，不知道哪些 candidate 共享端点。
本轮保持 frozen candidate、raw gain、`tau0=0.7209501005709171` 和 production matching 不变，
只加入 endpoint-incidence context，并用“所有 negative 必须低于 production threshold”的充分
安全条件训练。

本轮只做 fit7200 的 3-fold component-disjoint OOF。OOF 通过前不申请 fresh holdout，也不接入
生产；生产继续保持 v0.7.10。

## 冻结输入字段

每条 pair：

```text
21D pair token = 20D normalized descriptor + frozen raw gain
pair_indices = 两个 canonical endpoint index
```

每张图另含四个 frozen count features。sidecar 还保存 fit-only evaluation target 的五个 anchor
字段，用于 OOF production matching。pair label、target line、group type 不进入 forward。

`pair_indices` 只用于构建 incidence；anchor ID 的数值本身不得拼入网络。

## 固定模型

共享 pair encoder：

```text
21 -> Linear(24) -> GELU -> Linear(12) -> GELU
```

全图 context 沿用 encoded pair 的 mean/max，加四个 count features，共 28D。

对每个 endpoint 聚合所有 incident pair：

```text
12D mean(other incident encoded pairs)
12D max(all incident encoded pairs)
1D  log1p(other incident pair count)
= 25D endpoint context
```

没有其他 incident pair 时 other mean/count 为 0。两个 endpoint 的 25D context 使用
`mean(u,v)` 和 `abs(u-v)` 组成 50D 对称表示。residual head：

```text
[pair token 21, global context 28, endpoint context 50] = 99D
99 -> Linear(48) -> GELU -> Linear(24) -> GELU -> Linear(1)
```

参数量固定为：

```text
pair encoder 828
residual head 99*48+48 + 48*24+24 + 24*1+1 = 6,001
total = 6,829
```

最后一层 weight/bias 全零，step 0 严格等于 frozen baseline。residual 不裁剪；forward 必须对
pair order、endpoint order 和 anchor ID 重编号保持等变/不变契约。

## 固定安全 Loss

定义：

```text
r_p = residual[p]
m_p = raw_gain[p] + r_p - tau0
positive margin = 0.25
negative safety margin = 0.25
ranking margin = 0.50
```

每张图独立计算：

```text
L_pos   = mean(relu(0.25 - m_pos)^2)
L_neg   = mean(relu(m_neg + 0.25)^2)
L_worst = relu(max(m_neg) + 0.25)^2
L_up    = mean(relu(r_neg)^2)
L_rank  = mean(relu(0.50 + m_neg - m_pos)^2)
          over positive/negative pairs sharing endpoint
L_res   = mean(r_p^2)

L = L_pos + 2*L_neg + 8*L_worst + 2*L_up + 0.25*L_rank + 0.01*L_res
```

缺少某类 pair 时对应项为 0；每图先求均值，再跨 batch 求均值。`L_worst` 是 production 安全的
直接充分条件：若每张图全部 negative margin `<0`，maximum-weight matching 不可能选择 cross。
禁止使用 v0.9.17 dev 指标、旧 residual checkpoint、matching 离散输出或任何 holdout 反传。

checkpoint 前必须对本折 4,800 train 图完成 finite audit；checkpoint SHA 封存后才加载 OOF fold。

## OOF 门禁

每一折单独要求：

| 指标 | 门槛 |
| --- | ---: |
| images | 2,400 / 2,400 |
| selected cross-target pairs | 0 |
| selected pair precision | >=99.9% |
| multiplicity-2 recall | >=99.5% |
| pairable sample exact | >=95% |
| parallel-2 preservation | 100% |
| ordinary support loss | <=0.1pp |
| matching optimal | 2,400 / 2,400 |
| permutation deterministic | 100% |

合并 7,200 张 OOF 后必须再次满足相同指标，并且结构 tuple 严格优于同图 frozen baseline：

```text
K = (-cross, -parallel_violation, m2_matched, pairable_exact,
     -support_lost, precision)
```

全部通过为 `FIT-OOF-ENDPOINT-SAFE-RESIDUAL-GO`；任一折失败即为 NO-GO。GO 后才允许在全部
fit7200 上从零训练 final model，并申请全新且与所有既有暴露隔离的 `fresh_dev2`。

## 正式结果（2026-07-22）

| 指标 | frozen baseline | endpoint OOF |
| --- | ---: | ---: |
| selected cross-target pairs | 33 | 31 |
| selected pair precision | 99.98941% | 99.99012% |
| multiplicity-2 recall | 99.55087% | 99.71458% |
| pairable sample exact | 94.58255% | 97.18841% |
| parallel-2 violations | 2 | 1 |
| ordinary support lost | 31 | 30 |
| matching optimal | 7,200 / 7,200 | 7,200 / 7,200 |

三个 fold 均未通过零 cross 门禁：

| fold | cross | M2 recall | pairable exact | introduced cross samples |
| --- | ---: | ---: | ---: | ---: |
| 0 | 14 | 99.70118% | 97.27085% | 8 |
| 1 | 11 | 99.66986% | 96.46516% | 3 |
| 2 | 6 | 99.77114% | 97.83394% | 0 |

aggregate 结构 tuple 比 baseline 更好，净增加 495 个 M2 matched target 和 152 张 pairable exact，
但 `cross=31` 远未达到 0，且仍有一个 parallel-2 violation，因此正式状态为 NO-GO。

训练侧 safety loss 基本能够收敛：fold0 的 4,800 张 train 图全部 negative margin `<0`；fold1/2
分别只剩 1 / 9 张 train 图存在过阈值 negative。对应 OOF 却分别有 15 / 14 / 12 张不安全图，
说明主要剩余问题是跨 component 的稀有负样本泛化，而非 `L_worst` 完全不起作用。

OOF 共有 44 个 negative 被模型打到 threshold 以上，其中 31 个最终被 matching 选择。31 个
selected cross 中：

- 24 个来自 stress variant；
- 12 个原 raw gain 不高于 `tau0`，由 residual 新抬过门槛；
- 24 个没有任何共享 endpoint 的 positive candidate，endpoint-incidence ranking/context 无法提供
  正竞争证据；大量样本两端 degree 都为 1。

因此 endpoint incidence 解决了部分候选竞争，但不能区分“孤立真实 pair”和“孤立高分假 pair”。
当前 21D token 仅含角度、距离、区间重叠、墨迹统计和 decoded-line consistency，没有 candidate
周围的局部 raster。下一路线必须先在 fit-only 条件下加入来自完整 PNG 的规范化 pair crop；不能
只加训练步数、扩大 MLP 或对相同 hard negative 重放后直接申请 fresh holdout。
