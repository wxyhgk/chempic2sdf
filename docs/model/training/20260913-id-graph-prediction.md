# 冻结模型输出接入 ID 图：200 样本实跑

## 已完成

冻结 v0.10.3 Direct AtomPair 与原 R0 原子选择器，复用原 `atom_conditioned` OCR 字符串，
在 RTX 5090 上以原 CUDA BF16、batch size 6 完成同一批 200 张开发图推理。
没有训练，没有接入新 OCR，没有修改生产流程，也没有重跑旧失败的 8 路实验。

| 本轮检查 | 数量 |
|---|---:|
| 原子选择 ID 和归一化位置精确复现原 R0 | 200/200 |
| 新适配器保留全部候选 ID、像素坐标、阈值后键及类型 | 200/200 |

这是新的**无修补编译基线**，不是旧生产链的准确率：
不按坐标去重，不执行芳香修补、结构双胞胎删除、环融合或编译失败后的全碳回退。
仍明确保留原推断策略：未提供或无法解析文字的节点初始为碳；四面体和双键立体信息未预测。
默认碳与“失败后全碳回退”是不同步骤，后者本轮始终关闭。

104 次严格编译失败：60 次价态异常，27 次非环原子芳香性异常，17 次 Kekulé 化失败。
无效图仍完整保存并计入 200 的分母，没有删除、替换或重试失败图片。

## 已能看见的问题及解释边界

预测节点 7,444 个，真值节点 7,560 个；6 px 几何门限下匹配 7,326 对。
234 个真值节点未匹配、118 个预测节点未匹配，涉及 74 张和 64 张图片。
**未匹配同时包含漏检/多检和定位偏差，不能直接等同于漏原子/多原子。**

32 张存在半径内匹配歧义；属性与局部键比较只使用两侧均唯一的 7,291 对节点。
这些图片仍正常参加完整 SDF 评分。明确匹配上的基础属性差异为 75 个元素、19 个电荷，
涉及 54 张图片。显式氢数、no_implicit 和芳香标志另记为表示差异，不直接判化学错误。
原 OCR 共 2,097 个成功解析记录、4 个无法解析记录；5,343 个节点无文字记录而采用碳默认值。
“可解析”不意味着文字或元素正确，不能据此认定 OCR 已解决。

明确匹配端点之间：缺失键 54 条、额外键 44 条、原始键类别不一致 380 条。
另有 242 条预测键和 468 条真值键因端点无法明确匹配而不进入局部键比较。
这些数字不可相加或直接与原子错误数比较，不能充当因果瓶颈排名。

### 重要：原始键标签不同，不一定是化学结构错

冻结报告沿用字段名 `wrong_bond_types`，其实际定义只是原始类别不一致。
事后只读核对发现：**29 张非立体分子图完全正确的图片，仍存在共 78 条原始键类别差异**。
完整图评分已通过 RDKit 规范化，不会将这些差异算作分子图错误。
因此不能把局部 380 条差异都称作“错误化学键”，也不能据此直接决定重训键头。

差异主要与芳香表示有关：真值芳香 → 预测单键 251 条、单键 → 芳香 67 条、
双键 → 芳香 32 条、芳香 → 双键 23 条；其余 7 条为单/双/三键之间差异。
这要求下一步区分等价芳香/Kekulé 表达与真正不合法或不正确的整图。

事后分组核对中，78 张图片满足所有节点完整且无几何歧义、元素/电荷/同位素/自由基一致；
其中 61 张 SDF 有效、53 张非立体图正确。此条件**不包含氢数、芳香性或立体信息正确**，
不能把剩余 25 张直接归咎于键模型，但它说明仅对齐节点集合及基础属性不足以保证整图正确。

## 实现与可复用输出

`chemvector/experiments/id_graph_prediction/`：

- `adapter.py`：纯记录 → ID 图，独立校验候选及连边保真，保存原 OCR 与默认值来源。
- `runtime.py`：冻结协议、模型和输入哈希，运行冻结模型，先落盘预测及 receipt。
- `scoring.py`：只在预测完成后读真值；几何匹配、局部比较、严格 SDF 编译评分。
- `__main__.py`：串联执行并保存报告。

结果根目录：`outputs/experiments/id-graph-prediction-20260913/`。
`raw/` 保存全部选中原子、所有原子对的 presence/chemical logits 和原始 OCR；
`graphs/` 保存 200 个语义图，`sdf/` 保存 96 个有效结果；
`samples.jsonl` 保留逐样本分数及编译错误，`prediction_receipt.json` 记录精确复现与权重不变。
后续对现有节点的属性/键替换可直接复用这些预测，不必反复调用网络。

## 下一步建议

先推进**化学表示一致性和整图控制实验**，暂不启动 MoE/循环深度的新训练：

1. 复用已保存预测，在新协议下分别替换基础/完整原子化学属性与真键，保持节点集合不动；
   明确记录匹配歧义及不可用端点，比较有效 SDF 和规范化整图的 rescue/harm。
2. 对芳香类别差异区分“规范化后等价”与“真实错误”，避免将表示选择当成学习目标失败。
3. 若补全真原子集合的 A 轴，需要重新采样冻结视觉特征并运行后续头；不能通过修改已存键
   记录假装完成该干预。原 8 路实验仍未执行，不输出架构优劣排名。

本轮提供了真实预测基线和可复用记录；尚未证明应改变模型架构，也未证明外部 OCR 无效。
