# v0.9.10 Pair Matching 评估与阈值协议

> 状态：评估接口和 train-cal threshold 枚举完成；未读取 validation

## 评估边界

评估模块不训练 scorer，也不实现第二套 matching。每个 pair 的模型输出先转换为：

```text
relative_gain = pair_logit - gain_threshold
singleton_gain = 0
```

随后调用 `solve_evidence_carrier_pair_matching`。只有严格大于 0 的 pair gain 可以替代两个
singleton。

单样本评估报告：

- selected same-target / cross-target pair 数量和 precision；
- multiplicity-2 target recall；
- parallel-2 两个物理成员的 distinct preservation；
- ordinary target support loss，单位为百分点；
- pairable sample exact；
- matching latency、optimal 状态和候选排列确定性。

`pairable sample exact` 不做空集真值：样本必须至少包含一个 multiplicity-2 target，所有
multi-anchor targets 必须恰好是 multiplicity-2，且对应 pair 已在 target-free candidate pool
中，才进入 exact 分母。

support loss 使用保守身份协议：singleton 和 same-target pair 保留对应 ordinary target；
cross-target pair 本身不代表任一 target。若同一 target 仍有其他 singleton，其 support 仍保留。

Group metadata 支持两种等价输入：

- 完整生成 target：优先读取 `raw_keep_labels/raw_target_line_ids/raw_group_ids/raw_group_types`，
  并用 `anchor_source_indices` 做严格回溯校验；
- compact train cache：在 raw 字段缺失时读取逐 anchor 的
  `anchor_group_ids/anchor_group_types`。

两种路径最终都构造相同的 supported-target protocol。若 raw 字段只出现一部分，或同一
target 的逐 anchor group metadata 不一致，评估立即报错。

## Calibration Threshold

阈值只来自 train calibration logits。普通候选阈值是：

```text
nextafter(unique_calibration_score, +inf)
```

因此等于 source score 的 pair 会得到负 gain，而 singleton 始终保持 0。

此外强制加入：

```text
nextafter(global_min_calibration_score, -inf)
```

这个 lower-bound 保证 calibration 只有一个正 pair，或正确 pair 恰好位于全局最低 score
时，仍存在使它获得正 gain 的阈值。它在 trace 中使用独立 rule 标记，并计入 threshold
候选预算。

还强制加入 `0.0`，并在相邻的已选 calibration source score 之间加入算术中点。原因是
matching 最大化的是 `sum(pair_logit - threshold)`：threshold 不只改变单条 pair 的正负，
也会改变不同配对数量之间的整体偏好。只检查 score 边界可能漏掉区间内部的安全匹配。

这里仍是有上限的候选搜索，不是数学完备的 parametric matching。trace 和 protocol 明确
记录 `bounded_candidate_search=true`、
`mathematically_complete_parametric_matching_search=false`；完整临界点求解留作独立任务。

选择顺序固定为：

1. `selected_cross_target_pairs == 0`；
2. `parallel_2_violated_group_count == 0`；
3. 最大化 multiplicity-2 matched count；
4. 最大化 pairable sample exact count；
5. 仅在上述指标完全相同时，最小化 support loss 并偏向更高阈值。

若限制 `max_threshold_candidates`，候选集合仍强制保留：

- 全局最小和最大 score；
- `nextafter(global_min, -inf)` lower-bound；
- 固定阈值 `0.0`；
- 0 两侧最近的 calibration score；
- 所有 distinct-target negative 中的最大 score；
- 相邻已选 source score 的区间中点；
- 预算允许时的 negative score 和全局 score 分位点。

预算小于必保留边界数量时直接报错，不允许静默丢失保证 `cross=0` 的关键阈值。
