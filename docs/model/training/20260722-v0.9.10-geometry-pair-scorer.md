# v0.9.10 Geometry Pair Scorer

> 状态：全量 train-cal 完成；A 组正式 NO-GO；未读取 validation

## 目的

v0.9.9 已确认 LSD 经常把一条有宽度的物理线检测成两条边界。硬阈值配对虽然能覆盖
`99%+` 的 multiplicity-2 target，但会把相邻双键成员或拥挤结构中的独立线误合并。

本实验只回答一个条件问题：在 router 已正确给出 positive ordinary anchors 的前提下，固定
8 维局部几何/墨迹特征能否为 pair 相对两个 singleton 产生可靠 gain。

```text
positive ordinary LSD anchors
-> target-free training_wide pair candidates
-> 833 parameter geometry MLP
-> pair gain relative to singleton gain 0
-> deterministic maximum-weight disjoint matching
```

## Threshold 0 诊断

原始 head bias 定义的 threshold 0 能保留几乎全部正确配对：

| metric | threshold 0 |
|---|---:|
| selected pair precision | 99.9764% |
| selected cross-target | 9 |
| multiplicity-2 recall | 99.9289% |
| pairable sample exact | 99.4602% |
| ordinary support loss | 0.00795pp |
| parallel-2 direct violation | 1 |

这说明 A 组不是普通意义上的欠拟合，而是存在小量高风险不可分样本。9 个 selected cross 中
8 个来自 `stress`、1 个来自 `original`；7/9 的两个端点都没有 same-target positive pair
competitor，9/9 至少一端没有 competitor，因此现有 shared-anchor ranking 对它们没有直接
监督。对 9 个错误做 fit 最近邻审计，它们在标准化 8 维空间中全部更接近 positive，而不是
fit negative。继续提高共享 ranking 权重不能补回缺失的视觉上下文。

## 校准协议说明

Matching 优化的是 `sum(score - threshold)`，threshold 同时改变 pair 数量，因此最优分区可在
相邻 score 之间变化。校准器已补入固定 `0.0`、全局 lower bound 和相邻候选 score midpoint，
并明确标记为 bounded candidate search，不宣称数学上完备的 parametric matching。本次真实
数据粗审计在 `4.55..4.90` 仍有 1 个 cross，直到 `4.90726757` 才首次为 0，因此上述 A 组
NO-GO 结论不依赖漏掉某个明显安全的低阈值区间。

## 决策

按预注册路线进入 B 组，不扩大 A 组 MLP：

```text
frozen P0 carrier feature hi, hj
+ 8D geometry
-> [hi + hj, |hi - hj|, hi * hj, geometry]
-> small symmetric pair scorer
```

同时加入冻结 P0 decoded centerline 的一致性特征。同一物理线的两侧边界应解码到相近
centerline；两个独立 target 即使局部平行，也通常会解码到不同中心线。这是当前 8 维聚合
特征没有表达的证据。
