## 设计边界

代码位于 `chemvector/experiments/id_graph/`：

- `graph.py`：原生 ChemMol → `semantic-id-graph-0.1` → RDKit 分子 → V3000 SDF。
- `roundtrip.py`：固定样本、冻结协议、输入校验、独立评分及结果保存。

语义图包含原子 ID、元素、电荷、同位素、氢数、自由基、芳香性以及 ID 引用的键。
四面体立体标签绑定显式邻居 ID 顺序，构图时根据置换奇偶性调整；双键立体信息包含
两侧参照原子 ID，并从语义 E/Z 推导 RDKit 邻键方向，防止去氢清理时丢失立体信息。
不读取 Render 中的楔线方向来补化学语义。

像素位置存于独立 `observations` 字段，允许多个原子位置重合，编译器不消费该字段。
写出 SDF 时重新生成二维排版；它不是输入图片的几何复刻，也不会改动保存的像素观测。
原型仅支持当前声明的化学元素、单/双/三/芳香键与四面体及双键立体类型；
不支持的类型报错，不声称覆盖所有配位化学、非四面体立体或 SDF 元数据。

原生 ChemMol 适配器要求源 ID 稠密，并依赖源键 ID 所定义的插入顺序恢复手性参照。
语义图自身允许稀疏和任意重命名的 ID。未来接模型输出时必须显式提供邻居顺序，
不能把原始 CW/CCW 标签脱离参照顺序直接复制。

## 对训练方向意味着什么

现在有了一条在这批真值控制上通过的、身份不依赖坐标的诊断编译链。
**200/200 是编译保真结果，不是图像识别准确率，也不证明 MoE 或循环深度有效/无效。**
同位对象能被图结构保存，不代表它们能从图片中可靠辨认。

下一步应建立新的版本化端到端诊断：将冻结模型输出适配为 ID 图，先验证预测适配本身的
节点/键保真，再比较原子集合、化学属性、键连接三个真值替换轴及其组合。
坐标只用于明确的几何匹配，不能作为节点主键；重合候选的匹配歧义必须单独计数。
新实验需明确预测缺失字段的处理和与旧基线的编译差异，不能静默重跑旧 8 路实验。
待有完整图错误归因后，再决定优先改结构预测、外部 OCR 接入还是迭代修正；本轮不新开架构训练。
