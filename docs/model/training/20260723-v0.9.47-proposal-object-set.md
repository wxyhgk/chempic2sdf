# v0.9.47 Atom/Bond Proposal 集合选择

> 状态：容量 GO，train100 泛化不足  
> 训练：固定 ChemVision train 100  
> 验证：独立 ChemVision validation 100  
> 外部数据：未使用 USPTO 或 MR-TADF

## 目标

在 v0.9.46 的 target-independent Atom/Bond proposal 上联合训练：

- AtomObject presence；
- BondObject presence；
- endpoint-to-AtomObject incidence；
- incidence 支撑的 Atom/Bond 集合一致性。

推理不读取真实对象数量，不用键长阈值删边，也不执行最近邻附着。每图固定最多 128 个
Atom proposal 和 128 个 Bond proposal，presence logit 决定最终保留集合。

## 实现

- 联合集合头与损失：`chemvector/proposal_object_set.py`；
- 训练与严格整图评测：`chemvector/train_proposal_object_set.py`；
- 全局阈值审计：`chemvector/audit_proposal_object_set_thresholds.py`；
- 测试：`tests/chemvector/test_proposal_object_set.py`、
  `tests/chemvector/test_train_proposal_object_set.py`。

模型先从 Atom token 预测初始 presence；incidence 分布与 Atom 可信度共同进入 Bond
presence；被选 Bond 的 endpoint 支撑再反向聚合到 Atom，产生一次集合级 Atom 修正。

损失由候选 focal presence、图内最弱正例/最强负例 ranking、软计数和 incidence 组成。
计数只作为训练监督，不在推理时提供真实 count。

## 训练

v0.9.46 best incidence 作为 warm start，视觉、Atom proposal 和 Bond proposal 全冻结。
联合头共 178,565 参数。

```bash
.venv-train/bin/python -m chemvector.train_proposal_object_set \
  --output-dir outputs/checkpoints/chemvector-v0947-proposal-object-set-train100-val100-step1200 \
  --train-samples 100 \
  --validation-samples 100 \
  --max-steps 1200 \
  --batch-size 4
```

## 阈值审计

只在内部 validation 扫描全局 logit 阈值，不使用每图 count。最佳阈值为：

- Atom：`-2.5`，deployed exact 13%；
- Bond：`0.0`，deployed exact 34%；
- 联合 full object exact：8%。

阈值校准可将 full exact 从 4% 提到 8%，但远低于 proposal coverage 和 incidence 上限。
因此主要问题不是固定 `0.5` 概率阈值，而是 train100 的候选排序泛化不足。

审计输出：
`outputs/diagnostics/chemvector-v0947-proposal-object-set-thresholds/validation100.json`。

## 决策

- 联合 presence + incidence 表示：容量 GO；
- train100 checkpoint：部署 NO-GO；
- 继续在相同 100 图增加 step：停止；
- 下一步：保持架构与 validation 不变，将唯一训练图扩大到 1000，验证是否为数据覆盖问题。
