# 2026-07-15 v0.7.6 顶点召回与定位 pilot

> 状态：GO，当前最佳开发候选  
> 基础 checkpoint：`outputs/checkpoints/chemvector-v075-pilot-multiscale-balanced-jitter-1500/checkpoint-0000500.pt`  
> 最佳 checkpoint：`outputs/checkpoints/chemvector-v076-vertex-pilot-head-lr1e4-9k/best.pt`  
> SHA256：`dada9fae4d2cb1ec03d1284fdcd4bd50e260c7a89bc76095107c56b3dfb23174`

## 目标

v0.7.5 在 MR-TADF 上有 358 个错误，其中 255 个主要来自顶点检测或定位。250 个
顶点主错误样本的预测原子数与真值不一致；149 个样本恰好少 1 个原子。

本实验先判断固定 `vertex_threshold=0.3` 是否造成系统性漏检，再使用现有 9,000
张 ChemVision train 图片训练 vertex head。OCR、relation 和 repair 保持不变。

## 数据

- train：9,000 张，3 个字体家族。
- validation：500 张，训练未见字体家族。
- internal_test：500 张，训练和 validation 均未见字体家族。
- MR-TADF：只在候选确定后运行一次完整外部门控，不用于阈值或 checkpoint 选择。
- 暂不生成 72 万张全量语义层。

## 第一阶段：阈值扫描

固定模型参数，在 validation 和 internal_test 上扫描：

```text
0.15 / 0.20 / 0.25 / 0.30 / 0.35
```

主要指标为 vertex recall、precision、F1 和每图原子数 MAE。优先减少漏原子，但
不能用大量重复文字峰换取表面 recall。

扫描结果：

| split | threshold | precision | recall | F1 | count MAE |
|---|---:|---:|---:|---:|---:|
| validation | 0.25 | 88.29% | 97.90% | 92.85% | 3.781 |
| validation | 0.30 | 91.49% | 96.66% | 94.00% | 2.382 |
| validation | 0.35 | 93.54% | 94.73% | 94.13% | 1.853 |
| internal_test | 0.25 | 88.94% | 97.68% | 93.10% | 3.268 |
| internal_test | 0.30 | 91.81% | 96.25% | 93.98% | 2.132 |
| internal_test | 0.35 | 94.12% | 94.23% | 94.17% | 1.830 |

`0.15–0.25` 通过大量假顶点换取 recall，不能解决端到端问题。`0.35` 的 F1 和
count MAE 最好，但 recall 明显下降，可能加重 MR-TADF 已观察到的漏原子。当前
保持 `0.3` 作为 head-only 训练基线，训练后重新扫描阈值。

产物：

```text

```

## 第二阶段：head-only 训练

- 只训练 `vertex_head`。
- 共享视觉编码器、Pixel OCR、stroke/relation 和 decoder 全冻结。
- 使用 combined 原图和 Render JSON 精确原子中心。
- 先使用现有单通道 heatmap、offset 和 aromatic 目标，不同时修改 loss 或架构。

首次使用学习率 `3e-4` 跑 9,000 张时，前 8,000 张 loss 正常下降，但约 8,800 张
后出现 NaN，最终 checkpoint 被污染。失败产物保留在：

```text
outputs/checkpoints/chemvector-v076-vertex-pilot-head-9k/
```

该次运行同时暴露旧训练器只保存最终 checkpoint、无法回退到中途最佳点的问题。
训练器已增加定期验证、分段 checkpoint、`best.pt` 和非有限 loss 立即终止。重跑
使用学习率 `1e-4`，每 250 step 验证并保存一次。

成功训练命令：

```bash
.venv-train/bin/python -m chemvector.pretrain_vertex \
  --init-checkpoint \
    outputs/checkpoints/chemvector-v075-pilot-multiscale-balanced-jitter-1500/checkpoint-0000500.pt \
  --train-shards \
    'Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/train-*.tar' \
  --validation-shards \
    Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/validation-000000.tar \
    Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/internal_test-000000.tar \
  --output-dir outputs/checkpoints/chemvector-v076-vertex-pilot-head-lr1e4-9k \
  --train-samples 9000 --batch-size 8 --workers 0 \
  --learning-rate 1e-4 --validate-every 250 \
  --validation-batches 125 --threshold 0.3 \
  --tolerance-pixels 6 --seed 20260715
```

最佳点出现在 1,000 step。只有 92,548 个参数可训练，最终只有 10 个
`vertex_head.*` tensor 与 v0.7.5 不同，其余模型 tensor 逐位相同。

训练后的内部结果：

| split | threshold | precision | recall | F1 | count MAE |
|---|---:|---:|---:|---:|---:|
| validation | 0.30 | 93.24% | 97.20% | 95.18% | 2.028 |
| validation | 0.35 | 95.16% | 95.66% | 95.41% | 1.695 |
| internal_test | 0.30 | 93.80% | 97.05% | 95.40% | 1.718 |
| internal_test | 0.35 | 95.62% | 95.16% | 95.39% | 1.564 |

MR-TADF 已经以漏原子为主，因此外部门控保持 threshold `0.3`，不为降低内部
count MAE 而牺牲 recall。

## 门控标准

- 内部未见字体集 vertex recall 提升，precision 不显著下降。
- 原子数 MAE 下降。
- MR-TADF 原子数一致率从 76.00% 提升到至少 85%。
- MR-TADF 化学完全一致率从 67.45% 提升到至少 72%。
- 有效 SDF 不低于 89.73%。
- OCR、三个键长难度桶和交叉错连不能明显退化。

## 后续分支

如果 head-only 训练不能通过门控，再进入双通道 vertex head：分别预测隐式碳/线条
交点和可见文字原子中心，避免大号 `N/B` 多笔画形成多个顶点峰。

## 决策

接受 v0.7.6 为当前最佳开发候选。原子数一致率未达到预设 85%，但化学完全一致、
有效率和三个难度桶均超过门槛，且推理速度不变。

下一步先分析 45 个回归样本和剩余 191 个顶点错误，区分可见文字峰与隐式碳峰。
在此之前不生成 72 万全量数据，也不直接进入双通道架构。
