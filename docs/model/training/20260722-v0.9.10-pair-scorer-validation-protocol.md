# v0.9.10 Pair Scorer 显式 Validation 协议

> 状态：脚本与合成测试完成；真实 validation 尚未运行

公开 validation 与 train-cal 完全分离。入口只接受冻结的 `best.pt`，从 checkpoint 读取：

- model state 和 train-fit normalization；
- `gain_threshold`；
- train cache 路径和 SHA256；
- `training_wide` pairing config；
- train-cal GO gate。

脚本没有 threshold calibration 参数，也不导入 calibration 函数。validation shard 使用
`render_variant=None`，在一次数据流迭代中对每张图恰好执行一次：

```text
raster -> training_wide target -> frozen scorer -> frozen threshold
       -> deterministic matching -> metrics
```

循环结束后，使用 validation identity 与冻结 train cache 的 fit+calibration identity 做
molecule/source 双轴零重叠检查。不会重新打开 validation 数据做第二轮调参或 checkpoint
选择。

输出 `validation.json` 包含：

- checkpoint SHA256、cache SHA256 和冻结 threshold；
- 500 个 validation identity；
- train-cache/validation zero-overlap 审计；
- same/cross、multiplicity-2、parallel-2、support loss、sample exact；
- matching latency p50/p95/max 和 permutation determinism；
- 正式 GO/NO-GO gate 和逐样本评估记录。

正式命令：

```bash
.venv-train/bin/python -m chemvector.evaluate_evidence_carrier_pair_scorer \
  --checkpoint outputs/checkpoints/<run>/best.pt \
  --validation-shards Data/sdf/visual_svg_v0_1/pilot_10k/shards/validation-000000.tar \
  --output outputs/evaluations/<run>/validation.json
```

默认 `--limit=500`。`internal_test` 路径、非 `best.pt`、cache SHA 不一致、非
`training_wide` checkpoint、identity overlap 或样本数不足都会在发布结果前失败。
