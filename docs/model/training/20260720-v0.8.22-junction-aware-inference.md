# v0.8.22 Junction-Aware 正式推理接入

> 状态：骨架与有效率 GO，端到端化学能力仍 NO-GO  
> 日期：2026-07-20

## 目标

把 v0.8.21 的无 GT Bond selector 和 v0.8.20 视觉 Endpoint Grouper 接入真实图片到
ChemScene/SDF 推理，而不是继续使用训练缓存中的候选对象。

正式链路：

```text
768 图片
-> top-128 Dense Bond candidates
-> detector hidden + 完整 line-band + endpoint visual context
-> keep threshold 0.90
-> 仅在选中 Bond 上做视觉 endpoint grouping
-> OCR 标签附着
-> type-only graph corrector
-> ChemScene
-> 有效或诊断 SDF
```

## 实现边界

- 新增独立 `junction_aware_bonds` Junction source；
- `vertex` 和 `bond_endpoints` 旧路径保持不变；
- 单图上传遇到无效价态时返回 exit 0，同时保存 ChemScene 与 invalid diagnostic SDF；
- selector 全拒绝时不强制保留假键，写零原子 diagnostic SDF；
- 前端新增 `development-v0822` 实验 profile；
- 稳定默认仍是 v0.7.10。

## Internal Validation 498

固定数据导出：

```text
Data/benchmarks/internal_chemvision_v1/
```

图片为 validation 原始 768 PNG，真值由同一 ChemMol/Render/Layers 编译为 SDF。
该目录不得用于训练、阈值或 checkpoint 选择。

### 与 v0.8.16 同口径比较

| 指标 | v0.8.16 | v0.8.22 | 变化 |
|---|---:|---:|---:|
| Scene valid | 100.00% | 98.19% | -1.81pp |
| SDF valid | 49.60% | 52.41% | +2.81pp |
| Junction count | 72.49% | 75.50% | +3.01pp |
| Junction exact 6px | 66.67% | 68.67% | +2.00pp |
| Bond count | 70.68% | 74.30% | +3.62pp |
| 非立体结构一致 | 20.68% | 22.09% | +1.41pp |
| 完整化学一致 | 12.45% | 13.05% | +0.60pp |
| 匹配文字元素准确率 | 87.35% | 88.04% | +0.69pp |
| 平均推理时间 | 92.6ms | 104.1ms | +11.5ms |

Scene valid 回退来自 9 张图上 selector 明确拒绝全部候选。这些样本现在保存零原子
diagnostic SDF，不被伪装成有效预测。

### 失败构成

- 有效 SDF：261/498；
- 完整正确 SDF：65；
- 有效但错误 SDF：196；
- invalid diagnostic SDF：237；
- 价态失败：168，v0.8.16 为 193；
- 其他编译失败：69，其中 9 个为空集合 abstention。

所有 498 个样本都有预测或诊断 SDF 文件，可以在 benchmark 前端左右查看。

## 结论

Junction-aware selector 的骨架提升真实进入了端到端链路，Junction、Bond count、SDF
valid 和结构一致性均提高，因此接入方向 GO。

但完整化学一致只提高 0.60pp。大量错误日志为 O/N/B/F 等元素落在不可能价态，以及
芳香键集合无法 Kekulize。下一阶段不应继续调整骨架阈值，应固定 v0.8.22 骨架，单独
训练或约束 OCR 元素与 Bond chemical type。
