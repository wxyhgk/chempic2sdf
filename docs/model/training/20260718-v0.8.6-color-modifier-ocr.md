# v0.8.6 彩色修饰符 OCR

> 状态：OCR 组件 GO，端到端接入 NO-GO  
> 初始化：`chemvector-v078-ocr-adapter-role-1000/best.pt`  
> 输出：`outputs/checkpoints/chemvector-v086-ocr-modifier-color-500`

## 目标

解决普通 `N` 被识别成 `NH/N+` 的后缀幻觉，同时覆盖彩色原子文字。只训练 29,044
个 OCR adapter/role 参数，视觉、顶点和键分支冻结。

## 数据与增强

- `chemvision_layers_v0_2/font_pilot_10k` train/validation。
- 困难组优先采样：`N/NH/NH2/N+`、`O/OH/O-`、`B/B-/BH` 等。
- 50% 原始黑白，50% 按 bbox 做 CPK 文字着色：N 蓝、O 红、卤素绿、B 粉。
- validation 按字号和 `_bw/_color` 分桶。

## 结果

| 指标 | v0.7.8 | v0.8.6 |
|---|---:|---:|
| 可见字符串 exact | 85.62% | 89.16% |
| small color | 64.94% | 78.82% |
| normal color | 90.08% | 92.61% |
| N | 89.62% | 94.58% |
| NH | 88.05% | 97.61% |
| N+ | 52.38% | 59.52% |
| NH2 | 70.00% | 76.67% |

PP-OCRv5 mobile 的同一 100 图 pilot 只有 13.20% exact，修饰字符串低于 4.2%，
因此通用 OCR 直接替换 NO-GO。OCR common-label 硬路由也只有 50.40% 可见 exact，
同样 NO-GO。

## 真实图门控

在包含四个蓝色普通 N 的真实上传图片上：

- v0.8.5：`NH/N+/N+/NH`；
- v0.8.6：`NH/N+/N+/N+`。

虽然内部 crop 指标提高，但真实图未改善，不能替换部署 OCR。价态修复可以删除明显
不可能的显式 H，却不能安全删除可能真实存在的正负电荷。

## 决策

保留颜色增强、modifier 采样协议和 checkpoint；端到端接入 NO-GO。下一步数据必须
覆盖论文图的真实彩色字体、抗锯齿和键线邻接风格，并使用真实困难 crop 独立门控。
