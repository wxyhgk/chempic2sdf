# v0.8.23 无效价态结构化原子解码

> 状态：确定性修复 GO；未训练新权重  
> 日期：2026-07-21

## 目标

v0.8.22 已能稳定生成 Junction 和 BondObject，但大量结果因 O、N、B、F 等文字原子
落在不可能价态而无法写出有效 SDF。v0.8.23 保持 ChemScene 拓扑不变，只在 RDKit
sanitize 失败时搜索 OCR 候选原子状态。

约束如下：

- 有效 ChemScene 不做任何修改；
- 只修改文字原子的元素、电荷和显式氢状态；
- 候选来自 shifted/anchor CTC top-k；
- 每张图最多搜索 128 个组合，最多修改 4 个文字原子；
- 修复前后 Junction 和 BondObject 结构签名必须一致；
- MR-TADF 不参与搜索参数、阈值或 checkpoint 选择。

## 结论

结构化原子解码证明：相当一部分 invalid 并非骨架缺失，而是 OCR 原子状态与局部价态
冲突。该修复显著提高 SDF valid 和完整一致率，因此作为实验推理能力保留。

它没有提升 Bond candidate、Junction 或 OCR 视觉能力，也不能修复“有效但结构错误”的
分子，所以不应写成新模型权重或骨架精度提升。
