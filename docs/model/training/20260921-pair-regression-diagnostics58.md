# 键头首轮回退诊断：负例没有漏训，平均损失掩盖了局部假边

## 结论

本轮完成固定58图的保存结果诊断，没有加载模型checkpoint、重新推理或训练。
原试训仍为 **NO-GO / stop_regression**，默认initial、原验收条件和历史文件均不变。

最重要的进展是排除了两种具体解释：新增的两条确认假边并非未被采样的负例，
对保存logits重算原presence BCE时，其直接梯度也没有写反。
但保存数据不足以证明究竟是哪次参数更新使它们升高，不能据此宣布发现优化器错误
或已经证明了多任务梯度冲突。

## 1. 诊断范围与可复现性

- 固定26张基础见证 + 32张旧完整分子，均为训练/回放数据，不是独立测试准确率。
- 读取58张图的initial与50步保存预测，共17,328个候选pair。
- 50张实际更新图，按原日志恢复976个已采样正例、5,496个已采样负例。
- 只对上述同一批采样行，在初始和最终logits上各计算一次BCE及直接logit梯度：
  共100次保存logit求导，**不是100次模型反向或参数更新**。
- 标签恢复只适用于SHA绑定的单图采样器：正例前缀、负例后缀。
  没有采样的行不由本诊断擅自标为负例或unknown。
- 历史阈值0.85不变；MolBlock坐标通过原q1023坐标及candidate lineage精确关联。
  不采用近邻猜测；坐标碰撞、歧义和缺失编译结果不当作结构相同。

## 2. 平均损失下降，不等于完整结构安全

在每张实际更新图当时采样的同一批pair上，将初始/最终logits代入原BCE，
按图等权平均得到 **0.111464 → 0.009752**。50张中48张下降、2张上升。
这不是历史逐步训练loss曲线，也不包括chemical loss。

尤其值得注意的是 `curr_08d02946e879406f__font_large`：

- 该图采样BCE **0.489391 → 0.057465**，明显下降。
- 同时一条确认非边的概率 **0.069670 → 0.963315**。
- 整图从可编译变为碳价态超限，不能输出有效SDF。

因此，问题不只是“某张差图被其他图的收益平均掉”：即使同一张图的平均pair损失改善，
一条高置信度假边也足以破坏整个分子。后续不能只依靠平均loss判断训练是否成功。

全部58图在固定阈值下新增33条原始预测边、删除0条；按原指标差分，新增包括
23条已知真边、2条确认假边、8条未知对应边。未知对应不能直接算成假边。
17,328个presence logit中11,830个上升、5,498个下降，中位变化约+0.07192；
这个分布本身不能证明所有负例都系统性上升。

完整SDF正确数仍为19→21，旧19张正确图均保留；有效SDF为53→52。
38张初末规范化结构相同，其中也包含一直错误的结构，不能将38解释为正确数。

## 3. 两条假边的负监督方向确实正确

以下pair槽位仅标识本次历史保存结果，不能带入下一次候选集合。

| 样本（省略curr_） | 历史pair / 行号 | 本图更新步 | 存在概率：初始→最终 | 最终负例直接logit梯度 |
| --- | --- | ---: | --- | ---: |
| 4ef506af64e8f0b8__bond_short | (15,18) / 512 | 44 | 0.351084 → 0.950123 | +0.00301626 |
| 08d02946e879406f__font_large | (4,6) / 59 | 47 | 0.069670 → 0.963315 | +0.00982974 |

两行都位于各自真实采样日志的负例后缀。负例BCE对该logit的导数为 `p / N > 0`，
若只对这个独立logit做梯度下降，方向就是降低分数。

实际优化的却是共享参数，不是每个pair各自独立的logit；正例、其他负例、chemical loss、
其他图的更新和Adam状态均可能影响同一输出。上述方向核验不能恢复这些历史作用。

旧试训只保存初始/50步逐边分数、逐步聚合loss、采样行号和最终pair delta，
没有逐步探针、冻结特征张量或中间Adam状态。
日志中的“本图更新前loss”也只是整体平均值，不能反推出该条假边当时的分数。

## 4. 四个历史告警不是四次同样的最终结构破坏

| 样本（省略curr_） | 保存结果支持的分层解释 |
| --- | --- |
| 420203be8470416f__line_thick | pair(3,31)原始AROMATIC→SINGLE，连接未消失；编译后仍为AROMATIC，最终分子相同。原结构本来就不正确，不能算修好。 |
| cb5b7da426023d14__font_large | pair(11,37)的原始类型改变，但scene和编译后该边均一直是SINGLE；同时整图确实新增fallback、最终结构改变。这不能只解释成该边被删。 |
| 4ef506af64e8f0b8__bond_short | 新增确认假边，且原先已无法编译；两次都无MolBlock不算结构相同，更不是本轮新增的一次有效SDF损失。 |
| 08d02946e879406f__font_large | 新增确认假边，并实际丢失原先有效的SDF，是明确的化学有效性回退。 |

新诊断逐边同时记录raw、scene-before-fallback、sanitized MolBlock三层结果；
即使raw/scene未变，仅编译结果改变，也保留在变化记录中。
这种分层只用于解释，**不追溯放宽原来的原始类型键保护门槛**。

## 5. 已补上的下一轮观察能力

新增独立模块 `chemvector/training/curriculum/pair_negative_observer.py`，
默认未接入任何历史训练入口。它支持：

1. 在下一轮新建冻结缓存后，通过GT目标ID重新解析当前候选，确认探针确实是已知非边。
   两个目标分别是4ef样本的(31,34)、08d样本的(7,14)，不复用旧槽位。
2. 在eval / no-grad下只观察pair head，不执行优化器更新、不修改标签。
3. 将同一探针每次更新前后的logit、更新步号、更新样本一起记录，
   区分“本图更新时升高”和“其他图更新时升高”。
4. 校验缓存哈希及绑定关系；禁止将unknown或正例误用作负例探针。

探针是训练侧诊断，目标ID不作为推理输入或新的监督标签；观察到某一步升高也不能
直接证明是该步的某个loss分量导致。该模块目前只通过合成CPU测试，未在真实模型上运行。

新增31项合成测试；与原相关249项回归一起执行，**280 passed / 2.87秒**。
覆盖原始键型与最终图分离、编译层独立变化、缺失图不判等、负例采样恢复、
梯度方向、未采样行零梯度、缓存/探针篡改拒绝以及本图/其他图更新标记。

## 6. 后续优先级

优先取得两条假边的逐步轨迹，再决定是否修改采样、损失或共享参数范围。
下一次若授权极短试训，应从原initial出发，在固定58图、固定阈值和原保护条件下
接入观察器，不同时更换模型、扩大数据和修改目标，否则难以判断原因。

这不等于推荐退回“只训练presence最后一层”：历史257参数读出试验已在完整分子回归中
出现167→141的严格正确数下降，不能把已失败的方案当成未尝试过的安全方案。
