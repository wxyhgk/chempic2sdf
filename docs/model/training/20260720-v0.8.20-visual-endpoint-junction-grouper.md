# v0.8.20 方向对齐视觉 Endpoint Grouper

> 状态：容量与泛化 GO  
> 日期：2026-07-20

## 目标

在每条语义 Bond 始终只有两个 endpoint 的前提下，判断不同 Bond 的 endpoint 是否
属于同一 Junction。模型不能读取 GT atom ID、GT Junction 坐标、MR-TADF 或 USPTO
信息。

## 方法

每个 endpoint 从原始 768 图像裁取 32x32 墨迹 patch，并把所属 Bond 的出射方向旋转
到图像右侧。这样 CNN 可以用统一坐标系读取：

- 中心右侧的入射键；
- 中心左侧是否继续有墨迹，即终止或穿越证据；
- 双键、三键的平行线仍属于同一个 Bond Object，不产生额外 endpoint。

共享小 CNN 编码两个 endpoint patch，pair head 输入两个 embedding 的和、绝对差、
乘积以及 v0.8.19 的 15 维几何特征。GT atom ID 只生成 same-Junction 二分类标签。

## 协议

- Train：500 张。
- Validation：498 张，冻结验收。
- Pair：139,346，正样本 25,968。
- Epoch：20。
- 解码参数只在 train 500 上选择。
- 最佳解码：complete-link，threshold 0.70。
- GO 门槛：validation topology exact 必须超过固定半径 75.30%。

训练命令：

```bash
.venv-train/bin/python -m chemvector.pretrain_visual_endpoint_junction_grouper
```

## 结果

| 指标 | 纯几何 v0.8.19 | 视觉 v0.8.20 |
|---|---:|---:|
| Validation Node F1 | 98.25% | 98.27% |
| Validation Vertex exact | 75.90% | 78.11% |
| Validation Topology exact | 75.70% | 77.91% |

相对固定 12px 半径提高 2.61pp，相对纯几何提高 2.21pp。额外 pair 审计得到：

- pair precision：98.33%；
- pair recall：99.61%；
- pair F1：98.96%；
- Junction 分区整图 exact：85.74%。

结果表明方向对齐的终止/穿越视觉是有效信息，且 500 张已经能在独立 validation 上
泛化。它不是依赖 MR-TADF 风格的专项修补。

## 数值稳定性复核

实验中发现 `torch.cdist` 会把完全相同的大坐标 endpoint 算出约 0.35px 距离，导致
0.25px 审计重聚合错误拆点。已在 `bond_endpoint_junction.py` 改用稳定差分距离，并
复算 v0.8.18、v0.8.19、v0.8.20。固定 12px 基线仍为 75.30%。

## 决策

- 方向对齐视觉 Endpoint Grouper：GO。
- 不扩成独立 9k grouper 训练；下一步应将其冻结接入 top-128 Bond keep/drop selector，
  联合验证候选数量控制和 Junction decode。
- 稳定默认仍保持 v0.7.10，不替换正式推理 profile。
