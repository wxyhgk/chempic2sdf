> 状态：联合解码 GO

> 最终门控：locked internal_test 100

## 目标

替换“Atom 全局阈值、Bond 全局阈值、incidence argmax、再删无效边”的独立链路。一次联合决定：

- 哪些 AtomObject 存在；
- 哪些 BondObject 存在；
- 每根 BondObject 的两个 endpoint 指向哪些 AtomObject。

该求解器不读取键长、GT、OCR、元素、价态或环化学，不新增或删除图像 proposal。

## 约束

1. 每个 Bond proposal 最多选择一对 endpoint；
2. 被 Bond 引用的 Atom 必须被选择；
3. 同一无序 Atom pair 最多一个语义 BondObject；
4. 被选择的 Atom 必须至少参与一根 Bond；
5. self-bond 不进入候选；
6. 双键、三键仍各自为一个 BondObject；
7. endpoint 只在 learned incidence 的 top-2 内选择。

目标函数使用 threshold-centered Atom/Bond presence logit，并加入相对最佳 endpoint assignment
的 incidence log-probability。使用 SciPy HiGHS MILP 确定性求解。

配对结果：

- 非立体 exact 新增 5、回退 0；
- Chemical exact 新增 5、回退 0；

- MILP valid 新增 1、损失 3；3 个无效结果严格回退独立解码后，最终 valid 为 83%。

RDKit sanitize 失败时触发，3 个 fallback 样本原本都不是正确结构，因此不改变 exact 配对结论。
