# v0.8.29 Proposal-conditioned Bond Group Query

> 状态：表示与训练协议保留；泛化 checkpoint NO-GO  
> 日期：2026-07-21  
> 基础 checkpoint：`chemvector-v082-multiscale-joint-9k-1epoch/best.pt`  
> 稳定推理：仍为 v0.7.10，本实验未接入默认推理

## 目标

验证“每根化学键是一个完整 BondObject”能否替代固定空间 cell 内的多 slot 表示。核心
假设是：一根单键、双键或三键都只有两个语义端点，模型应对整根键做集合预测，而不是
把平行笔画端点当成四个或六个顶点。

本轮只回答 Bond query 表示是否可训练、是否能从 collision 训练集泛化到分子隔离的
collision holdout。它不训练 OCR，也不以 MR-TADF 或 USPTO 选择阈值和 checkpoint。

## 模型

Dense BondObject 先提供最多 128 个候选。每个候选建立三个 token：

```text
BondObject token + endpoint A token + endpoint B token
```

三个 token 共享候选的视觉特征、置信度、基础端点和键型信息，并通过两层 Transformer
decoder 读取全局视觉 memory。配置为 `d_model=192`、6 heads、FFN 768，Group Query
分支共 1,423,023 个参数。

模型预测对基础候选的残差：

- BondObject token：presence、display type、chemical type；
- endpoint token：二维端点修正；
- direction：保持基础候选输出，不参与本轮损失；
- 所有输出头最后一层零初始化，保证 step 0 与基础 Dense Bond 完全一致。

匹配使用整根键的无序端点代价，不使用置信度参与 Hungarian assignment。实现和测试还
约束 proposal 置换等变、单根键端点交换等变，避免重新引入固定 slot 身份。

## 数据与协议

数据来自 ChemVision Layers pilot train 前 8,974 张图片。固定 split 中有 569 张
collision 图片、565 个分子：

| 子集 | 图片数 | 说明 |
|---|---:|---|
| Collision train | 400 | occupancy 2 为 376 张，occupancy 3 为 24 张 |
| Collision holdout | 100 | occupancy 2 为 94 张，occupancy 3 为 6 张 |
| Ordinary replay | 400 | 保护普通候选几何 |
| Ordinary validation | 498 | 独立 validation split |

Collision train、ordinary replay 与 holdout 的分子重叠均为 0。所有 v0.8.29-v0.8.32
正式实验复用同一 split，SHA256 为：

```text
1ff119a6306ffaaf2415bbbc508f2f7164aa83035c2f6f7951f0b9a3db0b1687
```

正式泛化配置：batch size 8、学习率 `1e-4`、weight decay 0、端点残差尺度 0.1、
collision bond 权重 16、阈值 0.25、随机种子 20260721。视觉编码器和 Dense BondObject
均冻结。

容量实验使用 100 张 collision train，每张曝光 20 次。泛化实验混合 400 张 collision
和 400 张 ordinary replay；matched20 对照将每张曝光增至 20 次，共 16,000 exposure，
用于排除“只是训练步数不足”。

## 门控标准

泛化 checkpoint 必须同时满足：

- holdout secondary geometry recall 至少 50%；
- holdout collision cell geometry exact 至少 18%；
- ordinary known-object accuracy 相对 step 0 回退不超过 0.5pp；
- protected geometry retention 至少 95%；
- count、presence、display、chemical、direction 等非几何输出保持不变。

## 结果

Geometry-only 容量实验表明 Group Query 有拟合能力，但无法迁移到未见分子：

| 实验 | Collision cell exact | Secondary recall | Collision bond recall |
|---|---:|---:|---:|
| Capacity 100，step 0 | 2.97% | 18.40% | 15.49% |
| Capacity 100，固定初始匹配，2k | 34.65% | 56.80% | 53.10% |
| Capacity 100，动态匹配，2k | 30.69% | 46.40% | 49.12% |
| Molecule-isolated holdout，step 0 | 1.00% | 16.04% | 11.17% |
| Generalization 8k，最佳 | 3.00% | 19.81% | 15.05% |
| Generalization matched20，最佳 | 2.00% | 13.21% | 9.71% |
| Generalization matched20，最终 | 1.00% | 7.55% | 7.77% |

matched20 最佳点出现在 6,400 exposure，继续训练到 16,000 exposure 后 holdout 继续
下降。因此问题不是曝光不足。最佳 matched20 checkpoint 的 ordinary known-object
accuracy 为 70.61%，ordinary protected retention 为 99.62%，非几何不变量审计通过；
它保护了旧输出，却没有学到可泛化的端点修正。

全局 Group Query 能记住容量集，说明 loss、匹配和残差头可以工作；但每个 endpoint
token 只得到候选描述和较粗的全局 memory，没有直接读取端点附近的局部笔画。这个归纳
偏置不足与“训练集明显改善、隔离 holdout 不改善”的结果一致。

## 已否决配置

- Joint capacity objective：训练后 secondary recall 降到 7.20%，后续统一改为
  geometry-only；
- 纯动态 assignment：容量结果低于固定初始 assignment；
- matched20 长训练：未改善 holdout，反而出现更明显的训练/泛化分离；
- 当前全局 Group Query checkpoint：不接入稳定推理。

## 决策

- 完整 BondObject、三 token group、无序端点匹配和零步一致性：GO，作为后续实验底座；
- v0.8.29 的全局视觉路径：NO-GO；
- 下一步给每个基础端点显式采样局部视觉 patch，并比较“全模型训练”与“只训练局部
  残差”，确认问题是否确实来自局部证据缺失；
- 稳定默认继续保持 v0.7.10。
