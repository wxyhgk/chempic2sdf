# v0.10.2 Slow Bond Joint 10k

## 目标

从 v0.10.1 已适配 set/incidence 的 checkpoint 热启动，将 v0.10.0 的 Bond 学习率从 `1e-6`
降低到 `1e-7`，验证单纯的两时间尺度优化是否足以在不破坏 set 边界的前提下学习 Bond。

## 协议

- 源 checkpoint：`chemvector-v0101-set-first-style10k/selected.pt`；
- vision、Atom 冻结；
- Bond、set/incidence 联合训练；
- 训练 10,000 张，style/ChemVision/expanded-font 为 6,668/1,666/1,666；
- 其他学习率、loss、fresh probe 和旧域 regression 均与前两轮一致；
- 完整 fresh-dev baseline 重新计算；
- sealed-test 未读取。

## 决策

正式 NO-GO，不切换前端、不解封 sealed-test。

将 Bond 步长缩小十倍只能减轻崩溃，不能解决 Bond 输出分布与 set 决策边界失配。继续搜索
`5e-8`、`2e-8` 等学习率没有足够信息增益。下一步必须显式约束 set 实际消费的 Bond 输出：

- `heatmap_logits`，决定 proposal score 与 top-k；
- `object_features`，直接进入 set head；
- `endpoints` 与 display/chemical logits，决定 geometry/type 输入。

约束应以冻结的 v0.10.1 Bond 作为 teacher，并与 dense GT loss 同时优化；是否值得训练需先做
action/reachability 审计，确认在限制漂移的条件下仍存在可改善的 proposal。
