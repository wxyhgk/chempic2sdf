# 50 步逐步诊断：假键主要在其他图片更新时抬升，本图负监督只能小幅纠正

## 结论

用户回复“可以试试看”后，按讨论的固定条件完成一次真实诊断：**50 次 pair 更新、单卡
19.990 秒**，没有追加试验或部署。模型、数据、顺序、损失和阈值不变，只增加观察、有限快照
及一次不执行 optimizer.step 的局部梯度分析。

这次确实取得了此前没有的证据：两条已知假键在各自图片的更新中都略有下降；其他图片
更新带来的累计上升远大于这点纠正。它们在本图训练之前就已跨过预测阈值。
因此应优先验证跨样本的旧连接／非边保持，而不是继续追查“这两条负例没被采样或直接
BCE 梯度写反”。尚未证明特定 loss 分量、优化器或课程顺序是唯一根因。

本轮是故障复现，不是修复试训。指标完全复现原失败，默认仍为 initial。

## 1. 两条假键何时变坏

以下概率都来自同一新运行的单行探针；与完整 pair 读出的最大差异仅 1.431e-6，
小于事前固定的 atol=1e-4 / rtol=1e-5。

| 探针样本 | 初始概率 | 首次超过 0.85 | 本图更新前 → 后 | 最终概率 |
| --- | ---: | ---: | ---: | ---: |
| `curr_4ef506af64e8f0b8__bond_short`，目标 (31,34) | 35.1084% | 第 29 步 | 第 44 步：95.7616% → 95.6300% | 95.0123% |
| `curr_08d02946e879406f__font_large`，目标 (7,14) | 6.9670% | 第 32 步 | 第 47 步：96.5019% → 96.4425% | 96.3315% |

两条负例在本图更新时都被实际采样。分数往正确方向下降，但幅度不足以回到阈值以下。
候选通过本轮冻结缓存的 GT 匹配重新绑定，未复用历史候选槽位。

为使逐步变化能相加，累计使用 logit 而非概率：

| 探针 | 本图更新 Δlogit | 其他图片更新合计 Δlogit | 总变化 |
| --- | ---: | ---: | ---: |
| 4ef / Bridge | -0.03194 | +3.59324 | +3.56131 |
| 08d / NH | -0.01745 | +5.87723 | +5.85978 |

这不是“只有基础小图影响完整分子”：按本次固定顺序，22 次基础见证更新分别贡献
+1.33138 / +1.96386；28 次完整分子更新分别贡献 +2.22993 / +3.89593。
分组数只是这次顺序下观测变化的合计，不是对课程顺序的独立因果消融。

## 2. 第 21 步：最大单步抬升的具体证据

两探针最大的正跃迁都发生在第 21 步，当时更新的是
`selector_retention_new16:curr_f96989bdeccab353__reference`，目标 `C[18OH]`。
该图采样只有一条正键，没有确认非边；它并非错误数据或应当删除的数据。

- Bridge 假键 logit 增加 0.226933。
- NH 假键 logit 增加 0.341096，概率 21.6306% → 27.9643%。
- 真正跨阈值发生在更晚的第 29 / 32 步，不能把第 21 步称为唯一致错步骤。

按事前选择规则，只对 NH 的第 21 步做一次局部分析：在独立 pair 副本恢复保存的更新前
权重、冻结输入和采样行，重算正例 presence、负例 presence、chemical 三个损失分量；
没有反事实优化器更新或第二条训练轨迹。

| 分量 | 当步 loss | 对探针的局部负梯度方向投影 |
| --- | ---: | ---: |
| presence 正例 | 1.865001 | +3443.838391 |
| presence 负例 | 0 | 0 |
| chemical | 0.011041 | +25.903756 |

投影是无学习率、无 Adam 预条件的无穷小 SGD 方向：正数表示该方向会局部抬高探针分数。
**这些数不是可相加的 Adam 因果贡献，更不能按占比归因。**
总梯度裁剪系数约 0.012050，保存的裁剪后梯度与分量重算最大差异 1.211e-8。
把实际 Adam 参数增量投影到探针梯度上，预测 logit 变化 0.340805；实际为 0.341096，
一阶残差 0.000291。

这提供了“学习当前正连接可以抬高其他图非边”的局部机制证据，不支持把 chemical loss
直接定为主因。Adam 的历史状态、裁剪和多个步骤的累计仍然存在。

## 5. 下一项修复应验证什么

优先准备一个**跨样本确认非边的回放／保护项**，让更新当前图片时也保留其他已学图的

阈值与原整图验收。需要事先明确回放选取、独立权重、预算和初始对照，再确认新试验。

保护权重增强；不能在同一次试验同时调学习率、chemical 权重、课程顺序和采样比例。

本轮到此结束，不自动开修复试训。课程学习方向仍可保留，但“持续回放已学能力”需要
落实到更新过程，而不能只依赖训练末尾检查发现已经退步。
