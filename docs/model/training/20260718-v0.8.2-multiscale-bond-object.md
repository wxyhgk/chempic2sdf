# v0.8.2 多尺度空间 BondObject

## 目标

在不改变 ChemScene 协议、不引入最近邻删边和键长阈值的前提下，为 v0.8.1 的
stride-4 空间 BondObject 增加 stride-8/16 上下文，重点改善长键、双键和整图计数。

## 数据与边界

- 训练：`chemvision_layers_v0_1/pilot_10k` 的 8,974 张 train 图片。
- 验证：同数据集 scaffold 独立的 498 张 validation 图片。
- MR-TADF、USPTO 均未用于训练、阈值选择或 GO 决策。
- 几何仍由中心、`cos 2θ/sin 2θ` 和半长度表示；每根多线键仍是一个 BondObject。

## 实现

`MultiScaleDenseBondObjectDetector` 将 stride-8 和 stride-16 特征经零初始化 adapter
上采样到 stride-4。初始化时输出与 v0.8.1 逐位一致，因此可以区分多尺度增益和随机
初始化扰动。

两轮 adapter-only 没有超过单尺度。随后从 adapter checkpoint 联合微调一轮，最佳
checkpoint 为：

```text
outputs/checkpoints/chemvector-v082-multiscale-joint-9k-1epoch/best.pt
```

## 结果

| 指标 | v0.8.1 单尺度 | v0.8.2 多尺度 |
|---|---:|---:|
| known object accuracy | 67.55% | 70.66% |
| known object exact | 3.01% | 4.62% |
| count accuracy | 54.42% | 58.84% |
| oracle-junction SDF exact | 2.61% | 4.42% |

分桶变化：

| 类别 | 单尺度 | 多尺度 |
|---|---:|---:|
| 96-160px 长键 | 36.31% | 54.03% |
| SINGLE | 77.77% | 84.18% |
| DOUBLE | 47.20% | 68.33% |
| AROMATIC | 49.12% | 25.03% |

上限审计显示几何 accuracy 为 93.52%、几何 exact 为 53.21%，而完整 object exact
只有 4.62%。约 22.86 个百分点的局部损失来自键型，不来自几何。

## 决策

多尺度几何 GO：SDF exact `2.61% -> 4.42%`，长键和双键显著改善。直接继续训练会
回退，事后拼接旧类型头和训练期冻结类型头也都只有 3.01%，因此这两条方案 NO-GO。
下一步固定 v0.8.2 的几何与计数，独立验证二维线带键型分类器。
