# v0.9.61 非线性联合势容量实验

> 状态：固定 100 图容量 GO  
> 初始化：v0.9.49 best  
> 数据：固定 train 前 100 图  
> 外部数据：未使用

## 目标

v0.9.60 证明五个全局线性势无法改变整图选择。本轮不新增大模型，直接微调现有 178,565 参数
ProposalObjectSetHead，使 Atom/Bond presence 与 incidence 的 proposal 级非线性分数适配
v0.9.58 MILP。该实验只回答“现有非线性头有没有容量”，不代表泛化。

## 训练

- 固定 train100，1,500 step；
- presence/incidence 学习率 `1e-4/1e-5`；
- best checkpoint 按 train100 full object exact 选择；
- 视觉、Atom proposal 和 Bond proposal 继续冻结。

## 结果

| 指标 | v0.9.49 + MILP | v0.9.61 + MILP |
|---|---:|---:|
| SDF valid | 90% | 93% |
| Atom count match | 66% | 81% |
| Bond count match | 74% | 78% |
| 非立体 exact | 61% | 70% |
| Chemical exact | 50% | 57% |

这 100 图中 Atom/Bond proposal 同时完整覆盖仅 76 图；v0.9.61 的 70 个非立体 exact 达到
可表达上限的 92.1%。配对非立体 exact 新增 10、回退 1，净增 9。

## 决策

- proposal 级非线性势容量：GO；
- train100 checkpoint 泛化部署：NO-GO；validation full object exact 仅 25%；
- 下一步不扩大模型，使用全 9k 的 representable hard-example replay。
