# v0.9.77 新 Proposal 上的多域 Set/Incidence

## 目标

验证 v0.9.76 新增的跨风格 proposal coverage 能否转化为完整 Atom/Bond/Incidence 结构。
本轮冻结共享视觉和 v0.9.76 的 Atom/Bond proposal，只训练完整 presence 与 incidence head。

## 初始化

- source：`chemvector-v0976-multidomain-proposals-balanced18k/samples-004500.pt`；
- presence 学习率：`5e-5`；
- incidence 学习率：`5e-6`；
- 三个训练域各 6,000 张，严格等量；
- 三个 validation 域各 498 张；
- 每 4,500 总样本验证一次。

MR-TADF 和 USPTO 不参与训练、阈值、checkpoint 选择或提前停止。

## 门控

第一个 4,500 检查点重点检查：

- MolGrapher full exact 必须明显高于 1%；
- ChemVision 不应显著低于 34.54%；
- full-v0 不应显著低于 40.76%；
- 若 proposal recall 提升但 full exact 仍无法恢复，说明当前 set/incidence 表示不能吸收跨域
  feature，需要改变接口或对 proposal feature 做稳定化，而不是继续扩量。

输出：

`outputs/checkpoints/chemvector-v0977-multidomain-set-after-proposals-balanced18k/`

## 结果

第一个 4,500 总样本检查点触发 NO-GO：

- 三个域 Bond deployed exact 均为 0；
- ChemVision/full-v0/MolGrapher 的 Bond recall 分别只有 69.06%/79.77%/29.61%；
- Atom presence 已能部分恢复，说明失败集中在 Bond feature 与旧 set head 的接口失配。

因此在 5,400 总样本处停止。v0.9.76 全量更新了 Bond feature extractor 和多尺度 adapter，
虽然提高了几何 proposal recall，却改变了下游依赖的 128 维 object feature。下一轮必须冻结
该特征路径，只训练 proposal 输出分支。
