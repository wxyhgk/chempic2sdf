# 2026-09-10：同源参考生成器 v0.2——接缝辅助层与立体键

## 已完成

新增 `Data/sdf/text_source_renderer/v2/`，不改动上一轮已冻结的 v0.1
代码、默认导出或输出。职责分为：

- `renderer.py`：绘图协调、源分子不变检查、化学连接与绘图方向分离。
- `junctions.py`：接缝辅助路径的严格几何证据。
- `svg_records.py`：复用 v0.1 文字／键校验，恢复最终节点索引并验证辅助归属。
- `layers.py`：同源光栅标签、独立辅助掩膜、重叠保留与覆盖验证。
- `smoke.py`：有限合成样例、独立进程和冻结运行回执。

本机 RDKit 2026.03.3 探针中，相关 classless 路径表现为连接同一原子
两条相邻键首段的三点折线。v0.2 只接受有唯一几何证据、符合此限定模式的
路径，不把所有 classless 路径猜成键。具体契约见包内 README。

辅助图形单独记录 anchor atom、两条相邻 bond、实际 SVG 节点与 bbox；
**不新增化学键或原子**。其与键重叠的像素同时保留两个掩膜的归属。
semantic PNG 改为 bitset：bond=1、text=2、auxiliary=4、bond+auxiliary=5。
这是新的数据契约，不能直接当作旧版互斥类别标签使用。

立体键的另一处问题也已处理：绘图准备会将某些键的起终点互换，以记录
楔形／虚线楔形方向。v0.2 允许同一 bond ID 的无向端点对保持不变时发生
绘图方向交换，但拒绝真正的连接关系变化；原化学字段与 `drawing` 分开。
芳香化学键仍记录为 AROMATIC，实际绘制的 SINGLE/DOUBLE 另存。
