# v0.8.27 GT Pair 等价组 Bond Selector

> 状态：监督协议 GO；9k checkpoint NO-GO  
> 日期：2026-07-21  
> 基础 checkpoint：`chemvector-v0821-junction-aware-bond-selector-9k/best.pt`

## 目标

验证 v0.8.21 的主要限制是否来自候选标签冲突：同一条 GT 键可能对应多个视觉
BondObject 候选，但旧损失只把几何最优候选标正，其余等价候选全部作为普通负样本。

本轮保持部署顺序不变：

```text
Top-128 Bond candidate
    -> candidate selector
    -> 固定阈值
    -> Visual Endpoint Grouper
    -> predicted Junction pair 投影
```

GT atom pair 只用于训练标签和离线诊断，不进入模型特征。

## 标签审计

| 指标 | Train 8,974 | Validation 498 |
|---|---:|---:|
| GT 键 | 322,216 | 18,328 |
| 可表示 GT 键 | 320,267，99.395% | 18,219，99.405% |
| 多候选正组 | 128,420 | 7,039 |
| 被旧损失当负样本的等价候选 | 236,164 | 13,207 |
| 整图 candidate oracle | 90.31% | 88.76% |

将 Endpoint Grouper 前移到全部 128 个候选后，validation 平均仍有 121.19 个 unique
predicted pair，一对一 candidate oracle 只有 65.06%，低于 v0.8.21 的 70.88%
topology。因此“先全候选 grouping、再 pair selector”直接 NO-GO。

## 实现

新增：

```text
chemvector/equivalence_bond_selector.py
chemvector/pretrain_equivalence_bond_selector.py
tests/chemvector/test_equivalence_bond_selector.py
```

训练 overlay 包含：

- `group_ids`：相同 GT atom pair 的候选属于同组；
- `group_targets`：该 pair 是否为真实键；
- `canonical_targets`：组内端点几何最可靠的代表；
- `representable_count`：候选池实际覆盖的 GT 键数；
- GT display/chemical 类型，仅供可选组级类型监督。

部署特征仍为 v0.8.21 的 363 维输入。base cache 中 GT nearest distance、Oracle
self-loop 和 group ID 均未拼入特征。

首个 normalized-logmeanexp MIL 会同时抬高同组多个候选。500 张训练 topology 虽从
74.8% 提到 77.2%，validation 却从 70.88% 回退到 69.48%，同组 extras 从 0.336
增加到 0.446/图，因此否决。

最终使用 winner-anchored 目标：

```text
positive = BCE(canonical_logit, 1)
negative = BCE(max(negative_group_logits), 0)
exclusivity = SmoothL1(sum(sigmoid(positive_group_logits)), 1)
```

不启用 representative CE、cardinality 和 global margin。固定沿用初始化 checkpoint
的阈值 `0.9`，禁止通过 validation 重新校准。

## 训练配置

容量实验：

```bash
.venv-train/bin/python -m chemvector.pretrain_equivalence_bond_selector
```

9k 泛化实验：

```bash
.venv-train/bin/python -m chemvector.pretrain_equivalence_bond_selector \
  --train-samples 8974 --validation-samples 498 \
  --epochs 10 --batch-size 16 --thresholds 0.90 \
  --output-dir outputs/checkpoints/chemvector-v0827-winner-anchored-bond-selector-9k
```

- 初始化：v0.8.21 9k selector；
- 学习率：`3e-5`；
- 优化器：AdamW，weight decay `1e-4`；
- 随机种子：`20260721`；
- 可训练模块：原 `BondSetSelector`，模型结构和参数量不变；
- MR-TADF、USPTO：不训练、不选阈值、不选 checkpoint。

## 性能观察

9k 训练主要受 Python 逐组小张量操作限制，GPU 利用率约 37%-40%，显存不到 1 GB，
进程内存约 46 GB。能力实验完成前未改变实现；若以后复用该 loss，应先向量化 group
reduction，不能把当前耗时误判为 5090 算力不足。

## 决策

- GT pair overlay、泄漏断言、组级诊断和 winner-anchored loss：GO，保留；
- 全候选先 Endpoint grouping：NO-GO；
- normalized-logmeanexp 正组 MIL：NO-GO；
- v0.8.27 9k checkpoint：正式 NO-GO，不接入稳定推理；
- 稳定默认继续保持 v0.7.10；
- 下一步停止继续调 selector loss，转 Dense BondObject 同 cell slot 的 Hungarian
  置换匹配和跨 slot duplicate/exclusivity。
