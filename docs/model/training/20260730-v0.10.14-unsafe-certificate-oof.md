## 目标

v0.10.13 已证明 utility ranking 能找到大量有效 `DELETE(node)`，但同一个 head 的 safety
probability 无法作为零破坏证书。本版冻结 v0.10.13 的 30k ranking checkpoint，另训一个只
预测 `P(unsafe)` 的 63k 小模型，将安全证书与效用排序解耦。

已经消费过的 route-select 8k 只作为开发证据，按 `molecule_id` 确定性分成五折。每个 outer
fold 使用三折训练、一折 calibration、一折 evaluation；evaluation 不参与训练或阈值选择。
每折训练三个 seed，保守证书取三者最大的 unsafe probability。

## 失败取证

三 seed ensemble 的三次 harmful 分属三个不可互换的保护条件：

1. 删除了置信度更高、离 GT 更近的 proposal，低分 witness 无法保持 primary atom/bond 覆盖；
2. 两个距离 3.92px 的 proposal 在 10px topology-aware 匹配中对应两个不同 GT 原子；
3. removed 与 witness 的邻接集合相同，但一条对应边的预测 chemical type 不同，删除后丢失
   typed bond 覆盖。

现有 420D feature 只保留 pooled witness 与邻边概率摘要，没有保留逐邻边 chemical type
对应关系。把 BCE 训练到概率接近零也无法补回已经聚合丢失的信息，因此不继续加 epoch 或扩大
相同模型。

## 决策

- v0.10.14 判定 NO-GO，默认前端继续使用 v0.10.10；
- route-confirm 和 sealed test 均未读取；
- OOF checkpoint 仅保留为诊断产物；
- 下一版改用显式 structural-twin certificate：极近距离、完整邻接相同、逐邻边 chemical
  type 相同，再由冻结 ranking 选择每图最多一个动作。

事后开发审计显示，`<=2px + 非空邻接完全相同 + 逐邻边 chemical type 相同` 在当前 8k 上
达到 894 次执行、0 harmful、Skeleton `+4.76pp`、winner recall `43.14%`。该结果用于提出
v0.10.15 协议，不能回写为 v0.10.14 成绩，也不能替代未见 confirm。
