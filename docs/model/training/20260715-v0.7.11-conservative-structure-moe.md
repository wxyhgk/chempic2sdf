## 设计

v0.7.10 base expert 永久保留。新专家只负责已经证明适配有效的 MolGrapher 绘图域。
轻量 gate 读取冻结 base vision encoder 的 stride-4 特征，只有分数达到高阈值才选择
新专家，其余图片全部回退 base。USPTO 和 MR-TADF 不参与 gate 训练或阈值拟合。

gate 使用约 10,000 张平衡来源图片训练：MolGrapher 为 expert 类，ChemVision 为
base 类。validation 结果：

| 阈值 | MolGrapher expert recall | ChemVision 误路由 |
|---:|---:|---:|
| 0.90 | 80.2% | 0 / 498 |
| 0.99 | 52.0% | 0 / 498 |

外部 gate 审计：

- 阈值 0.90：USPTO 7/200 误路由，MR-TADF 0/200；USPTO 门控下降，因此否决。
- 阈值 0.99：USPTO 0/200，MR-TADF 0/200，接受为保守工作点。

## 部署去重

`chemvector.pack_structure_moe` 会逐 tensor 验证 base/expert，拒绝任何非
`vertex_head.*`、`stroke_head.*`、`relation_head.*` 的变化，只打包 28 个变化
tensor、238,856 个参数和 gate。

- 完整 expert checkpoint：约 199 MB；
- packed expert + gate：983 KB；
- 运行时共享 base vision、OCR 和其余模块；
- MolGrapher 1k 的 packed/unpacked `records.jsonl` 和 `summary.json` 逐字节一致。

## 2026-07-16 复核

该方案不再作为开发候选：

- gate 在 USPTO 和 MR-TADF 上零路由，旧域结果只是 v0.7.10 回退，不代表新能力；
- MolGrapher expert 单独的 detected skeleton exact 约 3.0%，路由后仅 1.3%；
- gate 学习的是数据来源风格，不是 expert 是否比 base 更正确；
- 首要瓶颈是顶点集合，继续调 gate 只是在不可用专家之间选择。

最终决定为 `NO-GO`。packed bundle 和 gate 代码保留用于复现，主线回到 v0.7.10，
后续由 v0.7.12 shadow-mode 集合式顶点实验接替。
