# 2026-07-31 v0.10.17 BondObject 主线 OCR 替换

> 状态：能力 GO / shadow，默认不切换  
> 新训练：无  
> 结构主干：v0.9.41 语义 BondObject utility router  
> OCR：v0.10.9 正确标签开放 byte CTC

## 目标

回到已经在 USPTO clean 1k 达到 72.7% Skeleton exact 的 v0.9.41 语义 BondObject 主线，
只将旧 v0.8.8 CTC 替换为协议兼容的 v0.10.9 CTC。Text Object、bbox、Junction、Bond、
router、阈值和 ChemScene 编译全部冻结。

本实验验证两件事：v0.10.9 是否能跨 AtomObject 协议复用，以及公开端到端 Atom/SDF 是否
实际改善。USPTO 和 MR-TADF 不参与 checkpoint 或阈值选择。

## 冻结组件

- selector：v0.7.39；
- 基础 BondObject：v0.8.2；
- 风格 BondObject：v0.9.37；
- style gate：v0.9.39；
- utility router：v0.9.41，break budget 0；
- Text bbox：v0.8.9；

两套 CTC 的配置均为 192 hidden、1 层、4 heads、24 bytes、64 time steps，state dict
协议一致。v0.10.9 CTC 共 758,945 参数，本版不新增参数。

## 决策

v0.10.17 判定能力 `GO`、部署 `shadow`。它证明“语义 BondObject 主干 + 更好的开放 OCR”是
当前有效路线，但由于完整 1k 仍有 paired break，前端保持非推荐，默认模型不自动切换。

下一版在内部数据上构造 v0.8.8/v0.10.9 双 OCR teacher，学习或证明一个只在新 OCR 更可靠时
切换的保守 router；USPTO 标签不进入训练或阈值选择。

## 前端烟测

运行中的 `0.0.0.0:8765` 无需重启即加载 `structure-v01017-bondobject-ocr`。真实上传
`uspto_clean_0003.png` 成功返回 60 Atom / 71 Bond、公式 `C57H42N2Si` 的有效 SDF，且与
官方结构完全一致。`test1.png` 仍因原有骨架过检产生 C 六价 diagnostic SDF，符合本版只替换
OCR、不改变结构模型的能力边界。
