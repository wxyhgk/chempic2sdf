# 2026-07-31 v0.10.18 保守双 OCR 路由

> 状态：组件与公开配对 GO / shadow  
> 结构主干：v0.9.41 语义 BondObject utility router  
> 主 OCR：v0.8.8  
> 专家 OCR：v0.10.9  
> Router：`outputs/checkpoints/chemvector-v01018-ocr-utility-router-4k/best.pt`

## 目标

v0.10.17 将全部文字切换到 v0.10.9 后，USPTO clean 1k 的 chemical exact 从 160 提高到
215，但有 20 个 paired break。本版恢复 v0.8.8 为主 OCR，只在推理可见特征能保守证明
v0.10.9 更可靠时切换单个 Text Object。

OCR router 不读取图片来源、GT、SDF、分子式、价态结果或 USPTO 标签。输入仅包括两套 CTC
输出的归一化 log score、字符串长度、是否可解析，以及解析后的元素、电荷、同位素、显式 H
和自由基。旧新输出相同时不调用 router。

## 模型

- 50 个标准化推理特征；
- `50 -> 64 -> 32 -> 1` MLP；
- 训练 2,000 step，batch 256，AdamW，学习率 `3e-4`；
- `new_break` 使用 8 倍负样本权重；
- 每 100 step 在 validation 构造 break budget `0/1/2/5/10` 前沿；
- checkpoint 选择优先比较 break-0 净收益，再比较更宽松前沿。

最佳 checkpoint 为 step 1900。validation break-0 阈值 `0.8989976` 选择 85 个分歧：
81 rescue、0 break、4 个两边都错。

## 修订安全协议

不使用已消费 internal test 搜索最优阈值，改为固定通用置信下限 `0.95`。随后在未参与本
router 训练或选模的 `chemvector_joint_v1/fresh_dev` 前 2,000 张进行新 confirm：

- 9,501 个匹配文字；
- 2,363 个旧新分歧；
- route 11；
- rescue 10；
- break 0；
- 两边都错 1。

`0.95` 通过 revised confirm，随后接入端到端。主 CTC 与 invalid-only atom reranker 都保持
v0.8.8；v0.10.9 只能通过 router 改写初始 Text Object，不能从结构化 reranker 绕过门控。

## 决策

v0.10.18 判定保守组件 `GO`，作为独立 shadow profile。它不是 v0.10.17 的替代关系：

- v0.10.17 是高收益版本，chemical exact 21.5%，但有 20 break；
- v0.10.18 是低覆盖安全版本，chemical exact 16.2%，公开 1k 零 break。

默认前端不自动切换。下一步若继续提高安全覆盖率，必须加入文字图像特征或图级双候选验证，
不能只降低 router 阈值。

## 前端烟测

运行中的 `0.0.0.0:8765` 动态加载 `structure-v01018-conservative-ocr-router`，无需重启。
真实上传 `uspto_clean_0099.png` 返回有效 SDF；诊断明确记录 1 个 OCR 分歧、1 次 route、阈值
`0.95`，最终将 `S-` 保守替换为 `S`，证明网页实际执行了双 OCR 路由而非旧静态 profile。
