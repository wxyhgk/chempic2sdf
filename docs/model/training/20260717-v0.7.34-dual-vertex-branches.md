# v0.7.34 文字与隐式骨架双顶点分支

## 结构

在 v0.7.33 独立文字对象分支之外，新增独立隐式骨架顶点头：

```text
共享冻结 stride-4 视觉骨干
  ├─ TextObjectCenterHead：文字中心、offset、bbox
  └─ ImplicitVertexHead：仅 visible_text=false 的骨架顶点
```

隐式分支把全部字符笔画视为背景，不再承担文字中心定位。

## 隐式分支

validation 500 选择 checkpoint 和阈值，最佳为约 43,992 曝光、阈值 0.52：

```text
F1                  91.36%
Count exact         22.29%
Vertex exact         9.64%
```

internal test 500 盲测：

```text
F1                  91.76%
Count exact         26.20%
Vertex exact        11.80%
```

旧 Oracle 审计中的隐式基线为 78.35% F1 / 2.8% exact。

## 双分支 Internal Test 500

| 模式 | F1 | vertex exact |
|---|---:|---:|
| 原始 dense | 75.04% | 0.4% |
| v0.7.33 文字 + 旧 dense 隐式点 | 83.14% | 1.8% |
| 双分支，全部使用预测数量 | 92.62% | 9.6% |
| 双分支，隐式数量 Oracle | 91.76% | 19.2% |

大字号 140 张，全部使用预测数量时达到 92.22% F1 / 10.0% exact。

## 结论

- 字符与骨架顶点解耦：GO；
- internal strict exact 相对原始 dense 提高 24 倍；
- 双分支局部 F1 已超过 92%，下一瓶颈是隐式顶点数量校准和整组选择；
- 下一步把双分支候选接入 256 候选 Structured Selector 与全点对线条图；
- 训练标签必须保持文字/隐式身份，不再用单一 Hungarian 身份标签混合两类候选。
