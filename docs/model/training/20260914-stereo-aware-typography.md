## 修复了什么

旧排版逻辑将 chemical SINGLE 的 SVG 直线段都当作可裁短的普通键，却没有区分虚楔的短横线。调试证实部分“留白会抹掉键段”来自对虚楔横线的误裁；旧版合格图中也有 39 张记录过虚楔笔画裁剪，共 42 次。因此之前的拒收不全是分子太大、布局放不下。

新增 `stereo_typography.py`，模式为 `stereo-aware-v1`，renderer ID `curriculum-same-svg-0.3`：

1. 复用旧同原子字符间距处理，但暂不裁键。
2. 用现有 drawing direction 区分普通笔画与立体笔画；非 NONE 方向以及其他非普通直线/辅助路径全部保护。
3. 碰撞文字按原子 ID 做一次有界整数平移，优先最小位移、较少纵向移动。位移半径上限为 `floor(min(8 px, 字号/3, 最短关联键锚点长度/5))`，元素字形中心不能更靠近其他原子。
4. 仅普通直线键按旧端点约定裁短。找不到安全位置时不扩大搜索半径、不缩字、不删笔画；最后仍执行原严格像素、归属和前景覆盖检查。

实际有 211 张合格图移动过整组文字，共 262 个标签；最大平移约 6.71 px。字体、字号、字符、顺序、化学图、原子锚点和立体方向不变。**文字位置及基线可以变化**，均记录在 `label_moves`，不延续旧模式“基线不变”的声明。

旧模式及默认选择保留用于复现，历史输出不改；使用新版必须显式给定 `--typography stereo-aware-v1`。
