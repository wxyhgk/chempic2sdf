# 2026-07-16 v0.7.19 Proposal Graph Edge Prior

> 状态：NO-GO；接口保留且默认关闭  
> 基础版本：v0.7.18  
> graph 权重：`outputs/checkpoints/chemvector-v0718-proposal-graph-rescue-9k/best.pt`

## 目标

v0.7.18 在 USPTO clean 1k 将完全一致提高到 29，但仍有 254 个 disconnected。
本轮不训练新权重，尝试把 proposal graph 的二元连接概率作为 `model_connect` 的
补桥排序先验。

## 约束

- 只在当前图不连通时参与 repair；
- 不改变原始 relation stroke；
- 不降低任何 relation 概率；
- 保留 relation 预测的键型，只提高连接排序分数；
- graph score 必须达到内部 validation edge F1 最佳阈值 `0.85`；
- GD906 和 USPTO 不用于选择阈值。

实现将 graph proposal id 一直映射到 OCR 过滤后的最终坐标点对。对满足阈值的点对，
bridge score 使用 `max(relation_score, graph_score)`。参数默认 `None`，旧推理逐位不变。

## 结果

GD906 在固定 `0.85` 下仍为 63 个顶点、2 个连通分量，未找到高置信跨分量 graph edge。

USPTO clean 1k：

| 指标 | v0.7.18 | v0.7.19 prior |
|---|---:|---:|
| 有效 SDF | 241 | 242 |
| 化学完全一致 | 29 | 29 |
| 原子数一致 | 11.5% | 11.5% |
| 键数一致 | 8.4% | 8.4% |
| disconnected | 254 | 252 |
| valence | 436 | 437 |
| 有效预测平均相似度 | 0.4730 | 0.4711 |

全量只有两个样本改变：

- `uspto_clean_0603`：断图变为有效错误，新增 2 条桥边，fingerprint similarity 为 0；
- `uspto_clean_0624`：断图变为价态失败，新增 5 条桥边。

输出：`outputs/evaluations/uspto-clean-1k-v0719-graph-edge-prior-t085/`

## 决策

- repair 阶段的 `max` edge prior：NO-GO；
- 显式 CLI/benchmark 接口保留，默认关闭，仅用于复现；
- 不降低 threshold 在 USPTO 或 GD906 上继续试探；
- 下一步在通用训练数据上训练 relation fusion，让 graph edge evidence 在关系判断阶段
  参与监督，而不是在 repair 末端硬抬分。
