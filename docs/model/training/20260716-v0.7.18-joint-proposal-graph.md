# 2026-07-16 v0.7.18 联合 Node-Edge Proposal Graph

> 状态：组件 GO；shadow 推理 GO；默认替换仍待更广公开集验证  
> 稳定模型：`outputs/checkpoints/chemvector-v079-relation-all-pairs-9k/last.pt`  
> keep 权重：`outputs/checkpoints/chemvector-v0717-stable-proposal-scale-9k-24k/best.pt`  
> graph 权重：`outputs/checkpoints/chemvector-v0718-proposal-graph-rescue-9k/best.pt`

## 问题

v0.7.17 的 keep head 只能先删顶点、再让 relation 看剩余点对。真实端点一旦被删，
后续即使看到清楚键线也无法恢复。本轮把高召回 proposals、原图线带和节点保留放进
同一个可监督图中，让边证据反向影响节点，而不增加距离删边规则。

## 结构

- 使用稳定 dense head 的 `3x3` 局部峰，阈值 `0.05`，每图最多 192 个 proposal；
- 对最多 18,336 个无向点对，从原始 768x768 图片采样 24 个位置、3 条平行线带；
- Hungarian 将 proposal 一对一映射到真实原子，直接从 ChemMol bonds 构造邻接标签；
- edge head 预测真实连接，训练使用全部正边和最高分困难负边；
- 每个节点接收最强 4 条 incident edge support 和聚合 edge message；
- node loss 不反向修改 edge encoder，避免 edge head 退化成隐藏 keep 分类器；
- 新增 29,475 个可训练参数，稳定主模型与 keep head 全部冻结。

proposal cap 审计表明 192 个候选在原尺度的 16px recall 为 95.30%，验证训练时为
95.00%。显存峰值仅 1.174 GiB，RTX 5090 上 batch 8 训练约 100 张/秒。

## 内部结果

第一版对所有 edge message 做 degree 平均，24k 后 edge F1 为 78.2%，但 6px vertex
exact 只有 6.3%，低于 v0.7.17 的 7.4%，判定 NO-GO。线带置白时 edge F1 几乎归零，
但 vertex exact 只下降到 5.9%，证明边头读到了线，传回节点的通道却太弱。

第二版加入 top-4 incident support、显式 residual rescue，并隔离 node loss 对 edge
encoder 的梯度。冻结最佳 checkpoint 后，在 MolGrapher validation 1k 上细扫 node
threshold `0.80-0.90`，`0.87` 最佳：

| 指标 | v0.7.17 keep | v0.7.18 graph |
|---|---:|---:|
| 6px vertex exact | 7.4% | 7.5% |
| 6px F1 | 83.51% | 83.21% |
| Count exact | 22.2% | 21.6% |
| Count MAE | 2.181 | 2.405 |
| Edge F1 | - | 78.35% |

F1 和 count 有小幅 tradeoff，但未明显回归，整图 exact 越过预设 7.4% 门控。线带置白
后 edge F1 降到接近 0，vertex exact 从 7.2% 降到 6.5%，证明线条证据已经实际参与
节点保留，而不是只作为无效辅助头。
