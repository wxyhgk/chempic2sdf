# P–O 样式差异：固定四结构的两档全因子诊断

接续 [公开排重与 64 图诊断](20260923-structure-expansion-public-and-bond-diagnostic.md)。
本轮只解释上一轮同一批 8 条 P–O 单键在 oa00 为 8/8、oa22 为 1/8 的差异，
不扩大分子身份、不再读取评估身份、不启动训练、不改变模型或阈值。

## 事前固定设计

使用上一轮诊断中**全部四个**含两条 P–O 单键的结构，而非另选失败最多的个例：

- `O=P(O)(O)CCO`
- `O=P(O)(O)Cc1ncco1`
- `O=P(O)(O)Cc1ccnnc1`
- `O=P(O)(O)Cc1ccc2cnccc2c1`

四者均在前序 1,525 个公开／私有筛查保留身份中；新样式只是这些身份的诊断变体，
没有新身份查询，也不自动加入原 12,112 张候选或任何训练清单。

| 控制因素 | 低档（oa00） | 高档（oa22） |
| --- | --- | --- |
| 字体 | DejaVu Sans | Liberation Sans |
| 字号 | 12 px | 24 px |
| 键长上限 | 28 px | 40 px |
| 线宽 | 0.8 px | 3.2 px |

完整 2⁴ 组合 × 4 个结构，共 64 张。旋转保持 0°，画布为原始 768×768，
不加噪声、不裁切或缩放模型输入。同一个 RDKit 排版器与同源 SVG 标签生成器不改动。
Profile 中键长是 RDKit cap 参数，不把它直接当成实际像素键长；逐键另测 anchor 距离。

组合编码的四位依次为字体、字号、键长、线宽；`0000` 使用原 `oa00` 名称，
`1111` 使用原 `oa22` 名称，其余为 `po` 加四位编码。
每一个一因素对比都保持其他三因素及化学身份、键 ID 不变，八条 P–O 单键各有八个背景，
即每因素 64 对比较。这些不是 64 个独立分子，不据此计算泛化置信区间。

## 控制与边界

- 外层 CPU 墙钟上限 300 秒、无自动重试；仍为原 initial 权重，selector -0.25、pair 0.85、匹配半径 6 px。
- 64 张必须全部通过原成图质量约束，否则在模型加载前停止，不填补、不跳过后继续称完整因子。
- 8 张原样式对照 PNG 必须与上轮字节哈希相同。
- 所有图片先通过原目标适配检查；真实预测仍只用图像，真值随后进入匹配／评分。
- 先推理 8 张对照，其 prediction digest、candidate trace、逐图指标必须完全复现旧结果，才继续新样式。
- 模型初末 state 相同，无梯度或优化器，OCR 不加载；完整 SDF／元素／立体准确率不在本轮范围内。
- 保存所有局部键结果、几何和 pair logits，后核验只重算保存的预测，不重新调用模型。

每张都有两条 P–O 单键和一条 P=O 双键对照；单键分母 128、双键分母 64。
不可达键保留在错误分母里；概率差只计算两端都可达的一因素对，不能把不可达误当作概率 0。
另存实际 anchor 长度、SVG 可见线段长度／anchor 长度比，以及预测端点位置误差。

改变一个 renderer 参数会连带改变排版／文字留白，这是该参数的总效应；
不能直接等同于固定隐藏特征的因果干预，也不自动说明具体哪条神经网络分支是根因。
四个结构来自已观察到错误的定向面板，不是新独立测试集。

## 执行结果

已完成全部 64 张，成图拒绝 0，目标适配检查 64/64 通过。
8 张旧样式 PNG 字节一致，8 张旧预测摘要、候选轨迹和逐图指标完全复现。
保存预测后核验 64/64 通过，无第二次模型推理。

### 1. 在这个面板上，字号是最明显的受控因素

下表汇总两种字体、两档键长和两档线宽，分母都是同一批八条单键在八种背景下的结果：

| 字号 | P–O 单键正确（存在性及键型） | 漏连 | 键型错 | 端点均可达 |
| --- | ---: | ---: | ---: | ---: |
| 12 px | **63/64** | 0 | 1 | 64/64 |
| 24 px | **10/64** | 54 | 0 | 64/64 |

保持其他三因素不变时，字号从 12 增到 24，**64/64 对的存在概率都下降**，
平均下降 0.524164（52.42 个百分点）；53 对从正确变成错误，没有一对从错误变成正确。
对应 anchor 距离没有实质变化（浮点误差约 1e-14 px）。
所以本轮观察到的是端点可达之后的连键判断对字号敏感，不是新增的端点定位缺口。
它仍不能排除端点的小幅偏移或上游隐藏特征变化对 pair 判断的影响。

| 单因素从低档切换到高档 | 平均存在概率变化 | 原正确变错 / 原错误变对 |
| --- | ---: | ---: |
| DejaVu → Liberation | -0.132547 | 9 / 0 |
| 字号 12 → 24 | **-0.524164** | **53 / 0** |
| 键长 cap 28 → 40 | -0.028793 | 8 / 3 |
| 线宽 0.8 → 3.2 | **+0.118839** | 1 / 4 |

每行都有 64 对，全部两侧可达。字体切换 41/64 对概率下降，键长切换 34/64 对下降，
线宽切换仅 8/64 对下降；不能把其他因素理解为对每一条键都有同方向效果。
这些平均效应只针对本次两档取值和等权背景，不代表任意字号、字体或结构的规律。

### 2. 可见线段缩短是线索，尚不是已证明的内部机制

放大字号后，SVG 可见线段长度 / anchor 距离的比值平均下降 0.192217，
与图上文字留白变大一致。但加粗线条也使此比值平均下降 0.026551，
存在概率却平均上升。因此不能把模型失效简单解释为“可见线越短必然越差”，
也不能再把旧 oa22 的失败笼统归因于粗线。

cap 28/40 对应本面板实际 anchor 距离约 42/60 px，增加 18 px；
cap 并非实际线段长度。扩大 cap 平均增加可见比例，却没有整体修复连键，
进一步说明需要查局部取样、文字端点邻域和尺度表征，而不是只调渲染长度。

P=O 双键对照为 59/64 正确，另有 2 条漏连、3 条键型错，并非所有文字邻接键都完全免疫。

### 3. 全图局部计数与边界

64 张共 688 条目标键，全部可达：619 正确、63 漏连、6 键型错。
688 个目标原子均匹配；模型选择 691 个候选，多出 3 个未匹配候选。
2,928 个确认非边中假阳性为 0；另有 35 个未知 pair，其中 8 个预测存在，
不能把未知 pair 当作确认非边，也不能据此声称最终图没有假键。

本轮没有 OCR、元素、立体化学或完整 SDF／整分子准确率评估。
四个结构是上一轮已暴露问题的定向诊断样本，不能将 63/64 或 10/64 当作泛化准确率。

## 下一步优先级

1. 先查大字号条件下，P–O 两端附近的局部图像证据如何进入 pair 表征：
   区分端点小偏移、沿键取样范围、局部尺度和文字留白的影响。
   本轮只隔离到 renderer 字号因素，不声称已经定位或修复具体内部模块。
2. 根据局部证据再制定定向监督：同结构多字号／字体配对，保留原先正确键、
   P=O 对照和确认非边回放；按结构隔离开发集，不让同结构换样式冒充独立泛化。
3. 满足数据发布检查并另行明确训练范围与单次预算后，再考虑小额 pair 试训。
   不自动降低全局阈值，不解冻 OCR／selector，不因四个结构的诊断就切换架构。
