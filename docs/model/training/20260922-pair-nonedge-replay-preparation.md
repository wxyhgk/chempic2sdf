# 跨图片确认非边回放：单变量修复准备完成，尚未试训

## 当前结论

已实现独立的回放训练入口，并通过 **247 项合成 CPU 测试**。只核验了固定训练池的元数据、
历史对照及代码哈希；本轮没有加载真实模型权重、真实模型前向、真实 optimizer 更新或 GPU 使用。
不能据此宣称假键已减少或准确率提高。默认模型仍为原始 initial。

上一轮一次性诊断许可已经消费，本轮没有生成新的许可或占用试训次数。
下一次真实运行需要确认：**一次、从原始 initial 出发、单卡、最多 50 次更新／58 次尝试／600 秒**。
不调参扫描、不自动重试、不部署；600 秒包含加载、缓存、初末评估及产物保存。

## 为什么只验证这项改动

上一轮在完全相同的训练条件下复现了回退：两条确认假键在本图负例更新时分数略降，
其他图片更新带来的累计上升却远大于这点纠正。优先验证“学习当前图时，能否同时保住其他图的
不连接判断”，无需立即更换架构或扩大 GPU 试错范围。

这不是认定某张基础图、chemical loss 或 Adam 是唯一根因；回放是否有效仍需实测。
历史对照与证据见 `20260922-pair-observed-trial-result.md`。

## 固定实验规则

```text
总损失 = 原主样本损失 + 1.0 × mean(softplus(另一图片的确认非边 logit))
```

- 使用已准入 fixed58 中原有的 32 张完整分子 TRAIN 图作为回放池，不引入新数据或开发样本。
- 历史缓存元数据共记录 15,513 条确认非边，每图至少 53 条。
- 真实执行时重新生成缓存和标签；每张图固定选初始 logit 最高的最多 32 条确认非边，
  同分按行号排序。不使用历史槽位标签、不动态挖掘、不硬编码两条故障边。
- 按实际完成的更新次数轮换回放图片，同一图片或同一分子则顺延。预排程覆盖全部 32 图，
  固定池预计 1,024 条，50 步最多回放 1,600 条次；“条次”不是不同原子对数量。
- 原主样本 loss、正例权重、chemical loss、采样、顺序、优化器、学习率、裁剪与阈值均保持不变。
  回放独立求平均，不把负例塞进原 loss 后连带改变 pos_weight；不添加回放 chemical loss。
- 主样本与回放合并一次 backward、一次裁剪、一次 AdamW 更新。主样本没有已知监督时完全跳过，
  不增加回放专用更新。只有 pair 头可训练，上游及 OCR 全冻结。
- 对照使用已独立核验的历史原目标 50 步运行，不再花 GPU 重跑对照臂。

单位系数 1.0 是事前固定的单个假设，不是搜索出的最优值。负监督也可能压低真键，
通过共享参数间接影响键类型；固定初始负例池还可能漏掉训练后才变难的负例。

## 比较与停止条件

首次更新之前，必须确认原 initial、执行环境、58 份新缓存回执及 58 份初始预测与历史对照完全一致。
不一致则停止，不自动切设备、重生成规则或更换对照。

保留原 full58 检查：每张图的旧正确类型键、旧正确 SDF、旧有效 SDF、新 fallback、确认假边，
以及冻结候选／文字签名。未知对应的预测边另行计数，绝不充当确认负例。
不是只检查两条探针，也不是只看 loss 或总正确键数增加。

两条探针继续逐步记录，同时明确区分“主图片直接监督”和“回放直接监督”，避免把回放效果
误记为纯跨图片泛化。有限事件快照包含主图、回放图、总裁剪梯度及 Adam 状态，最多四份／1 GiB。
旧的单图梯度分解不适用于新目标，修复运行不调用它。

最多 50 步就结束，即使原保护门返回允许继续也不追加训练。始终评估实际终态；不足 50 步明确
记为不完整。所有结果仅是 fixed58 训练／回放拟合证据，不是独立测试准确率。
