# v0.9.87 正 Margin 图上下文

## 问题

v0.9.86 将假键显著压低，但漏键增加。原 `atom_pair_group_loss` 包含 BCE 和整图 ranking：

```text
最弱真键分数 > 最强假键分数 + margin
```

该约束只保证相对顺序，不保证真键 logit 高于部署阈值 0。例如假键为 -2、真键为 -0.5 时，
ranking 已满足，但推理仍会删除真键。

## 失败的推理校准

先冻结 v0.9.86 权重，只在双域 validation 选择通用推理规则：

1. 全局 residual scale 0.8；
2. residual scale 0.8 + base-positive 高置信保护阈值 0.5。

两者在 validation 均维持 524/996 chemical exact，但 frozen locked internal test 都只有
520/996，低于 v0.9.86 的 521/996。因此规则校准支线 NO-GO，没有更新版本或前端。

## 训练修复

在 v0.9.86 相同的确定性双域协议上增加绝对正 margin：

```python
positive_margin_loss = relu(0.5 - positive_logit).mean()
loss += 0.25 * positive_margin_loss
```

其他权重保持不变：

- count weight：0.25；
- degree weight：0.25；
- residual L2：1e-4；
- ChemVision/full-v0 各 2,250 张；
- 双域 validation 各 498 张；
- 未使用 MR-TADF、USPTO、MolGrapher 或 internal test 选择训练权重。

训练 checkpoint：

```text
outputs/checkpoints/
  chemvector-v0987-atom-pair-graph-context-positive-margin-4k5/best.pt
```

## Validation 校准

正 margin 原始 scale 1.0 的 pooled chemical 为 525，但 ChemVision 比 v0.9.86 少 1 张。
固定扫描 residual scale 0.6-1.4 后，按“最弱域 chemical、pooled chemical、最弱域 presence、
pooled presence”的预定顺序选择 0.8：

| 指标 | v0.9.86 | v0.9.87 |
|---|---:|---:|
| ChemVision presence | 347 | 348 |
| full-v0 presence | 360 | 362 |
| pooled presence | 707 | 710 |
| ChemVision chemical | 250 | 251 |
| full-v0 chemical | 274 | 276 |
| pooled chemical | 524 | 527 |

## 判断

v0.9.87 GO。有效改进来自训练目标修复，不是长键数据、价态硬规则或 benchmark 特判。默认
前端 profile 为 `structure-v0987-carbon`，继续关闭 v0.9.84/85 line rescue。

当前假键已显著下降，但漏键仍高于 base。下一步应学习“哪些局部结构允许 graph context 删除
base-positive 键”，优先使用训练域的反事实删除标签，而不是继续扫描统一阈值。
