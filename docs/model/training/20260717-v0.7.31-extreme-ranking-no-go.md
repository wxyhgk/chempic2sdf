# v0.7.31 候选身份极值排序 NO-GO

## 假设

v0.7.30 的 16x16 困难边界取平均，可能稀释最强假候选和最弱真候选。本轮新增：

```text
softplus(margin + max_negative - min_positive)
```

并从 v0.7.30 最佳 3x3 patch checkpoint 继续训练。

## 结果

| 曝光 | F1 | vertex exact |
|---:|---:|---:|
| 初始 | 84.72% | 4.4% |
| 10k | 68.25% | 1.1% |
| 20k | 67.11% | 0.5% |
| 30k | 71.80% | 0.8% |

实验在 35k 主动停止，未继续浪费训练资源。

## 根因

Hungarian 为每个真值顶点只指定一个正候选，但 6px 评测允许多个近邻候选互换。
极值损失把同一真值附近其他同样正确的候选当作最强负样本，强迫模型学习任意的候选
身份差异，导致 F1 和 strict exact 同时下降。

## 决策

- 候选身份级 extreme loss：NO-GO，默认权重保持 0；
- v0.7.30 最佳 checkpoint 不变；
- 下一步按 6px 真值邻域建立候选等价组；
- 目标改为每个真值组覆盖一个候选、背景候选不选，并显式抑制同组重复选择；
- 在组级目标完成前，不再尝试更大的 extreme loss 权重。
