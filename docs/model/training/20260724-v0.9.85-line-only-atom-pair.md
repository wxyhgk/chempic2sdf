# v0.9.85 一等 Line-Only AtomPair

## 目标

v0.9.84 只能用全图线段提高已经存在于旧 AtomPair group 中的键。coverage 审计仍有一类明确
缺口：线段和两个 AtomObject 都已找到，但旧 dense Bond proposal 没有产生对应 AtomPair，
因此 learned group head 没有候选可选。

本版允许这类 line-only AtomPair 直接成为一等 Bond proposal：

```text
raster line segments
  -> 两端吸附到预测 AtomObject
  -> 排除已有 AtomPair group
  -> learned presence / display type / chemical type
  -> 固定两端 incidence
  -> 与旧 proposal 一起进入 joint graph decode
```

不设置最大键长，也不使用绝对线长或绝对原子距离作为特征。双键和三键仍各是一个 BondObject、
两个语义端点；多条 physical stroke 只增加同一 AtomPair 的支持数。

## 实现

- `chemvector/line_atom_pair_head.py`：尺度不变的 presence/type head；
- `chemvector/build_line_atom_pair_cache.py`：ChemVision/full-v0 双域缓存；
- `chemvector/train_line_atom_pair_head.py`：双域 validation 选择 checkpoint 和阈值；
- `chemvector/line_atom_pair_inference.py`：追加一等 Bond proposal 和固定 incidence；
- `chemvector.benchmark_joint_mr_tadf`：冻结外部 A/B；
- `chemvector.infer_joint_object_structure`：单图上传推理。

输入特征共 518 维：沿线视觉均值/最大值、两端 AtomObject 的对称特征、线段跨度与原子跨度比例、
端点误差、角度误差、支持 stroke 数和无向双角方向。80px 与 480px 的恒定视觉测试得到相同特征，
防止模型重新学习训练集键长分布。

## 判断

v0.9.85 为边际 GO：它证明没有旧 AtomPair group 的清晰线段可以通过 learned first-class
proposal 补回，并使极端长键继续净提升；但 overall 只净增 1 张，且 1 张标准样本因误补边回退。

不能继续只扩大同一个小 MLP。当前更关键的内部问题是：双域 validation 只有 12 个真正 rescue
正例，presence recall 不足 50%，而外部被选中的 line-only 候选多数仍未形成整图 exact。下一步
应扩充内部自然 line-only rescue 事件，并把“补一条键后整图是否更一致”纳入集合级训练或选择，
同时继续禁止绝对键长捷径和 MR-TADF 调参。

OCR、文字原子类型和开放缩写不属于本版；前端仍明确使用 C 占位。运行时 profile 为
`structure-v0985-carbon`，`recommended=false`。
