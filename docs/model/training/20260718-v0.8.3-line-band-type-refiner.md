# v0.8.3 二维线带键型 Refiner

## 目标

固定 v0.8.2 的 BondObject 中心、端点、排序和计数，只替换键型，验证“整根键的
二维线带”是否能解决多尺度模型的类型瓶颈。

## 实验一：复用 v0.7.38

将每个预测 BondObject 的两个端点组成独立 pair，一次前向读取全部二维宽线带。
端点正向和反向各推理一次并平均 logits，避免无向 BondObject 受到端点顺序影响。

旧 checkpoint 同时训练了全点对 edge、display、chemical 和 direction。直接替换
display/chemical 后，498 张结果为：

| 指标 | v0.8.2 baseline | 旧线带 plug-in |
|---|---:|---:|
| known object accuracy | 70.66% | 66.15% |
| SDF exact | 4.42% | 0.60% |

结论：旧模型的表征包含“是否成键”任务，不适合作为已确认键的纯类型分类器。

## 实验二：只用正键微调

移除 edge loss，只输入真实键；加入最大 6px 端点抖动和 50% 端点交换。双键 display
可达到约 89%，但 chemical accuracy 明显低于多尺度全局头。整块替换仍为 NO-GO；
仅在高置信度下修正 DOUBLE/TRIPLE 也没有改变 SDF exact。

## 实验三：纯 SVG 可见图元分类器

新增 `LineBandDisplayRefiner`：

- 输入为 `33 x 96` 二维墨线带，半径 16px；
- 不输入绝对坐标和图结构；
- 不预测 edge、chemical 或 direction；
- 只输出 `SINGLE/DOUBLE/TRIPLE/AROMATIC` 可见线型。

从零训练两轮后，最佳 known-endpoint display accuracy 为 79.42%，其中 DOUBLE
95.02%、TRIPLE 95.00%。回接预测 BondObject 后，局部 object accuracy 从 70.66%
提高到 71.22%，但整图 SDF exact 从 4.42% 降到 2.61%。另一个 checkpoint 可将
AROMATIC 提到 66.84%，同时 DOUBLE 降到 59.93%，暴露四分类 softmax 的类别竞争。

## 结论

局部二维线带确实学到了可见图元，但“逐键准确率提高”不等价于“整图完全正确”。
错误被分散到更多分子后，exact 反而下降。因此 v0.8.3 不替换 v0.8.2 类型头。

下一步不继续堆逐键分类训练量，改为结构化类型建模：把可见线数与芳香纹理解耦，
并在闭环/分子集合层面优化一致性和整图 exact。chemical 类型继续由全局图上下文负责。

## 端到端 Hybrid 接入

为避免 v0.8 继续停留在 Oracle-Junction 指标，新增
`chemvector.infer_chemscene_hybrid`：

```text
v0.7.39 predicted Text/Implicit Junction
    + 现有 Pixel OCR
    + v0.8.2 multiscale BondObject
    -> ChemScene Assembler
    -> SDF
```

Assembler 不按键长删除 BondObject。每个预测端点映射到一个预测 Junction；映射成
自环的对象和映射到同一原子对的碰撞会计入 diagnostics。芳香键集合无法通过 RDKit
Kekulé 校验时，编译器才按可见 SINGLE/DOUBLE 线型降级，并明确记录
`aromatic_fallback=true`。

`Data/images/test1.png` 已完成真实单图 smoke，可以生成 SDF 和渲染图。该结果只证明
端到端链路已经接通，不是准确率结论；公开 USPTO/MR-TADF benchmark 尚待固定本协议
后重新运行。

内部 498 张真实端到端评测结果：Junction exact 59.84%、SDF 有效率 53.41%、
非立体结构一致 30.12%、完整化学图一致 19.48%。匹配文字 Junction 的 OCR 元素
准确率为 95.37%，主要失败是 177 张非法价态，以及端点到 Junction 的远距离误映射。

将两端独立最近映射替换为“全局唯一 Junction 对”后，前 100 张完整一致从约 16%
降到 13%、有效率降到 45%，最大映射距离达到 299px。该硬约束 NO-GO；下一步训练
带 NULL 类别的 Junction-Bond Assembler，而不是强迫每个预测 BondObject 必须成边。
