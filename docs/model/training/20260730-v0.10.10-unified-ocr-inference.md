# 2026-07-30 v0.10.10 统一 OCR 推理接入

> 状态：工程 GO，默认前端 profile 已切换  
> 新训练：无，复用 v0.10.3/v0.10.5/v0.10.8/v0.10.9 checkpoint

## 目标

把已经分别通过门控的结构、角色、文字框和 OCR 组件接入同一条图片到 SDF 推理链，避免前端
继续运行“所有文字按 C 占位”的旧 profile。

## 推理链

1. v0.10.3 枚举全部最终 AtomObject 无序对并识别键。
2. v0.10.4 对完整 5/6 元芳香环做整环 chemical type 提升。
3. v0.10.5 在每个 Atom anchor 判断 TEXT/IMPLICIT。
4. v0.10.8 对 TEXT 回归文字 bbox。
5. v0.10.9 对 bbox crop 输出开放 byte 字符串。
6. 仅对能被标准原子标签 parser 解析的字符串写入 SDF 原子状态；未知开放字符串保留在诊断中。
7. 文字框写回后重新计算所有入射键端口，避免键穿过文字中心。

ChemScene 编译器现在显式返回“场景 AtomObject -> 原候选 index”映射，OCR 不再依赖隐式顺序。
