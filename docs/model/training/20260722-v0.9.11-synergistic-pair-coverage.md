## Target-Free Whole-Set Veto

规则只读取以下部署时可用的信息：

- B scorer 的 pair score；
- 初始 disjoint matching 选中的 pair；
- pair 的两个 anchor ID；
- frozen P0 解码出的有限线段坐标。

它不读取 target line ID、GT group、分子结构或化学标签。所有初始选中 pair 先按 score
从高到低排序；对每个较低分 pair，只允许所有更高分 pair 作为 contributor。候选 pair 的
两条 decoded line 各均匀采样 `65` 点，方向采用无向夹角，允许范围为 `<=6` 度，线段 tube
半径为 `3px`。角度判定在冻结的原生 FP32 坐标上使用
`abs(dot) + 1e-7 >= cos(6 degrees)`，其中 `angle_dot_tolerance=1e-7` 是固定协议字段。

只有同时满足以下条件才 veto 当前 pair：

1. 所有更高分 contributor pair 的联合覆盖，在当前 pair 两条线上的共同覆盖率
   `>=98%`；
2. 任意单个 contributor pair 对两条线的共同覆盖率都 `<90%`，即不能由一个更强 pair
   单独解释；
3. 至少有 `2` 个 contributor pair，且每个 contributor 对两条线的平均覆盖率
   `>=10%`。

这要求冗余必须由多个更强 pair 的协同覆盖解释，不能因一个近似重复 pair 就触发删除。
veto 是同步的：全部判断都基于同一份初始 matching，不让先 veto 的结果改变后续判定。
被 veto 的 pair 只退回为两个 singleton，不重新配对，也不修改其他 pair。

## 离散覆盖修复与性能实现

早期快速上界按连续区间长度估计覆盖率。该估计可能把离散采样点之间的空隙也计入缺口，
从而在真实 `65` 点离散覆盖已经达到门槛时产生假阴性。最终实现改为严格的离散投影上界：

- 在与正式判定相同的 `65` 个 query sample 上计算；
- 把所有角度合格的 contributor 有限线段投影到 query 轴；
- 投影区间按 `3px` tube 扩张，只在离散 sample 不可能达到 `98%` 时提前退出；
- 正式覆盖仍计算 sample 到有限 contributor segment 的真实距离。

精确距离计算使用逐分量平方和 `dx*dx + dy*dy`，避免额外向量临时量；decoded geometry
保持原生 FP32。该组合既保留离散协议，也把完整 calibration900 的 pipeline p95 压到
`20ms` 门槛以内。

## 结论与下一步

本轮证明 whole-set coverage 能在不损伤 m2 recall、P2 preservation、pairable exact 和普通
support 的前提下，删除低阈值 B 的最后一个 calibration cross，并满足 CPU 前处理的
`<20ms` 门槛。机制命中了 leftover-anchor bridge，而不是通过提高统一阈值牺牲真 pair。

但这仍只是 **post-hoc train/cal development audit**。规则是在观察 calibration 残差后设计的，
