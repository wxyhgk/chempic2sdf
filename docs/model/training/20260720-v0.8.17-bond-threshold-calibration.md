# v0.8.17 Bond Threshold 校准

> 状态：骨架召回改善，端到端 NO-GO  
> 日期：2026-07-20

## 目标

验证 v0.8.16 剩余骨架错误是否只是固定 `0.25` Bond threshold 过高。所有阈值只在
train 前 500 张选择，validation 498 和 USPTO clean 1k 不参与选择。

## Train 500

端点聚合半径固定 12px：

| threshold | Node count exact | Vertex exact | Topology exact |
|---:|---:|---:|---:|
| 0.10 | 67.80% | 65.80% | 63.40% |
| 0.15 | 74.00% | 72.00% | 70.40% |
| 0.20 | 76.60% | 74.80% | 73.80% |
| 0.25 | 77.60% | 76.00% | 73.20% |
| 0.30 | 76.00% | 74.00% | 69.20% |

按 topology exact 选择 `0.20`。

## Validation 498

| 指标 | threshold 0.25 | threshold 0.20 |
|---|---:|---:|
| Node count exact | 72.49% | 74.10% |
| Vertex exact | 70.68% | 72.09% |
| Topology exact | 67.67% | 69.68% |

阈值降低只带来约 2pp 骨架收益。

## USPTO Clean 1K

| 指标 | threshold 0.25 | threshold 0.20 |
|---|---:|---:|
| 纯骨架连通 exact | 73.20% | 76.00% |
| SDF valid | 73.00% | 69.10% |
| 完整化学一致 | 13.10% | 13.20% |
| 只错 Bond count | 45 | 20 |
| 同数量错连 | 1 | 0 |

低分候选中确实存在被 0.25 丢掉的真键，但无条件接纳也带来更多无效结构，端到端
几乎没有净收益。因此固定 0.20 不替换 v0.8.16 shadow 默认。

## 决策

- 语义端点和连边关系不是主要错误：数量一致时错连仅 0 至 1 张。
- 当前骨架瓶颈是 Bond candidate 召回与整图数量选择。
- 下一步使用 0.25 高置信骨架和 0.20 至 0.25 rescue pool，训练不依赖 GT Junction
  输入的 whole-set keep/drop；特征必须包括完整 line-band、端点聚合一致性和整图上下文。
- 禁止退回 stroke 顶点计数，也不能直接把所有低分候选加入 SDF。
