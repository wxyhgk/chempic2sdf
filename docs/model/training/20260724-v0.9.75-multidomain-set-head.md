# v0.9.75 多域 Set/Incidence Head

## 目标

v0.9.72 在 full-v0 validation 上明显高于 ChemVision，MR-TADF 又回退，说明 set/incidence
联合表示存在渲染域偏移。v0.9.73 的稳定 Bond adapter 容量不足，v0.9.74 的语义 proposal
分组未改善真实 SDF。本轮冻结视觉、Atom proposal 和 Bond proposal，完整重训 presence 与
incidence head。

## 数据

三个训练域严格等量，各 6,000 张：

- ChemVision semantic renderer；
- webdataset_full_v0 四布局；
- MolGrapher synthetic 原始绘图风格。

三个 validation 域各固定 498 张，checkpoint 首先最大化最弱域 full-object exact，再看 pooled
exact。MR-TADF 和 USPTO 不参与训练、阈值或 checkpoint 选择。

输出：

`outputs/checkpoints/chemvector-v0975-multidomain-set-head-balanced18k/`

## 结果

在第一个 4,500 总样本检查点触发 NO-GO，按门控停止，没有继续消耗剩余 13,500 张：

| 域 | 初始 full exact | 4,500 样本 |
|---|---:|---:|
| ChemVision | 34.54% | 31.33% |
| full-v0 | 40.76% | 39.76% |
| MolGrapher | 1.00% | 0.80% |

MolGrapher 初始 Atom/Bond proposal recall 只有 85.73%/78.76%。只重训 set/incidence
无法恢复从未进入 proposal 集合的对象，而且同时损害两个旧域，因此本轮为 NO-GO。

结论：下一步先进行多域 Atom/Bond proposal 训练，以 proposal recall 作为 checkpoint
选择指标；proposal 覆盖改善后再重训 set/incidence。
