# 2026-07-29 v0.10.4 Direct AtomPair 完整芳香环

> 状态：完成，编译器 GO / 默认部署待 OCR
> 基础 checkpoint：`outputs/checkpoints/chemvector-v0103-direct-atom-pair-style10k/selected.pt`
> 评测目录：`outputs/evaluations/chemvector-v0104-direct-aromatic-calibration`

## 目标

保持 v0.10.3 的 Atom、Bond presence 和 skeleton 逐位不变，只解决局部 ribbon 无法稳定区分
普通单双键与芳香环 Kekule 画法的问题。验证完整 5/6 元环是否应作为一个 chemical object
联合解码，而不是独立修改每条键。

## 协议

1. 使用 v0.10.3 presence threshold `0.85` 形成预测图。
2. 用有长度上限的 chordless-cycle 枚举预测图中的全部完整 5/6 元环，不依赖任意 cycle basis。
3. 环内 aromatic 概率均值和最小值同时过门槛才接受。
4. 接受后一次性把整环提升为 `AROMATIC`；非环键、未完整闭合的环和证据不足的环不修改。
5. 不修改 Atom、Bond presence、端点或 skeleton。

## 数据与校准

- fresh calibration：500 张，搜索 mean/minimum aromatic threshold。
- fresh evaluation：独立 1,000 张，阈值锁定后只评测一次。
- 最终阈值：mean `0.40`、minimum `0.05`。
- MR-TADF、USPTO 和 sealed test 不参与阈值选择；sealed test 未读取。
- 首轮诊断发现评测入口未开启 CUDA deterministic，pair 数与 v0.10.3 相差 216；该轮作废。
  补齐 seed、deterministic algorithms 和 cuDNN 配置后重跑，计数与 v0.10.3 完全一致。

`+9.9pp/+1.46pp`，正式 `GO`。v0.10.4 不产生新权重，checkpoint SHA 与 v0.10.3 相同；新增
前端非默认 profile `structure-v0104-direct-aromatic-carbon`。开放 OCR 尚未接入，因此不替换
当前默认 profile。
