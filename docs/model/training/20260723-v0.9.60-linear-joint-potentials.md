# v0.9.60 线性联合势函数

> 状态：训练集门控 NO-GO  
> 解码器：冻结 v0.9.58 MILP 约束  
> 数据：train-only 500 个候选图，482 个完整可表达图  
> validation/internal：未运行

## 目标

保持 v0.9.58 的约束和 endpoint top-2 不变，只学习五个全局势参数：

- Atom presence weight / bias；
- Bond presence weight / bias；
- incidence relative log-probability weight。

使用 averaged structured perceptron。每次由当前 MILP 解码整图，再用 GT 图与预测图的整图特征差
更新参数。训练样本必须满足 Atom/Bond proposal 全覆盖、所有真实 Bond incidence 可监督、GT
endpoint 位于 top-2、无重复 pair、所有 Atom 都有 incident Bond。

## 结果

- 候选 train 图：500；
- 可表达图：482；
- structured updates：169；
- 同集 exact：313/482 = 64.94%；
- 学习后同集 exact：313/482 = 64.94%；
- 正式训练耗时：20.37 秒。

平均势函数：

```text
atom weight = 0.981721
atom bias   = -0.019824
bond weight = 0.976385
bond bias   =  0.006195
incidence   = 0.447362
```

参数只轻微缩放初始化 `1/0/1/0/0.5`，没有改变任何整图 exact。按照训练集强门控，不消耗
validation，也不接 locked internal_test。

## 决策

- 五个全局线性势：NO-GO；
- v0.9.58 固定势与 MILP 继续作为当前结构 shadow；
- 下一步使用 proposal 级非线性势函数，输入 Atom/Bond 局部特征、incidence margin 和整图上下文；
- 先做固定 100 图容量实验，不能过拟合到高整图 exact 就不扩到 9k。
