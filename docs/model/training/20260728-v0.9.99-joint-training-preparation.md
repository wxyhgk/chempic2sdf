# v0.9.99 联合训练数据协议与工程 Smoke

## 目标

v0.9.98 证明 residual/action-verifier 缺少可学习 rescue，补丁支线停止。本轮不追求能力指标，
只完成大规模 Bond proposal、set presence、endpoint incidence 联合训练前的两项准备：

1. 固定 style train、fresh dev、sealed test 的数据协议；
2. 验证三域联合 loss、梯度和标准 checkpoint 的工程闭环。

## 数据现状

现有可用数据：

- `webdataset_full_v0`：180,000 个 molecule、720,000 张图；
- 其中 train molecule 162,008；
- `chemvision_layers_v0_1/pilot_10k`：9,000 张 train；
- `chemvision_layers_v0_2/font_pilot_10k`：9,000 张扩展字体 train。

full-v0 的分子规模足够，但扩展字体/语义分层数据只有 9,000 张，而且当前 validation/internal
已被多轮版本观察，不能继续充当 fresh 泛化证据。

## 新数据协议

新增：

```text
Data/sdf/chemvector_joint_v1/README.md
```

要求交付：

- `style_train_100k`：25,000 molecule、四渲染、100,000 张图；
- `fresh_dev`：2,000 molecule、8,000 张图；
- `sealed_test`：1,000 molecule、4,000 张图；
- fresh molecule/InChIKey/scaffold 与全部旧数据重叠为 0；
- train/heldout font family 隔离；
- commitment 在模型首次读取 fresh_dev 前固定；
- sealed_test 只在 candidate 通过 fresh_dev 后解封。

MR-TADF、USPTO 和旧 internal 不得成为该数据来源。

## 联合训练结构

工程入口：

```text
chemvector/train_joint_bond_set_multidomain.py
```

冻结：

- shared vision；
- Atom proposal head。

联合训练：

- 997,305 参数 multiscale Bond head；
- 178,565 参数 set presence/incidence head。

训练目标：

```text
dense Bond object loss
+ proposal set presence/incidence loss
+ 0.1 * graph-exact surrogate
```

set loss 通过被选中的 Bond features、scores 和 endpoints 回传到 Bond head；proposal top-k 和
Hungarian supervision 本身保持离散、target-independent。

## 三域工程 Smoke

在 fresh 数据未到位前，仅使用现有三域各 2 张：

- ChemVision v0.1：2；
- expanded-font v0.2：2；
- full-v0：2；
- 总计 6 张、1 个 optimizer step。

结果：

| 项目 | 数值 |
|---|---:|
| Total loss | 3.1003 |
| Bond loss | 1.9383 |
| Set loss | 1.1620 |
| Graph-exact surrogate | 1.6619 |
| Bond changed tensors | 50 |
| Set/incidence changed tensors | 39 |
| Bond maximum parameter delta | 1.01e-6 |
| Set maximum parameter delta | 2.03e-6 |

所有 loss、梯度和 checkpoint 均有效，证明 Bond 与 set/incidence 确实同时更新。6 张图的 exact
变化不具统计意义，不作能力结论。
