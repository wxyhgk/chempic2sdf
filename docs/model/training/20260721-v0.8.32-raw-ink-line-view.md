# v0.8.32 Raw Ink Line View 端点细化

> 状态：受控几何实验 GO；尚未接入稳定推理  
> 日期：2026-07-21  
> 基础分支：v0.8.30 endpoint-local local-only  
> 稳定推理：仍为 v0.7.10

## 目标

验证 v0.8.31 的问题是否来自特征图压缩和无向池化，而不是整根键视觉证据本身无效。
本轮直接读取原始图片中的墨迹，并让两个端点分别从“朝向键内部”的方向观察同一候选，
只预测端点几何修正。

## 实现

对每个 Dense Bond proposal 的基础端点，从归一化原图构造 raw-ink line view：

- 沿候选键的 4%-96% 区间采样 64 个位置；
- 垂直候选方向在 `-12 px` 到 `+12 px` 采样 25 行，形成 `25x64` 墨迹带；
- RGB/灰度图先转换为 `ink = 1 - gray`；
- endpoint A 使用正向 view，endpoint B 使用旋转 180 度的 view；
- 共享 CNN 将每个 view 编码为 64 维特征；
- 小残差头预测“沿键方向、垂直键方向”两个偏移，再旋转回图像坐标；
- raw-ink 修正与 v0.8.30 endpoint patch 修正独立相加。

raw-ink 残差头和 endpoint-local 残差头的最后一层均为零初始化。该 Group Query 分支
总参数 1,666,835；全局路径、presence/type heads、视觉编码器和 Dense Bond 均冻结，
只训练 243,812 个局部参数。

沿用固定 molecule-isolated split：


训练 4,000 exposure，每张训练图片曝光 5 次，batch size 8、学习率 `1e-4`、weight
decay 0、collision bond 权重 16、端点尺度 0.1、每 400 exposure 验证，随机种子
20260721。MR-TADF、USPTO 不参与训练、选阈值或选 checkpoint。

预设 GO 条件与前三轮完全相同，未因观察结果修改：secondary recall 至少 50%、cell
exact 至少 18%、ordinary known-object 回退不超过 0.5pp、protected retention 至少 95%，
并且 count 与所有非几何输出不变。

## 结果

容量实验最佳为 79.21% collision cell exact、91.20% secondary recall，证明 raw-ink
分支可训练。正式 early4k 最佳点出现在 2,400 exposure：

| 指标 | Step 0 | v0.8.30 patch | v0.8.31 feature band | v0.8.32 raw ink |
|---|---:|---:|---:|---:|
| Holdout cell exact | 1.00% | 16.00% | 14.00% | **18.00%** |
| Holdout secondary recall | 16.04% | **52.83%** | 51.89% | 50.94% |
| Holdout collision bond recall | 11.17% | **44.17%** | 42.72% | 43.69% |
| Holdout all-bond geometry recall | 68.84% | 76.10% | 75.89% | 76.01% |
| Holdout protected retention | 100.00% | 98.79% | 98.75% | 98.79% |
| Ordinary known-object accuracy | 70.66% | 71.21% | **71.26%** | 71.20% |
| Ordinary protected retention | 100.00% | 99.67% | 99.68% | **99.70%** |

v0.8.32 不是所有单项都优于 v0.8.30：secondary recall 低 1.89pp，collision bond recall
低 0.49pp；它的收益集中在整 collision cell 同时正确，由 16 个提高到 18 个。按照训练
前固定的联合门槛，五项检查全部通过，`go_checks.go=true`。

所有 presence、display、chemical、direction logits、proposal mask 和 Poisson-binomial
count 与基础候选一致，最大绝对差为 0。该不变量是冻结协议的结果，不能解读为这些任务
已经解决。

独立按 cell occupancy 复核后，18 个完整正确 cell 全部来自 occupancy 2：

| Holdout occupancy | Candidate recall | Secondary recall | Cell exact |
|---|---:|---:|---:|
| 2，94 个 cell | 45.74% | 54.26% | 18/94，19.15% |
| 3，6 个 cell | 4/18，22.22% | 3/12，25.00% | 0/6 |

因此本轮应精确记录为 `formal geometry GO / occupancy-2 mechanism GO /
occupancy-3 mechanism NO-GO`，不能表述为同中心三键已经解决。

冻结几何后的排序审计进一步确认了下一瓶颈。v0.8.32 的全部 128 个 refined candidates
在 collision holdout 中达到 43.69% candidate recall、50.94% secondary recall 和
18% cell exact；仍使用未训练的旧 presence logits 做 GT-known-count top-k 后，只剩
9.71%、14.15% 和 2%。当前排序分别只保留几何候选上限的 22.22%、27.78% 和
11.11%，因此下一阶段转向 presence selector 有直接证据，不再继续猜测端点几何。

## 决策

- 原始墨迹、endpoint-oriented line view：GO，是当前唯一通过预设联合门控的受控端点
  几何分支；
- occupancy 2 机制：GO；occupancy 3 机制：NO-GO，保留为后续独立上限问题；
- v0.8.32 checkpoint 仅作为实验 checkpoint 保留，尚不替换 v0.7.10 稳定推理；
- v0.8.31 feature line-band 不进入默认分支；
- 下一阶段冻结 v0.8.32 geometry，只训练候选 `presence_residual` 或独立 selector，检查
  “正确 refined candidate 已存在，但被 ranking/threshold 截断”的错误；
- 在接入推理前，必须补充完整 skeleton、SDF valid、公开 OCSR 和 CPU 延迟评测。

## 限制

- holdout 只有 100 个 collision cell，18% 恰好等于门槛，较 v0.8.30 只多 2 个样本；
- raw-ink view 以基础 proposal 为中心，基础候选完全缺失或严重偏离时无法恢复；
- 当前只训练端点几何，不改变候选数量、排序、键级、原子文字或化学有效性；
- ordinary validation 的 known-object 指标是候选对象诊断，不是端到端 SDF 准确率；
- 本轮未用 MR-TADF 或 USPTO 调参，因此也未宣称其外部分布已经提升。
