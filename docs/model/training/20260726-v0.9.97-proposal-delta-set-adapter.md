# v0.9.97 Proposal-Delta Set Adapter

## 目标

v0.9.96 训练全部 178,565 个 set/incidence 参数时，新 proposal 与 style 改善，但原 proposal
路径回退。v0.9.97 冻结 vision、Atom、Bond、v0.9.95 residual 和完整 set/incidence，只增加
读取“新旧 Bond proposal 差异”的零初始化 adapter。

原 proposal 路径不调用 adapter，因此是结构上的逐位不变，而不是通过 teacher loss 近似保持。

MR-TADF、USPTO 未参与训练或选模。locked internal 仅在 epoch 1 通过 official 后运行一次，
且未用于后续 scale、阈值或 epoch 选择。

## Proposal 对应协议

新旧 detector 的 top-k 排名可能变化，不能假设相同 query 下标对应同一个候选。对 style
validation 的前 100 张做 target-independent 审计：

- candidate proposal 总数：19,160；
- 新旧 dense `(slot, cell)` 交集：18,486，覆盖 96.48%；
- 每图 proposal-set 平均 Jaccard：93.22%。

adapter 不按 top-k rank 对齐，也不使用 GT 做匹配。每个新 proposal 自带原始 dense index，
直接用该 `(slot, cell)` 回查原 detector 在相同位置的 score 和 endpoints：

```text
score_delta    = new_score - original_score_at_same_dense_index
endpoint_delta = new_endpoints - original_endpoints_at_same_dense_index
```

该信息在部署时可直接计算。

## Adapter

共 2,306 个参数，分成两个零初始化头：

1. Bond presence residual：读取 score/endpoint delta、原始 set logit 和 incidence margin；
2. Incidence residual：读取 endpoint delta、新旧 endpoint 到 Atom anchor 的相对位置和原始
   incidence logit。

最后一层权重与偏置全部为 0。初始化时 Bond presence 与 incidence logits 逐位等于 v0.9.95。
Atom presence 完全不修改。

## 数据与训练

- paired style：250 个 molecule、1,000 张图；
- replay：ChemVision 500 张、full-v0 500 张；
- 每 epoch：1,000 style + 1,000 replay；
- 3 epoch，总曝光 6,000 张；
- learning rate：`1e-4`；
- residual L2 weight：`1e-4`；
- official validation：ChemVision/full-v0 各 498 张；
- style validation：498 张。

## 决策

v0.9.97 架构/official GO，部署 NO-GO：

- dense-index delta 协议不依赖 GT，可部署；
- 2,306 参数 residual 比 v0.9.96 的共享重训更稳定；
- 原 proposal 路径由 bypass 保证逐位不变；
- epoch 1 在 style 和 official 双域均有净增益；
- locked full-v0 回退 1 张，不接默认前端；
- 默认继续使用 `structure-v0992-carbon`。

locked 已消费，不再用于本版本调参。下一步回到 train-only 样本，为具体 adapter action 训练
安全 verifier；它只能放行预测为零回退的 residual 动作，再以 official validation 选阈值。
