# v0.9.30 OCR 与 Graph Corrector A/B

## 目标

v0.9.29 证明 USPTO clean 1k 的纯骨架 exact 为 72.4%，但整分子原子类型 exact 只有 29.2%、
键级 exact 为 50.5%。本实验固定 Bond/Junction、对象数量和阈值，只验证两个现成替换是否能直接
提升完整链路：

1. 将 v0.8.8 10k CTC 换成已训练 150 万次样本的 v0.8.11 Open Text CTC；
2. 关闭或仅在最终编译失败时启用旧 graph type corrector。

门控使用相同的 USPTO clean 前 100 张。MR-TADF 不参与训练、阈值或方案选择。

## 对象级 Micro 复核

整分子 exact 是合取指标。v0.9.29 的 1k sidecar 增加拓扑同构条件下的最优属性对齐后，得到：

- 单原子类型：22,092/22,906，`96.45%`；
- 单键级：22,501/25,270，`89.04%`；
- 拓扑同构枚举截断：0。

这说明原子错误较少但分散在 432 个分子，键级错误更多但集中在 219 个分子。两种粒度必须同时报告，
不能将 29.2% 的整分子原子 exact 误写成单字符准确率。

键级混淆高度集中：

- `AROMATIC -> SINGLE`：2,516；
- `AROMATIC -> DOUBLE`：157；
- `DOUBLE -> SINGLE`：50；
- 其余类型合计很少。

`AROMATIC -> SINGLE` 占全部键级错误的 90.9%，说明旧 corrector 的少量错误 chemical type 改动
会破坏整圈芳香化，而不是所有键类型都同样困难。

## A：Open Text CTC 直接替换

checkpoint：`outputs/checkpoints/chemvector-v0811-open-text-full-1500k/full/best.pt`。

| 指标 | v0.9.28 | Open Text |
|---|---:|---:|
| SDF valid | 77% | 61% |
| 化学 exact | 19% | 0% |
| 纯骨架 exact | 76% | 76% |
| 原子类型 + 骨架 | 29% | 1% |
| 单原子类型 micro | 96.42% | 84.63% |
| 完整非立体图 | 23% | 1% |

Open Text 输出大量 `NH/CH/NN/BH` 等错误后缀，未解析字符串进一步成为 dummy `*`。该 checkpoint
虽然在自身真实预测框 validation 达到 81.5%，但与 USPTO 当前检测框、字体和线条污染域不一致。
直接替换正式 NO-GO；不能用训练集 validation 指标代替公开端到端门控。

## B：关闭 Graph Corrector

| 指标 | v0.9.28 type-only | graph none |
|---|---:|---:|
| SDF valid | 77% | 67% |
| 化学 exact | 19% | 18% |
| 键级 + 骨架 | 56% | 61% |
| 单键级 micro | 89.47% | 96.15% |
| 完整非立体图 | 23% | 25% |

关闭 corrector 明显保护了原始 BondObject 键级，但损失 10pp SDF valid。旧 corrector 同时具有
“救无效图”和“破坏正确芳香键”两种相反作用，不能全开或全关。

## C：Graph Invalid-Only

新增 `graph_correction_mode=invalid_only`：先执行原始 BondObject、原子 invalid-only 解码和最终
aromatic fallback；只有最终仍无法编译时才启用 graph type corrector。

| 指标 | v0.9.28 | invalid-only r2 |
|---|---:|---:|
| SDF valid | 77% | 79% |
| 化学 exact | 19% | 19% |
| 键级 + 骨架 | 56% | 55% |
| 单键级 micro | 89.47% | 90.47% |
| 完整非立体图 | 23% | 23% |

该模式只触发 12 张并将 valid 提高 2pp，但未增加完整正确结构，键级整图还回退 1 张。因此机制作为
实验能力保留，当前 checkpoint/profile 不切换。

## 决策

- Open Text 1500k 直接接入：NO-GO；
- graph corrector 全关闭：NO-GO；
- graph invalid-only 协议：工程 GO / 模型替换 NO-GO；
- v0.9.28 shadow 和稳定默认不变。

下一实验使用最小改动结构化键解码：对 graph corrector 提议的 chemical type 变化做有限组合搜索，
以“能够 sanitize、修改键最少、芳香环破坏最少”为确定性目标，不再一次应用全部预测类型。
