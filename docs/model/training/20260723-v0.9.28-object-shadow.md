# v0.9.28 完整对象 Shadow

## 目标

停止继续叠加 pair-stage residual/veto/component scorer 后，冻结一条真实可运行的完整链路：

```text
PNG -> BondObject/TextObject -> Junction -> ChemScene -> SDF
```

本版本不训练新权重。它固定当前经过验证的八个组件 checkpoint、参数和 SHA，用于单图试用、
公开 benchmark 和后续逐组件归因。MR-TADF 不参与训练、阈值选择或 checkpoint 选择。

## 冻结协议

- profile：`chemvector/shadow_v0928.json`
- 单图入口：`python -m chemvector.infer_shadow_v0928`
- Bond：top-128 selector + junction-aware bond grouping
- Junction：视觉端点聚合
- OCR：预测 bbox + CTC
- 图修正：只修正键类型，不执行删边
- 原子解码：仅在 sanitize 失败时执行有限状态搜索
- 输出：ChemScene、有效或 diagnostic SDF、SDF 渲染图和指标
- checkpoint 数量：8，启动时逐个校验 SHA256

无效 SDF 使用 `sanitize=False` 仅作诊断渲染，指标仍明确记录 `sdf_valid=false`，不会冒充有效结构。

## 决策

`v0.9.28 Object Shadow` 可以用于真实图片试用和统一收集失败样本，但不能替换稳定默认：

- 完整图片到 SDF 链路：GO
- 正确、错误、无效产物保存与渲染：GO
- 前端实验 profile：GO
- 默认稳定模型替换：NO-GO
- pair-stage scorer 继续调参：停止

下一阶段不再以单个 pair 指标代替端到端结果。训练目标转为完整对象集合，门控同时检查公开集的
对象计数、无标签拓扑、原子类型、键类型、SDF valid 和完整结构一致率。
