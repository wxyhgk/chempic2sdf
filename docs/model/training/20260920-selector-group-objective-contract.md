# 组级 selector 监督：CPU 数学契约，不是第三轮试训

## 范围和状态

本原型只用合成的 CPU leaf logits 验证目标函数及其直接梯度，不读取真实训练／开发图片或预测，不构造模型、不加载 checkpoint、不执行 optimizer、不使用 GPU，不修改已有 matcher 或选择阈值。`training_authorized=false`。这不是训练准入或准确率结论。

## 唯一候选目标

沿用选择规则 `z >= -0.25`，令 `u = z - (-0.25)`。对同一化学节点的一组有效候选 `A`，定义独立 Bernoulli 概率 `p_i = sigmoid(u_i)`：

```
P(exactly one | A) = Σ_i p_i Π_{j != i}(1-p_j)
L_node(A) = -log P(exactly one | A)
          = Σ_i softplus(u_i) - logsumexp_i(u_i)

L_fragment = mean_{明确片段 i} softplus(u_i)
L = mean_{有效节点组 A} L_node(A) + L_fragment
```

两项系数固定为 1，无系数搜索。实现使用 log-space 的“零个／一个”状态递推，避免极端分数下大数相减。它只是一种节点／片段级数值契约，不与现有完整训练损失相加，也不决定未来实际训练目标。

原始 raw 正候选仅作为准入门槛：有效组必须已有至少一个稳定代表。组内有效替代候选与 raw 正候选完全同权，不按 raw 标签逐个做负例压制。未知归属、投影／量化敏感、没有可用代表的节点必须带原因排除；其片段也不接新监督。多节点归属重叠不择近修正，直接拒绝输入。

## 明确失败条件：数值通过不等于可训练

这个目标不含 `argmax`、winner tie-break 或伪标签，但仍存在无法回避的限制：

- **不只精确平局失败：**三候选均为 `z = -0.35`（比原阈值低 0.1）时全部漏选，但每个梯度为 `sigmoid(-0.1)-1/3 ≈ +0.1417`，梯度下降会进一步压低全部有效候选。改成不同分数 `-0.36, -0.35, -0.34` 仍然全部向下，故失败存在于一个开邻域，不能依赖“真实分数不完全相等”规避。
- 若一个节点有 `k >= 2` 个完全相同分数的候选，在 `u_i = -log(k-1)` 处每个梯度都为零。
- `k=2` 时驻点就在原阈值，硬选择得到两个候选；`k>2` 时所有候选都低于阈值，硬选择得到零个。二者都不是恰好一个。
- 二候选驻点沿候选差异方向是负曲率、沿共同移动方向是正曲率，即鞍点。对称直接梯度不会自行破缺。不能加入未批准的随机扰动或硬 winner 来掩盖问题。
- 不对称分数会偏向现有较强的有效候选。组内空间可替代并不意味着其键连接、属性等完全等价；本目标不检查那些属性。
- 它不满足 **“漏选时至少抬升一个有效代表”** 的最低契约。二候选漏选、或整组分数足够低时可能向上，并不足以证明一般的漏选保护。概率恰好一个与阈值后恰好一个不是同一个目标；不保证有限更新后恰好一个、不保证键端点覆盖，也不会修复候选定位。
- 未引用／排除候选只保证此原型的直接 logit 梯度为零。共享参数更新和现有其他损失仍可能改变它们；本原型没有测量这些相互作用。

因此当前结论是 **该单一数学候选已被 CPU 反例拦截，NOT READY FOR TRAINING，不是 GO**。没有添加 winner、随机打破对称、权重搜索或另一个目标来绕过反例。真实保存 logits 的只求导接线检查可报告梯度、驻点和准入覆盖，但不能当作模型效果改善，更不能据此自动启动训练。

## API 与检查

`tools.selector_group_objective.GroupSpec(node_id, acceptable_slots, representative_slots, fragment_slots=(), exclusion_reason=None)` 定义节点组；所有 slot 都是调用方一维 logits 中的整数索引。

`evaluate_group_objective(logits, groups)` 返回总损失、节点／片段损失、逐节点损失、参与／排除节点和有监督 slot。`ObjectiveResult.training_authorized` 恒为 `False`。输入限定 CPU float32/float64 且全部有限；不读取任何文件。

合成检查涵盖：精确枚举 Bernoulli 结果、`gradcheck`／二阶梯度检查、解析梯度 `sigmoid(u)-softmax(u)`、二候选漏选／重复的梯度方向、三及五候选漏选却全体下压的显式反例、有效替代保护、片段下压、排除和未知零梯度、输入不变、候选／节点顺序不变性、原始代表标签互换不变性、极端正负 1000 分数、错误组准入拒绝，以及上述对称驻点的显式失败反例。
