# v0.9.26 组件 Structured Matching OOF

> 状态：正式 3-fold OOF 已完成，结论为 `FIT-OOF-COMPONENT-STRUCTURED-NO-GO`。
> 组件枚举和结构 loss 可运行，但模型利用 baseline gain 形成捷径，未识别真正决定 cross 的活跃 negative。

## 目标

v0.9.25 证明多节点组件 oracle 可将 v0.9.23 的 cross 从 16 降到 8。本轮第一次把组件 matching
作为训练和推理的真实决策单元，而不是继续给每个 pair 独立打 veto 分。

## 冻结 sidecar

先冻结 v0.9.23 OOF baseline，并在每个 `anchor_count > 2` 组件中枚举所有由 baseline 激活边组成的
endpoint-disjoint matching：

```text
7,200 images
368,573 total pair candidates
23,159 active multi-anchor components
45,219 active component edges
90,396 feasible matchings
target-aware fields in cache = 0
```

孤立 pair 不进入新模型的决策范围，完整旁路 v0.9.23。

## 模型与 loss

154,497 参数模型包含：

- 480D 不降采样 profile 编码；
- pair token、baseline gain 和组件大小特征；
- 两轮共享-anchor message passing；
- 每条边一个 matching energy residual；
- 组件配置级 log-sum-exp structured loss；
- 全部多节点边的 positive/negative 辅助分类；
- 活跃 positive safety 和活跃 negative margin loss。

推理时模型只能从 v0.9.23 已激活边中删除。每个组件选择一个完整 matching，未选边降到 threshold
以下，选中边保留原 baseline score；不存在 score increase 或 rescue。

## 正式结果

| 指标 | v0.9.23 baseline replay | structured component |
| --- | ---: | ---: |
| selected cross | 16 | 16 |
| M2 recall | 99.64116% | 99.64016% |
| pairable exact | 96.39979% | 96.36551% |
| pairable exact count | 5,623 | 5,621 |
| parallel-2 violations | 1 | 1 |
| support lost | 21 | 21 |
| selected pair precision | 99.99489% | 99.99489% |

三折合计删除 477 条 positive、3 条 negative。3 条 negative 都没有参与最终错误 matching，因此 cross
完全不变；同时两张原本 exact 的图片变错。正式结论为 NO-GO，不能接入 shadow。

## 失败归因

冻结 sidecar 的 45,219 条真实激活边中：

```text
positive active = 45,208
negative active = 11
```

模型虽然在全部多节点候选上见到 50,595 个 negative，但只有 11 个 negative 处于真实推理的激活分布。
OOF residual 分布为：

| 分桶 | 数量 | residual mean | p50 |
| --- | ---: | ---: | ---: |
| positive active | 45,208 | +4.9087 | +4.8998 |
| negative active | 11 | +5.0258 | +5.0947 |
| negative inactive | 50,584 | -4.5853 | -4.6346 |

活跃 negative 和活跃 positive 被模型赋予几乎相同的强正 residual。模型没有从视觉理解错误边，而是利用
输入中的 `baseline_scores` 和 pair token 最后一维 `raw_pair_gain` 学会了“高分即保留”。这解释了为何
普通 negative 分类 loss 很低，真实 cross 却一个也没修掉。

## 下一步

v0.9.27 必须同时做两项修改：

1. score-blind forward：移除 `baseline_scores` 和 `raw_pair_gain`，只允许视觉、几何和组件关系进入模型；
2. counterfactual activation：训练时把普通多节点 negative 的 matching energy 人工提升到 threshold 上方，
   迫使模型学习用视觉证据压回错误边，而不是从原始分数判断 active/inactive。

baseline score 仍可在模型外部作为 matching 的确定性初始 energy，但不得进入可学习视觉编码器。评估仍只
使用自然 OOF 分数，不做反事实修改。
