## 目标与边界

v0.9.1 已证明 Visual SVG 自回归模型能记住固定 100 图，但在未见分子上只学到语法，
没有形成可用的图片到坐标映射。本轮停止自回归 token sequence，改为固定 query 的
unordered set prediction：每个 query 直接预测图元类型、存在性和连续坐标，训练时通过
Hungarian matching 与无序真值集合对齐。

本轮只做 capacity proof 和表示诊断：

- 训练、验证和审计均只读取同一份 100 图 capacity tar；
- 不运行 pilot 9k、500 张正式 validation、USPTO 或 MR-TADF；
- `internal_test` 继续封存；
- 不把同集容量结果表述为未见分子泛化率；
- 根目录 `VERSION` 保持 `0.8.33`，生产推理不切换。

## 全模型与 Refiner A/B

从同一个 step-6,000 checkpoint、相同数据、seed、batch、LR 和 fresh optimizer 继续
1,000 step：

| 指标 | 全模型到 7,000 | 只训 refiner 到 7,000 |
|---|---:|---:|
| recall@8q | 20.50% | 65.99% |
| recall@32q | 83.13% | 88.43% |
| endpoint p50 | 13.00q | 6.00q |
| endpoint p90 | 53.08q | 37.79q |
| Bond IoU | 32.19% | 47.20% |

全模型联训会让 classification、assignment、coarse geometry 和 refiner 同时漂移；
refiner-only 则保持 query 身份和粗表示稳定，只优化局部视觉修正。该 A/B 明确支持分阶段
训练，不支持继续用一个 optimizer 同时更新全部模块。

代表命令：

```bash

  --resume-checkpoint outputs/checkpoints/chemvector-v092-primitive-set-capacity100-localq5-endpoint25-lineobj-6000/step-006000.pt \

  --learning-rate 1e-4 --local-query-kernel 5 --endpoint-refine-kernel 25 \
  --line-geometry-objective --class-cost-weight 0.5 --endpoint-refiner-only
```

## Coarse Geometry A/B

残差审计显示 step-9,000 的 987 条 `>8q` 失败中：

- hashed wedge 为 577 条，占 58.5%；
- coarse error 大于 256q 为 584 条，占 59.2%；
- 两个端点都超过 8q 为 836 条，占 84.7%；
- 与文字框接触的线 recall@8q 为 90.1%，不是主要失败源；
- 长 single/double/aromatic 已分别达到约 92.1%/92.5%/91.4%。

因此从 step-9,000 做严格对照：A 继续 refiner-only，B 只训练 coarse geometry head，
两者都是 fresh AdamW、`3e-5`、1,000 step。

| 指标 | A：refiner only | B：coarse only | 判定 |
|---|---:|---:|---|
| recall@8q | 84.08% | 80.14% | B 回退 3.93pp |
| recall@32q | 92.76% | 92.02% | B 较差 |
| endpoint p50 / p90 | 3.00 / 20.02q | 4.12 / 23.97q | B 较差 |
| Bond IoU | 63.48% | 57.50% | B 未过 58.5% 门槛 |
| hashed-wedge recall@8q | 49.76% | 43.34% | B 回退 |
| coarse >256q 占比 | 15.03% | 15.09% | 没有改善 |
| invalid | 1 | 1 | 均未满足 0 |

coarse-only 改变了 coarse 输出，却没有降低 coarse 长尾，反而让 247 条原本通过的线变为
失败，只救回 40 条。该分支正式 NO-GO，不追加 step。

## Output Heads 诊断

从 step-9,000 冻结全部几何，只训练 type/count/text/stroke 2,000 step：

- text-box F1 从 2.65% 提高到 13.03%；
- count-head 的 line/text class-count exact 提到约 42%/41%；
- 总对象 count exact 始终为 100%；
- 除 16 个指定输出头张量外，其余权重逐位不变。

但进一步取证说明这不是可继续长训的主线：

- 全局 top-k 只保留 95.38% 的 Hungarian matched query；
- 292 个真 query 被 292 个高分未匹配 query 替换，query-set exact 只有 7%；
- 即使使用 GT 分类数量，text F1 也只从 13.03% 到 13.11%；
- Hungarian oracle text F1 只有 14.34%；
- text bbox IoU p50 为 0.111，中心误差 p50/p90 为 30.69/86.60q；
- 宽高误差已经较小，问题是 query 没有空间 anchor，text head 在做远距离绝对回归。

因此 output-head 长训和新增分类 count head都不能解决核心问题，作为 flat 主线 NO-GO。

## Visual SVG v0.2 Bond Group

flat v0.1 把双键、三键和虚楔键拆成多条独立线。残差审计已经证明 hashed wedge 是当前
主要失败源，因此新增 group-aware、纯视觉、q2047 可逆协议：

```text
Data/sdf/visual_svg_v0_2.py
Data/sdf/visual_svg_v0_2/README.md
Data/sdf/visual_svg_v0_2/schemas/visual-svg-0.2.schema.json
```

支持六类：`single_line`、`parallel_2`、`parallel_3`、`hashed_wedge`、
`solid_triangle`、`solid_quad`。每个 group 内嵌精确 physical members，成员坐标是确定性
重建的唯一真源；模型 target 不含 bond ID、atom ID、键级、方向或其他化学语义。

capacity100 全量结构往返：

| 项目 | 结果 |
|---|---:|
| v0.1 physical primitives | 6,320 |
| v0.2 bond groups | 3,493 |
| v0.2 text boxes | 976 |
| v0.2 总 target objects | 4,469 |
| 最大 physical / group target | 197 / 103 |
| v0.1 -> v0.2 -> v0.1 | 100/100 exact |
| 六类 group kind | 全覆盖 |

不同 group partition 即使扁平图元完全相同，也必须序列化为不同 target；source bond ID
重编号不改变 canonical target。P0 协议 GO。

## 决策

- AR token sequence：继续 NO-GO；
- unordered set prediction：机制 GO；
- stride-4 endpoint refiner：强 GO，保留为后续 group 模型的局部几何组件；
- 全模型同步续训：NO-GO；
- coarse-geometry-only：NO-GO；
- flat output-head 长训：NO-GO；
- Visual SVG v0.2 bond-group 可逆协议：GO；
- flat predictor 尚未达到完整 primitive capacity，不能进入 9k/500 正式门控；
- 下一步先完成 `Q=192` 的 bond-group set predictor，在 capacity100 上证明 group count、
  style、members 和 flatten 后几何容量，再决定是否进入 pilot train/validation。
