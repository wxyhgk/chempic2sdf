# 2026-07-21 v0.9.0 Raster-to-Visual-Primitives Capacity

> 状态：协议与数据 GO；旧 cross-attention 视觉接地 NO-GO；后续转 v0.9.1
> 稳定推理：保持 v0.7.10，不由本实验替换
> 数据协议：[Visual SVG v0.1](../../../Data/sdf/visual_svg_v0_1/README.md)

## 目标

本轮只验证一个问题：约 50M 参数的图像条件自回归模型，能否从 768x768 化学结构图
直接生成规范化的 `LINE/TRIANGLE/QUAD/TEXT_BOX` 序列。

它不尝试在同一个模型阶段同时解决 OCR、化学 Junction、键级、价态和 SDF。只有固定
100 图容量门槛通过后，才讨论扩到 9k/50k 和把物理图元组合成 ChemScene。

## 为什么终止旧 Proposal 主线

v0.7 和 v0.8 的 proposal、selector、junction 和 bond-query 实验积累了有价值的局部
模块，但整体路线长期受同一表示矛盾限制：

```text
旧路线：像素 -> 点/键 proposal -> 去重和筛选 -> Junction/Graph -> SDF
新路线：像素 -> 可见物理图元序列 -> 图元组合 -> Junction/ChemScene -> SDF
```

旧路线要求模型在读取像素时就决定“哪一个线端点是原子”。这会系统性混淆：

- 双键的两条平行物理线与两个真实化学端点；
- 三键的三条物理线与两个真实化学端点；
- 线段内部交叉与 degree-4 Junction；
- 楔形多边形顶点与原子顶点；
- 字符笔画与键线。

扩大候选池、增加 NMS、局部 patch、line band 或 selector 能改善局部召回和排序，
但不能消除上述对象定义冲突。继续扩大训练数据只会让模型更努力拟合一个含歧义的
中间目标，因此 v0.9 先退回可直接从图片验证的物理图元。

“终止”指停止把 proposal 路线作为下一代主架构，不表示删除历史实现或改变当前稳定
推理。已有模块仍可在后续 primitive grouping 和 ChemScene 阶段复用。

## 新架构

```text
768x768 RGB
    -> 共享 ChemVisionEncoder
    -> 24x24，共 576 个视觉 token
    -> 8 层 causal decoder
    -> Visual SVG v0.1 token
    -> grammar-constrained greedy generation
    -> 物理图元与 bond-layer 验收
```

配置使用 `d_model=512`、8 层 decoder、8 heads、FFN 2048、最大目标长度 2048。
Visual SVG 词表为 2,121，完整模型实测为 49,434,096 参数。

本轮复用 `ChemVectorModel` 的视觉 encoder、cross-attention decoder、teacher forcing 和
增量缓存，不复制 StarVector 的大语言模型。二者共享的核心是条件自回归分解：

```text
p(sequence | image) = product_t p(token_t | token_<t, image)
```

模型输出中没有 atom ID、bond ID、元素、文字字符串或化学键级。`TEXT_BOX` 只定位文字
区域，OCR 在下一阶段独立处理。双键和三键在本阶段允许分别输出两条和三条物理线，
不得提前合并成化学键或生成额外 Junction。

## capacity_100 数据

固定集由 `build_visual_svg_capacity_100.py` 从 ChemVision pilot 的 train split 生成：

- 100 张图片，对应 100 个互不重复分子；
- `original/rdkit/coordgen/stress` 各 25 张；
- 预注册覆盖双键、三键、虚楔、实楔、`QUAD`、文字密集、交叉键和长键；
- 每条目标序列不得超过 2,048 token；
- MR-TADF、USPTO 和 public holdout 均不参与训练或 checkpoint 选择。

100 图实验只证明协议、损失和模型容量可用，不能证明未见分子的泛化能力。

## Teacher Forcing 假成功风险

标准 teacher forcing 把真值前缀交给 decoder。即使模型完全忽略图片，也可能根据已知
前缀和固定记录顺序获得很高 token accuracy。因此以下结果不能单独作为 GO：

- 训练 loss 很低；
- teacher-forced token accuracy 很高；
- teacher-forced sequence exact 很高。

评估必须把同一 batch 的图片循环错配，再用原标签计算 loss。固定集中的分子互不重复，
错配后不允许仍保持接近正确图片的损失。

预注册视觉接地门控：

```text
mismatch_loss_ratio = mismatched_image_loss / matched_image_loss >= 2.0
```

同时必须运行不提供真值前缀的 grammar-constrained 自由生成。只有自由生成完成、语法
合法、图元集合正确，才能证明模型实际建立了 image -> sequence 映射。

## 容量门槛

以下门槛在训练前固定，不因运行结果下调：

| 指标 | GO 门槛 |
|---|---:|
| teacher token accuracy | >= 99.5% |
| teacher sequence exact | >= 95% |
| mismatch loss ratio | >= 2.0 |
| free generation completed | >= 99% |
| grammar valid | >= 99% |
| primitive exact | >= 95% |
| bond primitive count exact | >= 95% |
| text-box count exact | >= 95% |

`line_f1`、`text_box_f1`、`bond_iou_mean` 和 `bond_iou_min` 必须同时报告，作为非 exact
样本的误差护栏，但不能代替 `primitive_exact`。渲染 IoU 应与数据构建时记录的目标
primitive 基线比较，不能用更低阈值掩盖图元缺失。

如果 teacher 指标通过但 mismatch ratio 不通过，结论是 decoder 背诵序列；如果
teacher 指标通过但自由生成失败，结论是 exposure bias 或序列终止失败；如果固定 100
图在 5,000 optimizer step 内仍不能达到 teacher 门槛，停止扩数据并回查模型或协议。

## 预注册三阶段训练

三阶段均使用相同 tokenizer、`dropout=0`、相同 100 图和完整 25-batch validation。
阶段间通过 `--init-checkpoint` 只继承模型权重，重新建立 optimizer。

实际运行在第一阶段 1,000 step 的视觉接地门控即失败，因此没有按原计划继续消耗完整
5,000 step。下面的命令保留为训练前协议，不代表三个阶段均已执行完成。

### 阶段一：视觉接地

随机遮蔽 50% 非特殊前缀 token，迫使 decoder 使用图片。基线不启用 contrastive loss，
让错配图门控独立检验视觉依赖。

```bash
CUDA_VISIBLE_DEVICES=0 .venv-train/bin/python -m chemvector.train_visual_svg \
  --train-shards Data/sdf/visual_svg_v0_1/capacity_100/shards/capacity-000000.tar \
  --validation-shards Data/sdf/visual_svg_v0_1/capacity_100/shards/capacity-000000.tar \
  --output-dir outputs/checkpoints/chemvector-v090-visual-svg-capacity-100-stage1 \
  --epochs 120 --max-steps 3000 \
  --batch-size 4 --gradient-accumulation 1 --workers 0 --no-shuffle \
  --learning-rate 3e-4 --weight-decay 0 --dropout 0 \
  --token-corruption-probability 0.5 --image-contrastive-weight 0 \
  --max-target-length 2048 --validation-batches 25 \
  --validate-every 100 --save-every 250 --log-every 10
```

### 阶段二：前缀恢复

把遮蔽率降到 10%，学习率降到 `3e-5`：

```bash
CUDA_VISIBLE_DEVICES=0 .venv-train/bin/python -m chemvector.train_visual_svg \
  --train-shards Data/sdf/visual_svg_v0_1/capacity_100/shards/capacity-000000.tar \
  --validation-shards Data/sdf/visual_svg_v0_1/capacity_100/shards/capacity-000000.tar \
  --output-dir outputs/checkpoints/chemvector-v090-visual-svg-capacity-100-stage2 \
  --init-checkpoint outputs/checkpoints/chemvector-v090-visual-svg-capacity-100-stage1/last.pt \
  --epochs 40 --max-steps 1000 \
  --batch-size 4 --gradient-accumulation 1 --workers 0 --no-shuffle \
  --learning-rate 3e-5 --weight-decay 0 --dropout 0 \
  --token-corruption-probability 0.1 --image-contrastive-weight 0 \
  --max-target-length 2048 --validation-batches 25 \
  --validate-every 100 --save-every 250 --log-every 10
```

### 阶段三：干净自回归精调

移除 token corruption，用完整真值前缀完成最后 1,000 step：

```bash
CUDA_VISIBLE_DEVICES=0 .venv-train/bin/python -m chemvector.train_visual_svg \
  --train-shards Data/sdf/visual_svg_v0_1/capacity_100/shards/capacity-000000.tar \
  --validation-shards Data/sdf/visual_svg_v0_1/capacity_100/shards/capacity-000000.tar \
  --output-dir outputs/checkpoints/chemvector-v090-visual-svg-capacity-100-stage3 \
  --init-checkpoint outputs/checkpoints/chemvector-v090-visual-svg-capacity-100-stage2/last.pt \
  --epochs 40 --max-steps 1000 \
  --batch-size 4 --gradient-accumulation 1 --workers 0 --no-shuffle \
  --learning-rate 1e-5 --weight-decay 0 --dropout 0 \
  --token-corruption-probability 0 --image-contrastive-weight 0 \
  --max-target-length 2048 --validation-batches 25 \
  --validate-every 100 --save-every 250 --log-every 10
```

最终必须对 100 张图全部自由生成，不能只评前若干样本：

```bash
CUDA_VISIBLE_DEVICES=0 .venv-train/bin/python -m chemvector.evaluate_visual_svg \
  --checkpoint outputs/checkpoints/chemvector-v090-visual-svg-capacity-100-stage3/last.pt \
  --shard Data/sdf/visual_svg_v0_1/capacity_100/shards/capacity-000000.tar \
  --output-dir outputs/evaluations/chemvector-v090-visual-svg-capacity-100 \
  --limit 100
```

checkpoint 不按 teacher loss 自动晋级。只有 `generation_metrics.json` 的全部预注册门槛
通过，才进入下一阶段的数据规模实验。

## 决策

- Visual SVG v0.1 协议、物理图元提取、capacity_100 数据和评估门控：GO；
- 旧 `ChemVectorModel` cross-attention 容量训练：视觉接地 NO-GO；
- 预注册门槛保持不变，不用 teacher accuracy 代替图片错配和自由生成；
- 后续架构排查、Visual Prefix 接地和最终 capacity 结果见
  [v0.9.1 Visual Prefix 视觉接地与容量验证](20260721-v0.9.1-visual-prefix-grounding-and-capacity.md)；
- 本轮及后续 capacity 实验均不替换稳定 v0.7.10。
