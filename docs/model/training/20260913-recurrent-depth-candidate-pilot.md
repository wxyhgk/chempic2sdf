# 2026-09-13：循环深度候选筛选先导实验

## 结论

**本轮没有验证出循环深度的收益，不替换现有 set，也不扩大训练。**
共享层循环 4 次与单次共享层、4 层不共享模型的原子位置集合 exact 相近，
三者均低于现有冻结 set。固定 4 轮训练后改为 8 轮推理出现明显种子敏感性。
这只是否定本轮有限数据、训练配方和候选筛选任务下的替换方案，
不是否定 Looped Transformer，也没有验证完整分子图或 SDF。

实验目录：`outputs/experiments/recurrent-depth-candidates-20260913/`。
协议 SHA256：`9039ddc170235ef879d19bc33ade9580db701a3e7ae218709aa012617f6c7419`。

## 实际验证的命题

用户授权验证 Recurrent Depth / Looped Transformer 后，先选择一个有现成真实图像、
冻结特征和可靠几何标签的有限入口：**不删除 decoded 候选，训练循环头修正原子存在性**。
没有将现有模型原样重复执行冒充训练过的循环模型，也没有先删除 set 拒绝候选再声称找回它们。

输入为冻结模型预测的原子特征、几何、proposal 分数、incidence atom token 和 set 概率；
其中 incidence token 已携带冻结上游的关系信息，不能把输入描述成仅有原始局部像素。
这些均由图片产生，不使用真值。每轮重新注入同一编码后的输入，更新候选隐状态，
最后预测相对于冻结 set logit 的残差。零初始化残差头，起点与原有选择一致。
本轮不重训视觉骨干、不读取文字转写目标、不调用 OCR、不学习键连接或原子元素类型。

```text
冻结视觉／proposal／set 计算 → 全部 decoded 候选（最多 128，不按 set 删除）
                                  ↓
                          编码后的固定输入 E
                                  ↓ 每轮注入
                       共享 Transformer 核心 → 更新状态
                                  ↓
                   原子存在性 logit 残差 + 原 set logit
```

## 对照与训练协议

| 组别 | 独立核心层数 | 每次展开层数 | 参数量 |
|---|---:|---:|---:|
| tied1 | 1 | 1 | 119,425 |
| tied4 | 1 | 4 | 119,425 |
| untied4 | 4 | 4 | 343,777 |

- 隐藏维 96、4 个注意力头、FFN 宽度 192、dropout 0；所有组输入编码、注入和输出头相同。
- untied4 的四层初始化数值相同但 Parameter 独立；初始化时与 tied4 的前向一致。
- 三个种子：17、29、43。每个种子各组使用相同批次顺序，保存批次顺序 SHA。
- 每组 600 步、batch 32、AdamW、学习率 3e-4、weight decay 0.01、梯度裁剪 1。
- CUDA BF16 前向，FP32 参数与损失；使用 GPU 独占锁。
- 全部模型只取最后一步，不根据内部验证选择 checkpoint、延长训练或扫阈值。
- tied4 的 1／2／8 轮输出在训练完成后作为附加诊断，主比较仍为训练过的 4 轮。

tied1 与 tied4 是同参数量对照，但后者有更多计算。tied4 与 untied4 的核心执行次数和
张量尺寸相同，属于同展开计算路径对照；**没有宣称包括优化器更新在内的总训练 FLOPs
已经逐算子严格匹配**。untied4 需要更新更多独立参数。

数据仅来自已登记的 `style_train_100k/shards/train-000000.tar`，
依照 commitment 校验 shard 与 samples.csv 的 SHA；仅解码选定 PNG、ChemMol、Render。
按固定哈希排序选择 InChIKey 分组的 320 个分子，每个分子保留四种渲染变体：

- 训练：256 个分子、1,024 张图。
- 内部验证：64 个分子、256 张图。
- 两部分 molecule ID、InChIKey 均无交叉；标准化统计量只由训练部分计算。

**这是训练库内部划分，不是新 holdout。** 冻结上游可能见过两部分，且没有隔离 scaffold
和字体。没有读取 fresh dev、sealed test、MR-TADF 或 USPTO 评测数据。

## 评分定义

目标使用 Render 中原子 image_x/image_y，不推导或修订可见文字。
训练标签以全部 decoded 候选对真原子做 6px 内最大匹配数优先的一对一匹配产生。
评分时对实际被保留的候选重新进行同样的几何匹配，避免把能覆盖同一对象的另一候选
机械地记为错误；重复候选仍算额外原子。decode 阶段已经漏掉的真原子也计入 FN。

主指标 **原子位置集合 exact**：一张图上 FP=0 且 FN=0。
它不包含元素、电荷、键类型、键端点关联，因此不是原子身份全对，也不是分子图 exact。
新头使用固定 0 logit 阈值；加入残差前已将源 set 的 -0.25 阈值移到零点。

## 主结果

新训练组为三个种子的均值；原 set 为同一内部验证集上的冻结参考，不是重新训练的公平容量对照。

| 模型 | 位置集合 exact | 原子召回 | 每图额外原子 |
|---|---:|---:|---:|
| 原冻结 set | **57.42%** | 97.02% | 0.461 |
| tied1 | 51.82% | **97.48%** | 0.491 |
| tied4 | 51.56% | 97.12% | **0.388** |
| untied4 | 51.43% | 97.33% | 0.522 |

tied4 相比 tied1：exact 下降约 0.26 个百分点，平均 FP 从 125.67 降至 99.33，
但 FN 从 194 升至 222（分母为 256 张图、7,696 个真原子）。
因此不能把额外原子减少单独当作胜出：它同时变得更保守。
全部 decoded 候选的几何覆盖上限为 99.22%，筛选头不能恢复这个候选集之外的位置。

| 种子 | tied1 exact | tied4 exact | untied4 exact |
|---|---:|---:|---:|
| 17 | 52.34% | 50.39% | 51.95% |
| 29 | 51.95% | 52.73% | 51.17% |
| 43 | 51.17% | 51.56% | 51.17% |

没有以三次训练或同源内部验证声称统计显著优势。

## 深度外推与成本

下面只改变同一 tied4 checkpoint 的推理轮数，不重新训练，不据此挑选最优轮数：

| 推理轮数 | 平均 exact |
|---|---:|
| 1 | 51.17% |
| 2 | 51.95% |
| 4（训练深度） | 51.56% |
| 8 | 38.93% |

8 轮的三个种子分别为 16.41%、51.17%、49.22%。
这说明当前固定深度配方不能可靠外推；不能声称已经检验了随机循环训练、
截断反传或专门稳定化的 Huginn 配方。模型也没有训练 ACT 停机机制。

RTX 5090 上固定 batch 32、预热后的筛选头平均每图计时：
tied1 约 0.0079ms、tied4 约 0.0224ms、untied4 约 0.0225ms。
这是批量均摊的头部吞吐计时，**不含图像编码、候选生成或 SDF，也不是单图在线延迟**。

## 门槛与后续决定

训练前冻结的继续门槛：

- tied4 平均 exact 至少高于 tied1 1 个百分点：失败。
- tied4 比 untied4 的 exact 下降不超过 1 个百分点：通过。
- tied4 比 tied1 的每图 FP 增加不超过 0.1：通过。
- 至少两个种子 tied4 exact 高于 tied1：通过。
- tied4 比冻结源 set 的 exact 下降不超过 1 个百分点：失败。

**总体不通过，不做生产替换，不根据本轮结果修改协议。**
如果继续研究，应将“随机循环／稳定化训练”或“真正需要多步关系传播的键连接任务”
作为新的独立实验，而不是继续增加本轮循环数。不能由一个位置筛选小任务推断
循环图推理整体无效，也不能拿本轮结果证明 MoE 优劣——本轮没有 MoE 对照。
