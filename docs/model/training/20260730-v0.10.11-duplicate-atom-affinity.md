## 问题

GDG906 多出的 1 Atom / 3 Bond 来自两个相距 1.06px 的 B AtomObject。两者都连接相同三个
邻居，等价于同一视觉对象被复制。fresh 1k 进一步确认该模式不是 MR-TADF 特例：2px 内且
邻接相同的克隆解释约 25% Atom-set failure 和 23.5% Skeleton failure，且同时出现在 TEXT
与 IMPLICIT 原子。

## 零训练审计

冻结 v0.10.10 结构链，只允许删除重复节点，不修改 OCR、Direct AtomPair 或芳香阈值。

| fresh 1k | Atom exact | Skeleton exact | rescue/break |
|---|---:|---:|---:|
| baseline | 48.5% | 45.2% | - |
| GT duplicate Oracle | 57.9% | 53.0% | 94/78，break 0 |
| calibration 选中的图规则 | 56.0% | 51.7% | 75/65，break 0 |

Oracle 与实际规则均远超预设 `+1pp` 上限门，证明 duplicate identity 是主要瓶颈之一。

但不能直接部署固定 4px/同邻域规则：通用 style 数据存在合法的极近原子，部分结构还可能有
相同邻域，固定 NMS 不具备普适安全性。

## Learned Same-Object Head

- 参数：27,045。
- 候选：最终 AtomObject 中距离不超过 16px 的全部无序对，不限制邻居数。
- 输入保持对称：Atom feature 差/积、geometry 差、距离、proposal score、DirectPair
  presence、预测邻域 Jaccard、degree 和文字框 IoU。
- 正例：两个 proposal 独立落在同一 GT Atom 的 6px 匹配范围。
- 负例：其余全部近邻，包括真实近原子 hard negative。
- 三域 10k 共看到 1,173 个 duplicate positive、1,342 个 close negative。

calibration 500 的最佳 checkpoint 在 5,004 张：

- Atom exact：49.4% -> 55.4%；
- Skeleton exact：46.0% -> 51.8%；
- Atom/Skeleton break：0/0。

固定 fresh evaluation 1k：

- pair precision/recall：95.76% / 50.90%；
- Atom exact：48.5% -> 53.7%；
- Skeleton exact：45.2% -> 50.1%；

## 决策

能力增益明确，same-object affinity 和图感知集合方向正式 GO；但安全门要求真实近邻误合并
和 baseline-correct regression 都为 0，本轮没有通过，默认部署 NO-GO。不得根据 fresh eval
回调同一版本阈值。

下一版扩大到 50k 通用曝光，并将 fresh-dev 按 molecule 预注册为 4k route-select / 其余
route-confirm。训练增加所有 `<16px` 合法近邻，checkpoint 只由 route-select 选择；confirm
只运行冻结 winner。v0.10.10 前端继续作为默认。
