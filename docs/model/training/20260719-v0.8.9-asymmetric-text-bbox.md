# v0.8.9 非对称文字框

> 状态：bbox 组件 GO，实验 profile GO，稳定替换 NO-GO  
> 输出：`outputs/checkpoints/chemvector-v089-text-bbox-offset-9k-45k`

## 问题

旧 TextObject 协议使用同一个坐标同时表示原子连接 anchor 和文字 bbox 中心，再回归
对称的 `half_width/half_height`。普通 `N/O/F` 基本对称，但后缀字符串天然偏移：

| 标签 | bbox 平均横向偏移 | 平均纵向偏移 |
|---|---:|---:|
| N+ | +2.88px | +0.01px |
| NH2 | +3.02px | +2.71px |
| NH2+ | +7.68px | +0.83px |
| O- | +2.03px | +0.09px |

统一放大 bbox 无法解决该问题：它虽然保留后缀，也会吸入邻接键线。

## 实现

新增 `TextObjectBBoxHead`：

- `x/y` 仍是原子连接 anchor，不改变顶点、selector 和 bond 分支；
- `bbox_x/bbox_y` 是独立 OCR 裁框中心；
- bbox 偏移按 `half_width/half_height` 的相对比例预测；
- 从 v0.7.33 TextObject checkpoint 初始化；
- 冻结旧检测参数，只训练 130 个 bbox offset 参数。

偏移 crop 对亚像素变化较敏感，因此推理同时计算 anchor crop 和偏移 crop。只有偏移
crop 的归一化 CTC 序列分数至少高 `0.25` 才采用，否则回退 anchor crop。

## 结果

498 图、50% 黑白和 50% CPK 彩色：

| 协议 | matched OCR exact | modifier exact | simple exact | false modifier |
|---|---:|---:|---:|---:|
| v0.8.8 部署 bbox | 64.74% | 21.97% | 81.29% | 7.76% |
| 仅偏移 bbox | 68.63% | 34.15% | 81.98% | 7.90% |
| 偏移 + anchor margin 0.25 | 66.58% | 27.84% | 81.58% | 8.53% |

无保护的偏移框内部指标更高，但真实论文图将两个 B 识别成 S。margin 0.25 恢复三个
B，真实图输出与 v0.8.8 一致，同时仍保留约 1.84 个百分点部署净收益。

真实图的普通 N 原始输出仍为 `NH/NH/N/NH`，价态修复后为四个 N。说明 bbox 协议
已改善，但 OCR 的 N/NH 判别和长尾字符串数据仍是下一瓶颈。

## 决策

保留非对称 bbox 头和保守双 crop，加入前端实验 profile。稳定默认仍为 v0.7.10。
下一版不能继续调整全局 bbox 倍率，应转向字符串频次均衡和预测框分布微调。
