# v0.7.42 端点射线终止与穿越证据

## 问题

v0.7.41 联合边监督减少漏点，但把大量位于真实键线内部的候选提升成原子端点：

```text
unmatched extra vertices       301
extra within 3px of GT bond    162
extra near multiple bond        31
missing vertices               411
```

现有 line band 主要观察两个候选之间是否有墨线，无法区分真实端点和线段中点。

## 方法

对每个候选点对采样四条短射线：

```text
begin inward / begin outward / end inward / end outward
距离：3, 5, 7, 9, 11px
垂直带：-2, 0, +2px
```

真实端点通常是内侧有线、外侧终止；线内假点通常两侧连续。四个墨线均值作为
edge auxiliary 输入联合 node-edge 模型。它们只是学习特征，不直接删除候选。
全部 32,640 点对仍被保留。

## 结果

固定 100 图 5k exact 为 89%，容量通过。9k/498、15k 的 selector exact 为 59.44%。
端到端结果：

```text
role vertex exact              59.24%
strict skeleton exact          53.82%
>96px recall, bond=0.80        96.25%
```

机制审计相对 v0.7.41：

```text
unmatched extra vertices       301 -> 215
extra within 3px of GT bond    162 -> 107
extra near multiple bond        31 -> 17
missing vertices               411 -> 472
```

射线证据明确减少了线内假点，但模型变得过度保守，新增漏点抵消收益。

将 edge loss weight 从 1.0 降至 0.5 的受控消融，15k selector exact 仅 58.84%，
低于 1.0 的 59.44%，判定简单调 loss 权重 NO-GO。
