# v0.10.0 Fresh Joint 10k NO-GO

## 目标

使用已承诺的 `chemvector_joint_v1` 数据，首次在未见分子、未见 scaffold、未见字体的
fresh-dev 上固定基线，然后联合训练 Bond proposal 与 set/incidence。原计划训练 50,000 张；
若首个 10k 固定评测点出现明确结构性回退，则停止而不消耗剩余预算。

Bond proposal recall 基本保留，但 deployed exact 和整图 exact 崩溃，证明候选仍在，set head
却无法正确解释已移动的 Bond feature/score 分布。训练于 11,004 张时人工中止；最后一个完整、
可复现 checkpoint 是 10,002 张：

## 决策

`v0.10.0` 正式 NO-GO，不是部署候选，不切换前端，不解封 sealed-test。

该结果否定的是“Bond 与 set 从第一步以当前学习率同时移动”，不是新数据或对象路线。下一步
采用两时间尺度实验：先冻结 Bond，只训练 set/incidence 适配固定 proposal 分布；只有 fresh
probe 改善后，才允许用更低 Bond 学习率进行第二阶段联合微调。
