# v0.9.72 Bond Presence 校准

## 背景

v0.9.71 在 996 张双域 validation 上将 Atom deployed exact 从 50.30% 提到 65.56%，
incidence exact 从 52.31% 提到 67.57%，但 Bond deployed exact 从 52.11% 降到 44.18%。
30k 的 full-object exact 最佳为 37.25%，40k 回退到 35.84%，因此正式停止继续堆数据。

## 实验

从 v0.9.71 的 30k 最佳 checkpoint 初始化，冻结视觉、Atom proposal、Bond proposal、
Atom presence 和 incidence，仅训练最终 `bond_presence_residual`。该层只能重新选择已有
BondObject 候选，不能移动端点、增加顶点或改变键型。

- 校准训练：full-v0 train 10,000 张；
- validation：与 v0.9.71 相同的双域 996 张；
- 学习率：`2e-5`；
- 每 2,500 张保存并验证；
- MR-TADF/USPTO 仍不参与训练和 checkpoint 选择。

输出：

`outputs/checkpoints/chemvector-v0972-bond-presence-calibration-10k/`

## 结果

5k 与 10k 均达到相同的主门控，5k 先达到并保留为 best：

| 指标 | 校准前 | 校准 best |
|---|---:|---:|
| Atom deployed exact | 65.56% | 65.56% |
| Bond deployed exact | 44.18% | 44.68% |
| Incidence exact | 67.57% | 67.57% |
| Full-object exact | 37.25% | 37.65% |

最终 residual 校准只能带来 `+0.40pp` full-object exact，不是主瓶颈的完整解法。

## MR-TADF 外部测试

1,100 张只测不训，继续使用 Oracle 原子化学状态：

| 指标 | v0.9.65 稳定结构主线 | v0.9.72 |
|---|---:|---:|
| SDF valid | 88.55% | 88.82% |
| SDF 图 exact | **59.27%** | 54.00% |
| 标准键长 exact | **71.80%** | 68.06% |
| 长键 exact | **58.76%** | 57.63% |
| 极端长键 exact | **21.49%** | 8.33% |

v0.9.72 不替换 v0.9.65。结果说明数据扩量解决了内部 Atom/incidence 训练量问题，但
full-v0 的风格和 Bond presence 协议仍不能泛化到极端长键布局。下一阶段应保留 30k 学到的
Atom/incidence，并重新设计 Bond presence 的稳定特征与跨布局门控，而不是继续增加同分布数据。
