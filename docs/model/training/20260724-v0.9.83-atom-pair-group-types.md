# v0.9.83 AtomPair 组级键型

## 目标

从 v0.9.82 最佳 group presence checkpoint 热启动，在不改变组级存在性决策的前提下预测：

- display type：SINGLE/DOUBLE/TRIPLE/AROMATIC；
- chemical type：SINGLE/DOUBLE/TRIPLE/AROMATIC；
- direction：作为辅助监督，当前 ChemScene 编译仍固定为 `NONE`。

## 数据与边界

只使用 ChemVision 与 full-v0，每域 8,967 张。MolGrapher、MR-TADF、USPTO 均不参与训练、
阈值或 checkpoint 选择。

每个 proposal 保存其 Hungarian 匹配的真实 bond index。AtomPair group 仅在所有正 proposal
对应唯一真实 bond 时获得类型监督；冲突组屏蔽类型 loss。presence 网络完全冻结，只训练三个
类型线性头。

checkpoint 首先最大化两个域中较弱的 `chemical_deployed_exact`，该指标要求：组存在性整图
正确、真实键 coverage 完整、每个组的 chemical type 全部正确。display 与 direction 单独
报告，不阻塞当前 SDF 主指标；芳香键的显示方式不应与 SDF 化学键型混为一个门控。

输出：

`outputs/checkpoints/chemvector-v0983-atom-pair-bond-group-types-two-domain18k/`

## 内部结果

按 SDF chemical 口径，9,000 总样本 checkpoint 最佳：

| 域 | chemical 逐键准确率 | chemical 整图全对 | presence+chemical deployed exact |
|---|---:|---:|---:|
| ChemVision | 94.45% | 54.82% | 49.80% |
| full-v0 | 96.75% | 60.04% | 54.62% |

保存为：

`outputs/checkpoints/chemvector-v0983-atom-pair-bond-group-types-two-domain18k/best-chemical.pt`

display 逐键准确率约 75%-80%，明显低于 chemical。该差异符合芳香键/单双键显示方式与 SDF
化学键型并非同一目标，因此 display 不进入 SDF 主 checkpoint 门控。

## MR-TADF 外部结果

纯 AtomPair group 路径：

- SDF valid：84.73%；
- 结构/chemical exact：54.73%；
- 标准键：65.76%；
- 长键：61.58%；
- 极端长键：15.79%。

相对 v0.9.72，长键和极端长键明显改善，但标准键与 valid 回退。采用通用的有效性回退：
优先组级结果，仅当组级 SDF invalid 且 v0.9.72 valid 时回退旧路径。该规则不读取难度、
MR-TADF 标签或真值。

## 正式单图推理入口

AtomPair group 已接入 `chemvector.infer_joint_object_structure`，尝试顺序为：

1. AtomPair group primary joint/independent；
2. AtomPair group fallback joint/independent；
3. v0.9.72 primary/fallback；
4. 碳占位芳香修复。

回退只依据 RDKit 是否生成有效 SDF，不读取分子类型、键长难度或 benchmark 标签。前端实验
profile 为 `structure-v0983-carbon`，运行时热更新，无需重启服务，且明确标记文字按 C 占位、
`recommended=false`。

- 84 个顶点、100 根键；
- 有效 SDF 和渲染图均可下载；
