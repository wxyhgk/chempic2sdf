# 2026-07-29 v0.10.3 Direct AtomPair Bond

> 状态：完成，架构 GO / 默认部署待接入
> 基础 checkpoint：`outputs/checkpoints/chemvector-v0101-set-first-style10k/selected.pt`
> 输出目录：`outputs/checkpoints/chemvector-v0103-direct-atom-pair-style10k`

## 目标

验证稳定的最终 AtomObject 接口能否直接支持 Bond 分类，从而绕开已被 v0.10.0/v0.10.2
证明会漂移的 `Dense Bond proposal -> latent -> set selector` 链。每个无序 AtomPair 直接输出
是否存在键以及 `SINGLE/DOUBLE/TRIPLE/AROMATIC`，对应 MolGrapher 中可借鉴的稳定对象接口，
但不采用其最近邻、`1.75x` 键长和空白中点过滤。

## 数据

- 训练：style train 6,668 张、ChemVision replay 1,666 张、font-v2 replay 1,666 张。
- fresh calibration：按 sample key SHA256 最小值确定性抽取 500 张，只用于选阈值/checkpoint。
- fresh evaluation：紧接的独立 1,000 张，只在训练结束后评测一次。
- 26 张 ChemSVG 坐标碰撞样本从组件 probe 中显式排除并写入审计，不静默计作可训练样本。
- sealed test 保持权限 `000`，不得读取。
- MR-TADF、USPTO 不参与训练、选模或阈值选择。

## 模型与冻结范围

- 冻结：vision、Atom、旧 Dense Bond、旧 set/incidence。
- 旧 set 只负责选出最终 AtomObject；旧 Bond 不参与新键预测。
- 枚举所有已选 AtomObject 无序对，不做距离或邻居过滤。
- 从冻结 stride-4 stroke feature 沿两端读取 `9x32` ribbon；正反 180 度编码平均。
- Atom 特征只使用两端 mean 与 absolute difference，不输入绝对长度或绝对位置。
- Presence 监督使用全部正键和结构化 hard negative；正式评测枚举全部点对。
- 新增可训练参数：2,266,565。

## 训练配置

```bash
.venv-train/bin/python -m chemvector.train_direct_atom_pair_bond \
  --style-train-samples 6668 \
  --chemvision-replay-samples 1666 \
  --font-v2-replay-samples 1666 \
  --fresh-calibration-samples 500 \
  --fresh-eval-samples 1000 \
  --batch-size 6 \
  --learning-rate 2e-4 \
  --negative-ratio 6 \
  --minimum-negatives-per-image 48 \
  --validate-every-total-samples 2500 \
  --output-dir outputs/checkpoints/chemvector-v0103-direct-atom-pair-style10k \
  --seed 20260729
```

- 优化器：AdamW，weight decay `1e-4`。
- 混合比例：每 batch `style/ChemVision/font-v2 = 4/1/1`。
- calibration 阈值候选：`0.10..0.90`，步长 `0.05`。

## 失败样本与观察

- 1,611/44,125 个目标键无法由最终预测 AtomPair 表达，下一上限来自 Atom 选择/匹配，而非
  用键长规则补候选。
- Presence 整图已明显超过旧链，但 chemical Bond exact 只有 18.3%；下一步应在同一稳定
  AtomPair 接口上改进整图键型，而不是回到 Dense Bond latent。
- 本轮只产生组件级指标和 checkpoint，尚未生成逐图 SDF/渲染诊断；推理编译适配层必须先
  将 AtomPair 输出写入 ChemScene，之后才能切换前端。

## 决策

`GO`：Direct AtomPair Bond existence 正式替代旧 Dense Bond 候选链，继续实现 ChemScene
推理编译适配。当前 checkpoint 尚未直接接入默认前端；接入后必须再跑逐图 SDF、公开集和
MR-TADF 外部诊断，不能把组件门控冒充最终端到端准确率。
