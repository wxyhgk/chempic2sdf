# 保存预测的离线根因排查

## 结论

本批失败不是一种单一问题。已确认存在原子电荷/氢信息缺失、错误连边，以及仅属表示不同的
局部键类别差异。RDKit 的第一个异常反映失败位置，不一定指出出错模块：
“Kekulé 化失败”也可以由原子电荷或氢信息错误触发。

这轮只做诊断，没有修复生产推理，没有训练、网络重跑、阈值调参或接入新 OCR。
所有对照均使用此前保存的同一批 50 个分子、200 张开发图预测。

## 三个已单独验证的具体原因

| 样本 | 原始失败 | 仅在内存中改变一处 | 结果 |
|---|---|---|---|
| `fresh_dev_000001_coordgen` | Kekulé 化失败 | 候选 ID 15 的 N：formal_charge 从 0 改为 +1 | SDF 有效、非立体整图正确 |
| `fresh_dev_000444_coordgen` | Kekulé 化失败 | 候选 ID 15 的 N：explicit_h_count 从 0 改为 1 | SDF 有效、非立体整图正确 |
| `fresh_dev_001376_coordgen` | C 显式价态为 7 | 删除候选 ID 6 与 8 间误预测的三键（键 ID 292） | SDF 有效、非立体整图正确 |

前两个节点的保存 OCR 字符串都是 `N`。这证明化学属性不完整，但本轮没有检查裁剪像素，
**不能进一步断言是 OCR 识别、裁剪、文字标签还是解释环节单独造成的**。
第二例的负对照：只把另一个 NH 节点 ID 13 的 no_implicit 改为 False，仍然失败。
第三例对应真值原子 40、38，真值不存在该连边。其余属性和键均不改即可恢复正确。

这些是主对照完成后的单点验证，另存 `single_field_followup.json`、`single_bond_followup.json`，
未改动输入预测、旧报告或生产输出。

## 十组离线属性/连键替换

所有替换仅发生在 6 px 内两侧均唯一的几何匹配上；不补原子、不删原子、不移动坐标。
真键替换只重建这些明确节点的诱导子图；涉及未匹配/歧义节点的原预测边原样保留。
因此真值不可用的区域没有被悄悄删掉。每组分母始终为 200。

表中每格为“有效 SDF 数 / 非立体整图正确数”：

| 属性替换 | 保留预测键 | 替换明确匹配节点间的真键 |
|---|---:|---:|
| 不替换属性 | 96 / 53 | 124 / 73 |
| 元素、电荷、同位素、自由基 | 99 / 67 | 132 / 92 |
| 显式氢数、no_implicit | 96 / 56 | 126 / 78 |
| 原子芳香标志 | 93 / 53 | 123 / 73 |
| 全部非立体原子属性 | 101 / 77 | 139 / 107 |

相对原始预测：

- 基础属性替换挽回 14 张整图正确结果，没有伤害原正确结果。
- 键替换挽回 20 张整图正确结果，没有伤害原正确结果。
- 全属性替换挽回 26 张、伤害 2 张；净增 24 张。
- 全属性加键替换挽回 54 张整图正确结果，没有伤害原正确结果。

有效 SDF 与正确整图必须区分：最后一组使原 104 个无效图中的 47 个变为有效，
同时使原 96 个有效图中的 4 个失效；最终为 139 个有效图，仍有 61 个无效图。
单独复制真实属性到仍有错误连边的图中可能造成新的不一致，不能当成可直接部署的修补算法。

## 控制与适用范围

- 原预测基线逐样本精确重放：200/200（包括无效状态及异常记录）。
- 源真值图非立体编译控制：200/200。
- 106 张节点集合完整且可唯一对应的子集：原预测 53 张整图正确，
  全属性加真键后 106/106 正确。
- 总计 107 张正确中，另 1 张是 `fresh_dev_001023_coordgen`，虽几何匹配不完整，
  最终化学图仍可正确。这再次说明几何门限未匹配不等于真实漏检。

剩下未达正确的 93 张不能全部归为“漏原子”：它们受到未匹配、多余节点、匹配歧义、
定位偏差以及保留的边界错误等共同限制。本轮没有执行补全真原子集合并重采样视觉特征的 A 轴，
也没有执行旧 8 路实验。因此不能给出完整架构瓶颈排名。
所有增益均为含真值的离线替换增益，不是模型提升、部署收益或新数据上的准确率。

## 芳香表示核对

对明确匹配的同一条边，比较原始类型和 RDKit sanitize 后的类型：

- 原始类型差异 380 条。
- 113 条在归一化后相同（局部表示差异，不代表所在整图一定正确）。
- 8 条归一化后仍不同。
- 259 条所在预测图无法有效归一化，保持“无法判断”，不把它们都算表示差异或真实类型错误。

此前 29 张整图正确图片上的 78 条差异，本次全部确认归一化后相同。
因此旧局部报告的 `wrong_bond_types` 实际是 raw label disagreement，不能照字面解释成化学错误。
旧冻结报告保持不动，本轮在 `representation.jsonl` 逐条补充归一化结果。

训练代码的可确认事实：`train_direct_atom_pair_bond.py:202` 从原始 bond_chemical 构建类别目标，
`direct_atom_pair_bond.py:251` 对正例采用逐对 cross entropy；该损失未按整图化学等价合并标签。
这说明**逐键标签目标与规范化整图终点不完全相同**，不是证明训练规范化类别的策略必然错误，
更不是证明 MoE 或循环深度架构优劣。

## 后续优先级

先处理输出语义、约束和监督指标的关系，暂不因这些结果重开架构训练：

1. 对电荷/氢相关失败，检查已有固定样本的 OCR 框和原始字符串来源，区分视觉证据缺失与
   化学解释错误。外部 OCR 应提供证据，不应让一个可解析的 `N` 自动等价于确定无电荷、无氢。
2. 对误连边，设计可单独评测的价态/连通性约束候选检查；不能直接推广为删边规则。
   价态约束不足以保证分子正确，本轮也没有实现这一修复。
3. 在修订训练目标之前，分别报告规范化整图正确率、真正连接错误、局部等价表示差异，
   并补上缺失节点 A 轴诊断。不要依据 380 条原始标签差异盲目重训键头。
