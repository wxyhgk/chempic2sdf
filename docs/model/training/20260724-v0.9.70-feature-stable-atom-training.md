# v0.9.70 Feature-Stable AtomObject 扩量

## 假设

冻结旧 Atom head 的 `input_projection + context`，使下游看到的 `object_features` 逐位保持
不变；只训练 heatmap、anchor offset、role、text 和 count 输出头。该实验用于区分完整 feature
drift 与 geometry/score 联合分布漂移。

## 结果

训练使用同一 8,967 张可表示 train、498 张 validation、2,000 step。最佳 checkpoint 位于
step 1,250：

| 指标 | 初始 | 最佳 |
|---|---:|---:|
| proposal 整图 exact | 73.49% | 79.52% |
| proposal atom recall | 98.59% | 98.96% |
| 12-16px recall | 78.26% | 95.65% |

输出：

`outputs/checkpoints/chemvector-v0970-feature-stable-atom-full8967-step2000/`

它证明旧 feature 不变时仍能学习密集顶点，但整体覆盖上限明显低于全量解冻版。接旧
selector 后，GDG906 为数量正确但连接错误，GDG1005 仍出现 valence invalid。说明下游失配
不只来自 object feature，还来自 Atom geometry、score 与 incidence 的联合分布变化。

## 决策

Feature-stable head-only 训练 NO-GO，不替换 v0.9.65。下一阶段停止独立升级 Atom head，改为
Atom presence、Bond presence、endpoint incidence 的同批联合训练；新增顶点及其两条入射键
必须在同一个图级损失中共同获得梯度。
