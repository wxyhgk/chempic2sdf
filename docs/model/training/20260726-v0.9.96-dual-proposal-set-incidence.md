# v0.9.96 双 Proposal Set/Incidence 重对齐

## 目标

v0.9.95 的 Bond residual 在 official/internal 上均提高 proposal recall，但直接配合旧 set/incidence
时，locked full-v0 的 full object exact `210→208`。本轮冻结 vision、Atom、原 Bond detector
和 v0.9.95 residual，只重训 set/incidence，使同一个 head 同时兼容：

```text
新 proposal：原 Bond + v0.9.95 heatmap/endpoint residual
旧 proposal：原 Bond，不启用 residual
```

MR-TADF、USPTO 未参与训练或选模。由于没有 candidate 通过 official 双路径门控，本轮未读取
locked internal。

## 数据与协议

- paired style：250 个 molecule、1,000 张图；
- replay：ChemVision 500 张、full-v0 500 张；
- 每 epoch 曝光 1,000 style + 1,000 replay；
- replay 的每张图同时经过新、旧两套 proposal；
- style 只监督新 proposal；
- official validation：ChemVision/full-v0 各 498 张；
- style validation：498 张；
- set/incidence 共 178,565 个可训练参数；
- presence/incidence 学习率为 `2e-6 / 2e-7`；
- 原 proposal 输出使用冻结 teacher 做 MSE/KL 保持。

硬选模要求四条路径全部不回退：

1. 新 proposal + ChemVision；
2. 新 proposal + full-v0；
3. 原 proposal + ChemVision；
4. 原 proposal + full-v0。

每条路径同时检查 Bond deployed exact 和 full object exact。通过后才比较 style full exact。

## Weight-Space Scale Calibration

对 teacher 10 checkpoint 做确定性权重插值：

```text
W(scale) = W(base) + scale * (W(trained) - W(base))
```

第一次校准入口漏设 deterministic CUDA，baseline 未复现，因此该次输出作废。修正后 baseline
逐项复现，再扫描：

| Scale | 最坏 official 回退 | 安全 |
|---:|---:|---:|
| 0.00 | 0 | 是，原模型 |
| 0.25 | -1 | 否 |
| 0.50 | -1 | 否 |
| 0.75 | -2 | 否 |
| 1.00 | -2 | 否 |

没有安全非零 scale，也没有生成部署 candidate。

## 决策

v0.9.96 协议 GO / checkpoint NO-GO：

- 双 proposal replay 和逐域双路径门控应保留；
- 共享 set/incidence 全量重训可改善新 proposal 和 style；
- 更新从 scale 0.25 起就产生 full-v0 回退，说明修改范围仍过宽；
- 不运行 locked internal，不切换前端默认模型；
- 默认继续使用 `structure-v0992-carbon`。

下一步冻结完整 set/incidence，只增加零初始化、proposal-delta-conditioned residual。它只读取
新旧 proposal 的 score/endpoint 差异并修正新路径；原 proposal 输入时 delta 为 0，结构上保证
原路径逐位不变，再用双域 official 检验新路径是否真正净增。
