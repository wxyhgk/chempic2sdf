# 2026-07-16 v0.7.12 集合式顶点与密集几何吸附

> 状态：顶点方向 GO，relation 尚未通过

## 目标

验证当前单通道 heatmap、固定阈值和 NMS 是否是整图顶点准确率的主要上限，并测试
集合式 Atom Query 能否负责原子计数、dense heatmap 能否只负责精确几何候选。

## 数据审计

- 审计来源：MolGrapher pilot train 前 500 张；
- 审计输出：`outputs/audits/molgrapher-v0712-train-500/`；
- 固定过拟合集：`Data/sdf/molgrapher_synthetic_v0_1/overfit_100/train-000000.tar`；
- 100 张样本来自 500 张审计候选，按原子数、可见文字和多键分桶轮询；
- 未使用 MR-TADF。

审计发现：

- validation 中存在整图叠加原子序号的图片，例如 `validation_000088`；
- 普通末端碳可能被画成大号 `CH3`，不能从 ChemMol 字段直接推导视觉角色；
- 原验收只检查锚点 48px 内存在墨迹，不能证明锚点位于正确视觉中心；
- 自动原子序号筛查偏保守，只用于排除过拟合集候选，不用于删除全量数据。

## 解码校准

在 MolGrapher validation 1k 上扫描：

```text
vertex threshold: 0.05 - 0.50
tolerance: 4 / 6 / 10 / 16px
maximum vertices: 128 / 192
```

最佳 6px vertex exact 约 3.4%，16px 约 4.1%。最大顶点数 192 没有收益，证明问题
不是单纯阈值或容差校准。

评测输出：`outputs/evaluations/v0712-molgrapher-vertex-grid-1k.json`。

## 100 图过拟合对照

| 方案 | 可训练参数 | 最佳 Count MAE | 最佳 vertex exact |
|---|---:|---:|---:|
| 当前 vertex head | 92,548 | 0.34 | 87% |
| vertex head + 解冻最后一个 stride-4 block | 171,748 | 0.25 | 90% |
| 纯 Atom Query | 约 2.1M | 0.00 | 最高 60%（6px） |
| Atom Query + dense 一对一吸附 | 约 2.1M + dense head | 0.00 | 95%（4px/6px） |

纯 Atom Query 使用 128 个 reference query、Hungarian matching、presence/center/aromatic
输出，并增加 stride-4 局部 3x3 可微采样。它能稳定解决计数，但少量坐标仍漂移。

最终混合方式：

```text
Atom Query -> 决定原子集合和数量
dense heatmap -> 低阈值输出候选峰
Hungarian one-to-one snap -> 每个 query 最多吸附一个候选峰
```

NMS 不再决定最终原子数，dense 分支也不删除任何候选边。

核心结果：

- Count exact：100%；
- Vertex precision / recall / F1：99.79% / 99.79% / 99.79%；
- 4px 和 6px vertex exact：95%；
- 12px vertex exact：96%。

评测输出：

- `outputs/evaluations/v0712-overfit100-atom-query-local-grid.json`；
- `outputs/evaluations/v0712-overfit100-atom-query-dense-snap.json`。

## 骨架结果

将融合顶点接入现有全点对 relation：

| Edge threshold | Edge precision | Edge recall | Skeleton exact |
|---:|---:|---:|---:|
| 0.50 | 81.20% | 99.43% | 8% |
| 0.60 | 86.49% | 98.98% | 14% |

阈值 0.70 时仍有 198 条多边和 94 条漏边。顶点已通过 GO 门槛，当前第一瓶颈转为
relation 对检测坐标扰动和全点对 hard negatives 的鲁棒性。

骨架输出：`outputs/evaluations/v0712-overfit100-atom-query-skeleton/summary.json`。

## 已否决方案

- 继续调整 v0.7.11 style gate：不能提高实际专家能力；
- 直接扩大 MolGrapher 到 50k/300k：标签审计和过拟合能力未确认前无诊断价值；
- 无 reference 的纯 query：query 身份交换，presence 全体激活；
- 只使用冻结 stride-8 全局特征：计数可学，像素级定位不足；
- 纯 Atom Query 单独输出坐标：6px 整图 exact 未达到 95%。

## 决策

顶点方向 `GO`：v0.7.12 采用“Atom Query 集合计数 + dense 几何吸附”作为 shadow
候选，不替换当前生产推理。

整模型仍为 `NO-GO`：下一步固定本次融合顶点，在检测后顶点上训练 relation，重点
采样多余边、交叉错连、近邻非键和长真键。100 图 detected skeleton exact 达到 85%
后，才进入 10k 干净数据验证。
