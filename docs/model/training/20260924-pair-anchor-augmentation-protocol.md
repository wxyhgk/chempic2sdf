# 键端点扰动监督：固定 58 图 CPU 准备协议

接续 [九位置均值失败结果](20260924-po-pair-translation.md)。本轮只检查训练侧增强的
标签／采样契约和覆盖，不运行真实模型，不承诺训练效果，不改训练默认入口。

## 固定范围

只使用 `chemvector-selector-retention-fit-20260919` 的 58 个 training_samples，
以及已保存 initial 几何、匹配和原采样记录。原 admission 的用途仍为
`local_selector_retention_fit_only`；此准备不扩展准入，也不重复使用已消耗的一次性训练授权。
只读训练 meta/layers/graph 与旧缓存，不打开图片、开发／封存样本，不查新身份，
不加入反复用于诊断的四个 P–O 结构，不加载 checkpoint。

## 扰动与标签

- 原位置全部原采样行保留。复现 seed `20260921 + manifest ordinal`、
  negative_ratio=6、minimum_negatives=48 的 known-only sampler。
- 只平移沿键视觉取样的坐标，候选 lineage、atom features、score features、
  原匹配与键型标签不变。两端共同偏移 `{-4,0,+4}px²`；不是两端独立扰动。
- 原 normalized FP32 anchor 上加偏移；所有距离用 FP64 核验，image_size=768。
  真值只用于训练增强的身份保护，不替换预测坐标，不进入推理输入。
- 新增八视图仅保留两端均位于图内、距**原对应原子**不超过 6 px、
  严格比其他真值原子更近的原采样行。并列、跨归属与未知对应一律不新增监督。
  不重匹配、不裁剪、不重新采负例、不扩大正例集合。排除原因可能重叠，不能直接相加。
- 零偏移即使有几何歧义也保留原监督，同时显式记录 guard flags；
  保持原损失不等于证明原标签全部无歧义。
- 统计 ribbon 中间 4%–96%、横向 ±12 px 内的非端点真值原子，
  **只作几何风险提示，不删负例**，也不等同于发现了真实可见线条。

## 损失原型与未来执行边界

独立 opt-in 原型是 `L_original + L_one_shift`，两项均沿用 existing
`direct_atom_pair_loss` 的存在与正例键型监督。不是平均 logits，不选择最佳偏移。
额外分支按保留行计算自己的正负权重；原分支的值及梯度保持不变。
权重 0 仅用于合成张量上的逐值／梯度等价测试。空增强跳过，原空监督整步跳过。

若以后获准实现定额试训，每个 attempt 最多原位置加一个偏移；按固定八偏移轮换，
空偏移不重抽，不把九个视图当成九张独立图。上游、OCR 和阈值仍冻结。
这不是训练 launcher、预算授权或独立泛化验收。

## 准备验收与资源

预期原位置：1,103 正例、6,244 确认负例；未知 pool 626 行仍不采样；
4 张图空分支。1,150 个目标键中 47 个因当前候选不可达，仍保留在分母。
逐键报告 SINGLE/DOUBLE/TRIPLE/AROMATIC、P–O/P=O 和每个偏移的保留／排除数，
另报每条原采样行有 0–8 个可用新增视图的分布，不能只报视图总量。

新准备、保存结果后核验各单独 CPU 120 秒上限，自动重试 0。
无模型加载／真实前向／真实反传／optimizer／GPU，合成测试允许人工 logits 求导。
后核验重查 SHA 绑定和原始来源，并用独立标量几何计算核对逐视图排除及 ribbon 提示。
通过只说明本契约能复现，不说明已解决漏键，也不代表可以直接训练。
