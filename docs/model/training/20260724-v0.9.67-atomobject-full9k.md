# v0.9.67 AtomObject 全 9k 扩量

## 目标

验证 GDG906、GDG1005 的近距离顶点合并是否主要来自 AtomObject 只训练 100 张图，而不是
OCR 或 BondObject 缺失。训练只读取 ChemVision train，MR-TADF 只用于训练完成后的外部测试。

## 数据与协议

- ChemVision train 原始 8,974 张；
- 按损失实际使用的 `q1023 -> 192x192` cell 协议发现 7 张同 cell 冲突；
- 正式训练 8,967 张，batch 16，2,000 step，学习率 `1e-4`；
- validation 498 张用于 checkpoint 选择；
- MR-TADF 不参与训练、阈值或 checkpoint 选择。

碰撞过滤修复后，每轮显式核验接受数量与跳过 key，正式训练未再中断。输出：

`outputs/checkpoints/chemvector-v0967-atom-object-full8967-step2000-rerun/`

validation 的总体最佳为 step 1,750，密集点专项最佳为 step 250：

| proposal atom recall | 98.59% | 99.49% | 99.62% |

| 指标 | 旧 Atom head | v0.9.67 step 250 |
|---|---:|---:|
| Atom proposal 整图完整率 | 93.73% | 97.73% |
| 全部 Atom recall | 99.87% | 99.94% |
| 12-16px recall | 89.67% | 97.28% |
| 12-16px 图片桶 exact | 73.33% | 95.00% |

GDG906 已由 83/104 恢复到 84/104，并得到完全一致 SDF；GDG1005 由 101/129 恢复到
102/129，但仍有局部连接错误。

## 端到端回归

直接用新 Atom head 替换旧 head、其余 selector/incidence 不变时，MR-TADF 单尺度完整结果：

| 指标 | v0.9.64 旧 head | v0.9.67 直接替换 |
|---|---:|---:|
| SDF valid | 79.45% | 78.00% |
| 原子数一致 | 69.18% | 61.82% |
| 键数一致 | 65.00% | 61.00% |
| SDF 图 exact | 55.55% | 48.64% |

新版本救回 83 个旧错误，同时破坏 159 个旧正确样本。Atom proposal 扩量本身 GO，但直接
替换 NO-GO。原因是下游 selector/incidence 仍按旧 Atom feature、geometry 和 score 联合分布
训练。
