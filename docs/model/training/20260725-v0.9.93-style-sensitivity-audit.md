# v0.9.93 扩量 Verifier 与跨风格审计

## 目标

本轮保持 v0.9.92 架构和上游模型全部冻结，只扩大候选级 Chemical RETYPE verifier 的
train-only 数据曝光。同时把“模型受图片风格影响很大”改造成可重复的 paired audit：同一个
分子有四种渲染，结构真值完全相同，模型结果不应随外观改变。

MR-TADF、USPTO 和 locked internal 均不参与训练、阈值或 checkpoint 选择。

## Paired Style Audit

数据：

```text
Data/sdf/chemvision_layers_v0_2/font_pilot_10k/shards/validation-000000.tar
```

原始 shard 有 500 张，其中 2 张在 ChemSVG v0.4 加载时发生坐标碰撞跳过；实际评估 498 张，
覆盖 125 个分子。124 个分子具备完整四种渲染，1 个不完整分子不进入 paired 指标。

v0.9.93 总体结果：

| 指标 | 数值 |
|---|---:|
| Presence exact | 351 / 498，70.48% |
| Chemical exact | 253 / 498，50.80% |
| 四渲染 presence mixed outcome | 84 / 124，67.74% |
| 四渲染 chemical mixed outcome | 70 / 124，56.45% |
| 四种渲染全部 chemical exact | 21 / 124，16.94% |

主要分桶 chemical exact：

| 因素 | 最好 | 最差 | Gap |
|---|---:|---:|---:|
| Layout | coordgen 63.20% | stress 20.16% | 43.04pp |
| Multiple-bond offset | medium 57.48% | wide 43.66% | 13.81pp |
| Rotation | medium 54.43% | low 44.97% | 9.46pp |
| Font family | rasa 53.65% | nimbus-roman 47.32% | 6.33pp |
| Kekulize | false 53.41% | true 48.19% | 5.22pp |
| Line width | thin 51.85% | medium 48.85% | 3.00pp |

这说明用户观察成立，但“风格”需要更精确地拆分：字体会影响结果，影响更大的却是布局、拥挤/
交叉操作、双键间距和旋转。模型读取的是 raster 统计，不会因为输出类似 SVG 就自动获得风格
不变性。

输出：

```text
outputs/evaluations/chemvector-v0992-style-sensitivity-validation498/metrics.json
outputs/evaluations/chemvector-v0993-style-sensitivity-validation498/metrics.json
```

新增只读入口：

```bash
python -m chemvector.evaluate_style_sensitivity \
  --checkpoint CHECKPOINT \
  --output outputs/evaluations/STYLE_AUDIT/metrics.json
```

## 决策

v0.9.93 NO-GO：

- 同风格 verifier 扩量在 train-dev 有收益，但 official validation 无新增；
- paired 风格分裂仍超过一半分子；
- presence 完全由冻结上游决定，最后一层 verifier 无法修复；
- 默认前端保持 `structure-v0992-carbon`；
- 不消费 locked internal。

下一实验应训练上游的 paired consistency，而不是继续扩大同风格 verifier：同一 molecule 的
不同字体、字号、线宽、双键间距、旋转和布局共享 ChemScene 真值，并约束 Atom/Bond set、
incidence 和最终图输出一致。第一轮只用受控、语义保持的 renderer 参数变化，不先加入任意模糊、
透明背景或压缩噪声。
