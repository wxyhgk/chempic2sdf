# v0.9.94 AtomPair 跨风格一致性

## 目标

v0.9.93 证明同一分子的四种渲染会产生明显不同结果。本轮不继续扩大最终 verifier，而是把
paired consistency 上移到 v0.9.87 AtomPair graph context：

```text
同一 molecule 的 original / rdkit / coordgen / stress
    -> 训练期 GT 匹配得到 query -> target atom ID
    -> 同一 target AtomPair 的 presence 概率对齐
    -> 整图 count 与 target-atom degree 对齐
```

目标原子 ID 只用于构造训练损失，不保存到推理输出，也不参与部署连接关系。

MR-TADF、USPTO 和 locked internal 均未用于训练、选模或 scale calibration。

## 数据

- paired style train：250 个 molecule、1,000 张图片，每个 molecule 四种渲染；
- replay：ChemVision 500 张、full-v0 500 张；
- 每 epoch：1,000 style + 1,000 replay；
- 共 3 epoch，总曝光 6,000 张；
- style validation：498 张，124 个完整四渲染 molecule；
- official validation：ChemVision/full-v0 各 498 张。


## 表达上限

现有冻结 proposal 在 style validation 上的 representable 为：

| 分桶 | Representable |
|---|---:|

因此 context 层最多只能重排已有 AtomPair，无法为 crossed/near-nonbonded 图片创造缺失的
Atom/Bond proposal。这是本轮最重要的上限约束。

## 实验 A：全 Context 微调

从 v0.9.87 热启动全部 context 参数，同时使用：

- 常规 presence/count/degree/positive-margin；
- paired edge/count/degree consistency；
- 双域 replay 和冻结 teacher 保持项。

## 实验 B：129 参数安全 Adapter

为避免全 context 漂移，保持 v0.9.87 完全冻结，只在 residual 最后一层隐藏表示上训练一个
零初始化 `Linear(128, 1)`：共 129 参数。训练后把 adapter 权重直接加回原 context 最后一层，
因此输出仍是标准 `atom-pair-graph-context-0.1` checkpoint。

同时修正实验 A 的两个问题：

- count consistency 先除以目标键数，避免大分子主导；
- 只有同一 molecule 的四张图全部 representable 时才计算 paired consistency。

## Adapter Scale Calibration

固定 Epoch 3，扫描 `0.00–1.00`、步长 `0.05`：

- `0.00–0.15`：与 baseline 完全相同；
- `0.20–0.90`：先损失 1 张 ChemVision，style 无收益；
- `0.95–1.00`：style exact `348→349`，但 ChemVision 仍为 `348→347`。

最佳安全 scale 为 `0.0`，即不启用 adapter。输出：

```text

outputs/checkpoints/chemvector-v0994-atom-pair-style-residual129-calibrated/best.pt
```

## 决策

v0.9.94 NO-GO：

- 全 context 一致性会通过系统性漏键降低 mixed；
- 129 参数安全 adapter 没有零回退收益；
- scale calibration 不存在安全非零区间；
- style 失败主要发生在 proposal 不可表达阶段，context 层位置太晚；
- 默认前端继续使用 `structure-v0992-carbon`；
- 不运行 locked internal。

下一步把 paired supervision 上移到 Atom/Bond proposal 集合：同一 target atom/bond 在四种渲染中
应有一致的 object presence、anchor/port 和 incidence；优先提高 stress proposal
representability，再讨论 graph context 或最终 verifier。
