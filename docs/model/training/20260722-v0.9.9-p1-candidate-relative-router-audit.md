# v0.9.9 P1 Candidate-Relative Router 路线审计

> 状态：路线协议确定；尚未训练

## 问题

P0 validation500 的标签分布为：

```text
ordinary positive  44,880
ignored            13,882
ordinary negative      53
```

当前数据几乎没有可训练的普通负样本。若继续复用 P0 keep 标签，模型只能学会保留所有
carrier，无法在部署时处理文字笔画、hashed wedge 和 filled polygon。

## 受控审计

- `12,144 / 13,882 = 87.48%` 的 ignore 来自纯文字 bbox；
- 其余主要来自 hashed / polygon 区域；
- 只有 `187 / 13,882 = 1.35%` 是 near-ordinary ambiguity；
- GT bbox 规则可路由 88.78% ignore，误伤 0.100% ordinary positive；
- 完美 text pixel mask 可路由 89.17% ignore，误伤 0.029% positive；
- pixel mask 相比 bbox 只多 0.39pp，不足以支持先训练全图语义分割。

oracle bond-only 会把候选从 117.63/图降到 92.79/图，但 ordinary positive 几乎不变，
只是让文字候选消失。候选消失不会补齐 P1 negative，因此不能解决监督闭环。

## 选择的路线

```text
raw raster
-> raw LSD
-> candidate-relative router
   -> ordinary: P0 extent / physical-line pipeline
   -> text: TextObject / OCR
   -> hashed: dash-cloud symbol head
   -> filled polygon: triangle/quad symbol head
   -> background/noise: DROP
```

不在 LSD 前擦除像素。OCR bbox、polygon contour 和 hash dash-cloud 规则先作为 router 强先验
和确定性基线；全图 pixel head 只保留为 fallback。

最小模型复用 P0 的 337,620 参数与 `carrier_features`，增加 5 类线性 route head，仅新增
645 参数。先冻结 P0；若线性容量不足，再增加不超过 50k 参数的 candidate context adapter。

训练标签为 `ordinary / text / hashed / filled_polygon / background`。重叠和 near-ordinary
ambiguity 继续 ignore；hashed group 内全部 dash 的监督权重总和固定为 1，避免一个虚线组
按 dash 数量压制其他类别。损失使用 class-balanced focal CE 加 ordinary-vs-rest BCE，
extent/normal loss 只作用于 ordinary positive。

## 门控

先在 train-only 分层 256 图做 capacity，再用 pilot train 9k 到固定 validation500 做泛化。

| 指标 | GO |
|---|---:|
| ordinary keep recall | >= 98% |
| ordinary keep precision | >= 80% |
| router 后 q8 ordinary recall | >= 97.9% |
| 相对 P0 q8 下降 | <= 0.5pp |
| 原 ignore 被显式路由 | >= 90% |
| hashed group route recall | >= 90% |
| polygon route recall | >= 95% |
| 16/32px translation regression | < 2pp |
| invalid geometry | 0 |

若线性 head 和 50k adapter 都无法达到 capacity 门槛，才说明 candidate strip 缺少必要上下文。
只有全图 pixel head 在同等 ordinary recall 下将 precision 提高至少 3pp、剩余 OOS leakage
减半且 CPU 延迟增加不超过 15%，才允许升级为主路线。

## 决策

P1 的首要问题是显式分流和负样本协议，不是继续提高普通 LSD 几何，也不是在 LSD 前训练
大语义分割器。正式训练前仍需先解决同一 physical line 的多 anchor 去重。
