# v0.9.32 Semantic Bond Relation v0.1

## 目标

针对 `Data/images/test1.png` 和 `test2.png` 中模糊线条被拆成多键、漏键和错误键级的问题，冻结
Vertex/Junction、OCR 和候选选择，验证以下表示：

```text
一个无序 Junction pair
    -> 一个规范化二维 Bond relation
    -> visible display type
    -> ring-aware chemical type
```

模型不再把双键表示为多条独立物理线。两个端点的顺序反转后，输出通过双向编码平均保持不变。

## 模型

新增：

- `chemvector/semantic_bond_relation.py`
- `chemvector/pretrain_semantic_bond_relation.py`
- `tests/chemvector/test_semantic_bond_relation.py`

每条 GT 键生成两个规范化视图：

- local：`6×64×192`，覆盖完整键走廊；
- context：`6×128×192`，覆盖端点外侧和环上下文。

六个通道为 RGB、ink 和两个 endpoint heatmap。训练时 50% 样本执行固定高斯模糊和 0.72 倍
下采样再放大，同一 Bond relation 的标签不变。display 与 chemical type 使用独立 head。

模型参数：1,679,976，checkpoint 约 20 MB。

## Pilot 训练

数据：`chemvision_layers_v0_2/font_pilot_10k`。

- train cache：500 张；
- validation：200 张跨字体图片，7,208 条 GT 键；
- 总曝光：10,000 张；
- batch：2；
- 训练 pair：仅 GT positive relation，不训练 existence；
- 最佳 checkpoint：step 6,000。

最佳结果：

| 指标 | Clean | Degraded |
|---|---:|---:|
| display accuracy | 79.40% | 79.50% |
| chemical accuracy | 92.91% | 92.99% |
| joint accuracy | 75.44% | 75.60% |
| chemical SINGLE | 95.91% | 96.11% |
| chemical DOUBLE | 83.21% | 83.58% |
| chemical TRIPLE | 100% | 100% |
| chemical AROMATIC | 90.38% | 90.23% |

Clean 与 degraded chemical accuracy 相差 0.08pp，证明该对象表示对本轮模糊/缩放操作稳定。

## 直接逐键覆盖失败

将 semantic chemical argmax 直接覆盖所有预测键，在 USPTO clean 100 上使 valid 降到 27%、
键级整图降到 11%。主要原因是靠近芳香环的外侧单键也被局部 context 判成 AROMATIC/DOUBLE。
单条关系的宽上下文仍不能无约束地决定 chemical aromatic type。

## 环级融合

新增 `aromatic_ring_only`：

1. 非环键保持原类型；
2. 只检查预测图中的完整 5/6 元环；
3. 环内所有边的 aromatic 证据均达到下限，且整环均值过阈值时，一次性提升整个环；
4. 不允许逐键产生部分芳香环。

固定阈值为 mean 0.72、minimum 0.25。低阈值将改键数从 4 增至 20，但 USPTO 100 无净收益，
因此停止阈值扫描。

## 决策

- Semantic Bond relation 表示：GO；
- 模糊/缩放一致性：GO；
- 环级 aromatic fusion：GO；
- 逐键 chemical 全覆盖：NO-GO；
- 当前 checkpoint 替换 shadow：NO-GO，原因是 valid -10.6pp；
- Vertex/Junction 继续冻结。

下一实验训练通用 Relation existence。`test2` 的长连接键只作为失败样例和长度分桶之一，不做
专项过采样或键长阈值；随后设计只修改最少键/原子的 structured invalid rescue，补回 valid，
而不允许旧 corrector 覆盖已确认的环语义。
