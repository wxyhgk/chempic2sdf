# v0.7.44 候选二维 Patch 受控 A/B

## 目标

v0.7.42 和 v0.7.43 使用射线、角度等手工标量后，只能在漏点和线内假点之间折中。
本轮检验一个更严格的问题：在训练数据、参数量、损失和候选池相同的条件下，
`32×32` 原图二维 patch 是否明显优于已经存在的 `3×3×96` stride-4 特征 patch。

候选协议保持不变：文字和隐式阈值均为 0.05，最多 256 个候选，6px 匹配与同角色
抑制，全部 32,640 个候选点对保留。没有距离、最近邻或键长裁剪。

## 实现

新增两种参数量接近的节点残差：

```text
A: 3×3×96 冻结视觉特征 -> MLP -> 192 维节点残差
B: 32×32 原图墨线 patch -> 四层 CNN -> 192 维节点残差
```

A、B 的最后一层都零初始化。可训练参数分别为 569,327 和 565,855，差异约 0.6%。
原图 patch 在缓存阶段以亚像素坐标采样并量化为 uint8，训练时恢复到 `[0,1]`。

同时增加明确线内困难负样本：候选必须不属于任何真实顶点组、距离真实键段不超过
3px、投影位于 0.15 到 0.85、距离键端至少 8px，并且距离任一真实原子超过 10px。
损失要求每个真实顶点组的最佳候选高于最难线内假点。该监督不直接删除候选。

评测记录现在会为每个漏点保存 `candidate_available`，从而区分：

- 候选已经生成，但 selector 没选中；
- 正确角色候选根本没有生成。

## 容量测试

固定 validation 前 100 图，训练 5,000 exposures：

| 模型 | 可训练参数 | 最佳 exact | 门槛 |
|---|---:|---:|---:|
| A：feature patch | 569,327 | 90% | 88% |
| B：pixel patch | 565,855 | 90% | 88% |

两组均通过容量门槛。

## 2k 受控 A/B

两组使用相同的 2,000 张训练图、498 张 validation、10,000 exposures、随机种子和
损失权重。模块评测结果：

| 模型 | 最佳 deployed exact | Count exact | F1 |
|---|---:|---:|---:|
| A：feature patch | 57.83% | 63.65% | 97.82% |
| B：pixel patch | 56.22% | 63.25% | 97.84% |

B 相对 A 为 `-1.61pp`，没有达到预注册的 `+3pp` 晋级要求。

接入 v0.7.38 Bond Object 后：

| 指标 | A：feature | B：pixel |
|---|---:|---:|
| Role vertex exact | 57.83% | 55.22% |
| Coordinate vertex exact | 58.84% | 56.02% |
| Skeleton exact，bond=0.90 | 52.61% | 50.80% |
| 长键条件 recall，bond=0.80 | 95.59% | 97.04% |
| 漏点 | 473 | 512 |
| 候选存在的漏点 | 267 | 306 |
| 候选不存在的漏点 | 206 | 206 |
| 多余点 | 276 | 244 |
| 3px 线内假点 | 152 | 116 |

B 确实减少了 36 个线内假点，但同时增加 39 个漏点，且增加的全部是“候选已经
存在但被 selector 拒绝”的漏点。这是与 v0.7.42 相同的单边交换，不是有效提升。

## 候选覆盖实测

使用新审计重新评测 v0.7.43 的 498 张 validation：

```text
总漏点                         454
候选存在但 selector 漏掉       251
正确角色候选不存在             203
涉及无候选漏点的图片            59
```

因此约 44.7% 的漏点无法由任何候选后 selector 修复；此前按 Candidate recall 估算的
约一半方向基本正确，但现在已经有逐点实测值。

## 决策

- 大原图 patch 相对同容量 feature patch 判定 NO-GO，不进入 9k 正式训练；
- patch 能学习线内构型，但将其直接耦合到 REAL 分数会导致过度保守；
- 不替换 v0.7.38 shadow，不打 tag；
- 下一步把 `PASS_THROUGH` 作为独立辅助类别或上下文，不再直接作为 REAL 排序惩罚；
- 候选生成侧单独处理 203 个无候选漏点，不能与 selector 调参混为一轮实验。
