# 逐图偏移排程与接线已核验；原图交叉线风险已定位

接续 [固定 58 图增强准备](20260924-pair-anchor-augmentation-result.md) 和多 agent 审查。
本轮落实前两步：**修正排程／行号接线，并复核唯一被提示的训练图局部**。
不是新训练结果，没有模型准确率变化。

## 1. 消除了固定 58 图与八偏移的周期冲突

新增 `PerImageOffsetCycle` 以每张图自己的访问次数推进，八个偏移顺序沿用原定义。
空原监督、空增强都消耗一次访问，不重抽、不按标签或分数寻找好方向。
旧哈希绑定协议与代码保留，新实现不改现有训练／推理默认入口。

下面都是**保存行号上的 CPU 计数模拟**，没有真实 optimizer update：

| 固定范围 | 实际模拟尝试／非空更新 | 原位置正／负观察 | 新增正／负观察 | 原可达真键中未获增强 |
| --- | ---: | ---: | ---: | ---: |
| 50 次非空更新上限 | 54 / 50 | 976 / 5,496 | 575 / 3,290 | 528 |
| 58 图完整一遍 | 58 / 54 | 1,103 / 6,244 | 650 / 3,727 | 453 |
| 新排程完整八次访问 | 464 / 432 | 8,824 / 49,952 | 5,880 / 31,255 | 0 |
| 旧 global-attempt 对照八轮 | 464 / 432 | 8,824 / 49,952 | 5,764 / 30,372 | 50 |

旧规则每图最多遇到四个方向，50 条真键及 288 条确认非边永久拿不到增强。
新规则在完整八次访问中，各图均遇到八方向；所有原采样行至少获得一次合格增强，
复现旧准备的 37,135 条潜在重复观察。**464 次只是计数核验，不是扩展 GPU 预算。**

有限预算的缺口也已显式化：50 次非空更新只走到第 54 张图，
最后 4 张图的 127 条可达真键、748 条采样非边连原位置回放都没被访问。
完整一遍需要 58 次尝试／54 次非空更新（其中 4 张为空）；5 次非空原监督的增强分支为空。
两种短排程都只使用固定顺序的第一个非零偏移 `(-4,-4)`，不是八方向稳健训练。

4 条可达 P–O 和 3 条 P=O 在完整一遍中均获原位置和增强各一次；
缺失的第 5 条 P–O 仍为零。三键原位置 5 条，增强只有 3 条。
47 条不可达目标仍保留在分母。逐图计数只消除周期遗漏，
不消除 GT 距离筛选的方向／键型偏差，也不增加化学结构多样性。

## 2. 补齐行号转换和实际 pair 调用接口

新增独立 CPU 原型 `pair_anchor_wiring.paired_objective`：

- 从调用当时的候选、原对应关系与目标建立监督／偏移计划，不读取历史 plan 当作新缓存。
- 显式把全 pair `row_id` 转换为 `sampled_position`；乱序、非连续、缺失和重复行号有测试。
- 原／偏移两次调用的 feature map、atom features、scores 和候选身份不变；只平移取样坐标。
- 上游输入 detach，pair 必须 eval；未知对应不能进训练行。原监督空则不 forward，
  增强空则只算原位置；纯负例分支仍保留，不能与完全空监督混为一谈。
- weight=0 连额外 forward 都跳过。用两份相同的随机初始化 CPU toy linear 模块，
  连续 3 步 AdamW 验证原入口与新入口的 loss、梯度、参数、优化器状态、RNG 逐值一致。

合成测试里的 toy 参数更新不是实际分子模型训练。weight=1 仍会改变共享参数总梯度，
不能从原 loss 项保留推断旧正确键一定不退步。当前接口明确拒绝 GPU；
实际 GPU cache/launcher 及执行设备等价性仍需单独实现和验证。

## 3. 原图复核：交叉的 C=O 早已在原始采样带里

仅打开已核对 PNG/SVG SHA 的原训练图
`curr_d5ee3c0fcdc3c6c7__line_thick`，没有读新的开发／封存图或隔离 P–O 图。

检查对象为 row 1523，候选 39–42，对应 C12—O13 的 bond 12：
chemical SINGLE，drawing BEGINWEDGE。另一条 **C9=O10 的 bond 9** 与它在图上交叉，
但两条键在原图标签里没有共享端点。

| 取样偏移 | 本楔形键墨迹落入 ribbon | 外来 C=O 墨迹落入 ribbon | 第三原子提示 |
| --- | ---: | ---: | --- |
| 原位置 `(0,0)` | 179 / 182 px | 180 px | 无 |
| `(-4,-4)` | 170 / 182 px | 178 px | C9 |
| `(-4,0)` | 178 / 182 px | 171 px | C9 |

数值来自按原 SVG 节点分别栅格化的墨迹与连续 ribbon 足迹相交，
不是模型特征图、离散采样权重、可见概率或准确率；不同键的计数不能当成不重叠像素相加。
所有九个偏移的数值（包含不合格视图）均保存，没有只挑两个提示视图报告。

![原图、原位置及两个提示偏移](../../../outputs/audits/chemvector-pair-anchor-wiring58-20260924/visual.png)

蓝框是连续 ribbon 范围，红线是预测端点连线，紫点标出进入范围的非端点 C9。
左侧原始局部不加标记。可直接看到：交叉线不是这次平移制造的新图像错误。

因此，“无第三原子提示”**不能当成采样带内没有别的键线的证明**。
原 C—O 标签仍对应同一化学边，未发现需要重配／改标签的依据；本键墨迹也没有消失。
保留该困难正例和原困难负例，把本键及相邻 C=O、交叉处非边列入后续保护检查。
这完成了局部可见性复核，不保证模型能消解交叉，也不证明所有增强样本均无歧义。

## 后续建议

先准备 **58 图单遍、54 次非空更新上限**的有／无增强匹配对照协议，
避免 50 次更新截断最后 4 张回放图；这只是预算草案，不是现在开训或自动增加旧预算。
两臂都从相同 initial 与同设备新缓存出发，使用相同图序、原监督、阈值、评估集合；
只比较额外偏移分支，不同时更改 selector、OCR 或追加另一种非边回放策略。

验收必须包含原位全部候选对、每条初始正确类型键、确认假边、原有效／正确 SDF 和
fallback，不只比较净增或 loss；交叉 C—O/C=O 专门列出，unknown 仍单列。
未获增强的 453 条可达真键依旧有原位置回放，不得从验收中消失。
这仍只是 train-fit 可行性，不是八方向稳健性或独立泛化结论。

实际开跑前还需匹配对照的预算、GPU 执行设备接线／缓存验证、新用途与单次运行授权。
旧授权不复用，暂不自动训练；本轮 `safe_to_launch=false`。
