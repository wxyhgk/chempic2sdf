# v0.9.55 Object Presence / Incidence Oracle 阶梯

> 状态：诊断完成  
> 权重：v0.9.49 best  
> 数据：固定 internal_test 100

## 目标

固定图像、proposal、阈值、键型和 Oracle 原子化学状态，分别替换对象 presence 与 incidence，
测量当前联合链路的真实瓶颈。Oracle incidence 只作用于 cache 中可监督的真实 Bond proposal。

## 结果

| Object presence | Incidence | 非立体 exact | Chemical exact |
|---|---|---:|---:|
| predicted | predicted | 36% | 31% |
| Oracle | predicted | 34% | 30% |
| predicted | Oracle eligible | 34% | 29% |
| Oracle | Oracle eligible | 51% | 46% |

单独替换任一分支都会改变去重、删边和错误补偿，不能产生净收益；二者同时正确时 exact 增加
15pp。这证明下一目标必须是 Atom/Bond presence 与 incidence 的集合级联合匹配，不能继续独立
优化 endpoint micro accuracy、全局 count 或单边阈值。
