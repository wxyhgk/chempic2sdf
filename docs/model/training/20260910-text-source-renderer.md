# 2026-09-10：同一 SVG 来源的可见文字参考生成器

## 本轮结论

已实现独立参考生成器 `Data/sdf/text_source_renderer/`，并验证：
**文字标签来自实际生成 PNG 的最终 SVG 字符节点，不再从化学 H 数推算。**
这解决的是新样本的图文监督一致性；没有证明旧数据已经修好，也没有证明
模型的原子／线条混淆已经解决，更不能由此推断 MoE 或其他模型架构的优劣。

原型仍是新渲染协议：固定 DejaVu Sans、RDKit noFreetype 输出、CairoSVG
光栅化。不能把这个协议重绘得到的文字记录回填到旧 FreeType PNG 上。

## 下一步重点

当前实现拆成渲染协调、SVG 归属、光栅标签、运行器四层，不依赖模型或 OCR
审计模块。下一步首先补全**接缝辅助图形的独立归属契约**，扩展折线、环、
立体键等合成回归；不能为了扩大支持率，把未归属路径一律塞进键标签。

这一步之后再讨论新版本数据的覆盖率与受控训练对照。参考生成器不意味着
推理必须变成“先 OCR、再找线条”；可见文字和化学属性分离是监督数据契约，
不是推理串行顺序。所有当前输出保留 `training_authorized=false`。
