# 阶段3：21个筛选缺口与单候选排序约束

## 结论与执行决定

继续原计划第三阶段，已定位initial中21个“raw候选存在但selector没有保留”的节点。
其中8个是真候选分数低于所属笔画伪点，7个局部排序正确但分数未过阈值，
6个尚无稳定的所属伪点配对。不能用一种“多保留一点”的修正解释全部21个缺口。

**优先研究真节点与所属伪笔画的判别，而不是继续调低阈值或扩大训练量。**
这8个排序倒置在四个历史阶段中均未消失，且每个节点只有一个空间合格候选。
因此先实现了一个明确拒绝多候选组的成对排序数学原型。
CPU检查通过，但它不是完整训练目标，更不是模型已经改善。

默认仍为initial；上轮热图试训checkpoint仍拒绝采用。本轮没有模型前向、加载权重、
模型参数梯度或优化器更新，没有使用GPU，没有启动/授权新训练，也没有改推理阈值、OCR、匹配器或标签。

## 新增原型：只验证单候选相对判别

实现位于`tools/selector_singleton_rank.py`，数学目标为：

```text
L_rank = mean_node mean_owned_fragment softplus(z_fragment - z_valid)
```

节点等权，不因一个字形产生更多片段而增加该节点总权重。
只允许恰好1个空间合格候选、有稳定片段配对且监督slot互不重叠的节点。
显式拒绝多候选组，不通过argmax挑选伪标签，不复用此前失败的exactly-one损失。
21个缺口中有2个多候选组，因此本原型明确不覆盖它们。

对8个节点、6张图、25个所属片段的四阶段保存logits计算导数：

- 每阶段8个真候选的直接下降方向均向上，25个片段均向下；相对分差方向均改善。
- 每节点真候选导数等于所属片段导数之和的负值，共同平移方向导数为0。
- 每阶段其余735个未被该公式引用的候选logit直接导数为0。

这些只是输出分数的数学性质。**未被公式引用的logit导数为0，不代表共享参数更新后这些节点不变。**
本轮没有检查实际selector共享参数方向，也没有执行有限步训练。
上轮热图试验已说明：有利方向检查不能代替真实旧图保护。

此目标对整体分数平移不敏感，因此不能作为完整训练损失。
反例：真/伪分数为(-3,-5)与(2,0)时排序损失相同，固定-0.25阈值的选择结果却不同。
排序正确既不保证真候选被保留，也不保证伪点被排除。
本轮没有把它与其他损失任意加权、没有权重搜索或新的训练准入。

## 下一步的唯一优先项与停止条件

优先做**单候选节点的固定阈值判别原型**，而非继续单独优化排序。
先核对这8个节点/25个片段的标签适用性，再固定一个同时满足下列要求的监督契约：

1. 对核准的节点，目标必须同时包含`z_valid >= -0.25`和`max(z_owned_fragment) < -0.25`。
   不能用相对margin变好或总体召回增加替代这两个决策。
2. 在合成反例中覆盖：整体平移、相同特征冲突、多片段等权、未知片段不监督；
   多候选组仍单独留出，不恢复被否决的exactly-one目标。
3. 然后检查冻结骨干下真实selector的共享参数方向，以及固定58图旧节点的逐ID风险。
   若目标点上升同时伤害原有正确节点，停止；不直接换优化器、解冻骨干或放大数据试错。
4. 若以后获得一次有限步试训准入，验收必须同时看固定阈值的真/伪选择、旧节点覆盖、
   逐ID可达键、实际正确连接/键型和严格SDF。总量增加不能抵消某张旧图正确键丢失。

步骤1—3还没有完成；当前尚无新完整训练目标或新GPU试训方案获准。
7个局部排序正确的缺口、6个负例证据不足的缺口和10个raw缺口分别保留，
不宣称以上原型能解决全部问题。上轮Br方向冲突和旧图峰替换也继续作为约束保留。
