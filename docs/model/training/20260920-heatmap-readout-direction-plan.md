# 顺序推进阶段1：固定7图、129参数共享方向检查

用户“开始按照顺序推进”确认先做CPU方向检查，支持后才进入新的单卡600秒/400步定额试训。
本文件在新特征观察之前固定阶段1方案；不是已有结果报告，也不扩大数据准入。

## 执行范围

- 默认initial不变，固定此前7张旧训练/回放图、226个原子，其中10个raw缺失、其余216个。
- CPU最多120秒，每张真实图片一次vision/atom前向，共7次；GPU、优化器步数、自动重试均为零。
- 捕获原子头隐藏特征，先保存图像前向结果，再读取对应目标坐标。
- 与上一轮CPU dense快照逐张逐值核对；失败则不继续解释历史缺口。
- 原模型全部冻结。由保存logits的focal-loss导数，链式投影到128个热图权重和1个偏置。
  不更新模型，不在真实参数上积累.grad，不运行下游或OCR。
- 每图热图包含全部原子；梯度按7张图的原始focal热图损失等权平均，不只拟合10个缺口。
- 输出每图自身方向、全批共享方向，以及所有226个原子和216个原有raw正峰的分差变化方向。
  原有raw正峰的数量必须由实际原指派核对，不能直接假定216全部在GT所在格。
- 固定半径、阈值、top-k、offset和所有其他输出；不扫描任何超参数。

## 事先固定的停止规则

关注量为GT格logit减去3×3邻域中最大其他格logit的右方向导数。
多个邻格同分时使用最大方向导数，不任意挑选有利平局。

若10个漏点中不足6个分差改善，或10个分差方向之和不为正，判为当前方向NO_GO。
如关注竞争格实际是另一个真值原子，也不直接准入压制该格的方案。
数值零容差固定1e-8。这是保守工程关卡，不是统计显著性检验或数学不可行性证明。

NO_GO：不消耗条件式GPU试训预算，不换优化器绕过关卡，不自动解冻更大网络；
先解释冲突发生在单图内部还是跨图共享方向，提出一个针对性后续方案。

DIRECTION_SUPPORTED：只支持准备计划中限定的阶段2，不意味着恢复了候选、
保护了旧图或提高了分子准确率。阶段2仍须绑定58图用途、固定唯一配方、检查缓存失效，
重跑受新候选影响的筛选及连键，并执行原有正确点/可达键保护和200步无恢复早停。

阶段1未计算完整58图的梯度，也不是AdamW方向或任意有限步长的模拟。
不能从一次方向失败推出129参数空间、所有优化器或整个自研架构不可行。
没有开发64逐图读取、封存测试读取、身份查询或全批训练数据发布。
