# v0.7.33 独立文字对象中心分支

## 结构

新增独立 `TextObjectCenterHead`，共享冻结的 stride-4 视觉骨干，但不与隐式顶点
共享输出头。分支预测：

- 文字对象中心 heatmap；
- 亚像素中心 offset；
- bbox 半宽和半高。

标签来自 ChemVision Layers 的文字实例，不读取字符内容、元素或化学含义。bbox 用于
屏蔽文字笔画产生的 dense 假顶点。

## 训练

- train：9,000 张，3 个字体家族；
- validation：500 张未见字体；
- internal test：500 张另一未见字体，只作最终盲测；
- 视觉骨干完全冻结；
- 可训练参数：92,613；
- 最佳 checkpoint：约 43,992 次图片曝光。

validation 最佳：

```text
F1                  96.34%
Count exact         63.65%
Text vertex exact   60.24%
```

## Internal Test 500

纯文字对象检测：

| 子集 | F1 | strict exact |
|---|---:|---:|
| 全部 500 | 94.30% | 55.60% |
| 大字号 140 | 96.26% | 64.29% |

与隐式 dense 顶点合并，隐式点数量使用真值进行机制验证：

| 模式 | F1 | vertex exact |
|---|---:|---:|
| 原图 dense | 75.04% | 0.4% |
| 真实文字对象 Oracle | 84.42% | 2.8% |
| 预测文字对象 | 83.14% | 1.8% |

预测分支获得了 Oracle 增益的大部分，F1 提高 8.10 个百分点，exact 提高 4.5 倍。

## 决策

- 独立文字对象中心与 bbox 分支：GO；
- 大字号不是该分支的瓶颈，反而比总体更准确；
- 当前合并后的主要瓶颈转移到隐式骨架顶点，其 F1 只有 78.35%；
- 下一步把隐式顶点训练标签限制为 `visible_text=false`，并使用预测文字 bbox 作为
  抑制区域；随后再接回 256 候选全点对线条图。
