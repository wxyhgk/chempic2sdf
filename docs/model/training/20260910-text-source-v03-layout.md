# 2026-09-10：v0.3 文字排版修订与固定矩阵配对

## 结果与决策

在上一轮相同的 128 个主样本上，严格验收从 **106/128（82.8125%）提升到
127/128（99.21875%）**。原成功样例 106 个全部保留，原拒绝样例恢复 21 个，
剩余 1 个拒绝，0 个程序错误。12 个负对照仍全部按预期拒绝。

**不据此启动训练或替换旧生成器。** 本轮也发现了新的质量风险：部分大画布
样例的标签／键留白偏大。严格无重叠不等于视觉分布合理。

## 实际改动

新增独立包 `Data/sdf/text_source_layout/`，不编辑被冻结的 v0.1、v0.2、
覆盖运行器源文件或旧输出。

1. 原生画布 padding 从 0.08 改为 0.12，额外标签 padding 从 0 改为 0.25。
2. 用最终字体的实际光栅墨迹测量字符 bbox，为同一标签内部添加有界水平间距。
   字符内容、发射顺序、字号、上下标高度不变；空间处理不改写键／辅助路径。
3. 新增独立质量记录，区分同标签字符接触、跨标签字符接触、文字／键相交、
   文字／辅助图形相交与触边裁切。

最终验收仍调用**冻结的 v0.2 compile_layers**，保持 alpha>0 的支持集，
没有把阈值改成 128，没有重分类旧拒绝样例，没有自动重试或筛换输入。
改动作用在实际 SVG／PNG，而不是只改标签或通过率统计。

质量记录中的 before_spacing 是“v0.3 预留空间后、字距调整前”的图，
不是 v0.2 图。多个改动合并测试，不能把全部提升单独归因于字距修正。

## 剩余失败与目视发现

唯一剩余拒绝为 `polyamine__compact`：错误为 `Degenerate auxiliary junction`。
预留更多文字间距后，局部键段过短，仍无法满足已有辅助路径契约。
没有放宽该契约来使其通过，也不将其算作程序错误。

主代理目视检查了以下 6 张恢复成功的原始新 PNG：
zwitterion__baseline、isotope_ammonium__baseline、anhydride__baseline、
polyamine__baseline、polyol_ring__compact、disconnected_salt__large。
可见字符、上下标、化学线条与文字间距调整；未对全部 127 张逐一人工检查。

复核也观察到大画布留白风险。在 `disconnected_salt__large` 中，按
“关联直线键端点到 carbonyl O 墨迹 bbox 的最小欧氏距离”测量：

- v0.2 对应诊断重放：约 11.819px。
- v0.3 最终 SVG：约 46.853px。

原例在 v0.2 因另一个 O/负号字符接触而拒绝，因此这里的旧 SVG 来自上一轮
明确标记的诊断重执行，不是首次失败时保存的成功样本。此距离只是一个
局部布局指标，但足以提示：用更大留白消除相交，也可能造成新的视觉偏差。

## 回归与边界

新增 32 项测试，与原有相关回归合计 **309 项通过**。涵盖旧合成文字、
化学属性／立体方向、同源 PNG 重放、质量记录绑定、只改水平坐标、
有界间距、不可见画布外墨迹检测、严格拒绝传播、负对照、配对退化统计、
新旧共同成功样本的化学／转录一致性、协议与文件完整性等。

四份早期协议的 752、755、756、7 项源记录均无变化；v0.1 的 5 项、
v0.2 的 11 项、上一轮覆盖的 16 项源记录也均一致。
没有读取新的训练／评估分子语料，没有运行 OCR 或训练，没有改变默认入口。
所有输出继续 `training_authorized=false`。

## 下一步重点

优先把**标签／键留白改为受像素尺度约束的布局**，增加最大间距边界，避免
随绘图规模产生过大空隙；同时保留当前字距、裁切和相交检查。
先解决已经观察到的留白副作用，再用未参与修订的新样本做独立验证。
本次 99.2% 不外推到真实语料，也不用于判断 MoE 或其他模型架构的优劣。
