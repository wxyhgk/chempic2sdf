## 2. 连键更新观察适配器已完成，真实诊断未执行

新增 `chemvector/training/curriculum/pair_observed_update.py`，包裹原有
`pair_cached_trial.update_once`，不复制或改写其采样、损失或优化器实现。
固定观察对象由训练 manifest 解析，下一次必须从新缓存重新绑定目标，不复用历史候选槽位：

| 样本完整键 | 目标原子对 | 历史概率变化，仅作问题背景 |
| --- | --- | --- |
| `full_molecule_expansion:curr_4ef506af64e8f0b8__bond_short` | (31, 34) | 0.351084 → 0.950123 |
| `full_molecule:curr_08d02946e879406f__font_large` | (7, 14) | 0.069670 → 0.963315 |

每次非空更新：先同步记录两个探针，再调用一次原更新，最后记录更新后的两个探针。
记录包含更新样本、step/attempt、本图或其他图更新、探针负例是否被本次采样、logit 变化。
只能定位“在哪次更新时变化”，不能直接归因到 presence / chemical 某个 loss 分量。

观察要求 eval/no-grad、固定缓存和确认非边；未知、正例、过期绑定均拒绝。
探针的随机数调用与更新隔离；空监督不观察、不调用优化器、不消费步数。
记录失败、更新失败、外部步数／pair 状态改变后禁止在同一实例继续或重试。
失败时参数可能已经改变，不能把日志失败解释为权重回滚成功。

准备入口：`tools/prepare_pair_observed_trial.py`。
53 项相关合成测试通过，逐值比较有／无观察器的损失、采样、参数、Adam 状态和 CPU RNG。
**这些测试包含微型合成模型更新，不是 ChemVector 真实训练，也不证明 GPU 数值一致性。**

未来草案限额为固定 58 图、最多 50 步／58 次 batch 尝试、单卡整个 worker 最多 600 秒、
单次运行、无自动重试；原 initial、目标、阈值和整图保护条件不变。
50 次更新最多增加 200 次单 pair 探针前向，不调用文字、OCR 或上游模块。

## 3. 数据来源与使用历史：不能把“没在 58 图里”当成独立

本轮只读取固定来源的训练清单、历史诊断计划及三个训练日志，不打开图像、开发逐图预测、
封存测试或私有身份服务。只对训练／已知隔离诊断 SMILES 在本地计算结构分组。
继承原已发布 train/dev 分离证据，不做新评估身份查询或重新划分。

已发布池包含 **13,151 个训练条目、2,173 个 molecule_id**；原发布报告记录 12,985 张不同 PNG。
其中课程图 657、旧完整分子图 1,668、新增完整分子图 10,826。
`reference` 样式有 2,146 条，但此次未看图片，不能仅凭样式名认证视觉干净。
包含单／双／三／芳香键结构；**多片段结构为 0**，不能据此验证跨片段错误连接。

排除关系不是仅 sample key：通过 molecule_id、声明／重新计算的核心分组、连接前缀做
传递合并，得到 2,122 个关联结构组件。记录分为：
