# v0.9.24 有序邻域 Veto OOF

> 状态：正式 3-fold OOF 已完成，结论为 `FIT-OOF-PAIR-NEIGHBORHOOD-VETO-NO-GO`。
> 近共线邻域包含有效信号，但重新塞回独立 pair veto 后被 v0.9.23 严格支配。

## 目标

v0.9.23 剩余错误集中在双键/三键与单线相接的 junction。单个 `2×24×48` crop 能看到白缝，
却不知道候选上下还有哪些只覆盖左半或右半的近共线线段。本轮为每个 pair 加入 target-free
carrier neighborhood。

## 邻域表示

每个 pair 最多保留 12 条近共线 anchor，先按绝对法向距离选最近邻，再按带符号法向偏移排序。
每条邻线使用 8D token：

```text
signed normal offset
angle difference
whole overlap
left-half overlap
right-half overlap
relative start
relative end
length ratio
```

完整 OOF sidecar：

```text
7,200 images
368,573 pairs
float16 [pair,12,8] + bool mask
target-aware fields in cache = 0
```

模型保留 v0.9.23 的 480D profile，并将邻居 `8→16` 编码后拼接 ordered flatten、mean、max 和
count。总参数 108,033。训练仍使用 v0.9.21 普通安全 loss；forward 不读取 group type、group ID
或 pair label。评估基线固定为：

```text
consensus = min(v0.9.19, v0.9.20)
candidate = consensus + one-way neighborhood veto
```

## 正式结果

| 指标 | raw | consensus | neighborhood veto |
| --- | ---: | ---: | ---: |
| selected cross | 33 | 19 | 17 |
| M2 recall | 99.55087% | 99.64149% | 99.64083% |
| pairable exact | 94.58255% | 96.38265% | 96.39979% |
| parallel-2 violations | 2 | 1 | 1 |
| support lost | 31 | 25 | 22 |

三折合计删除 2 个 negative，同时误删 2 个 positive。两个被正确删除的 negative
`000008304/pair7` 和 `000003450/pair50` 都已经被 v0.9.23 删除；新增变化
`000002277/pair4` 和 `000003870/pair6` 都是 positive。因此 v0.9.24 没有提供 v0.9.23 之外的
安全修复，并被 v0.9.23 的 `cross=16 / positive veto=0` 严格支配。

## 结论

邻域统计能命中 multi-line junction，但逐 pair 输出仍将一个组件拆成多个独立二分类决定。
模型没有直接优化“整组 matching 是否正确”，所以只能重新学习 v0.9.23 已会的局部删除，并开始
误伤 positive。停止继续扩大该 veto 的参数、步数或 loss 权重。

下一步只在多节点候选组件上训练联合 matching；孤立 pair 继续使用 v0.9.23，不被组件模型改写。
