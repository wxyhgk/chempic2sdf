# v0.7.11 结构残差适配器

> 状态：NO-GO  
> 基础 checkpoint：`outputs/checkpoints/chemvector-v079-relation-all-pairs-9k/last.pt`  
> 最终 checkpoint：`outputs/checkpoints/chemvector-v0711-molgrapher-structure-adapters-mixed-10k/last.pt`

## 目的

结构头插值无法同时保留 USPTO 和 MR-TADF。该实验冻结 v0.7.10 的全部已有参数，
只增加末层零初始化的残差支路，保证训练前对同一输入的输出逐位等于旧模型。

新增支路：

- vertex：`96 -> 32 -> 4` 卷积残差，27,812 个可训练参数；
- pair feature：`128 -> 32 -> 64` 残差；
- relation logits：`64 -> 32 -> 4` 残差；
- pair 与 relation 合计 8,836 个可训练参数。

## 数据与训练

两阶段均使用 80% MolGrapher Synthetic train、20% ChemVision font pilot replay，
每阶段 10,000 次图片采样，画布固定为 768 x 768，学习率 `1e-4`。

vertex：

```bash
.venv-train/bin/python -m chemvector.pretrain_vertex \
  --init-checkpoint outputs/checkpoints/chemvector-v079-relation-all-pairs-9k/last.pt \
  --train-shards 'Data/sdf/molgrapher_synthetic_v0_1/pilot_10k/shards/train-*.tar' \
  --validation-shards Data/sdf/molgrapher_synthetic_v0_1/pilot_10k/shards/validation-000000.tar \
  --replay-shards 'Data/sdf/chemvision_layers_v0_2/font_pilot_10k/shards/train-*.tar' \
  --replay-probability 0.2 --train-samples 10000 --batch-size 8 \
  --learning-rate 1e-4 --residual-adapter --adapter-dim 32 --freeze-base-head
```

relation：

```bash
.venv-train/bin/python -m chemvector.pretrain_relation \
  --init-checkpoint outputs/checkpoints/chemvector-v0711-molgrapher-vertex-adapter-mixed-10k/best.pt \
  --train-shards 'Data/sdf/molgrapher_synthetic_v0_1/pilot_10k/shards/train-*.tar' \
  --validation-shards Data/sdf/molgrapher_synthetic_v0_1/pilot_10k/shards/validation-000000.tar \
  --replay-shards 'Data/sdf/chemvision_layers_v0_2/font_pilot_10k/shards/train-*.tar' \
  --replay-probability 0.2 --train-samples 10000 --batch-size 2 \
  --learning-rate 1e-4 --include-all-train-pairs --include-all-validation-pairs \
  --residual-adapter --adapter-dim 32 --freeze-base-head
```

## 局部结果

- vertex validation：precision 60.20%，recall 74.83%，F1 66.72%，count MAE 7.071；
- relation validation：edge F1 90.90%，可见键级准确率 91.69%；
- Oracle vertex skeleton exact：15.5%（阈值 0.4），旧基线为 8.3%；
- detected vertex skeleton exact：0.5%（阈值 0.5），旧基线为 0.5%；
- vertex exact：0.7%，旧基线为 0.8%。

## 决策

适配器明确改善了“给定正确顶点后的连线”，但没有改善端到端顶点集合，继续跑
USPTO/MR-TADF 不会改变这一事实，因此按早停规则不执行外部门控，不升版。

下一轮不能只靠普通 replay 标签。更合理的训练方法是保留一个冻结的 v0.7.10
teacher，在 replay 图片上直接约束新模型的 vertex heatmap、offset、aromatic 和
relation logits 接近 teacher，同时在 MolGrapher 图片上学习新标签。这样约束的是
旧行为本身，而不是仅仅重复旧数据的监督任务。
