# G3 P5-E6 Refine Error Decomposition

> 日期：2026-08-08
>
> 状态：已完成

## 目标

P5-E5把动作扩到1,378后，calibration/holdout恢复率提高到77.42%/53.73%，证明数据量有效但
仍未过门。本轮不训练，只对冻结P5-E5的98个跨scaffold Oracle动作拆解剩余错误，判断当前标签
是否混合了不同视觉机制。

## 固定分桶

- source距离：`(6,8]`、`(8,10]`、`(10,12]`px；
- 目标语义：ChemScene `IMPLICIT/TEXT`、元素、incident degree；
- 文字干扰：任一GT文字bbox是否与source中心32x32 crop相交；
- 局部拥挤：source 16px内GT数量，目标最近邻`<16`、`16--32`、`>=32`px；
- center-field证据：目标cell在4--13px环带内的rank，以及3px内是否存在局部峰；
- 预测误差：方向角`<=30`、`31--90`、`>90`度，预测半径、heatmap margin和entropy。

每个split动作数必须保持31/67；单桶至少5个动作才作解释。只读calibration和holdout，强制正确
Oracle source；不读dev、`confirm_v2`、外部或封存集，不训练、不创建tag。

下一实验只能针对两个域方向一致、样本量达门的错误机制预注册；不得从单个小桶直接提出修复。

## 实际结果

冻结P5-E5完整重放31/67个动作，恢复率严格复现77.42%/53.73%。主要分桶如下：

| 因素 | calibration | holdout | 结论 |
|---|---:|---:|---|
| target `IMPLICIT` | 74.07%（27） | 50.94%（53） | 难于文字目标 |
| target `TEXT` | 100%（4） | 64.29%（14） | OCR不是主因 |
| crop无/有文字 | 75.0%/85.71% | 54.76%/52.0% | 无一致文字惩罚 |
| source 16px内1个GT | 79.17%（24） | 62.16%（37） | 较容易 |
| source 16px内2个GT | 60.0%（5） | 42.31%（26） | 两域一致下降 |
| target degree=1 | 92.86%（14） | 68.18%（22） | 较容易 |
| target degree=2 | 66.67%（12） | 33.33%（27） | 最大稳定结构缺口 |
| 方向误差`<=30°` | 100%（22） | 97.22%（36） | 方向正确几乎必过 |
| 方向误差`>90°` | 0%（4） | 0%（16） | 20个全部失败 |

source距离没有跨域一致的单调关系；目标3px内有无center-field局部峰只产生有限且不一致的差异。
holdout的31个失败中，17个source附近至少有2个GT，16个方向误差大于90度，26个目标附近没有
center-field局部峰。文字目标只占5个失败。

因此当前主要问题不是OCR、固定距离或半径回归，而是局部存在多个结构上合理对象时选错方向；
degree=2目标最突出。方向角是失败形态而非可直接用于推理的Oracle特征，下一步必须审计错误预测
是否落向同crop内另一GT，不能直接用角度做修复。
