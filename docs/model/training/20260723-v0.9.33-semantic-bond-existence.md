# v0.9.33 Semantic Bond Existence

## 目标

本实验不训练“长键识别器”，而是训练统一的 Bond relation existence：

```text
一个无序 Junction pair + 完整二维视觉上下文
    -> 两点之间是否存在一条化学键
```

所有 GT 键均为同一种 existence 正样本，不按长度删除、降权或专项过采样。键长只用于验证集分桶，
检查模型是否在某一尺度上失效。MR-TADF 和 `test2` 只作外部诊断，不参与训练、阈值或 checkpoint
选择。

## 表示修正

v0.9.32 的键级分支保留归一化长度特征，但 v0.9.33 的 existence 分支已切断该显式输入：

- local/context 两个规范化二维 relation view 进入独立 `edge_visual`；
- existence head 不读取 `geometry_encoder(length)`；
- 正反端点编码后取平均，保证无序 pair 不变；
- 距离只写入评测统计，不作为 existence head 的输入。

训练负样本包含长度匹配 non-bond、交叉 non-bond 和随机 non-bond。长度匹配的用途是消除“近就是
键、远就不是键”的数据捷径，不是训练某种特殊键长。

## Pilot 训练

初始化：v0.9.32 Semantic Bond Relation step 6000。

- train cache：500 张唯一图片；
- validation：200 张跨字体图片；
- 总曝光：10,000 张；
- clean/degraded 混合；
- endpoint jitter：标准差 1.5 px，上限 5 px；
- edge head 学习率：`3e-4`；
- relation 主干学习率：`2e-5`；
- type 辅助损失权重：0.1。

最佳 sampled-pair validation：

| 指标 | Clean | Degraded |
|---|---:|---:|
| Precision | 99.28% | 99.28% |
| Recall | 99.50% | 99.45% |
| F1 | 99.39% | 99.36% |
| Relation set exact | 81.5% | 80.5% |
| 最短四分位 recall | 99.67% | 99.67% |
| 最长四分位 recall | 98.78% | 98.56% |

四个长度分桶没有出现断层，支持“统一识别键关系”的表示假设。

## Dense 全点对门控

采样验证不能代表真实推理。新增
`chemvector.evaluate_semantic_bond_existence`，对每张图片的全部无序 GT Junction pair 评分，且
不按距离删除任何 pair。

内部跨字体 100 张共有 61,217 个 pair、3,587 条正键：

| 指标 | Clean | Degraded |
|---|---:|---:|
| 最佳内部阈值 | 0.99 | 0.92 |
| Precision | 99.18% | 98.20% |
| Recall | 98.16% | 98.77% |
| F1 | 98.67% | 98.49% |
| Relation set exact | 70% | 66% |
| False positive | 29 | 65 |
| False negative | 66 | 44 |

结论是：模型已学到可泛化的键存在性视觉语义，但 sampled negative 与 dense all-pair 推理之间仍有
分布差距。少量高分 non-bond 和漏键足以破坏整图，当前 checkpoint 不能直接替换完整图生成。

## 决策

- Semantic Bond existence 表示：GO；
- existence 分支显式去除长度输入：GO；
- sampled relation 分类：GO；
- dense 全点对直接生成整图：NO-GO；
- USPTO/前端替换：暂不执行，先通过内部 dense gate；
- 长键专项训练、键长删除阈值：禁止。

下一版使用模型自身在完整 non-bond 集合上产生的高分错误做视觉 hard-negative mining，并扩大唯一
训练图片覆盖。hard negative 由模型分数选择，不由键长选择；目标是减少整图中的 FP/FN，而不是
继续提高已经接近 99% 的采样 F1。
