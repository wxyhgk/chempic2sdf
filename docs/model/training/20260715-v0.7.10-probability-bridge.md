# 2026-07-15 v0.7.10 概率桥接修复

> 状态：接受为当前最佳开发候选  
> checkpoint：`outputs/checkpoints/chemvector-v079-relation-all-pairs-9k/last.pt`  
> 类型：不训练新权重，只升级推理与 repair 协议

## 目标

v0.7.9 的全点对 relation 训练减少了多余边和价态失败，但 USPTO clean 1k 的
断图从 204 增加到 242。原因是 repair 只拿到了阈值化后的模型边，低于
`edge_threshold=0.4` 的连续概率被丢弃；一旦墨线检测也没有找到桥边，后续无法
知道模型对其余点对的相对置信度。

本轮保持 OCR、vertex、relation 和视觉主干全部不变，只让 repair 使用模型已经
计算出的全点对概率。仍然不使用键长阈值，也不按每个原子的近邻数量剪枝。

## 实现

- `ParallelChemSVGResult` 保留每个点对的连续边概率和预测键型；
- `model_connect` 对墨线桥边先按模型概率排序，再比较墨线 gap；
- 墨线候选仍无法连通时，允许边概率不低于 `0.1` 的点对连接不同分量；
- 概率恢复的桥边保留模型预测的 `DOUBLE` 或 `TRIPLE` 键型；
- benchmark 和单图 CLI 记录 `model_bridge_strokes`，便于定位被兜底恢复的边。

这里的 `0.1` 只用于已经断开的图，并且候选必须连接两个不同分量、不能跨过中间
顶点。它不是普通出边阈值，不会把所有低分边加入图。
