# v0.9.69 双 Atom proposal 融合

## 假设

保留旧 Atom head 的 128 个候选和旧 feature 空间，只追加最多 16 个新 Atom head 独有、
且与旧候选相距超过 6px 的坐标。新增坐标的 object feature 从旧 head 同 cell 采样，避免
直接引入完整的新 feature 分布。

## 实现与训练

- `fuse_predicted_atom_proposals`：固定 128+16 slot 融合；
- benchmark 和 proposal cache 均支持可选 rescue Atom checkpoint；
- train 8,974、validation 498 的 144-slot cache 均零拒绝；
- selector 从 v0.9.62 warm start，训练 1,500 step。

输出：

- `outputs/checkpoints/chemvector-v0969-dual-atom-proposal-cache-train8974/`
- `outputs/checkpoints/chemvector-v0969-dual-atom-proposal-cache-validation498/`
- `outputs/checkpoints/chemvector-v0969-dual-atom-selector-step1500/`

## 结果

validation full-object exact 最高仅 28.51%，低于单头重对齐的 33.33%。GDG906 数量恢复但
连接仍错，GDG1005 仍不正确。新增 slot 加大了 incidence 身份选择难度，简单候选拼接正式
NO-GO；因此未继续运行 1,100 张完整 MR-TADF。
