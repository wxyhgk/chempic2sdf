# 2026-07-17 v0.7.27 Grounded 全点对真实线条图

## 目标

v0.7.26 的 dense candidate assignment Oracle 在 6px 下达到 96.09% F1，但部署型
顶点 F1 只有 90.02%。本轮不再先决定最终顶点再看边，而是让全部高召回候选点对
读取原图线条，再用边证据反向帮助候选排序。

全程保留以下约束：

- 不按键长删除点对；
- 不只保留最近邻；
- 最多 128 个候选的全部无向点对都可读取真实像素；
- MR-TADF、USPTO 不参与训练、阈值选择或 checkpoint 选择。

## 架构

```text
v0.7.26 dense candidates + query context
    -> selector candidate hidden / base logits
    -> 全部候选点对采样原图 line band
    -> endpoint context + 几何 + 中间候选 blocker
    -> edge logits
    -> incident edge message
    -> 有界 node residual
    -> node logits
```

`blocker` 特征用于表达：若 A、C、E 近似共线，且 C 是高置信候选，则 A-E 是跨过
中间顶点的可疑边。它只作为学习特征，不是长度阈值或确定性删边规则。

新增 graph 参数 93,122。v0.7.26、Atom Query、dense head、视觉主干、OCR 和现有
relation 全部冻结。

## 指标定义复核

`count exact` 只要求预测点数等于真值点数；`vertex exact` 还要求每个预测点都在
6px 内与真值一对一匹配。例如真值 `{A,B,C,D}`、预测 `{A,B,C,X}` 时，数量正确，
但整图顶点错误。因此 known-count 解码可以接近 100% count exact，同时只有较低的
vertex exact。这不是统计冲突，而是候选子集选择错误。

第一版从第一步起同时训练 edge 与 node residual：

```bash

  --grounded-selector-checkpoint \
    outputs/checkpoints/chemvector-v0726-dense-query-fusion-9k-45k/best.pt \

  --validation-shards Data/sdf/molgrapher_synthetic_v0_1/overfit_100/train-000000.tar \

  --train-samples 10000 --validation-samples 100 --epochs 100 \
  --batch-size 2 --learning-rate 1e-4 --validate-every 1000
```

线条读取明显有效，但随机早期边消息破坏了已有 selector。该联合训练方式判定 NO-GO。

## 两阶段训练

改为：

1. 前 5,000 次样本只训练 edge reader，节点输出严格保持 v0.7.26；
2. Edge 固定后，只训练 `edge_message + node_residual` 共 42,241 个参数；
3. Node residual 用 `2 × tanh(raw)` 限制在 `[-2, 2]`，不能任意覆盖 selector。

```bash
.venv-train/bin/python -m chemvector.pretrain_grounded_graph \
  --grounded-selector-checkpoint \
    outputs/checkpoints/chemvector-v0726-dense-query-fusion-9k-45k/best.pt \
  --train-shards Data/sdf/molgrapher_synthetic_v0_1/overfit_100/train-000000.tar \
  --validation-shards Data/sdf/molgrapher_synthetic_v0_1/overfit_100/train-000000.tar \
  --output-dir \
    outputs/checkpoints/chemvector-v0727-grounded-graph-two-stage-overfit100 \
  --train-samples 10000 --validation-samples 100 --epochs 100 \
  --batch-size 2 --learning-rate 1e-4 \
```

## 化学安全约束

新增独立的高置信 H/D/T 约束接口：

- 只在 OCR 置信度达到配置门槛时启用；
- H/D/T 最多保留一条最高分 incident edge；
- H/D/T 参与的键只允许单键；
- OCR 不确定时完全不修改预测。

该约束已有单元测试，但尚未接入稳定推理。其他元素价态、芳香性和连通性仍只允许
作为软约束，不能用不可靠 OCR 硬删真实骨架。

## 决策

- 全点对真实线条 edge reader：GO；
- 中间候选 blocker 特征：保留，后续需独立消融；
- 从第一步联合 node-edge：NO-GO；
- 两阶段 known-count 候选排序：容量 GO；
- 当前 set-count 校准：NO-GO，仍会偏向少选点；
- 不替换 v0.7.10 稳定推理，不扩到 9k。

下一步冻结 v0.7.27 的 edge reader 和候选排序，只训练独立 count calibration；先在
固定 100 图证明 set-count 能恢复且不损失 18% known-count vertex exact，再做 9k/1k
泛化门控。

## v0.7.29 复核

本实验的 node/edge 标签使用 16px 匹配，最终 vertex exact 使用 6px；同时训练入口的
高精度矩阵乘法模式会让 `torch.cdist` 出现近坐标相消误差。因此本文的 80.44% Edge
F1 和 12%→18% node 结果仅保留为历史记录，不能作为当前 6px 正式基线。修正监督后
Edge F1 为 83.51%，whole-set known-count vertex exact 达到 45%。详见 v0.7.29。
