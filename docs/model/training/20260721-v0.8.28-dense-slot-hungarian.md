# v0.8.28 Dense Slot Hungarian 置换匹配

> 状态：标签修复 GO；固定 cell slot 架构 NO-GO  
> 日期：2026-07-21  
> 基础 checkpoint：`chemvector-v082-multiscale-joint-9k-1epoch/best.pt`

## 目标

验证 Dense BondObject 在同一空间 cell 内使用固定 slot 排序时，是否因标签身份跳变而
学不会第二根、第三根键。实验只修改训练监督，不改变图片、视觉编码器和 ChemScene
协议。

核心约束保持不变：

- 双键、三键各自仍是一个 BondObject，只有两个语义端点；
- 不按键长删除候选；
- 不使用最近邻预剪枝或硬价态预过滤；
- MR-TADF、USPTO 不参与训练、选阈值或选 checkpoint。

## 标签审计

旧实现按原始有向端点 `(begin_x, begin_y, end_x, end_y)` 给同 cell 的键排序，但端点
损失又把一根键的两个端点视为无序。反转任意一根无向键的端点，图像和几何对象不变，
slot 标签却可能交换。

在 pilot train 前 8,974 张中：

| 指标 | 数值 |
|---|---:|
| 同 cell 多键图片 | 608，6.78% |
| 精确 ChemScene 坐标 collision 图片 | 569 |
| Collision cells | 656 |
| Slot 0 正样本 | 288,636 |
| Slot 1 正样本 | 656 |
| Slot 2 正样本 | 40 |
| 端点反转会改变 slot 排列的 collision cells | 99.89% |

Slot 1 监督约为 Slot 0 的 `1/465`，Slot 2 约为 `1/8,020`。仅把每根键的端点先排序
无法解决 slot 极度稀疏和跨布局身份跳变。

## 实现

修改：

```text
chemvector/dense_bond_object.py
chemvector/pretrain_dense_slot_matching.py
tests/chemvector/test_dense_bond_object.py
```

新增 cell-local permutation-invariant 监督：

1. 对一个 cell 的 `S` 个预测 slot 与 `K` 个 GT BondObject 做 Hungarian 匹配；
2. 匹配代价使用无序端点、center、`cos(2θ)/sin(2θ)`、length 和键型；
3. 匹配 slot 动态写入正 heatmap，未匹配 slot 和空 cell 仍为 focal negatives；
4. 增加 cell-count 辅助损失；
5. 增加 assignment-aware 同 cell duplicate/exclusivity 损失。

presence/heatmap 不进入匹配代价，避免预测分数自强化。测试覆盖 GT 顺序置换、单键端点
反转、未匹配 slot 负监督、动态正样本数和有限梯度。

## 结果

| 指标 | Fixed | Hungarian | 差值 |
|---|---:|---:|---:|
| 最佳 epoch | 1 | 8 | - |
| Collision cell geometry exact | 6.00% | 8.00% | +2.00pp |
| Collision cell object exact | 2.00% | 1.00% | -1.00pp |
| Secondary geometry recall | 19.81% | 23.58% | +3.77pp |
| Bond geometry recall | 16.50% | 22.82% | +6.31pp |
| Cell count accuracy | 20.00% | 11.00% | -9.00pp |
| Duplicate cell rate | 0.00% | 1.00% | +1.00pp |
| Ordinary known-object accuracy | 70.06% | 66.55% | -3.51pp |
| Ordinary predicted-count accuracy | 58.43% | 23.09% | -35.34pp |
| Ordinary predicted-object exact | 3.21% | 0.40% | -2.81pp |

预设门槛全部未通过：

- collision geometry exact 相对 Fixed 至少 `+10pp`：实际 `+2pp`；
- secondary geometry recall 至少 `50%`：实际 `23.58%`；
- duplicate cell rate 至少减半：实际从 `0%` 增至 `1%`；
- ordinary known-object accuracy 回退不超过 `0.5pp`：实际回退 `3.51pp`。

更强的停止规则也触发：Hungarian secondary recall 低于 `30%`。继续增加 collision
replay、slot 数或 loss 权重，不能解决固定栅格槽位的稀疏监督和局部对象身份问题。

## 决策

- 同 cell 固定排序确有标签冲突：确认；
- cell-local Hungarian 与置换不变测试：GO，作为通用监督工具保留；
- 当前 Hungarian checkpoint：NO-GO，不接入稳定推理；
- 固定 cell 多 slot Dense BondObject：架构 NO-GO，停止调参；
- 下一步：完整 Bond query/group-query。每个 query 预测一根键的存在性、两个无序端点、
  display/chemical 键型和方向，再由端点生成 Junction；
- 稳定默认继续保持 v0.7.10。
