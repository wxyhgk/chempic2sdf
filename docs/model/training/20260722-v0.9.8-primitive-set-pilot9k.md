## 首轮命令

```bash
.venv-train/bin/python -m chemvector.train_primitive_set \
  --train-shards Data/sdf/visual_svg_v0_1/pilot_10k/shards/train-000000.tar \
  --validation-shards Data/sdf/visual_svg_v0_1/pilot_10k/shards/validation-000000.tar \
  --init-vision-checkpoint outputs/checkpoints/chemvector-v090-visual-prefix-capacity-final-clean-1000/best-teacher.pt \
  --output-dir outputs/checkpoints/chemvector-v098-primitive-set-pilot9k-fresh-full-step1000 \
  --max-steps 1000 --batch-size 4 --gradient-accumulation 1 --workers 1 \
  --learning-rate 1e-4 --validate-every 500 --save-every 250 --log-every 50 \
  --local-query-kernel 5 --endpoint-refine-kernel 25 \
  --line-geometry-objective --class-cost-weight 0.5 --seed 20260721
```

1,000 step 等于 4,000 次样本呈现，约 0.44 epoch。该实验只判断是否脱离 zero-shot
近零区域，不以最终能力为目标。

## 门槛

Step1000 provisional GO：

```text
Bond IoU             >= 0.20
line F1@8            >= 0.02
primitive count MAE  <= 12
invalid samples      <= 2%
white loss ratio     >= 1.25
step1000 必须优于 step500
```

Hard NO-GO：

- Bond IoU `<=0.12` 且 line F1 `<0.005`；
- validation loss 下降但几何指标不动；
- white-image loss ratio 仍接近 1。

若落在中间区，只延长到 2,250 step，即一个完整 epoch，再判定。只有完整 validation 的
count-head line F1 `>=0.70`、Bond IoU `>=0.55`、count MAE `<=2`、invalid `<=1%`，
才允许进入 endpoint-refiner-only 精修。

## 架构风险

当前 288 queries 绑定固定约 17x17 reference grid，learned query identity、局部采样和
绝对坐标残差都与 reference 绑定。容量模型的 coarse 位置在未见图上仍有弱信号，但
endpoint refiner 只能在粗端点附近读取局部窗口，无法救回远距离错误。若完整一轮 9k
full-model 后几何仍无明显改善，下一步应改动态 proposal/reference 或 iterative reference，
而不是继续追加 refiner step。

## Step 1,000 正式外部验证

训练内置 validation 的 loss 降至 `1.7220`，white-image loss ratio 为 `2.3437`，matched
type accuracy 为 `92.91%`。这些指标证明模型读取了图像且学会了匹配后类别，但不能证明
自由 query 已经定位到正确图元。

因此使用独立 `evaluate_primitive_set` 在 validation 前 100 张上同时评估 threshold 和
count-head 解码。正式结果位于：

```text
outputs/evaluations/
  chemvector-v098-primitive-set-pilot9k-fresh-full-step1000-validation100/
```

| 解码 | line F1@8q | Bond IoU | primitive count MAE | primitive exact |
|---|---:|---:|---:|---:|
| threshold 0.5 | 0.146% | 11.39% | 38.44 | 0% |
| count head | 0.152% | 10.04% | 21.85 | 0% |

Step 500 的 threshold line F1 为 `0.0171%`、Bond IoU 为 `8.81%`。Step 1,000 虽有小幅
数值变化，但仍同时满足预注册 Hard NO-GO：

```text
Bond IoU <= 0.12
line F1  < 0.005
```

因此不延长到 2,250 step，也不进入 endpoint-refiner-only 阶段。

## 因果审计

capacity100 checkpoint 的 coarse 端点在同集和未见图上接近：p50 分别为
`112.39q / 110.32q`；真正归零发生在 endpoint refiner：

| 范围 | refined p50 | recall@8q |
|---|---:|---:|
| capacity100 | 2.82q | 85.07% |
| unseen100 | 83.40q | 0.06% |

只把 capacity 图片水平平移 16px，line F1@8q 即从 `81.4%` 降至 `0.16%`。query
reference 也没有形成局部 ownership：预测线中心距 reference 的 p90 为 `496q`，只有
`34.9%` 位于 `64q` 内。相同字体但未见分子的对照仍为近零，因此主因不是字体或 OCR，
而是无界坐标残差与全局 Hungarian 让固定 query/refiner 记住了绝对位置模板。

## 正式决策

```text
raster -> fixed free queries -> unbounded endpoint residual

NO-GO
```

保留 Visual SVG v0.1/v0.2、typed carrier、v0.9.7 typed affinity 和 exact-cover；停止给
当前 288-query primitive-set 追加训练。下一实验必须满足：

1. 图元坐标由可见线条证据产生，模型不能自由重写 carrier；
2. proposal 生成应平移等变，并单独报告平移审计；
3. 单/双/三键以完整 group 或冻结 physical lines 表示，双键内部不能再产生四个语义端点；
4. 先在 pilot validation 验证 proposal coverage，再训练 keep/type/affinity；
5. `internal_test` 继续封存，MR-TADF 不参与阈值或 checkpoint 选择。
