# 2026-07-16 v0.7.13 检测顶点关系与困难负边

> 状态：100 图过拟合 GO，尚未验证 9k 泛化  
> 基础 checkpoint：`outputs/checkpoints/chemvector-v0711-molgrapher-relation-mixed-10k/last.pt`  
> 顶点 checkpoint：`outputs/checkpoints/chemvector-v0712-overfit100-*`  
> 最佳输出：`outputs/checkpoints/chemvector-v0713-detected-relation-pair-10k/best.pt`

## 目标

v0.7.12 已把 100 图的顶点完全一致率提高到 95%，但把检测顶点接入旧 relation 后，
skeleton exact 只有 23%。本轮验证两个问题：relation 是否必须直接适应检测坐标扰动，
以及全点对中的大量非键是否需要按当前模型分数进行困难负样本训练。

本实验只验证模型容量和训练协议，不代表公开数据集或 MR-TADF 上的泛化结果。

## 数据与冻结范围

- 固定数据：`Data/sdf/molgrapher_synthetic_v0_1/overfit_100/train-000000.tar`；
- 分子/图片数：100，每张重复曝光 100 次，共 10,000 次图片曝光；
- Atom Query：冻结，负责原子集合和数量；
- dense vertex head：冻结，只提供低阈值候选峰和一对一坐标吸附；
- 视觉主干和 OCR：全部冻结；
- relation 候选：检测顶点的全部无向点对，不按距离删除；
- MR-TADF：未参与训练和阈值选择。

检测顶点先通过 Hungarian matching 与真值顶点一对一对应，再把真值边和键级映射到
检测点对。未匹配检测点参与训练时按非键处理。

## 损失函数

每张图保留全部真边，并从非键中选取当前 `edge_logits` 最高的困难负边：

```text
负边数 = min(全部负边, max(32, 8 * 真边数))
```

总损失由三部分组成：

```text
edge focal BCE
+ positive-pair bond cross entropy
+ 0.2 * softplus(1.0 + strongest_negative - weakest_positive)
```

ranking 项直接约束最难假边的分数低于最弱真边。它不改变推理候选集合，也不引入
键长阈值。

## 实验一：只训练 relation head

```bash
.venv-train/bin/python -m chemvector.pretrain_detected_relation \
  --init-checkpoint outputs/checkpoints/chemvector-v0711-molgrapher-relation-mixed-10k/last.pt \
  --query-checkpoint outputs/checkpoints/chemvector-v0712-overfit100-atom-query-local-finetune/best.pt \
  --dense-checkpoint outputs/checkpoints/chemvector-v0712-overfit100-head-only/last.pt \
  --shards Data/sdf/molgrapher_synthetic_v0_1/overfit_100/train-000000.tar \
  --output-dir outputs/checkpoints/chemvector-v0713-detected-relation-head-10k \
  --samples 100 --train-samples 10000 --epochs 100 \
  --learning-rate 3e-4 --disable-relation-dropout \
  --edge-thresholds 0.40,0.50,0.60,0.65,0.70,0.75,0.80,0.90 \
  --validate-every 1000 --log-every 500
```

- 可训练参数：4,420；
- 最佳 skeleton exact：54%；
- Edge precision / recall：96.25% / 97.11%；
- 多余边 / 漏边：93 / 71。

结论：检测坐标上的重新校准明显优于原来的 23%，但 relation head 接收到的固定 pair
features 不足以区分最难的交叉错连和近邻非键。

## 实验二：训练 pair encoder 与 relation head

```bash
.venv-train/bin/python -m chemvector.pretrain_detected_relation \
  --init-checkpoint outputs/checkpoints/chemvector-v0711-molgrapher-relation-mixed-10k/last.pt \
  --query-checkpoint outputs/checkpoints/chemvector-v0712-overfit100-atom-query-local-finetune/best.pt \
  --dense-checkpoint outputs/checkpoints/chemvector-v0712-overfit100-head-only/last.pt \
  --shards Data/sdf/molgrapher_synthetic_v0_1/overfit_100/train-000000.tar \
  --output-dir outputs/checkpoints/chemvector-v0713-detected-relation-pair-10k \
  --samples 100 --train-samples 10000 --epochs 100 \
  --learning-rate 1e-4 --train-pair-encoder --disable-relation-dropout \
  --edge-thresholds 0.30,0.40,0.50,0.55,0.60,0.65,0.70,0.75,0.80,0.90 \
  --validate-every 1000 --log-every 500
```

- 可训练参数：146,308；
- 最佳 checkpoint：`best.pt`，8,000 次图片曝光；
- 最佳阈值：0.65；
- Skeleton exact / edge-set exact：89% / 89%；
- Edge precision / recall：99.47% / 99.19%；
- Bond accuracy：98.98%；
- 多余边 / 漏边：13 / 20。

最终 `last.pt` 在 10,000 次曝光时为 88% skeleton exact，阈值 0.70，多余边和漏边
分别为 9 和 18。最佳点出现在训练结束前，后续扩大数据时应使用独立 validation
选择 checkpoint，而不是默认采用 `last.pt`。

## 决策

100 图 detected skeleton exact 已超过预设的 85% 过拟合门槛，因此训练协议和可训练
容量判定为 `GO`。提升来自 pair features 对检测坐标和困难非键的适应，不是 MoE 回退。

当前 checkpoint 仍是同一批 100 图上的训练内结果，不能接入正式推理或据此宣称公开
benchmark 提升。下一阶段按以下顺序推进：

1. 审计 MolGrapher pilot_10k 的原子序号、额外标注和锚点；只有坐标越界等硬错误
   进入过滤清单，低精度像素启发式不得直接删样本；
2. 在干净的 9k train 上分别训练 Atom Query 和 dense 顶点分支；
3. 冻结 9k 顶点，在检测后全点对上训练 pair encoder 与 relation head；
4. 只使用 scaffold 独立的 MolGrapher validation 1k 选阈值和 checkpoint；
5. 通过内部门控后再评测 USPTO clean 1k 与 MR-TADF，不用它们调参。
