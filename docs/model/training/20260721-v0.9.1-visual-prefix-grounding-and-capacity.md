# v0.9.1 Visual Prefix 视觉接地与容量验证

> 状态：固定 100 图 capacity GO；跨分子泛化未验证
> 日期：2026-07-21
> 数据：`Data/sdf/visual_svg_v0_1/capacity_100/`
> 最终 checkpoint：`outputs/checkpoints/chemvector-v090-visual-prefix-capacity-final-clean-1000/best-teacher.pt`
> 稳定推理：仍为 v0.7.10，不由本实验替换

## 目标

v0.9.0 已建立 Visual SVG v0.1 协议和固定 100 图容量集，但旧 cross-attention 模型在
1,000 step 后的错配图片损失比仍为 `0.999985`。这表示 decoder 可以利用真值 token
前缀学习语言先验，却几乎没有利用图片。

本轮只回答两个问题：

1. 怎样让自回归 decoder 对图片产生可测量、可复现的依赖；
2. 在同一固定 100 图上，约 41.3M 参数模型能否完成 Visual SVG 自由生成。

本实验仍不预测 OCR 字符串、化学 Junction、键级、价态或 SDF。它也不是泛化实验。

## 模型变化

旧模型把视觉 token 放在每层 cross-attention 的 `memory` 中。Visual Prefix 模型改为把
视觉 token 放到同一个 prefix-LM attention 流：

```text
768x768 RGB
    -> ChemVisionEncoder + raw-ink content
    -> 12x12，共 144 个视觉 prefix token
    -> 8 层 prefix-LM decoder
    -> Visual SVG v0.1 token
```

attention 约束为：

- 视觉 token 可以双向读取全部视觉 token，但不能读取文字 target；
- 每个 target token 可以读取全部视觉 prefix；
- target token 之间保持严格因果，不能读取未来 token；
- loss 只覆盖 `input_ids[:, 1:]` 的有效 target token，不覆盖视觉 prefix；
- full forward 与逐 token `decode_step` 的 logits 必须一致，单元测试最大差异为
  `1.3411e-07`，低于 `1e-5` 门槛。

关键修正不是单纯把 cross-attention 改成 prefix，而是把 attention 的视觉 value 改为
只含图片内容的 `content-only values`。位置编码仍参与 query/key，不能作为 value 捷径；
文字 residual 也不能在 visual-only 分支中绕过图片。

最终配置为 `d_model=512`、8 层、8 heads、FFN 2048、Visual SVG 词表 2,121、目标长度
2,048、`visual_grid_size=12`、`ink_subgrid=8`、`dropout=0`，完整模型实测为
41,286,372 参数。

## 视觉接地排查

标准 causal teacher forcing 的 mismatch ratio 定义为：

```text
mismatch_loss_ratio = mismatched_image_loss / matched_image_loss
```

visual-only 诊断会把非特殊 target 前缀替换为 `[UNK]`，再计算正确图与错配图的 loss 比。
它用于判断图片内容是否已经进入预测，不作为最终自由生成指标。

| 实验 | Step | 关键结果 | 决策 |
|---|---:|---:|---|
| 旧 cross-attention | 1,000 | causal mismatch `0.999985` | NO-GO，图片被忽略 |
| 初版 Visual Prefix | 500 | causal mismatch `0.999996` | NO-GO，仅换 attention 形式无效 |
| visual-only + 普通 residual/value | 500 | visual-only mismatch `1.000384` | NO-GO |
| 去文字 residual、仍含位置 value | 300 | visual-only mismatch `1.000095` | NO-GO |
| content-only visual value | 300 | visual-only mismatch `1.066297` | 机制 GO |
| 追加 causal grounded 训练 | 500 | 独立 causal mismatch `1.070430` | 接地 GO，进入容量训练 |


## 决策

- 旧 cross-attention Visual SVG 基线：视觉接地 NO-GO；
- 只改为 Visual Prefix：NO-GO；
- visual-only residual 或把位置编码混入 value：NO-GO；
- content-only visual value：视觉接地机制 GO；
- causal grounded 训练：独立图片错配门控 GO；
- 最终 clean step-200 checkpoint：固定 100 图 capacity GO，全部预注册门槛通过；
- 不替换 v0.7.10 稳定推理，不宣称 OCSR 或 SDF 能力已经提升。

## 适用边界

这是严格的同集 capacity proof。100 张图同时用于训练、验证和最终自由生成，仅证明模型、
协议、因果 loss、增量解码和 grammar generation 链路有能力记住并重建这 100 张图。

它不能说明模型能识别未见分子、未见布局、未见字体、USPTO、MR-TADF 或真实论文图片。
下一阶段必须使用 molecule-isolated 的训练/验证划分，并保持公开 OCSR 和 MR-TADF 只作
外部评测；在独立分布通过前，不得把本轮 `99% primitive exact` 表述成泛化准确率。
