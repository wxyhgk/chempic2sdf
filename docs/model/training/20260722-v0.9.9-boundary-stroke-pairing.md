## 问题

Evidence Carrier P0 的正 raw LSD anchor 明显多于 ordinary line member。validation 前
100 张中，4,353 个具有 extent-eligible raster carrier support 的 ordinary member 对应
9,049 个正 anchor，平均 `2.079 anchors / member`。其中：

| 正 anchor multiplicity | ordinary members |
|---:|---:|
| 1 | 12 |
| 2 | 4,205 |
| >2 | 136 |

`96.60%` 的受支持 member 恰好产生两个正 LSD anchor。本实验验证这是否主要来自同一黑色
stroke 的两侧 raster boundary，以及它们能否在 P0 前确定性地合成 centerline。

## 配对协议

实现：

```text
chemvector/evidence_carrier_stroke_pairing.py
chemvector/audit_evidence_carrier_stroke_pairing.py
tests/chemvector/test_evidence_carrier_stroke_pairing.py
tests/chemvector/test_audit_evidence_carrier_stroke_pairing.py
```

配对函数只接收完整 raster 与 raw LSD segments，不接收 target line、target ID、分子结构或
sidecar。候选 pair 条件保持为：

| 条件 | 固定值 |
|---|---:|
| 最大夹角 | `3 degrees` |
| 法向间距 | `0.5 - 4.0 px` |
| 最小共同投影 | `8 px` |
| 对较短 segment 的覆盖率 | `>= 0.70` |
| 两线间条带墨迹占比 | `>= 0.80` |
| 墨迹 darkness 阈值 | `0.25` |

artifact 记录 canonical config SHA256；它是固定配置声明，不被表述为代码能够机械证明的
时间顺序。候选按 interval IoU、墨迹占比、平均 darkness、角度和相对 3px stroke width
的偏差排序。最终 tie-break 使用 canonical segment geometry，不再使用输入 array index。

先接受 mutual-best pair，再对剩余候选做 disjoint greedy matching。pair centerline 只使用
两条 LSD 的共同 overlap extent，不使用 union extent，避免在最低 70% overlap 时把未观察
区间外延为 evidence。未配对 LSD anchor 原样保留。

每张正式样本还会反转 raw LSD 输入顺序重新运行一次，要求输出 carrier set 和 selected
pair source partition 均相同。

## 指标限定

`associate_evidence_carriers` 只检查 angle、perpendicular distance 和 overlap。这里的
`packed_support_coverage` 因此只表示：

```text
普通 member 是否仍至少具有一个可进入 extent 训练/解码的 carrier
```

它不检查 extent endpoint，不是 q8 line recall，也不代表完整物理线已经恢复。

`packed_gt_positive_dedup_ratio` 定义为：

```text
有 extent-eligible support 的 ordinary members
/
packing 后被 GT 标为 positive 的 carriers
```

它只衡量 GT-positive carriers 内部的重复度，不是全部输出 proposal precision。被标成
`no_positive_member` 的 pair 可能来自文字或其他 out-of-scope stroke，不能直接叫假 pair；
`one_positive_member` 和 `cross_target_positive` 则是硬合并的明确风险。

### 边界假设

| 指标 | raw | overlap-centerline packed |
|---|---:|---:|
| all anchors / carriers | 24,111 | 15,173 |
| GT-positive carriers | 17,591 | 8,999 |
| extent-eligible supported members | 8,643 | 8,642 |
| extent-eligible support coverage | 98.845% | 98.833% |
| GT-positive dedup ratio | 49.133% | 96.033% |

GT-positive carrier 减少 8,592，reduction 为 `48.843%`。raw multiplicity 恰好为 2 的
8,303 个 member 中，8,257 个被正确配对，pair recall 为 `99.446%`。因此可以确认：

```text
约 2.08 个正 LSD anchor / ordinary member
主要确实来自同一黑色 stroke 的两侧 raster boundary。
```

共同 overlap centerline 只令 extent-eligible support coverage 相对 raw 下降 `0.0114pp`，
明显比 union extent 更保守。192/192 张通过反转输入排列检查。

### 为什么仍不能硬合并

| 风险指标 | molecule-disjoint192 |
|---|---:|
| cross-target positive pairs | 2 |
| one-positive-member pairs | 8 |
| no-positive-member pairs | 339 |
| parallel-2 strict preservation | 1,765 / 1,766 = 99.943% |
| parallel-2 direct cross-target merge | 1 |
| extent-eligible all-member sample exact | 170 / 192 = 88.54% |
| one-positive-carrier-per-member exact | 136 / 192 = 70.83% |
| permutation determinism | 192 / 192 = 100% |

`no_positive_member=339` 不能单独判为错误，因为 ordinary scope 排除了文字、hashed 和 polygon
等真实 stroke。真正否决 hard merge 的是：2 个 cross-target pair、8 个 one-positive pair，
以及 1 个 parallel-2 两成员直接误合并。这些决定一旦在 learned model 前执行就不可逆。

继续放宽 hard threshold 会增加误合并；继续收紧会删除正确边界 pair。局部 occupancy 也
无法在所有重叠或拥挤区域区分一条粗 stroke 与两条独立 bond member。因此确定性 hard
preprocessor 正式 **NO-GO**。

## 下一步

当前几何与 raster 规则只负责生成高召回 pair 候选。每个 raw anchor 同时保留 singleton：

```text
raw LSD anchors
  -> singleton_i candidates
  -> pair_ij candidates + overlap centerline_ij
  -> learned relative score(pair_ij versus singleton_i/singleton_j)
  -> disjoint exact matching
  -> selected stroke carriers
  -> P0 extent / typed affinity
```

matching 使用 exact-cover 约束，每个 raw anchor 必须恰好被一个 singleton 或 pair 覆盖。
pair score 必须相对 all-singleton baseline 计算。molecule-disjoint 审计中的 cross-target 与
one-positive 模式作为普通 hard negatives，不针对 MR-TADF 手写规则。

下一阶段至少报告：

1. same-target pair precision / multiplicity-2 recall；
2. cross-target 与 one-positive pair 必须均为 0；
3. parallel-2 distinct preservation 必须为 100%；
4. extent-eligible support coverage 相对 raw 的损失；
5. one-positive-carrier multiplicity 与 qualified sample exact；
6. permutation determinism 与 matching p95 延迟；
7. 后续 P0 extent 解码后的 q8 endpoint 指标，不能用 support coverage 替代。

当前结论：

```text
boundary-pair candidate generation: GO
irreversible deterministic pairing: NO-GO
pair/singleton soft scoring + disjoint exact matching: NEXT
```
