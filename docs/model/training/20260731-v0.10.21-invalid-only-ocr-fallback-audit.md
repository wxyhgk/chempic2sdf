# 2026-07-31 v0.10.21 Invalid-only OCR Fallback

> 状态：统一推理与公开配对 GO / shadow
> 主分支：v0.9.41 + v0.8.8 OCR  
> 专家分支：v0.9.41 + v0.10.9 OCR

## 目标

v0.10.19/v0.10.20 证明单 Text Object 概率不能作为安全证书。本实验不训练新模型，验证
确定性图级条件：仅当主分支 SDF 无效、专家分支 SDF 有效时采用专家，否则保持主分支。

路由只读取两个预测自身的 `sdf_valid`，不读取真值、SMILES、InChIKey 或 benchmark 指标。

## 数据

第一阶段复用已经冻结并完成的 USPTO clean 1k 成对输出：

- 主分支：`outputs/evaluations/uspto-clean-1k-v0941-bond-utility-router/records.jsonl`
- 专家分支：`outputs/evaluations/uspto-clean-1k-v0941-v0109-ocr-swap/records.jsonl`

随后把协议接入统一单图和 benchmark 推理，并从图片重新运行完整 USPTO clean 1k。该版本
不训练新参数，不读取 MR-TADF 或 sealed test。

## 结果

离线审计和实际统一推理得到完全相同的指标。实际运行中主分支无效 242 张；其中专家有效并
被采用 98 张，两边都无效 144 张：

| 指标 | 主分支 | 全量专家 | Invalid-only Hybrid | Rescue / Break |
|---|---:|---:|---:|---:|
| SDF valid | 704 | 785 | 802 | 98 / 0 |
| Formula | 208 | 276 | 237 | 29 / 0 |
| Atom count | 604 | 676 | 690 | 86 / 0 |
| Bond count | 609 | 680 | 694 | 85 / 0 |
| Nonstereo exact | 203 | 272 | 232 | 29 / 0 |
| Chemical exact | 160 | 215 | 187 | 27 / 0 |

Hybrid valid 高于全量专家，是因为主分支有效而专家无效的样本不会被切换。Chemical exact
从 16.0% 提高到 18.7%，虽然低于激进专家的 21.5%，但相对主分支严格 0 break。

对象分解保持 Skeleton exact 72.7%，Atom-typed 29.4%，Bond-typed 59.8%。主路径平均
`0.233s`；触发第二分支的样本平均 `0.570s`；总体平均 `0.315s`。

单图推理会始终保存 `candidate-primary.chemscene.json`。主分支无效时还会保存
`candidate-fallback.chemscene.json`；候选可编译时保存对应 `.sdf`。最终 `metrics.json` 的
`diagnostics.invalid_ocr_fallback` 记录触发、选择、原因和两边错误。

## 决策

`GO`，作为非推荐 shadow profile 接入前端；默认模型保持不变。该门只保证不破坏主分支的
SDF valid/chemical exact，不代表已经解决 Skeleton 或所有 OCR 错误。
