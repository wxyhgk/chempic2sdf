# v0.9.92 候选级 Chemical RETYPE Verifier

## 问题

v0.9.91 证明 RETYPE 候选覆盖充足，并能把一步改型 action top-1 训练到 43.75%，但分离
gate、联合 softmax 和 global safety gate 都无法安全部署。原因是 global gate 没有直接读取
“被修改的边”和“目标键型”，无法判断当前 top action 是否真的会把整图修成 exact。

v0.9.92 保持以下边界：

- 冻结 v0.9.89 one-move 的 presence 结果；
- 冻结 v0.9.91 累计 9k 的 RETYPE action 模型；
- verifier 只允许修改一条已存在边的 chemical type；
- 不增加或删除边，不改变 display geometry，不使用绝对键长或元素价态规则；
- 只用 ChemVision/full-v0 train-fit 与 train-dev 选择 seed 和阈值；
- MR-TADF、USPTO 不参与训练或选模。

## 模型

每个具体 RETYPE 候选都作为独立动作，例如：

```text
group 17: SINGLE -> DOUBLE
group 17: SINGLE -> TRIPLE
group 42: AROMATIC -> SINGLE
```

verifier 直接读取：

- 被修改 group 的 26D relation/chemical feature；
- 全图 group hidden 的 mean/max；
- 当前键型与目标键型 embedding；
- v0.9.91 gate、action prior、action rank margin；
- 当前 chemical margin、目标 logit 与相对当前类型 logit。

训练目标不是“这张图是否需要 RETYPE”，而是“执行这个具体动作后整图是否 exact”。每张图：

- 若存在一个精确 RETYPE，正动作必须超过最强错误动作至少 1.0 margin；
- 原本正确、需要多次编辑或候选动作均错误时，全部动作都是 KEEP hard negative；
- 输出层零初始化，因此初始阈值 0.0 时严格回退为 KEEP。

train-dev 各 498 张。模型 seed 为 `20260725 / 20260726 / 20260727`。

| Seed | train-dev chemical exact | ChemVision / full-v0 | Rescue / break | Verifier top-1 |
|---|---:|---:|---:|---:|

| 20260726 | 551 -> 553 | 257->257 / 294->296 | 2 / 0 | 62.50% |

按 minimum-domain chemical exact、pooled chemical exact、break、rescue 的固定顺序选择 seed
20260725。阈值扩展后固定为 `-1.75`。同 seed 正式重跑的训练曲线逐段一致。

## 推理接入

新增参数：

```text
--atom-pair-chemical-retype-verifier-checkpoint
```

推理顺序为 v0.9.87 graph context -> v0.9.89 one-move presence -> v0.9.92 chemical RETYPE。
verifier 只覆盖获批 group 的 chemical logits，其他 group 和全部 presence logits 保持不变。

前端新增默认 profile `structure-v0992-carbon`，旧 `structure-v0989-carbon` 保留为回退。
`test1.png` smoke 能加载完整链并执行一条 RETYPE，但仍因历史 carbon placeholder 五价问题输出
diagnostic SDF；这不是本版键型修复的回归。OCR 尚未接入，不能把碳占位结果称为完整化学识别。

## 决策

v0.9.92 GO：

- 候选级 verifier 替代失败的纯 global safety gate；
- 官方 validation 净增 5 张 chemical exact，locked internal 净增 6 张；
- locked internal 两域分别增加 5 张和 1 张，0 break；
- 默认结构 profile 切换到 v0.9.92；
- 下一步继续分析剩余 RETYPE 正例中 verifier target rank 较低的局部模式，但不得根据 locked
  internal 重新调阈值。
