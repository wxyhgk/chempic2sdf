# v0.9.29 SDF 对象分解 Benchmark

## 目标

旧 benchmark 的化学 exact 会同时受到对象数量、连接拓扑、原子类型、键级、价态和立体化学影响，
无法直接决定下一轮训练目标。本实验只比较真值与预测 SDF 图，不使用 SMILES，将结果拆成：

1. 纯连接骨架：忽略元素、原子属性和键级；
2. 原子类型 + 骨架：保留元素、同位素、电荷和自由基，忽略键级；
3. 键级 + 骨架：保留键类型和芳香性，忽略原子类型；
4. 完整非立体图：同时保留原子类型、键级和芳香性。

有效 SDF 优先 sanitize，以统一 aromatic/Kekulé 表达；sanitize 失败时回退为原始 diagnostic SDF，
因此无效价态预测仍可参与纯骨架分析，但不会被标成有效 SDF。

实现：`chemvector/benchmark_object_decomposition.py`。未来
`chemvector.benchmark_chemscene_ocsr` 完整结束时会自动生成分解结果。

## USPTO Clean 1k

输入为冻结的 `v0.9.28 Object Shadow`，没有 oracle，也没有使用 MR-TADF 调参。

| 指标 | 数量 | 比例 |
|---|---:|---:|
| SDF valid | 769 | 76.9% |
| 化学完全一致（含立体） | 153 | 15.3% |
| 原子数和键数同时正确（含 diagnostic SDF） | 727 | 72.7% |
| 纯连接骨架 exact | 724 | 72.4% |
| 原子类型 + 骨架 exact | 292 | 29.2% |
| 键级 + 骨架 exact | 505 | 50.5% |
| 完整非立体图 exact（含 diagnostic SDF） | 212 | 21.2% |

条件指标：

- 数量同时正确后，纯骨架 exact：724/727，`99.59%`；
- 骨架正确后，原子类型 exact：292/724，`40.33%`；
- 骨架正确后，键级 exact：505/724，`69.75%`；
- 骨架正确后，完整非立体图 exact：212/724，`29.28%`。

724 个骨架正确样本按原子/键级两个独立布尔指标分桶：

| 原子类型 | 键级 | 数量 |
|---|---|---:|
| 正确 | 正确 | 217 |
| 正确 | 错误 | 75 |
| 错误 | 正确 | 288 |
| 错误 | 错误 | 144 |

其中 5 张存在分子对称性：原子类型和键级分别可找到同构映射，但不存在同时满足两者的同一映射，
因此完整非立体图为 212，而不是 217。

## 结论

当前关于“骨架仍是主要问题”的判断不成立。727 张对象数量正确的图中只有 3 张连接拓扑错误：
`uspto_clean_0146`、`uspto_clean_0294`、`uspto_clean_0474`。几何层剩余主要是 273 张多/少对象，
不是 count-correct 条件下的错连。

能力上限也给出明确优先级：

- 假设原子类型全部修好，保持当前骨架和键级，非立体图上限约为 50.5%；
- 假设键级全部修好，保持当前骨架和原子类型，上限约为 29.2%；
- 当前完整非立体图为 21.2%。

因此下一轮优先级为：

1. 开放文字/原子类型识别；
2. 对象集合 cardinality，重点处理多一个、少一个和空输出；
3. 键级分类；
4. count-correct 条件下的连接修复仅保留为低优先级专项。

本实验不训练新权重。分解 benchmark 协议和前端展示 GO；`v0.9.28` 模型权重与稳定默认均不变。

## v0.9.30 对象级复核

在 724 个纯骨架正确样本上，拓扑同构条件下的单原子类型 micro accuracy 为 96.45%，单键级为
89.04%；所有图均在 4,096 个映射上限内完成，没有截断。原子错误更分散，键级错误数量更多且
90.9% 为 `AROMATIC -> SINGLE`。因此整分子 exact 与单对象 micro 必须并列报告，后续训练同时
处理公开域 OCR 适配与芳香键保护，不能把 29.2% 解释为单字符准确率。
