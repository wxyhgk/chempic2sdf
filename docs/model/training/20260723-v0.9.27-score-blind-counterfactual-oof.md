# v0.9.27 Score-Blind Counterfactual OOF

> 状态：最终硬门槛未通过，结论为 `FIT-OOF-COMPONENT-SCORE-BLIND-NO-GO`。
> 按预注册规则，pair-stage 微调支线在本轮后停止，不再继续调整 loss、阈值或组件头。

## 硬门槛

本轮开始前已固定决策：

```text
aggregate cross <= 8
M2 recall >= 99.5%
pairable exact 不低于 v0.9.23 baseline
precision >= 99.9%
parallel-2 violation 不恶化
```

通过才接完整 PNG→SDF shadow；失败则停止 pair-stage 支线，返回完整 BondObject/ChemScene 路线。

## 修改

### Score-Blind Forward

模型输入删除：

- `baseline_scores`；
- pair token 最后一维 `raw_pair_gain`。

baseline 只在模型外作为确定性 matching energy 使用。单元测试将两种分数分别改成 `-100/100`，
学习 residual 保持逐位一致，证明 forward 不再读取 score 捷径。

### Counterfactual Activation

训练时对完整多节点组件枚举所有候选 matching，不再只使用自然激活边。每条边统一赋予：

```text
counterfactual base energy = +0.5
```

因此 50,595 条普通 negative 在训练 structured loss 中全部被放入激活能量区间，模型只能依靠
480D profile、20D 无分数几何 token 和两轮共享-anchor message passing 恢复正确 matching。

正式 OOF 评估不使用反事实分数，仍只读取冻结的 v0.9.23 自然 baseline。

## 正式结果

| 指标 | v0.9.23 baseline replay | score-blind counterfactual |
| --- | ---: | ---: |
| selected cross | 16 | 16 |
| M2 recall | 99.64116% | 99.64083% |
| pairable exact | 96.39979% | 96.38265% |
| pairable exact count | 5,623 | 5,622 |
| parallel-2 violations | 1 | 1 |
| support lost | 21 | 21 |
| selected pair precision | 99.99489% | 99.99489% |

三折合计移除 477 positive 和 3 negative。与 v0.9.26 相同，这 3 条 negative 均未参与最终错误
matching，因此没有减少任何 cross。aggregate branch gate 同时失败于：

```text
cross_at_most_8 = false
pairable_exact_not_below_baseline = false
```

## 结论

移除 score 捷径和大规模反事实激活仍无法区分真正的自然活跃错误边。这说明当前 pair-stage 表示中，
决定 cross 的少数错误并不是通过更多 pair 分类、消息传递或 structured loss 可以可靠修复的。

继续做以下操作没有依据：

- 增大组件头参数；
- 继续改变 loss 权重；
- 更激进地删除 active pair；
- 使用 MR-TADF 定向样本调门槛；
- 再增加一个 `v0.9.x` pair veto/residual。

pair candidate pool 的标签 oracle 仍为 cross 0，问题在视觉对象表示和候选生成/分解边界，而不是
matching 求解器。后续回到完整图片的一等对象建模：直接预测 BondObject、TextObject 和它们的端点，
通过 ChemScene 编译 SDF，并以 USPTO clean 和外部 MR-TADF 诊断完整 PNG→SDF 行为。
