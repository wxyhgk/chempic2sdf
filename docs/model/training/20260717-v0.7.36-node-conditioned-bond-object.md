# v0.7.36 端点条件化 Bond Object

## 问题

双键和三键由多条平行显示线组成，但化学图中分别只是一条键。旧顶点模型可能把
副线端点当成原子，使一个双键产生多个伪顶点。v0.7.35 的自由 Bond Queries 在固定
100 图有容量，但扩到 9k 后 endpoint pair recall 只有 4.62%，因此本轮不再让 query
从整图自由回归两个端点。

## 结构

本轮先使用已知原子端点验证键读取器，再接入 v0.7.34 双分支预测端点：

```text
文字对象顶点 + 隐式骨架顶点
    -> 枚举全部无向端点对
    -> 沿端点轴采样 64 点
    -> 垂直方向采样 25 条、覆盖正负 12px 的二维线带
    -> 小型 CNN 保留平行 stroke 的二维排列
    -> edge / display type / chemical type / direction
```

每个端点对只输出一个 Bond Object。没有最近邻候选、键长上限、空白过滤或长键
预删除。模型共 239,070 个参数，直接读取 768x768 原图像素，不依赖语义 mask。

## 100 图容量实验

命令：

```bash
.venv-train/bin/python -m chemvector.pretrain_node_conditioned_bond \
  --train-shards Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/train-000000.tar \
  --validation-shards Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/train-000000.tar \
  --output-dir outputs/checkpoints/chemvector-v0736-node-conditioned-bond-overfit100 \
  --train-cache-samples 100 --validation-samples 100 \
  --train-samples 40000 --epochs 400 --batch-size 4
```

40,000 次图片曝光后的结果：

```text
Edge precision             99.85%
Edge recall               100.00%
Edge F1                    99.93%
Skeleton exact             96.00%
Bond Object exact          31.00%
Display accuracy           92.86%
Chemical accuracy          93.30%
DOUBLE edge recall        100.00%
DOUBLE object recall       90.95%
TRIPLE edge recall        100.00%
TRIPLE object recall       85.71%
```

这证明二维宽线带可以把双键、三键的多条显示 stroke 聚合成一个连接对象。

## 9k 泛化实验

训练 8,974 张、验证 498 张，训练曝光 45,000：

```bash
.venv-train/bin/python -m chemvector.pretrain_node_conditioned_bond \
  --train-shards 'Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/train-*.tar' \
  --validation-shards Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/validation-000000.tar \
  --output-dir outputs/checkpoints/chemvector-v0736-node-conditioned-bond-9k-45k \
  --train-cache-samples 8974 --validation-samples 498 \
  --train-samples 45000 --epochs 6 --batch-size 4
```

已知真实端点时：

```text
Edge precision             98.67%
Edge recall                99.67%
Edge F1                    99.16%
Skeleton exact             78.31%
Bond Object exact          12.25%
Display accuracy           79.43%
Chemical accuracy          87.97%
DOUBLE edge recall         99.04%
TRIPLE edge recall        100.00%
```

键集合已经泛化。Bond Object 完全一致较低主要来自键型：单条局部线带可以可靠判断
是否存在连接，但不能独立判断整个环应使用芳香表示还是 Kekule 单双键表示。该问题
需要环级图上下文，不能继续用局部分类器或单纯扩量掩盖。

## 预测端点评估

接入 v0.7.33 文字对象和 v0.7.34 隐式顶点，在同一 498 张独立验证集评估：

```text
Vertex F1                              92.85%
Vertex exact                            9.84%
Edge F1                                84.44%
Edge recall given matched endpoints    98.70%
Edge exact given vertex exact          79.59%
Strict skeleton exact                   7.83%
```

49 张顶点集合完全正确的图片中，39 张边集合也完全正确。端到端 exact 的第一瓶颈
仍是顶点整组选择，而不是键读取器；缺失端点会让相关真边不可恢复。

评估产物：

```text
outputs/evaluations/chemvector-v0736-node-conditioned-bond-predicted-validation498/
```

## 决策

- 一端点对一个 Bond Object：GO；
- 宽二维线带聚合双键、三键：GO；
- 全端点对读取且不做距离删除：GO；
- 自由 Bond Queries：保持 NO-GO；
- 下一步优先提高双分支顶点整组 exact，并为键型增加环级上下文；
- 稳定推理继续使用 v0.7.10，本轮仅为 shadow 组件。
