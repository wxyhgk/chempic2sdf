# v0.9.76 多域 Atom/Bond Proposal

## 目标

v0.9.75 证明跨风格瓶颈位于 proposal coverage，而不是 set/incidence 容量。本轮冻结共享视觉、
presence 和 incidence，只训练 Atom/Bond proposal head，让模型先在三种绘图域中稳定“看见”
语义原子对象和语义键对象。

## 数据与边界

三个训练域严格等量，各 6,000 张：

- ChemVision semantic renderer；
- webdataset_full_v0 四布局；
- MolGrapher synthetic 原始绘图风格。

三个 validation 域各固定 498 张。MR-TADF 和 USPTO 仍只做外部测试，不参与训练、阈值、
checkpoint 选择或提前停止。

双键和三键继续各自作为一个 BondObject，只包含两个语义端点；不使用键长阈值删边。

## 选择指标

checkpoint 第一优先级是三个域中最弱的 joint proposal recall，即每个域 Atom/Bond recall 的
较小值再取全域最小值。该指标直接约束跨域 coverage，不使用冻结旧 set head 的 full exact
选择 proposal checkpoint。

第一个 4,500 总样本检查点需要同时满足：

- MolGrapher Atom/Bond proposal recall 明显高于 85.73%/78.76%；
- ChemVision 和 full-v0 的 proposal recall 不出现不可接受回退；
- 若只是把三个域一起拉低，应立即停止并改为域适配器或可训练视觉层。

输出：

`outputs/checkpoints/chemvector-v0976-multidomain-proposals-balanced18k/`

## 第一阶段结果

在 4,500 总样本处暂停 proposal 训练，先验证新增 coverage 能否被后端利用：

| 域 | Atom recall 初始 | Atom 4,500 | Bond recall 初始 | Bond 4,500 |
|---|---:|---:|---:|---:|
| ChemVision | 99.53% | 99.43% | 98.22% | 98.04% |
| full-v0 | 99.63% | 99.59% | 98.30% | 98.26% |
| MolGrapher | 85.73% | 93.25% | 78.76% | 87.43% |

结果满足 proposal 阶段 GO 条件：MolGrapher coverage 显著提升，两个旧域基本不回退。

冻结的旧 set head 在新 proposal feature 上失配，Bond deployed exact 暂时降为 0。这不是
proposal coverage 的否定，而是明确要求下一步重新训练 presence/incidence。为避免在尚未证明
coverage 可转化前继续消耗数据，本轮先保留 `samples-004500.pt`，转入 v0.9.77。
