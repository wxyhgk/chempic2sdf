## 目标

在 v0.10.5 已解决 TEXT/IMPLICIT 路由后，让 OCR 直接适配当前预测 AtomObject crop。现成
v0.8.8 CTC 在 fresh calibration 500 的最佳原子状态 accuracy 仅 56.3%、TEXT raw 9.3%、
整图 exact 0.2%，直接接入 NO-GO。

## 协议

- 冻结 v0.10.4 结构和 v0.10.5 角色门。
- 只对 role probability ≥0.85 的 AtomObject 生成 crop。
- crop 中心为 anchor，宽高采用预测 extent 的 1.5 倍并保留 4px context。
- 匹配 TEXT 使用 GT 可见原始字符串；误报 TEXT 和未匹配 TEXT 使用 blank CTC 目标。
- 从 v0.8.8 初始化并微调完整 Pixel CTC。
- CUDA 前向、CPU deterministic CTC loss，梯度传回 GPU。

## 数据与门控

- style/ChemVision/font-v2：6,668/1,666/1,666 张。
- fresh calibration 500；独立 fresh evaluation 1,000。
- state accuracy ≥95%，state exact ≥20%。
- MR-TADF、USPTO、sealed test 不参与训练或选模。

## 结果

| calibration 500 | 未微调 v0.8.8 | 2.5k | 5k |
|---|---:|---:|---:|
| State accuracy | 56.3% | 72.88% | 72.88% |
| TEXT raw accuracy | 9.3% | 0% | 0% |
| State exact | 0.2% | 0% | 0% |

72.88% 正好对应全部隐式 C 比例。模型在加入误报 TEXT 的 blank 目标后学会输出全 blank，loss
约 0.7–1.1，但没有恢复任何字符。5k 与 2.5k 结果完全相同，因此在约 6k 曝光时提前停止；
独立 fresh evaluation 1k 未读取，sealed test 未读取。

## 决策

`NO-GO`。不能在同一个 CTC softmax 中让 blank hard negative 与真实字符串共同主导优化。
下一版应只用真实 TEXT 训练 CTC；误报 TEXT 由独立 binary blank gate 处理，或直接依赖已达到
99.47% precision 的 v0.10.5 角色门。
