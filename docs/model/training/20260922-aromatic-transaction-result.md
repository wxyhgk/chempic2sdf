## 实现边界

1. 仍使用原来的 presence=.85、芳香均值=.40、最小概率=.05；不按结果搜索阈值。
2. 只从保存的 pair logits、候选对应关系、已经应用 OCR 的原子属性及 scene 生成提案。
   目标 SMILES、GT 原子／键标签和样本名不进入事务验收函数；身份只在外层评分。
3. 回放适配器首先重建旧芳香提升并要求保存 scene **完全一致**。无法重建则报错，
   不用数值容差或经验补丁强行对齐。当前适配器只支持本批保存 trace 的格式。
4. 重叠或共享原子的候选环并为同一原子事务；事务排序固定，不做排列或子集搜索。
5. 先验证 raw 全图；已无效则沿用原路径。每个候选只在独立深拷贝上编译，失败时保留
   事务前状态，而不是清空所有已经接受的芳香提升。
6. 不改变原子元素、显式 H、charge、文字、几何、端点、原始 logits、presence 阈值及训练标签。
   只允许事务内的 display/chemical type 改动，逐项记录 proposed／accepted／rolled_back。
7. 没有接入默认推理或部署。原训练报告及 `stop_regression` 保持不变；
   `420203` 的 raw 类型保护失败不能因最终 MOL 相同而追溯改判。
