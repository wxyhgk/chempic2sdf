# 2026-07-29 v0.10.9 正确标签 Full CTC

> 状态：GO，最终 OCR 组合门通过  
> 输出：`outputs/checkpoints/chemvector-v0109-correct-label-ocr-style10k`  
> 初始化：干净 v0.8.8 CTC + v0.10.8 learned bbox

## 目标

验证 v0.10.6/0.10.7 的失败是否完全来自错误训练协议。本版只修正三件事：

1. 字符串按 ChemScene AtomObject 顺序读取，不再用空间 target index 索引源 SDF atom_id。
2. crop 使用 v0.10.8 learned bbox，不使用 atom anchor 或失效的旧 predicted center。
3. 显式解除 Pixel Encoder runtime freeze，确保卷积层参与反向传播。

结构模型、v0.10.5 role gate 和 v0.10.8 bbox 均冻结；OCR 仍是开放 byte CTC，不改为闭集
元素分类，也不加入化学价态约束。

## 配置

- style/ChemVision/font-v2：6,668/1,666/1,666 张。
- 只训练已匹配且 GT 可见字符串非空的 TEXT crop。
- v0.8.8 的 Pixel Encoder、Transformer 和 byte 输出头全部解冻。
- learning rate：`1e-4`；batch size：6；总计 10,000 张分子图。
- fresh calibration 500 每 2.5k 评测并选模；门通过后只读一次 fresh evaluation 1,000。
- sealed test 未读取；MR-TADF/USPTO 未参与训练、阈值或 checkpoint 选择。

## 解冻审计

12 张 smoke 后 Pixel Encoder 最大权重变化为 `2.0e-4`。正式 selected 与 v0.8.8 比较：

- 6/6 Pixel Encoder tensor 全部变化；
- 最大绝对变化：`0.0448442`。

因此本轮不是只训练 CTC 上层的“假解冻”。

## 决策

通过最终组合门 `state accuracy >= 95%`、`state exact >= 20%`，正式 GO。v0.10.6/
v0.10.7 的 NO-GO 结论撤销；其 checkpoint 仍因错误监督而废弃，不允许 resume。

下一步把 v0.10.5 role + v0.10.8 bbox + v0.10.9 CTC 接入统一推理 profile，再跑完整公开与
MR-TADF 外部 benchmark。模型能力提升阶段不使用这些外部集选阈值。
