# v0.8.4 Junction-Bond Assembler

> 状态：完成，默认替换 NO-GO  
> 基础 checkpoint：v0.7.39 Junction + v0.8.2 multiscale BondObject  
> 输出目录：`outputs/checkpoints/chemvector-v084-junction-bond-assembler-2k`

## 目标

验证 Hybrid 端到端中的主要错误是否来自“每个 BondObject 端点独立吸附最近
Junction”。新模块对每个端点在全部预测 Junction 与显式 NULL 之间分类，不使用
键长阈值，也不使用 MR-TADF 或 USPTO 调参。

## 数据

- 训练：`chemvision_layers_v0_1/pilot_10k` 的前 2,000 张 train 图片。
- 验证：scaffold 独立的全部 498 张 validation 图片。
- 上游预测被冻结并缓存；训练标签由 6px Junction 匹配与 12px BondObject 匹配生成。
- 文字中心与可见线端点通过 `begin_atom/end_atom` 对应，不强制坐标重合。
- MR-TADF、USPTO：未用于训练、阈值或 GO 决策。

## 模型与训练

每个端点-Junction pair 使用相对位移、距离、绝对坐标、BondObject 中心、方向、
长度、置信度和 Junction 角色。伪 BondObject 或缺失 Junction 的端点监督为 NULL。
模型只有约 53 KB checkpoint；上游视觉、OCR、Junction 和 BondObject 全部冻结。

```bash
.venv-train/bin/python -m chemvector.pretrain_junction_bond_assembler \
  --train-shards 'Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/train-*.tar' \
  --validation-shards 'Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/validation-*.tar' \
  --output-dir outputs/checkpoints/chemvector-v084-junction-bond-assembler-2k \
  --train-samples 2000 --validation-samples 498 --epochs 40 \
  --cache-batch-size 8
```

## 局部结果

| 指标 | nearest 标签基线 | learned |
|---|---:|---:|
| endpoint accuracy | 92.98% | 97.84% |
| non-NULL endpoint accuracy | 99.93% | 99.80% |
| object target exact | 91.38% | 96.81% |
| decoded pair exact | 不适用 | 98.18% |
| NULL endpoint accuracy | 0%（无 NULL） | 71.67% |

## 端到端结果

| 模式 | SDF valid | bond count | nonstereo | chemical exact |
|---|---:|---:|---:|---:|
| nearest baseline | 53.41% | 66.47% | 30.12% | 19.48% |
| learned | 59.84% | 62.05% | 29.52% | 19.08% |
| learned rescue | 53.41% | 66.47% | 30.12% | 19.48% |

激进 learned 模式净增加 32 张有效 SDF，但丢失 22 张 bond-count exact，并使完整
正确样本净减少 2 张。保守 rescue 只在 nearest 产生自环或重复 pair 时启用 learned
映射，最终逐项追平 baseline，没有新增完整正确样本。

## 决策

组件 GO：显式 NULL 和 learned assignment 能明显减少非法价态，证明局部分配可学。
默认替换 NO-GO：局部 pair 指标不能转化为新的整图正确结构。下一步不继续扩大该
MLP 数据量，转向联合节点-边集合修正，并在训练目标中同时约束键集合、价态和环闭合。
