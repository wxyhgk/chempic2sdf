# 2026-09-22 多样案例库 v1

## 目的与边界

响应“多样性不够，需要很多案例”：在不启动训练的前提下，扩充干净的化学结构图片，
并分别核算图片、分子身份、骨架、局部环境及样式，避免把换字体当作新分子。
本次不调整模型架构、OCR 或默认推理，不读取评估样本文件，不查询封存身份索引。
新增数据仍为隔离候选，不能直接当作已准入训练数据。

## 来源和设计

候选池为既有 v0.2 代码模板、12 个显式标签场景种子，以及固定 TRAIN58 清单中
32 个 `old_full_molecule` 身份；仅使用训练行的结构，不读取原样本文件。
该清单 SHA256：`f5e3a7163eef5c49118ad78dcf05778f4ad889dc9b6389097ef20896b79e2111`。

源池共 3,520 个不同 canonical isomeric SMILES，其中模板侧 3,488 个、旧 TRAIN 32 个。
与既有 3,484 个模板身份相比，新增种子实际仅增加 4 个模板身份；这次主要补样式与场景，
不是发现数千个全新分子。
既有基础扩量批次已包含 20,904 张原始成图／3,484 个结构，因此本批也不是首次达到万图规模。
本批内部不同像素数不等于跨历史批次新增图片数，尚未进行跨批像素去重。

确定性选取 768 个结构（736 个模板、32 个旧 TRAIN），每个计划 16 种样式，共 12,288 次成图。
选样不使用模型成败；按局部特征的支持数量递减加权，保留固定标签种子和 TRAIN32。

OA(16,5,4,2) 覆盖五个因子的全部两两水平组合，不是 4⁵ 种全组合。
质量拒绝和内部去重后，以实际保留覆盖为准，不能假定每个分子仍有全部 16 种。
沿用一个 RDKit 排版引擎，四个旋转不等同于四种独立结构排版。

计划选中结构含 716 个去立体连接身份、48 个非空 Murcko 骨架。

## 下一批应补什么

骨架计划报告：`outputs/audits/case-diversity-scaffold-gaps-20260922/`。
现有源池共 227 个非空 Murcko 骨架，本批计划覆盖 48 个；已列出缺失 179 个骨架的代表分子。
每个骨架选择重原子最少的代表，ID 打破平局，不依赖模型得分。
若未来全部加入，计划层面为 947 个结构、227 个非空骨架；不是本次已生成或已准入结果。
该清单参照计划 768 个结构，未来执行前须依据最终质量保留身份重新计算。
本次完成后已核对保留身份集合与计划集合完全相同，因此当前实际保留集合仍对应这 179 个缺口。
这 179 个是**本批样式矩阵尚未覆盖**的骨架，已存在于旧模板源池，
不能称为全项目新增骨架或全项目原先完全没有的化学案例。

建议顺序：

1. 当前批次的质量对账和保留身份核对已完成；继续按独立结构支持量定位稀有局部环境缺口。
2. 补本批缺失的环骨架样式，并单独分层补充无环链长/支化环境；Murcko 不衡量无环骨架多样性。
   若目标是扩大整个项目的化学覆盖，还须扩展结构来源／模板，并以相对已有全部模板和训练身份的
   新增连接身份、骨架和局部环境衡量收益，不能把这 179 个旧骨架当成新化学覆盖。
3. 处理真实可见标签与解析/训练目标的兼容性，核验实际候选可达性；图格无冲突不代表模型能找出节点。
4. 完成跨批重复核查及另行授权的身份准入，再固定数据和训练预算，进入小额对照试训。

不直接对所有旧分子无限增加样式，不把生成数量当作训练收益，也不因此重启大规模训练。
当前也没有覆盖配位键、氢键、金属或波浪键；新增此类场景必须先确定表示和监督合同。
