# v0.9.10 Frozen P0 Pair Scorer

> 状态：正式 train/calibration `NO-GO`；未读取 validation500 与 `internal_test`

## 目标

A 组仅使用 8D 几何/墨迹特征。在 `cross=0` 时 multiplicity-2 recall 只有
`94.563%`，说明几何描述不足以区分残余困难 pair。B 组在相同 target-free candidate pool
上加入冻结 P0 的视觉证据：

```text
8D pair geometry
+ symmetric frozen-P0 anchor embeddings
+ 12D decoded-line / candidate-centerline consistency
-> pair gain
-> disjoint pair/singleton matching
```

本实验仍是 positive ordinary anchor 条件下的能力实验，不是完整端到端 OCSR。

## 模型与训练

模型共 `11,873` 参数：

```text
anchor 128D -> 32D projector
(h_i+h_j, |h_i-h_j|, h_i*h_j)
+ normalized 8D geometry
+ normalized 12D consistency
-> 64D pair head -> scalar gain
```

训练固定使用：

- seed `9911`；
- fit-only normalization；
- balanced per-image BCE + shared-anchor ranking；
- 每图 top-4 hard-negative，权重 `0.5`；
- 最多 50 epoch，patience 10；实际在 epoch 26 早停；
- 只保留 calibration loss 最低的 5 个 checkpoint，再按真实 matching 指标选最终模型。

输出：

- 最低 calibration loss 在 epoch 16；结构指标最终选择 epoch 9。

## 残差诊断

`threshold=0.720950` 的唯一 cross 位于：

- sample `000001473`；
- molecule `chembl:CHEMBL4061291`；
- variant `stress`；
- candidate pair `[44, 53]`，score `2.700503`；
- 两个 anchor 分别来自 target 13 和 16。

关键不是两个真实键完全没有被识别。target 13 的正确 pair `[48, 98]` 得分 `4.391057`，
target 16 的正确 pair `[69, 83]` 得分 `5.311574`，两者已经同时被 matching 选中。错误是
两条已被更强 carrier 解释的视觉线仍各自剩余一个冗余 anchor，当前 pair/singleton 目标又把
这两个 leftover anchors 额外配成一对。

`threshold=0` 的 4 个 cross 也以 surplus anchor 为主：2 个 cross 的两个 target 均已有正确
pair，另外 2 个至少有一侧 target 已有正确 pair。这说明当前首要残差已从独立 pair
classification 转成 whole-set coverage：系统不知道某条视觉线已经被其他 carrier 解释过。

## 结论与下一步

Frozen unary P0 evidence 有效，但 B 组正式 `NO-GO`。继续增加 MLP 宽度、调整统一 threshold
或反复改变 hard-negative 权重，都没有直接命中剩余机制。

下一实验优先验证 target-free 的 coverage-aware set objective：高置信 carrier 先解释视觉
线，随后对已由其他 carrier 解释的 leftover anchor pair 施加冗余 veto 或 set-cover penalty。
如果该规则不能在通用分桶中稳定删除 surplus cross 且不损伤 parallel-2 / m2 recall，再转向
带更大视野的 pair-conditioned crop 模型。正式新路线需要新的未见 layered audit，不能继续把
已经用于选模和残差分析的 calibration900 当作独立证据。
