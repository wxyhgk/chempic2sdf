# v0.9.46 预测 Proposal Incidence

> 状态：predicted-proposal incidence GO，完整对象选择与 SDF 仍为 NO-GO  
> 训练：固定 ChemVision train 100  
> 验证：独立 ChemVision validation 100  
> 外部数据：未使用 USPTO 或 MR-TADF

## 目标

移除 v0.9.45 容量实验中的 GT-associated proposal。AtomObject 和 BondObject proposal
必须只由冻结模型自身的 heatmap 局部峰产生：

- 不向 decoder 提供真实原子数或真实键数；
- 不用 GT 选择空间 cell；
- Atom 和 Bond 候选上限均固定为 128；
- GT 只在训练/评测阶段通过 Hungarian 匹配生成监督标签；
- incidence forward 仍只读取预测对象 feature、geometry 和类型概率。

本实验只验证预测候选中的 endpoint-to-AtomObject incidence。它尚未训练 Atom/Bond
presence selector，因此 128 个 Bond 候选中的假对象不会在本指标中被当作最终输出。

## 实现

- target-independent proposal 与监督匹配：`chemvector/predicted_incidence.py`；
- 冻结模型覆盖审计：`chemvector/audit_predicted_incidence.py`；
- 训练器：`chemvector/train_predicted_incidence.py`；
- 测试：
  `tests/chemvector/test_predicted_incidence.py`、
  `tests/chemvector/test_train_predicted_incidence.py`。

Atom proposal 使用单通道 heatmap 的 `3x3` 局部峰；Bond proposal 在三个空间 slot 内分别
取局部峰。阈值固定为 0.01，只用于排除极低分峰，不使用键长删除候选。

匹配半径：

- Atom anchor：6px；
- Bond 两端最大误差：12px；
- Bond endpoint 顺序无关，若预测方向相反则同步翻转 AtomObject 指针监督。

## 冻结基线审计

使用 v0.9.45 incidence checkpoint，不做新训练：

| 指标 | Train capacity 100 | Validation 100 |
|---|---:|---:|
| Atom recall | 100% | 98.79% |
| Atom image coverage | 100% | 74% |
| Bond recall | 96.91% | 97.04% |
| Bond image coverage | 80% | 71% |
| Incidence eligible recall | 96.91% | 95.29% |
| Incidence image coverage | 80% | 64% |
| Eligible endpoint accuracy | 97.95% | 95.36% |
| Eligible bond accuracy | 96.19% | 91.49% |

这说明 v0.9.45 的 GT-associated 100% 不能直接迁移到预测候选。主要新增困难是每图约
103 个 Atom 候选形成的对象身份竞争；同时冻结 proposal 的 validation 整图覆盖上限只有
64%。

审计输出：

- `outputs/diagnostics/chemvector-v0946-predicted-incidence-audit/capacity100.json`；
- `outputs/diagnostics/chemvector-v0946-predicted-incidence-audit/validation100.json`。

## 训练

共享视觉、空间 AtomObject 和空间 BondObject 全部冻结。v0.9.45 的 74,113 参数 incidence
head 作为 warm start，只重训该 head。

```bash
.venv-train/bin/python -m chemvector.train_predicted_incidence \
  --output-dir outputs/checkpoints/chemvector-v0946-predicted-incidence-train100-val100-step1000 \
  --train-samples 100 \
  --validation-samples 100 \
  --max-steps 1000 \
  --batch-size 4 \
  --validate-every 100 \
  --log-every 20 \
  --learning-rate 1e-4
```

训练约 119.6 秒。训练集在 step 200 后，所有可覆盖 incidence 达到 100%；独立 validation
在 step 200/300 达到最高 46% image exact，之后继续训练没有收益。

## 判断

学习式 incidence 能在完全 target-independent 的高干扰 proposal 中显著泛化，方向 GO。
结果再次否定最近邻附着：同一组冻结 proposal 上，只调整学习式 incidence 就将独立整图
从 13% 提到 46%。

当前还不能识别完整分子：

1. validation 只有 64% 图片同时覆盖全部可监督 Atom/Bond；
2. 128 个 Bond 候选尚未做 target-independent presence/集合选择；
3. 指标未惩罚最终输出中可能保留的假 Atom/Bond；
4. 尚未编译 ChemScene v0.2、SDF，也未验证化学类型和 OCR。

## 决策

- predicted-proposal incidence：GO；
- v0.9.46 `best.pt`：作为下一阶段 warm start；
- 继续把 incidence 训练到更多 step：停止，validation 已进入平台；
- 替换稳定推理：NO-GO；
- 下一步：在相同 predicted proposal 上联合训练 target-independent Atom/Bond presence 与
  incidence 一致性，先提高完整对象集合 exact；不得用 GT count、键长阈值或最近邻附着。
