# v0.8.30 Endpoint-local 端点细化

> 状态：局部视觉归纳偏置 GO；正式 checkpoint NO-GO  
> 日期：2026-07-21  
> 基础 checkpoint：`chemvector-v082-multiscale-joint-9k-1epoch/best.pt`  
> 稳定推理：仍为 v0.7.10，本实验未接入默认推理

## 目标

验证 v0.8.29 泛化失败是否因为 endpoint token 没有直接读取端点附近的局部笔画。假设是：
如果基础候选已经大致覆盖一根键，端点最终落点主要由小范围局部图像决定，不需要让全局
Transformer 重新学习整张分子。

## 实现

在 stride-4 视觉特征上增加 endpoint-local 分支：

1. 用 `1x1 Conv + GroupNorm + GELU` 将 96 通道投影为 32 通道；
2. 围绕每个基础端点双线性采样 `5x5` patch，约对应原图 `20x20 px` 的局部区域；
3. 将 patch 与对应 endpoint token 拼接；
4. 通过小型 MLP 预测二维端点残差，并与 v0.8.29 的全局残差相加；
5. 最后一层零初始化，保持 step 0 parity。

完整 Group Query 分支为 1,619,601 个参数。另设 local-only 对照：冻结全局 Transformer、
全局 endpoint/presence/type heads，只训练 196,578 个 endpoint-local 参数。该对照用于
区分“局部视觉有效”和“更大模型参数更多”两种解释。

## 数据与协议

沿用 v0.8.29 的固定 molecule-isolated split：400 collision train、100 collision
holdout、400 ordinary replay、498 ordinary validation，split SHA256：

```text
1ff119a6306ffaaf2415bbbc508f2f7164aa83035c2f6f7951f0b9a3db0b1687
```

正式 early4k 配置为 4,000 exposure，每张训练图片曝光 5 次，batch size 8、学习率
`1e-4`、collision bond 权重 16、端点尺度 0.1、每 400 exposure 固定验证一次。最佳
checkpoint 只能由内部 holdout 与 ordinary validation 选择。MR-TADF、USPTO 不参与训练、
选阈值或选 checkpoint。

门控标准与 v0.8.29 相同：secondary recall 至少 50%、collision cell exact 至少 18%、
ordinary 回退不超过 0.5pp、protected retention 至少 95%，且所有非几何输出不变。

## 容量结果

| Capacity 100 | Cell exact | Secondary recall | Collision bond recall |
|---|---:|---:|---:|
| v0.8.29 全局 Group Query | 34.65% | 56.80% | 53.10% |
| v0.8.30 全模型训练 | 85.15% | 94.40% | 92.48% |
| v0.8.30 local-only | 78.22% | 90.40% | 89.38% |

局部 patch 显著提高了容量上限。local-only 虽低于全模型训练，但仍远高于 v0.8.29，
说明主要新增能力来自端点局部证据，不只是全局 Transformer 继续记忆。

## 泛化结果

下表均为各自最佳 checkpoint；v0.8.29 step 0 是共同基线：

| Holdout / Ordinary 指标 | Step 0 | 全模型 endpoint-local | Local-only |
|---|---:|---:|---:|
| Collision cell geometry exact | 1.00% | 15.00% | 16.00% |
| Secondary geometry recall | 16.04% | 50.94% | 52.83% |
| Collision bond geometry recall | 11.17% | 43.20% | 44.17% |
| Holdout protected retention | 100.00% | 98.75% | 98.79% |
| Ordinary known-object accuracy | 70.66% | 71.32% | 71.21% |
| Ordinary protected retention | 100.00% | 99.69% | 99.67% |

全模型和 local-only 都使 holdout secondary recall 超过 50%。local-only 的整 cell exact
更高，且最佳点更早出现在 2,400 exposure；冻结全局路径没有损失泛化，反而减少了全局
分支对小训练集的过拟合。

local-only 只未通过一项门槛：collision cell exact 为 16%，距离预设 18% 差 2 个
cell。count、presence、display、chemical、direction 和 proposal mask 均与基础模型完全
一致，非几何不变量审计通过。

## 决策

- 显式 endpoint-local patch：GO，后续端点细化必须保留；
- local-only 冻结协议：GO，作为下一轮受控实验的默认训练范围；
- v0.8.30 checkpoint：NO-GO，未达到 18% cell exact，不接入稳定推理；
- 下一步测试沿整根候选键采样的视觉证据，但必须与 endpoint patch 独立做 A/B，不能把
  容量集拟合提升误判为泛化提升。

## 限制

- 分支只能修正已存在的 Dense Bond 候选，不能恢复候选池完全漏掉的键；
- 只训练几何，不解决候选 presence/ranking、键级、OCR 或完整 SDF；
- collision holdout 只有 100 个 cell，1 个样本即 1pp，16% 与 18% 的差异仍需后续重复
  和公开分布验证；
- MR-TADF 与 USPTO 仅保留为外部诊断，不参与本轮结论。
