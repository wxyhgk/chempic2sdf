# v0.9.9 P0.5 无目标标签 Decoded-Line 聚类 Oracle

## 目的

连续 Extent Oracle 已证明 LSD carrier 的方向支持和有限线段重建上限足够高，但同一条
physical line 通常对应多个 LSD anchor。P0.5 检查在不读取 `target_line_id` 的条件下，
能否仅靠重建线的几何关系完成确定性去重，并为后续 typed affinity / exact-cover 提供
更小的 carrier 集合。

本实验不修改 trainer、translation audit 或稳定生产推理；`internal_test` 继续封存。

## 固定协议

输入为每个正 LSD anchor 经 continuous normal + extent oracle 重建后的有限线段。聚类函数
只接收：

- decoded finite segment；
- 原始 LSD anchor segment；
- 与 GT 无关的稳定 LSD source ID；
- 画布宽高。

`target_line_id`、bond group、元素和 SDF 均不进入聚类函数。GT 只在簇和 medoid 冻结后
用于计算指标。

每条线先 canonicalize，使方向指向 `+x`，严格竖直线指向 `+y`。随后运行确定性
complete-link，要求任意待合并两簇的全部 cross-pair 同时满足：

| 条件 | 固定阈值 |
|---|---:|
| unoriented angle | `<= 2 deg` |
| supporting-line normal distance | `<= 2 px` |
| finite interval IoU | `>= 0.85` |
| unordered endpoint error | `<= 8q` |

complete-link 距离取四项阈值归一化距离的最大值。每轮选择距离最小的合法簇对；同分按
canonical decoded geometry、canonical anchor geometry、稳定 source ID 裁决。因此输入顺序
或端点反转不会改变 source-ID 分区和代表。

每个簇的代表是簇内归一化总距离最小的真实成员 medoid。禁止平均坐标，避免生成没有
raster anchor 支撑的新几何。

## 判定

预注册式可行性门槛为 pair F1 `>=99%`、cross-target merge `=0`、q8 loss `<=0.5pp`、
positive partition exact `>=95%`、p2 distinct `=100%`。当前 pair F1 和 partition exact
未过门，因此：

**作为一步完成的精确去重器，P0.5 正式 NO-GO。**

但失败具有单向性：没有把不同 physical line 合并，没有损失任何 q8 覆盖，也没有吞掉
双键的两条平行成员；问题全部来自同一 GT line 被保守拆成多个簇。输出只比 4,355 条
ordinary GT physical line 多 50 个簇，却把 9,049 条输入压缩了 51.32%。因此：

**作为 geometry-preserving conservative precluster，方向保留为 GO 候选。** 后续 typed
affinity 可以只学习合并剩余 split clusters，而不让几何聚类承担有风险的跨平行线合并。
不能为了追求 partition exact 直接放宽 normal/endpoint 阈值；这会首先威胁 p2 distinct。

## 与 P0 正式结果的关系

P0 `best.pt`（step 900）在 validation500 的 q8 member recall 为 `98.3907%`，single / p2
coverage 分别为 `98.1996% / 98.2476%`，long coverage 为 `96.1479%`；translation100 的
member regression 最大仅 `0.207pp`。但 q8 structural exact 在 `+32px` 下从 `79%` 降至
`72%`。

这与 P0.5 的结论一致：成员级几何和召回可以稳定，整图 exact 仍会因任意一个 split、漏线
或分区错误而下降。后续报告必须同时给 member/q8 指标和 sample partition/structural exact，
不得用前者替代后者。

## 下一步

1. 保持当前 conservative complete-link 簇作为不可改写几何的原子单位。
2. 对 21 个 partition 非 exact 样本统计 split cluster 的视觉/anchor 差异，建立只含相邻
   conservative clusters 的 affinity 候选，不恢复全载体二次枚举。
3. learned P0 输出接入前，先以 continuous oracle clusters 验证 DROP exact-cover 能否在
   不降低 q8/p2 指标的条件下合并这 50 个额外簇。
4. learned P0 接入后重复同一审计，并单独报告 extent error 导致的新 split 和 cross-target
   merge；continuous oracle 的 79% 不能当作 learned 上限自动继承。
