# 2026-07-16 v0.7.21 可训练视觉 Atom Query

> 状态：固定 100 图 GO，跨域坐标 GO，跨域 cardinality NO-GO  
> 稳定推理基线：`v0.7.10`  
> 本轮协议：纯 Atom Query 直接坐标，不使用 dense snap

## 目标

验证下面这条视觉到结构路线能否先在固定数据上完整过拟合：

```text
stride-4 高分辨率视觉特征
-> 集合式 Atom Query
-> 每个 query 预测 object/no-object + 原子中心
-> 后续全局边关系、OCR
-> SDF
```

本轮重点不是扩大数据，而是确认模型本身有能力直接读出所有原子点。固定 node
threshold、固定宽 NMS 和 dense peak 吸附均不参与门槛评测。

## 代码变化

- Transformer decoder 支持逐层 Hungarian auxiliary supervision；
- query 最终层直接输出 presence、中心坐标和芳香标记；
- 支持低学习率解冻视觉 stem 与指定数量的 stride-4 block；
- 增加每图最差 3 个匹配点的尾部坐标损失；
- 增加 `implicit vertex / atom text` 二分类视觉角色，不识别具体字符；
- 增加零初始化的第二次局部采样与 refinement，第二阶段半径为 64px；
- query checkpoint 保存完整有效视觉 encoder 状态，评测时自动恢复；
- 保留 probability-sum cardinality 与独立 count head 两种无固定阈值解码实验；
- 旧 v0.7.12 checkpoint 可缺少新增头，并继续作为初始化使用。

## 数据与边界

- 训练/验证：`Data/sdf/molgrapher_synthetic_v0_1/overfit_100/train-000000.tar`；
- 固定 100 张图片，训练和验证相同，只用于能力上限测试；
- 不使用 MR-TADF 训练、调参或选择 checkpoint；
- 不使用 USPTO clean/large/abbreviated 选择 checkpoint；
- 结果不能解释为泛化准确率。

## 实验过程

初始化 checkpoint 的纯 query 基线为：Count exact 100%，6px vertex exact 60%。
v0.7.9 与 v0.7.11 的 116 个视觉 encoder tensor 逐位一致，因此使用稳定 v0.7.9
作为基础视觉 checkpoint 不引入额外变化。

| 阶段 | 训练方式 | 最佳 6px exact | 结论 |
|---|---|---:|---|
| v1 | auxiliary `0.5`，共享预测头 | 41% | 辅助层梯度破坏最终坐标头，停止 |
| v2 | auxiliary 独立预测头 | 29% | 随机辅助头仍扰动共享 decoder，停止 |
| v3 | auxiliary 关闭，query/视觉均 `1e-5` | 69% | 可训练高分辨率视觉有效 |
| v4 | coarse 权重 `0.25` + 最差 3 点损失 | 74% | 尾部损失有效但进入平台 |
| v5 | 只训练 120,386 参数角色头 | 74% | 角色准确率 100%，坐标严格不变 |
| v6 | 角色代价加入 Hungarian | 75% | 角色错配只解释少量失败 |
| v7 | 只训练第二次局部 refinement | **97%** | 通过 90% 能力门槛 |

v4 的距离审计显示 26 张 6px 失败图中，17 张在 16px 仍失败，最大偏移 77px。
覆盖图表明错误集中在拥挤文字/线端点和局部 query 竞争，并非普遍亚像素噪声。单次
refinement 最多修正 32px，是 74%–75% 平台的直接结构性限制。

## 决策

固定 100 图能力测试 `GO`。这轮证明：集合式 query 的 cardinality 可以保持 100%，
纯 query 坐标也能超过 90%；先前 60%–75% 上限主要来自单次局部 refinement，而不是
必须依赖 dense heatmap、数据量不足或模型总参数不足。

该 checkpoint 不是泛化模型，因此随后使用 scaffold 独立的内部 pilot，从训练开始
共同学习双阶段 refinement。逐层 auxiliary 必须采用 warm-up 或低权重课程，不能从
随机辅助头以 `0.5` 权重直接接入。MR-TADF 和 USPTO 继续只读，不用于门控。

## 集合计数校准

从 128 个 query 的 object 概率构造可微 Poisson-binomial 计数分布，以真实原子数做
负对数似然，并取分布众数解码。只训练 193 个 presence 参数、曝光 20,000 张后：

- Count exact：20.2% → 21.4%；
- Count MAE：1.834 → 1.743；
- 6px F1 基本不变；
- 6px vertex exact 仍为 0%。

最佳计数 checkpoint：

```text
outputs/checkpoints/chemvector-v0721-molgrapher9k-set-count-20k/best.pt
```

- step / 曝光：1500 / 12000；
- SHA256：`b754f6c8c1a1d9a424626b68fb9c133834aa85e97bab458086547b0ab2132525`。
- 独立评测：`outputs/evaluations/v0721-molgrapher-validation1k-set-count-grid.json`。

该消融说明集合计数分布目标有效，但只校准最终 presence 头不足。下一步必须让计数
损失以低权重反向进入 query hidden，同时使用独立旧域门控防止坐标回退。

## Count-Aware Query Decoder

新增受控训练模式，只解冻 presence、最后 N 层 query decoder 和 decoder norm；坐标、
角色与双阶段 refinement 头保持冻结，但坐标损失仍通过这些冻结头约束 hidden。最佳
checkpoint 还必须满足最低 6px F1，避免用计数提升换取坐标退化。

| 方案 | 可训练参数 | Count exact | Count MAE | 6px F1 |
|---|---:|---:|---:|---:|
| presence-only | 193 | 21.4% | 1.743 | 39.80% |
| 最后一层 decoder | 594,049 | 22.4% | 1.723 | 40.05% |
| 最后两层 decoder | 1,187,521 | **23.9%** | **1.648** | **40.14%** |

最终 count-aware checkpoint：

```text
outputs/checkpoints/chemvector-v0721-molgrapher9k-count-decoder2-12k/best.pt
```

- step / 曝光：1000 / 4000；
- SHA256：`f7de6f7221177279168b8d2f5a641fe6755df3a48f87afe843c99178afe1f253`；
- 独立评测：`outputs/evaluations/v0721-molgrapher-validation1k-count-decoder2-grid.json`；
- checkpoint 选择门槛：6px F1 不低于 39.5%。

最后两层优于一层，证明分子级 cardinality 需要 query 之间更深的全局交互。但继续
开放第三层会扩大坐标回归风险，且无法解决独立 Bernoulli 假设。下一步改为显式全局
cardinality token，与 Poisson-binomial set loss 联合训练。

最终决策更新为：固定 100 图能力 `GO`，跨域坐标主干 `GO`，count-aware decoder
方向 `GO`，当前 cardinality 准确率仍 `NO-GO`。稳定推理仍为 v0.7.10。
