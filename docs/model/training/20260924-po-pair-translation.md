# 连键取样稳健性：固定九位置、无真值的均值对照

接续 [端点与三路特征诊断](20260924-po-pair-attribution.md)。
上轮真实端点校正恢复 54 条大字号漏连，但使用了真值，且损坏一条双键。
本轮只验证一种不读取真值的取样方法，不训练、不部署，不改阈值或上游模型。

## 事前固定方案

- 原四结构全部 64 张，沿用 frozen initial 和原阈值；不生成新图、不查询身份。
- 原位置作为对照；其余八位置取二维网格 `{-4, 0, +4} px²`，即一个 stride-4 特征格的尺度。
- 每次将所有入选原子的**取样坐标**平移相同偏移；不改变两端相对方向／长度，
  不重算检测特征／检测分数，不改变候选集合、最终图坐标或原子匹配。
- 覆盖全部候选原子对，不按 P/O 元素、标签、分数高低或是否漏连决定处理对象。
- 先完成全部九位置预测，再让真值进入评分；绝不搜索最优坐标或取最大存在概率。
- 仅测试一个固定汇总：`p(edge)=mean(p_v)`，
  `p(type|edge)=sum(p_v × p_v(type|edge)) / sum(p_v)`。
  即平均联合边／键型概率，再求条件键型；沿用原芳香提升规则和 0.85 存在阈值。
- 数值计算使用 float64，概率取 machine epsilon 仅避免 log(0)，输出 float32。
- 坐标越界直接停止，不裁剪、不替换个例、不减少参与汇总的位置。

这只处理共同平移不确定性，不覆盖两端独立偏移、角度变化或长度误差。
九视图共享同一原图和上游特征，不能当成九份独立证据或独立样本。

## 固定验收与资源

主观察量是大字号 P–O 单键，但所有目标键、确认非边与未知 pair 都必须同时报告。
面板通过需同时满足：

1. 大字号 P–O 正确数增加。
2. 原先正确的目标键无一丢失／错型，包括 P=O 与其他键，不能只看净增。
3. 确认假连接数不增加。
4. 未知 pair 的预测存在数不增加；该项只是保守数量约束，未知不被当成假边。

即使通过，也不是泛化验收或部署授权；此前 4 个结构已反复用于诊断。
本面板没有三键或完整 OCR／立体化学／SDF 验收。

固定 CPU 上限 300 秒；1 次模型加载、64 次结构前向、576 次完整 pair 前向。
其中原位置的 64 次必须精确复现旧 prediction digest，不再额外重算零偏移。
无 GPU、梯度、优化器、OCR 或自动重试。保存所有视图原始 logits 与汇总预测，
后核验不重新调用模型，只重算九视图汇总、原芳香规则、匹配与评分。

## 执行结果

**方案明确失败，面板检查不通过，未部署。**
默认模型、checkpoint、正式推理、原样本和阈值均未修改；不是原模型再次训练退步。
没有调整偏移、权重或阈值补救这份结果，也没有再跑一次模型。

### 全图局部计数

| 指标 | 原预测 | 九位置等权平均 |
| --- | ---: | ---: |
| 正确目标键 | **619/688** | **45/688** |
| 漏连 | 63 | 643 |
| 存在但键型错误 | 6 | 0 |
| 确认非边中的假连接 | 0/2,928 | 0/2,928 |
| 未知 pair 中预测存在 | 8/35 | 1/35 |

原正确键损坏 **574** 条，没有原错误变正确；574 条全部变成漏连。
键型错误降为 0 是因为大量边被整体压到存在阈值以下，不能称为键型识别改善。
688 条目标键的端点仍全部可达，上游与匹配均未变化。

| 局部对照 | 原正确 | 平均后正确 |
| --- | ---: | ---: |
| 12 px，P–O 单键 | 63/64 | **0/64** |
| 24 px，P–O 单键 | 10/64 | **0/64** |
| 12 px，P=O 双键 | 32/32 | 31/32 |
| 24 px，P=O 双键 | 27/32 | 8/32 |

全部普通单键 272 条在平均后都漏连；芳香键剩 6/352 正确，双键剩 39/64 正确。
这不是只在 P–O 标签附近出现的均值退化。
主指标不改善、原正确键丢失，两条必要条件都失败，因此即使假连接未增加也不能采用。

### 保存分数的事后分析：横向偏移是重要线索，均值并不产生稳健性

不追加模型前向，从全部九位置已保存 logits 分析：

- 688 条真边只有 **18 条**在九个位置都超过原存在阈值。
- 小字号的 64 条 P–O 单键在九位置中仅有 3–5 个位置超过阈值；
  大字号单键仅有 1–4 个位置超过阈值。
- 将原本正确的 619 条键、各自八个非零偏移，按偏移相对原预测连线的横向分量事后分组：

| 横向偏移分组 | 重复观察数 | 平均存在概率 | 跌破阈值 |
| --- | ---: | ---: | ---: |
| ≤1 px | 592 | **0.953533** | 37 |
| ≥3 px | 2,644 | **0.266446** | 2,082 |

这两个分组不是独立样本，也不是逐键成对、只改变横向分量的因果对照；
1–3 px 的观察不在这张辅助表内。它是事后解释，不参与模型选参数或原面板验收。
共同平移保持预测键方向和长度不变，但使固定原图中的线条相对 ribbon 中心移动。
结果支持进一步处理沿键视觉编码的横向位置敏感性，不证明仅改某一层必然解决。

例如固定 `curr_2d1ccea044e8ee7d__oa22` 的 P–O bond 1：
原位置概率为 0.0417，平移 `(0,-4)` 为 0.9964，`(-4,0)` 为 0.9956，
另几个位置却接近 0；九位置平均只有 0.3827。
这是同一张图、同一候选对的采样响应，不是将某个优选偏移接入正式推理。

更重要的是：在八个非零位置中，出现了 **2 条不同的确认非边**超过阈值（共 2 次），
尽管原位置及均值预测的确认假边均为 0。
所以“某个位置看起来有键”不能直接变成“选择最高分加边”。这些反例完整保存在响应报告中。

## 结论与下一步

1. **停止这条九位置均值推理补丁，不调低全局阈值，不改成按最大分加边。**
   仅在推理时平均并不保证判别器对这些扰动稳健，本轮反而稀释了真实连接的证据。
2. 下一步准备训练侧的最小改动：在已准入训练图的预测候选对上增加固定、小范围端点扰动，
   保留原位置监督与正确键回放；同一候选对的图身份不变，未知 pair 仍不当负例。
   同时回放双键、芳香键及确认非边，不能只增加 P–O 正例。
3. 先检查扰动输入／标签一致性、近邻线歧义和负例覆盖，再另定一次 pair-only 小额试训预算。
   不自动训练、不解冻上游或 OCR；这四个已反复诊断的结构不充当独立验收集。

只读检查当前 `train_direct_atom_pair_bond.py` 训练循环时，看到它直接使用预测原子坐标进行
单位置 pair 读取，没有显式端点扰动分支。但这不是历史训练过程的完整审计，
不能据此断言“缺少增强”就是全部根因，或保证加增强一定有效。
