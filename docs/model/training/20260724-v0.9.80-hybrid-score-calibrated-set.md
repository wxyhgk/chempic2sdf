# v0.9.80 学生发现与教师分数标尺

## 目标

v0.9.79 的学生 proposal 提高了跨风格 coverage，但原始 score/type/geometry 接口使旧 set head
失效。接口审计显示，恢复教师 score 分布比替换 feature 或 type 更有效。本轮固定 proposal，
使用稳定 score 标尺重新训练 set/incidence。

## 接口

- 候选位置、端点和键型：v0.9.79 学生；
- object feature：v0.9.72 教师在学生候选 cell 上的特征；
- score：保留学生候选排序，但按每张图的 rank 映射到教师 score 分布；
- set/incidence：从 v0.9.72 初始化并训练。

该方案保留学生新增候选，同时消除绝对 score 尺度漂移。三域继续严格等量，MR-TADF/USPTO
不参与训练或 checkpoint 选择。

## 门控

第一个 4,500 总样本必须让 MolGrapher full exact 明显高于 1%，且 ChemVision/full-v0
恢复到可比较水平。若仍失败，说明问题不只是 score 标尺，而是当前 set/incidence 对 proposal
身份和几何变化缺少不变性，需要改变后端表示。

输出：

`outputs/checkpoints/chemvector-v0980-hybrid-multidomain-set-balanced18k/`

## 结果

第一个 4,500 总样本检查点触发 NO-GO：

| 域 | full exact |
|---|---:|
| ChemVision | 2.21% |
| full-v0 | 6.43% |
| MolGrapher | 0.00% |

score 标尺可以避免部分候选泛滥，但无法让旧 proposal-wise set head 适应新的候选身份和
几何。结论是当前后端表示缺少 proposal 不变性，不能继续通过 feature/score/type 接口校准
解决。下一步转为按预测无序 AtomPair 聚合候选并做组级存在性与键型决策。
