# v0.9.36 Predicted Junction Supervision

## 目标

解决 v0.9.35 的 GT Junction 训练到 predicted Junction 推理分布偏移。冻结 v0.9.28
junction-aware 生成器，在普通训练图片上产生真实预测点，再定义预测点对的 Bond existence 标签。

本实验仍不训练长键：

- 所有可表达 GT 键均为正样本；
- non-bond hard negative 只按视觉模型分数选择；
- 匹配半径只用于离线建立 predicted point 到 GT atom 的监督对应；
- 推理阶段没有匹配半径或键长删除阈值。

## 数据协议

新增 `chemvector.build_predicted_junction_relation_data`：

1. 冻结 v0.9.28 Bond selector 与 endpoint grouper；
2. 对训练图片生成 predicted Junction；
3. 使用匈牙利匹配将 predicted Junction 一对一映射到 GT atom；
4. 两个预测点分别映射到一条 GT 键的两个端点时，该 pair 为正；
5. 未匹配点、重复点、偏移点和其他预测点对自然形成负样本；
6. 使用 v0.9.35 分数选出最难 non-bond。

生成失败的图片会记录原因并由后续样本补足，训练加载器严格只读取 manifest 中成功生成的 key，
禁止失败样本偷偷回退到 GT Junction。

500 张 train manifest：

- predicted points：16,209；
- point match rate：99.56%；
- point-count exact：79.4%；
- GT bond recoverable：94.25%；
- 失败候选：9；
- 匹配距离均值：1.24 px，最大 11.43 px。

100 张 validation manifest：

- predicted points：3,136；
- point match rate：99.62%；
- point-count exact：74%；
- GT bond recoverable：92.55%；
- 失败候选：3；
- 匹配距离均值：1.27 px，最大 8.74 px。

这说明坐标偏移本身很小，但漏点直接使约 7.5% 的 validation GT 键无法由任意 pair classifier
表达。

## 训练结果

初始化：v0.9.35 best。500 张 predicted-Junction train，最多 10,000 曝光；最佳 checkpoint
出现在 2,000 曝光。

内部 predicted-Junction dense100：

| Relation set exact | v0.9.35 | v0.9.36 |
|---|---:|---:|
| Clean | 88% | 91% |
| Degraded | 89% | 91% |

最佳 clean precision/recall/F1 为 99.35% / 99.94% / 99.64%；degraded 为
99.29% / 99.88% / 99.58%。继续训练后 validation 回落，说明 500 张 predicted-point 数据已开始
过拟合，best checkpoint 正确保留在 step 2,000。

## USPTO Clean 100

固定 threshold=0.5，冻结 Junction、OCR 和编译协议：

| 指标 | v0.9.28 | v0.9.35 | v0.9.36 |
|---|---:|---:|---:|
| Skeleton exact | 76% | 69% | 74% |
| Atom-typed skeleton | 29% | 26% | 29% |
| Bond-typed skeleton | 56% | 55% | 61% |
| SDF valid | 约 77% | 69% | 71% |
| Chemical exact | 约 19% | 18% | 20% |

predicted-Junction supervision 将 skeleton 提高 5pp、bond-typed 提高 6pp，证明分布对齐训练有效。
但 paired audit 相对旧 shadow 为：

- 74 张两者都正确；
- 2 张旧版正确、新版错误；
- 0 张旧版错误被新版修正；
- union skeleton 75%，intersection 74%，均未超过旧版 76%。

## 决策

- predicted-Junction 数据协议：GO；
- GT point 到 predicted point 分布对齐：GO；
- v0.9.36 全量替换现有边集合：NO-GO；
- 继续只扩大 pair 数据：停止。

原因不是长键，也不是 relation 模型完全无效。USPTO clean 中旧版在原子/键数量正确时拓扑几乎
已经全部正确；剩余 skeleton 错误主要来自 Junction cardinality。pair existence 可以判断两个已
存在点是否相连，但不能凭空生成缺失节点。

下一阶段应将 Bond 视觉证据反向用于 Junction rescue：检测到稳定的关系端点证据而对应 Junction
缺失时，提出新节点候选；同时抑制文字笔画和重复端点形成的多余节点。训练和评测仍不使用键长删除
规则，MR-TADF 继续只作外部诊断。
