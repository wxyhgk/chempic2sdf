# v0.9.49 Proposal 集合选择扩量到全 9k

> 状态：全量 pilot 扩量 GO，下一步接 ChemScene/SDF shadow  
> 训练：ChemVision pilot 三个 train shard，共 8,974 张可迭代图片  
> 选择：ChemVision validation 前 100 张  
> 固定门控：ChemVision internal_test 前 100 张  
> 外部数据：未使用 USPTO 或 MR-TADF

## 目标

将 v0.9.48 的 1000 图结果扩到 pilot 的全部训练图片，继续验证数据覆盖对
target-independent Atom/Bond presence 与 incidence 泛化的影响。

保持不变：

- 冻结视觉、空间 AtomObject 和空间 BondObject；
- 每图最多 128 个 Atom proposal 和 128 个 Bond proposal；
- 178,565 参数联合 proposal set head；
- 不提供真实对象数量；
- 不使用键长阈值、匿名 Junction 或最近邻附着。

## 冻结 Proposal 缓存

视觉与两个 proposal detector 均冻结，因此先将 proposal、候选标签和 incidence 监督缓存，
避免训练时反复解码 PNG 和运行冻结网络。

- 构建器：`chemvector/build_proposal_object_cache.py`；
- train：8,974 条，18 个 cache shard，0 拒绝，约 694 MB；
- validation：100 条，0 拒绝；
- internal test：100 条，0 拒绝；
- train cache 构建耗时：203.2 秒。

数据汇总原本标记 train 9,000 张；当前三个实际 tar 可迭代记录为 8,974，本轮按实际文件
完整读取，不虚构或自动复制缺少的 26 条。

缓存目录：

- `outputs/checkpoints/chemvector-v0949-proposal-cache-train9k`；
- `outputs/checkpoints/chemvector-v0949-proposal-cache-validation100`；
- `outputs/checkpoints/chemvector-v0949-proposal-cache-internal-test100`。

## 训练

新增缓存训练器：`chemvector/train_cached_proposal_object_set.py`。从 v0.9.48 best warm
start，batch 32，presence/incidence 学习率分别为 `5e-5/5e-6`。

```bash
.venv-train/bin/python -m chemvector.train_cached_proposal_object_set \
  --output-dir outputs/checkpoints/chemvector-v0949-cached-proposal-object-set-train8974-step3000 \
  --max-steps 3000 \
  --batch-size 32 \
  --presence-learning-rate 5e-5 \
  --incidence-learning-rate 5e-6 \
  --atom-decision-threshold 0 \
  --bond-decision-threshold -0.5
```

3000 step 训练耗时 61.7 秒。最佳 checkpoint 为 step 1750。

## 判断

数据扩量继续有效：在冻结 proposal 和相同架构下，train100 -> train1k -> train8974 的
validation full object exact 为 `8% -> 24% -> 35%`；固定 internal test 从 19% 提高到
24%。Presence 泛化确实需要更多候选分布，而不是只靠 100 图容量实验。

收益已经开始放缓，且 incidence internal exact 仍为 38%。继续只扩大同一集合头不能回答
最终 SDF 能力：当前指标不包含 OCR 字符串、完整原子化学状态、键型编译和 RDKit 往返。

## 决策

- 全 8,974 图扩量：GO；
- 缓存训练路径：GO，后续冻结 proposal 实验统一复用；
- v0.9.49 替换稳定推理：NO-GO；
- 下一步：把 v0.9.49 选择出的 Atom/Bond/incidence 编译为 ChemScene v0.2，保存正确、
  错误和无效 SDF/渲染图，先跑内部 shadow；之后才进入 USPTO 公开门控。
