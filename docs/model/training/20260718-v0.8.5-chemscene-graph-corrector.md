# v0.8.5 ChemScene 图级修正

> 状态：type-only 小幅 GO，edge keep NO-GO  
> 基础 checkpoint：v0.7.39 Junction + v0.8.2 multiscale BondObject  
> 输出目录：`outputs/checkpoints/chemvector-v085-chemscene-graph-corrector-2k`

## 目标

验证逐键分类之后增加整图节点-边上下文，能否修正键型组合、芳香状态和非法价态。
本轮不使用键长阈值，不使用 MR-TADF 或 USPTO 调参。

## 数据与模型

- 训练：2,000 张 `chemvision_layers_v0_1` train 图片。
- 验证：scaffold 独立的全部 498 张 validation 图片。
- 预测候选覆盖：真实键 recall 96.46%，70.08% 图片覆盖全部真实键。
- 模型：三层 Junction-BondObject 消息传递，约 932 KB checkpoint。
- 节点输入：坐标、TEXT/IMPLICIT 角色、预测度数。
- 边输入：端点、长度、方向、置信度和 v0.8.2 预测键型。
- OCR 元素条件本轮关闭，保持单变量实验。

最佳 checkpoint 出现在 epoch 12；继续训练到 epoch 18 已出现验证回退，因此保留
epoch 12 的 `best.pt`。

## 局部验证

| 指标 | v0.8.2 输入 | v0.8.5 best |
|---|---:|---:|
| display accuracy | 79.12% | 79.99% |
| chemical accuracy | 94.81% | 96.19% |
| type-only set exact | 5.42% | 20.48% |
| keep+type set exact | 5.42% | 10.84% |

## 端到端结果

| 模式 | SDF valid | bond count | nonstereo | chemical exact |
|---|---:|---:|---:|---:|
| v0.8.3 nearest | 53.41% | 66.47% | 30.12% | 19.48% |
| v0.8.5 type-only | 55.22% | 66.47% | 30.12% | 19.68% |
| v0.8.5 keep+type | 61.85% | 27.91% | 14.46% | 9.24% |

type-only paired 审计：SDF valid 新增 12、回退 3；完整 exact 新增 2、回退 1。
keep+type 再次证明“有效 SDF 更多”不代表识别更准，它通过大量删边降低非法价态，
同时破坏真实结构。

## 决策

- 图级 type-only：小幅 GO，作为实验 profile 接入前端。
- edge keep：NO-GO，不进入默认推理。
- 稳定默认仍为 v0.7.10。
- 下一步固定边数量，加入环级芳香状态和价态一致性辅助目标，不再无约束删边。
