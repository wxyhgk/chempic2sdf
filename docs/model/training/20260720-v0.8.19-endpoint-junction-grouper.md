# v0.8.19 Endpoint Same-Junction Grouper

> 状态：边际 GO，视觉证据仍有必要  
> 日期：2026-07-20

## 假设

使用两个 endpoint 的坐标差、所属 Bond 方向、长度和 detector score，训练 15 维几何
特征 MLP，预测两个语义 endpoint 是否属于同一 Junction。GT atom ID 只作为二分类
监督，不进入模型输入。

聚类同时比较 complete-link 与 single-link，并禁止同一 Bond 的两个端点进入同组。

## 原始结果与审计错误

原始记录报告 validation topology exact 58.43%。复核发现
`junctions_from_bond_endpoints()` 使用 `torch.cdist` 计算亚像素距离；对完全相同、但
坐标数值较大的点，浮点消差会产生约 0.35px 的伪距离。审计使用 0.25px 半径重新
聚合显式分组后的同坐标点，因此错误地把同一 Junction 再拆开。

现已改为逐项差分的 `stable_pairwise_distances()`，并增加大坐标亚像素合并回归测试。

## 修正后结果

训练 500 张，共 139,346 个 endpoint pairs，其中正样本 25,968。

| 指标 | Train 500 | Validation 498 |
|---|---:|---:|
| Node F1 | 98.17% | 98.25% |
| Vertex exact | 79.00% | 75.90% |
| Topology exact | 79.00% | 75.70% |

最佳仍为 complete-link、threshold 0.50。validation 比固定 12px Oracle endpoint
clustering 的 75.30% 高 0.40pp。

## 结论

纯几何 same-Junction 建模不是失败方向，但增益只有 0.40pp，属于边际 GO，不足以
单独承担后续 Junction decode。下一版继续加入：

- endpoint 原图 patch；
- 入射线终止/穿越证据；
- TextObject bbox 与 anchor；
- 必要时再比较固定数量 Junction slots 的集合级分配。
