## 目标与边界

固定 100 图 capacity 已达到 `99% primitive exact`，但那只是同集记忆证明。本轮第一次
使用未见 molecule、未见 scaffold 和未见字体家族的 validation，检验 Visual Prefix
能否从图片生成 Visual SVG v0.1。

本轮仍只恢复 `LINE/TRIANGLE/QUAD/TEXT_BOX`，不预测 OCR 字符串、化学 Junction、键级、
价态或 SDF。MR-TADF、USPTO 和公开 OCSR 数据没有参与训练、阈值或 checkpoint 选择。

## Polygon 评估器修复

旧版 `polygon_true_positives` 把 triangle 和 quad 放进同一个 Hungarian cost matrix，并把
异类型距离设为无穷大。当某一行或列全部为无穷大时，SciPy
`linear_sum_assignment` 会抛出 `ValueError: cost matrix is infeasible`。这不是模型输出
本身的语法错误，而是评估器无法处理合法的异类型 polygon 数量组合。

修复后 triangle 与 quad 分别建立和求解匹配矩阵，再累加 true positive；回归测试覆盖
“预测同时含 triangle/quad、GT 只含 triangle”的情况。clean500 自由生成使用修复后的
评估器。zero baseline 的 polygon 预测与命中均为 0，不受该匹配崩溃影响。

```text

tests/chemvector/test_evaluate_visual_svg.py
```

## NO-GO 边界

当前 AR token-sequence 泛化训练判定 NO-GO，理由不是 teacher loss 不够低，而是 clean、
mixed、strong 和 coordinate-aware 均没有把 teacher-forced 改善转化成自由生成的
image-to-primitive 映射。原定短门控边界及已完成结果如下：

| 指标 | GO 边界 | clean500 | coordinate-aware 300 |
|---|---:|---:|---:|
| free generation completion | >= 0.99 | 0.84 | 0.37 |
| 四个边界坐标占比 | < 0.02 | 0.4845 | 未复核 |
| line count 与 GT 相关系数 | > 0.50 | 0.148 | 未复核 |
| free bond IoU mean | 明显高于 zero 的 0.022301 | 0.018885 | 0.007624 |
| primitive F1 | 必须非零并持续改善 | 全部为 0 | 全部为 0 |
| checkpoint 选择 | 不得只按 teacher loss | 只按 teacher loss | 只按 teacher loss |

这次 NO-GO 不否决 Visual SVG 协议，也不证明更多数据无用。它否决的是继续用当前损失
组合扩大 AR token-sequence 的 step 或直接运行 internal test。`internal_test` 保持封存，
直到下一架构、训练目标和 checkpoint 选择规则冻结后才允许运行一次。

## 最终决策与下一步

本轮已经依次验证 clean、mixed、strong contrastive 和 coordinate-aware loss。最后一个
实验虽把 coordinate soft MAE 从 `248.50q` 降到 `236.97q`，但 free completion 降到 37%、
全部 primitive F1 仍为 0、IoU 只有 0.7624%。因此当前 AR token-sequence 训练路线停止，
不再通过追加 step、提高 contrastive 权重或继续调整坐标 token loss 消耗训练预算。

下一步使用完全相同的 `pilot_10k` train/validation 切分和首轮 300 optimizer-step 预算，
做 unordered primitive set predictor A/B：用固定 primitive queries 直接预测图元类型、
存在性和连续坐标，通过 Hungarian 集合匹配训练，最后确定性排序并序列化为 Visual SVG。
对照组保留本轮 coordinate-aware AR 结果；A/B 必须比较 completion、primitive count、
各图元 F1、bond IoU 和计算量，不能只比较 teacher loss。

在 set predictor 的架构和门控规则冻结前，不运行 `internal_test`，也不使用 MR-TADF、
USPTO 或公开 OCSR 数据选择 checkpoint。
