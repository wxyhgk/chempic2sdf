# 2026-07-16 v0.7.20 跨字体全局 Proposal Graph

> 状态：全局图组件 GO；固定阈值部署 NO-GO  
> 基础模型：`outputs/checkpoints/chemvector-v079-relation-all-pairs-9k/last.pt`  
> 初始化 graph：`outputs/checkpoints/chemvector-v0718-proposal-graph-rescue-9k/best.pt`  
> 候选 checkpoint：`outputs/checkpoints/chemvector-v0720-style-global-10k/best.pt`

## 目标

验证 StarVector 审计得到的两个假设：

1. 当前 72 万张主数据虽然结构多，但主要来自单一 RDKit 绘图域；字体和绘图风格
   隔离验证比继续增加同风格图片更有信息量。
2. v0.7.18 只让边证据局部救点，缺少整张分子的全局一致性；在 proposal 上增加
   轻量全局 transformer，并允许 node loss 与 edge branch 联合更新，可能改善跨风格
   顶点选择。

本轮不训练 MR-TADF、USPTO clean/large/abbreviated，也不使用它们选择 checkpoint
或阈值。

## 数据

- 主训练：`chemvision_layers_v0_1/pilot_10k` 的 9,000 张训练图片；
- 主验证：同一 pilot 的 500 张 validation；训练与 validation 字体家族重叠为 0，
  scaffold 重叠为 0；
- replay：MolGrapher synthetic 9k，概率 50%；
- 保留验证：MolGrapher synthetic validation 1k；
- 外部审计：固定内部选择完成后，才运行 USPTO clean 1k 和 MR-TADF 1,100。

ChemVision pilot 仍使用 RDKit SVG renderer，因此本轮只证明跨字体、字号、线宽和
布局的迁移，不等同于真正的跨绘图器训练。

## 模型与冻结范围

- 在最多 192 个 proposals 上增加两层全局 transformer；
- `node_dim=64`、4 heads、FFN 256；
- edge message 不再 detach，node/edge 两个 loss 可以联合更新；
- 稳定视觉主干、vertex head、OCR、relation 和 proposal keep 全部冻结；
- 可训练参数：129,443；v0.7.18 为 29,475；
- 峰值 CUDA 显存约 2.5 GiB。

旧配置默认 `global_layers=0` 且关闭联合梯度，因此历史 checkpoint 行为保持不变。

## 训练配置

```bash
.venv-train/bin/python -m chemvector.pretrain_proposal_graph \
  --dense-checkpoint outputs/checkpoints/chemvector-v079-relation-all-pairs-9k/last.pt \
  --proposal-keep-checkpoint outputs/checkpoints/chemvector-v0717-stable-proposal-scale-9k-24k/best.pt \
  --init-graph-checkpoint outputs/checkpoints/chemvector-v0718-proposal-graph-rescue-9k/best.pt \
  --train-shards 'Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/train-*.tar' \
  --replay-shards 'Data/sdf/molgrapher_synthetic_v0_1/pilot_10k/shards/train-*.tar' \
  --replay-probability 0.5 \
  --replay-reject-keys-file outputs/audits/molgrapher-v0713-train-9k/reject_keys.txt \
  --validation-shards Data/sdf/chemvision_layers_v0_1/pilot_10k/shards/validation-000000.tar \
  --retention-validation-shards Data/sdf/molgrapher_synthetic_v0_1/pilot_10k/shards/validation-000000.tar \
  --retention-validation-reject-keys-file outputs/audits/molgrapher-v0713-validation-1k/reject_keys.txt \
  --output-dir outputs/checkpoints/chemvector-v0720-style-global-10k \
  --train-samples 10000 --epochs 3 --batch-size 8 \
  --sample-shuffle-buffer 1000 --shard-shuffle \
  --learning-rate 5e-5 \
  --global-layers 2 --global-heads 4 --global-ffn-dim 256 \
  --joint-node-edge-gradients \
  --validation-batches 125 --validate-every 500 \
  --validate-before-training --evaluate-line-ablation
```

双域平均指标选择 step 1,000、8,000 张暴露量的 checkpoint。最后 10,000 张版本
字体域略高，但 MolGrapher 略回落，因此没有覆盖 `best.pt`。

## 内部结果

| 域 | 指标 | v0.7.18 | v0.7.20 best |
|---|---|---:|---:|
| held-out 字体 500 | 6px vertex exact | 32.93% | 36.75% |
| held-out 字体 500 | Count exact | 43.17% | 45.38% |
| held-out 字体 500 | Edge F1 | 88.53% | 89.36% |
| MolGrapher 1k | 6px vertex exact | 7.50% | 7.70% |
| MolGrapher 1k | Count exact | 21.90% | 21.70% |
| MolGrapher 1k | Edge F1 | 78.35% | 78.45% |

两个内部域共同选择统一 node threshold `0.90`。线带置白后 edge F1 为 0，字体域
vertex exact 从最终模型的 37.35% 降到 34.54%，证明模型确实使用了可见线条。

### MR-TADF 1,100

MR-TADF 未参与训练和阈值选择。统一 threshold `0.90` 在大型复杂分子上明显过删：

| 指标 | 稳定 v0.7.10 | v0.7.20 |
|---|---:|---:|
| 有效 SDF | 92.09% | 84.82% |
| 化学完全一致 | 79.73% | 49.00% |
| 原子数一致 | 82.18% | 51.09% |

该反例说明问题不只是视觉风格：固定 node threshold 还与分子规模、proposal 数量和
结构复杂度耦合。小分子验证得到的高阈值不能直接迁移到大型分子。

## 决策

- 跨字体隔离验证协议：GO；
- 两层全局 proposal transformer：组件 GO；
- node-edge 联合梯度：组件 GO；
- 统一固定 threshold `0.90`：NO-GO；
- v0.7.20 替换稳定 v0.7.10：NO-GO；
- 不根据 MR-TADF 重新调低 threshold，避免外部集反向进入调参。

下一版应在内部验证中按真实原子数、proposal 数和画面占用率分层，研究软 cardinality
或集合式停止机制，让每张图片自行决定保留数量。只有内部复杂度分层选定后，才能再次
运行公开和 MR-TADF 外部审计。
