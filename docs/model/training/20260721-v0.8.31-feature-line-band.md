# v0.8.31 Feature Line-band 端点细化

> 状态：NO-GO；保留为可选实验分支  
> 日期：2026-07-21  
> 基础分支：v0.8.30 endpoint-local local-only  
> 稳定推理：仍为 v0.7.10，本实验未接入默认推理

## 目标

验证沿整根候选键读取视觉特征，是否能在 v0.8.30 的端点 patch 基础上进一步解决同 cell
多键。假设是：端点 patch 只看到局部交汇，而整段 line-band 能提供“这两个端点是否由
同一条连续笔画连接”的证据。

## 实现

本轮在 v0.8.30 的 32 通道 endpoint-local 特征图上，为每个基础候选采样一个方向对齐的
line-band：

- 沿候选端点之间采样 32 个位置；
- 垂直候选方向采样半径 2 个 feature cell，总宽度 5；
- 将正向 band 与 180 度翻转 band 平均，保持无向键端点交换不变；
- 通过小 CNN 和池化得到 64 维整键特征；
- 同一个整键特征同时提供给两个 endpoint-local residual。

该 Group Query 分支总参数 1,649,713；全局路径继续冻结，只训练 endpoint patch、
line-band encoder 和局部 residual，共 226,690 个参数。最后一层保持零初始化。

## 结果

| 指标 | v0.8.30 local-only | v0.8.31 line-band | 差值 |
|---|---:|---:|---:|
| Capacity cell exact | 78.22% | 82.18% | +3.96pp |
| Capacity secondary recall | 90.40% | 91.20% | +0.80pp |
| Holdout cell exact | 16.00% | 14.00% | -2.00pp |
| Holdout secondary recall | 52.83% | 51.89% | -0.94pp |
| Holdout collision bond recall | 44.17% | 42.72% | -1.46pp |
| Holdout protected retention | 98.79% | 98.75% | -0.04pp |
| Ordinary known-object accuracy | 71.21% | 71.26% | +0.05pp |
| Ordinary protected retention | 99.67% | 99.68% | +0.01pp |

容量集拟合更好，但 molecule-isolated holdout 的三项 collision 几何指标全部回退。唯一
未通过的正式门槛仍是 cell exact：14% 低于 18%。其余门槛通过，count 和所有非几何
logit 仍保持不变。

该结果说明 stride-4 特征上的对称、池化 line-band 可以增加拟合能力，但没有提供可泛化
的精细线条证据。可能限制包括：特征图已丢失原始像素级笔画位置；正反向平均去除了端点
角色；整段池化容易把交叉线、平行线和目标线混在一起。实验只能证明当前实现无收益，
不能推出“整键视觉证据无用”。

## 决策

- v0.8.31 checkpoint：NO-GO，不接入稳定推理；
- feature line-band sampler 和测试保留，供以后消融，不作为下一版默认分支；
- 不继续增加 feature band 宽度、采样点或 MLP 参数；
- 下一步直接从原始图片采样窄墨迹带，并为两个端点构造相反方向的定向视图，避免先经过
  stride-4 特征压缩和无向平均。

## 限制

- 仍依赖基础候选的两个端点，无法创建候选池中不存在的键；
- 当前结论只覆盖 occupancy 2/3 的 100-cell holdout；
- 只评估候选端点几何，不等于 skeleton exact、SDF valid 或公开 OCSR 准确率。
