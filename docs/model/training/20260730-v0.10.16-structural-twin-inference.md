## 目标

把 v0.10.15 已通过 42k 结构 confirm 的完整候选接入 v0.10.10 图片到 SDF 链路，同时保持
旧默认路径零变化。只有显式启用 `--structural-twin-suppression` 才加载冻结的 v0.10.13 30k

## 接入边界

删除发生在最终 AtomObject 和全部 Direct AtomPair 已生成之后、OCR 与 ChemScene 编译之前：

1. 将原始 atom query index 确定性映射到紧凑 action sample；
2. 使用 2px、等邻接、逐边 chemical type 一致规则获证；
3. 冻结 ranking 在获证动作中选一个正 utility 动作；
4. 从 `atom_mask` 删除该 query，并过滤所有包含它的 Direct AtomPair 输出；
5. OCR、芳香环融合、ChemScene 和 SDF 编译只读取幸存对象。

每图仍最多删除一次。规则、presence threshold 和 ranking 权重均与 v0.10.15 相同。
