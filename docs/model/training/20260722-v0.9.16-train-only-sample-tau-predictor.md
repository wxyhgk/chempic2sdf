## 阶段 A：真实区间 Manifest

v0.9.15 有 846 / 900 张 calibration 图命中提前证书。这些证书只保证某个
保守低阈值区间可达，没有计算真实相邻 hull boundary，因此不能直接当训练标签。

manifest 生成必须：

1. 对 fit 8,100 和 calibration 900 全部关闭 early shortcut；
2. 完整枚举 parametric upper hull，并为每个开区间计算真实相邻 boundary；
3. 在每个非退化开区间的 25%/50%/75% 三个严格内部点重放 production
   matching，三点状态完全一致才记为 robust interval；
4. 保留所有 target-aware 目标上等价的 robust intervals，不只保留一个人工选中点；
5. 将 candidate 本身缺失的样本标记为 `candidate_unreachable`，单独统计并排除于
   predictor loss，不得把它们伪装成 threshold 学习失败；
6. 没有任何 oracle-equivalent robust interval 的其他样本标记为 `scalar_unreachable`，
   不进入 interval loss，但必须在审计中单独报告。

“oracle-equivalent”只比较冻结 target-aware 结构目标：cross-target pair 更少、P2
violation 更少、m2 matched 更多、pairable exact 更好、support loss 更少、precision
更高。threshold 离 0 或 `tau0` 的距离不得用来删除这些并列区间。

## Target-Free 特征

每个 candidate pair 是一个 21D token：

- frozen B scorer 输出的 20D `normalized_pair_descriptors`；
- 同一 scorer 在原始 FP32 score scale 上的 1D `raw_gain`，不减 threshold。

全图另加四个固定、target-free 计数特征：

```text
g0 = log1p(anchor_count)
g1 = log1p(candidate_pair_count)
g2 = log1p(count(raw_gain > tau0))
g3 = log1p(count(unique anchors incident to raw_gain > tau0))
```

严格使用 `>`，`tau0` 固定为 `0.7209501005709171`。这四项只需扫描 pair 集合，
不增加 matching solve，时间复杂度为 `O(P)`。

## 固定模型

pair token 共享同一个 DeepSets encoder：

```text
21 -> Linear(32) -> GELU -> Linear(16) -> GELU
```

对所有有效 pair token 分别做 16D mean pooling 和 16D max pooling，拼接为 32D。
若某图 `P=0`，mean/max 都定义为 16D 全零，禁止用任务标签补默认值。
再拼接四个全图计数得到 36D，head 固定为：

```text
36 -> Linear(16) -> GELU -> Linear(1) -> delta(x)
tau(x) = tau0 + delta(x)
```

不加 LayerNorm、attention、matching-in-the-loop、图像 backbone 或第二个输出头。可训练参数精确为：

```text
21*32+32 + 32*16+16 + 36*16+16 + 16*1+1 = 1,841
```

进入 pooling 前必须按 `(first_anchor_id, second_anchor_id)` 升序做规范排列。候选输入
置换后先恢复该规范顺序，`delta(x)` 和最终 matching 必须 bitwise deterministic。

## Interval Loss

对每个 oracle-equivalent robust 开区间 `I_k=(lower_k, upper_k)`，先将每个有限
boundary 向区间内缩 5%：

- 两侧有限：`scale_k = upper_k - lower_k`；
- 只有一侧有限：`scale_k = max(1, abs(boundary_k - tau0))`；
- 两侧均无限：`scale_k = 1`。

有限 lower 替换为 `lower'_k = lower_k + 0.05 * scale_k`，有限 upper 替换为
`upper'_k = upper_k - 0.05 * scale_k`。单区间的线性归一化 hinge 为：

```text
d_k(tau) = (max(0, lower'_k - tau) + max(0, tau - upper'_k)) / scale_k
```

无限一侧对应的 hinge 项记为 0。每张图的训练 loss 是所有等价区间中的最小值：

```text
L(x) = min_k d_k(tau(x))
```

不使用 SmoothL1、中点回归、oracle interval 人工择一或额外 `delta` 正则。
`candidate_unreachable` 和 `scalar_unreachable` 样本不进入 loss 分母，但仍保留在
manifest 和最终结构评估中。
