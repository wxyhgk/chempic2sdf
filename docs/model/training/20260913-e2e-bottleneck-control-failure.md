## 原计划与停止条件

参考路径为冻结 v0.10.3 Direct AtomPair 与此前固定的 R0 A 文字记录，
后者使用 CPU FP32 greedy OCR。它是明确限定的诊断基线，不声称代表所有前端路径。
固定关闭 structural twin suppression 和 aromatic ring fusion。

三个干预轴：

- A：给出完整真原子集合/位置；在这些位置采样冻结视觉特征，再运行原键、role/bbox/OCR 头。
- B：用真原子化学属性替换几何匹配上的既有节点属性。它包含文字识别和解释的上限，
  **不是“完美可见文字 OCR”**，不把有争议的历史 CH2 标签当权威转写。
- C：给出既有匹配节点间的真键及键类型；不补缺失原子，不删除多余原子。

单独与组合共 8 路。原定主指标为保留元素、同位素、电荷和键级的非立体分子图 exact，
另报立体图 exact、无效 SDF、碳回退及各条件下的 rescue/harm。
预先规定：全真值控制必须 200/200，否则不能据此排名架构瓶颈。

本轮未删除失败图片、没有改坐标、没有降低控制要求，也没有用另一个分子替换它们。
这使原计划尚未完成，但避免将表示问题混入网络模型的比较。

## 代码中的表示限制

1. `Data/sdf/chemsvg_sequence_v4.py:196` 明确拒绝重复量化坐标。
2. `Data/sdf/chemscene_v0_1.py:410` 构造真值场景仍经过上述 ChemSVG 序列，
   并通过 coordinate → atom ID 的字典恢复身份。
3. `Data/sdf/chemscene_v0_2.py:219` 即使使用独立 AtomObject ID，也继续要求所有 anchor 唯一。
4. `mol_from_chemscene_v0_2` 导出时仍转经 v0.1，不是仅修改一个 parser 条件就能安全解除限制。

因此可以确认：**合法语义分子图不必满足当前视觉中间表示的唯一坐标约束**。
这一类边界在历史数据/表示记录中已有提及；本次是在近期固定文字开发集上重新遇到它，
不是宣称首次发现。此前局部文字和候选实验未要求完整图经过这条编译链，不能替代此控制。

## 结论边界与下一步

两张图占本批 1%，不能用它们解释其余 99% 上的识别错误，更不能据此证明 MoE、
循环深度或 atom-first/bond-first 谁优谁劣。目前仍然没有本批完整的瓶颈排名。

下一步需要明确图区分：

- 语义身份：原子 ID、属性、以 ID 引用的键。
- 视觉观测：坐标、文字框、键笔画及其来源；坐标可以重合，不充当对象唯一身份。
- 可辨识性/数据质量：允许图结构保存多个同位对象，不等于模型一定能从图像恢复它们。

建议先做隔离的 **ID 驱动语义图 → SDF** 往返原型，确认它不依赖 SVG 的坐标唯一性，
并测试重复坐标、节点重排、同位素、电荷和立体属性。它是诊断适配器原型，
不是直接删除旧校验或迁移生产协议。若要继续 8 路实验，需要新的明确协议，
记录哪些编译边界发生了改变；原失败实验保持不可变。
