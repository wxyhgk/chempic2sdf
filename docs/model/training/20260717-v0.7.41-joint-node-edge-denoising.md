# v0.7.41 联合节点与边去噪

## 问题

v0.7.40 每轮都使用同一批冻结 edge logits，只训练节点残差，并没有真正实现联合图
恢复。本轮给每层增加有界 edge residual，并使用真实邻接监督修正全部候选点对：

```text
节点状态 -> 修正全部边 -> 修正后的边聚合回节点
```

仍保留 32,640 个点对，不使用距离或最近邻裁剪。相比 v0.7.40 只增加 130 个参数，
总可训练参数 310,111；主要变化是训练目标，不是模型规模。

## 容量与泛化

没有一个 bond 阈值同时通过 skeleton 和长键门槛。

## 错误审计

相对 v0.7.40：

```text
missing vertices           513 -> 411
unmatched extra vertices   188 -> 301
extra within 3px of bond   102 -> 162
extra near multiple bond    15 -> 31
```

联合边监督确实减少漏点，但把更多线段内部候选提升成真实端点。现有 line band 主要
观察两个候选之间是否有墨线，没有显式观察墨线是否穿过候选继续延伸，因此无法稳定
区分“真实端点”和“位于真实键内部的假点”。这正是双键被拆成多个顶点的机制。
