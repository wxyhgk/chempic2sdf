## 目标

v0.9.5 的 192 个匿名 free group slots 存在交换身份和类型塌缩。v0.9.6 删除 free
slots，让每个 frozen flat proposal 都成为潜在 group root：

```text
frozen flat proposals
  -> proposal encoder
  -> proposal-to-proposal symmetric pointer
  -> top-k root selection
  -> exclusive member assignment
  -> frozen carrier fitting
```

模型不生成坐标、端点或 stroke。GT group 的任意 member 都可以作为 latent root，训练
使用 softmin 消除固定 root 标签。

## 失败原因

训练和推理解码不一致：

1. 训练时每个 GT group 独立 softmin 选择一个 latent root。
2. 被选 root 的 keep 为正，同组其余成员为负。
3. 推理时在整图独立按 keep top-k 选择 root。
4. 没有全局约束保证每个真实 group 恰好选择一个 root。
5. group type、member count 和 pointer ownership 不参与联合选择。
6. ownership 对每个 proposal 独立 argmax，不满足 p2/p3/hashed 的容量约束。

因此增加训练步数只能继续改善局部 affinity，不能从结构上消除重复 root、漏 group 和
非法成员数。

## 正式判定

```text
proposal-anchored latent root
  + independent top-k root selection
  + independent member argmax

NO-GO
```

保留的结论：

- frozen flat proposal 坐标继续使用；
- proposal-to-proposal 相容性具有学习信号；
- Visual SVG v0.2、typed carrier codec 和 frozen carrier fitting 继续使用；
- 后续不得重新引入 free slots、latent root 或坐标回归。
