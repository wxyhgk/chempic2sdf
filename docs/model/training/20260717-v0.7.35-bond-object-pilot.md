# v0.7.35 Bond Object 自由查询 Pilot

## 动机

双键、三键和虚楔由多个显示 stroke 构成，但化学图中只是一条键。当前顶点模型可能
把副线端点误作原子。本轮把每条化学键定义为一个 Bond Object，直接预测两个端点、
bbox、显示类型、化学类型和方向。

模型使用 128 个全图 queries，不依赖已检测原子，不生成最近邻候选，不使用键长、
空白或长键预删除。

## 100 图容量实验

单次全局回归端点在 40k 曝光后只有 16.63% endpoint pair recall。增加两轮候选
对齐局部 refinement 后，最佳达到：

```text
Endpoint pair recall  96.65%
Display accuracy      100%
Chemical accuracy     100%
Count accuracy        100%
Bond Object exact      55%
```

这证明“一条化学键一个对象、多 stroke 共享端点”的表示可以学习。

## 9k/498 泛化实验

数据加载器实际有效样本为 train 8,974、validation 498；其余样本因 ChemSVG 坐标
碰撞被显式排除，没有自动替换。训练 44,870 次图片曝光后的最佳 validation：

```text
Endpoint pair recall   4.62%
Display accuracy      51.36%
Chemical accuracy     56.32%
Known-count exact       0%
Predicted exact         0%
```

自由 Bond Queries 在固定 100 图具备容量，但无法从 9k 多样整图中同时发现大量键、
分配 query 并精确回归两个端点。

## 决策

- Bond Object 语义表示：GO；
- 两阶段端点 refinement：GO；
- 从整图自由发现全部 Bond Objects：泛化 NO-GO；
- 下一步采用混合结构：v0.7.34 双分支先产生高召回原子端点，再对全部端点对读取
  中心线及平行偏移视觉特征，由 node-conditioned Bond Object 预测存在性和键型；
- 仍禁止最近邻截断、估计键长和长键预删除；
- 现有数据足够下一阶段 box/endpoints pilot。per-bond stroke mask 留待数据侧补充。
