# v0.9.62 可表达难图 Replay

> 状态：训练与联合 SDF 指标 GO  
> 初始化：v0.9.49 best  
> 数据：train 8,974 / validation 100 / locked internal_test 100

## 方法

先用冻结初始化 checkpoint 扫描全部 train cache，只保留以下难图：

1. Atom proposal 完整覆盖；
2. Bond proposal 完整覆盖；
3. 所有真实 Bond incidence 可监督；
4. 当前 full object exact 为 false。

共得到 3,249 张 representable hard 图。训练 batch 中 75% 从 hard pool 采样，25% 从完整
8,974 图 replay，避免 train100 记忆化。训练 1,500 step，best 按 validation full object exact
选择；实际 best 为 step 1000。
