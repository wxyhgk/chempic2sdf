## Pair-Local Raster

每个 candidate pair 从完整 PNG 提取 `2×24×48` crop：

1. 使用候选两条 LSD 边界的平均方向建立规范坐标系；
2. 将 pair overlap centerline 旋正到水平方向；
3. 纵向保留 6px padding，法向保留至少 8px padding；
4. channel 0 为完整 PNG 的 inverted grayscale ink；
5. channel 1 为候选两条 LSD segment 的软几何 mask；
6. 交换两条候选或反转任一 segment 端点，crop 必须不变；
7. cache 使用 uint8，训练传入 GPU 后除以 255。

## 模型

参数量固定为 15,353：

```text
local CNN:
  Conv 2->8 -> pool
  Conv 8->16 -> pool
  Conv 16->24 -> global average pool

pair fusion:
  [21D token, 24D local] -> 36 -> 16

context:
  global mean/max + 4D count
  endpoint other-mean/all-max/log1p-count

residual head:
  147 -> 48 -> 24 -> 1
```

最后一层 weight/bias 为零，step 0 严格等于 frozen raw gain。loss、`tau0`、maximum-weight
matching、门禁和 v0.9.18 相同。

## 失败复核

25 个 selected cross：

- 17 个来自 stress；
- 20 个在 frozen raw gain 中已经高于 threshold；
- 5 个由 pair-local residual 新引入；
- 22 个没有共享 endpoint 的 positive candidate；
- 13 个两端 candidate degree 都为 1。

审计 contact sheet 显示，大多数 crop 已经包含可判别空间模式：候选上/下方的第二条平行键、端点
交叉、斜线穿越、文字边缘或邻键。当前 CNN 最后使用 global average pooling，把这些模式压成近似
相同的纹理统计，丢失“干扰位于上方、下方还是端点”的位置。下一版复用同一 cache，只将局部
编码器改为保留粗空间网格的 `3×6` pooling；不应先加训练步数或扩大数据。
