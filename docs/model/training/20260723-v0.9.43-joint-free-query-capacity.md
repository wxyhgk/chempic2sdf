# v0.9.43 联合 Free-Query 容量实验

> 状态：NO-GO  
> 数据：固定 100 张 ChemVision train 图片  
> 视觉编码器：v0.9.8 pilot 9k checkpoint，冻结  
> 外部数据：未使用 USPTO 或 MR-TADF

## 目标

直接用两组无序 query 联合预测 AtomObject、BondObject 和 endpoint-to-atom incidence。
Atom query 输出 anchor、role 和文字几何；Bond query 输出两个可见 port 和键型；每个
bond endpoint 对所有 atom query 输出指针 logits。Bond 匈牙利匹配同时读取 port 几何
和 incidence 代价，不存在推理末端最近邻附着。

## 实现

- 模型：`chemvector/atom_bond_scene.py`；
- 训练与评测：`chemvector/train_atom_bond_scene.py`；
- 测试：`tests/chemvector/test_atom_bond_scene.py`。

首轮 1000 step 暴露出坐标不接地后，加入 stride-4 的两级 Atom anchor / Bond port
局部 patch 细化，并将几何损失权重从 12 提高到 64。随后保持同一优化器续训到
5000 step。

## 判断

模型很快学会每张图有多少 Atom/Bond，也能学习总体键型分布，但两个自由集合从零开始
同时争抢对象身份，匈牙利置换长期不稳定。局部 patch 只能修正已接近对象的 query，不能
把错误的全局身份变成正确对象。

因此失败原因不是数据量，也不是 incidence 公式，而是 free-query 几何身份缺少稳定空间
锚点。继续增加训练步数或参数没有依据。

## 决策

- 联合 Atom/Bond/incidence 目标：保留；
- 双 free-query 几何生成：NO-GO；
- checkpoint：不进入推理；
- 下一步：完整 AtomObject 和 BondObject 都使用空间 proposal，incidence 在 proposal
  之间学习，不恢复匿名 Junction 或最近邻 OCR。
