# 2026-07-16 v0.7.25 共享顶点分布关系重训

## 目标

v0.7.24 已把 Atom Query、stride-4 dense vertex head 和 relation 统一到同一视觉
主干，但旧 relation 从未在新的 set-count + dense-snap 检测顶点分布上训练。本轮固定
v0.7.24 顶点流水线，只重训 pair encoder 和 factorized relation head，验证多余键是否
主要来自关系模型与新顶点坐标分布不匹配。

本轮继续保留所有预测顶点的无向全点对。没有加入最近邻边、键长上限、长键删除或
MR-TADF 定向样本。

## 训练器修正

旧 `pretrain_detected_relation` 存在四个会造成训练/推理分布不一致的问题：

1. 额外加载 dense checkpoint 并运行第二套视觉主干；
2. Atom Query 使用固定阈值解码，而 v0.7.24 推理使用 set-count；
3. 没有加载 query checkpoint 中训练过的视觉权重；
4. 训练和验证共用一个缓存，无法用 scaffold 独立 validation 选择 checkpoint。

v0.7.25 改为：

```text
同一次 shared stroke feature
  -> Atom Query set-count 选择顶点集合
  -> packed dense head 提供局部峰
  -> 一对一 query/peak snap
  -> 全部无向点对读取线带
  -> factorized edge / bond head
```

监督阶段仍用 Hungarian 把预测顶点映射到真值顶点，但只接受 12px 内的映射；更远的
检测点按 `NONE` 监督。这个距离只用于分配训练标签，不参与推理边候选建立，也不会删除
任何长键。

checkpoint 选择依次比较 skeleton exact、edge-set exact、edge F1 和 edge precision。
另增加 relation-only 指标，直接衡量当前检测点对上的边分类能力，避免该容量门控被
上游 vertex exact 硬封顶。

## 固定 100 图容量门控

数据：

```text
Data/sdf/molgrapher_synthetic_v0_1/overfit_100/train-000000.tar
```

命令：

```bash
.venv-train/bin/python -m chemvector.pretrain_detected_relation \
  --init-checkpoint outputs/checkpoints/chemvector-v079-relation-all-pairs-9k/last.pt \
  --query-checkpoint outputs/checkpoints/chemvector-v0724-shared-dense-snap/best.pt \
  --train-shards Data/sdf/molgrapher_synthetic_v0_1/overfit_100/train-000000.tar \
  --validation-shards Data/sdf/molgrapher_synthetic_v0_1/overfit_100/train-000000.tar \
  --output-dir outputs/checkpoints/chemvector-v0725-shared-detected-relation-overfit100 \
  --train-cache-samples 100 --validation-samples 100 \
  --train-samples 10000 --epochs 100 \
  --learning-rate 1e-4 --train-pair-encoder --disable-relation-dropout \
  --edge-thresholds 0.30,0.40,0.50,0.55,0.60,0.65,0.70,0.75,0.80,0.90 \
  --validate-every 1000 --log-every 500
```

可训练参数为 146,308。relation-only 复评结果：

- edge precision：84.92%；
- edge recall：97.44%；
- edge F1：90.75%；
- 可见键级准确率：100%。

严格 skeleton exact 仍为 0，因为这批图上的 v0.7.24 vertex exact 本身为 0；因此它
不能用于判断 relation 容量。relation-only F1 超过 90%，证明 pair encoder 和 relation
head 在当前顶点分布上可以充分收敛，允许进入 9k 泛化训练。

## MolGrapher 9k / 1k 正式训练

训练只使用 9,000 张 train 图片；checkpoint 和阈值只使用 scaffold 独立的 1,000 张
validation。MR-TADF、USPTO 和跨字体 internal 均未用于训练或选择。

```bash
.venv-train/bin/python -m chemvector.pretrain_detected_relation \
  --init-checkpoint outputs/checkpoints/chemvector-v079-relation-all-pairs-9k/last.pt \
  --query-checkpoint outputs/checkpoints/chemvector-v0724-shared-dense-snap/best.pt \
  --train-shards 'Data/sdf/molgrapher_synthetic_v0_1/pilot_10k/shards/train-*.tar' \
  --validation-shards Data/sdf/molgrapher_synthetic_v0_1/pilot_10k/shards/validation-000000.tar \
  --output-dir outputs/checkpoints/chemvector-v0725-shared-detected-relation-9k-45k \
  --train-cache-samples 9000 --validation-samples 1000 \
  --train-samples 45000 --epochs 5 \
  --learning-rate 1e-4 --train-pair-encoder --disable-relation-dropout \
  --edge-thresholds 0.30,0.40,0.50,0.55,0.60,0.65,0.70,0.75,0.80,0.90 \
  --validate-every 5000 --log-every 1000
```

最佳 checkpoint 出现在 35,000 次图片曝光：

## 跨字体保留性

未参与训练和 checkpoint 选择的 ChemVision font internal 500：

| 关系模型 | 最佳阈值 | Edge precision | Edge recall | Edge F1 | 假边 | 漏边 |
|---|---:|---:|---:|---:|---:|---:|
| v0.7.9 旧 relation | 0.55 | 57.70% | 50.73% | 53.99% | 6,380 | 8,451 |
| v0.7.25 | 0.30 | 72.50% | 48.72% | **58.28%** | 3,170 | 8,795 |

跨字体 Edge F1 提高 4.29 个百分点，假边减少 50.31%，但 recall 下降 2.00 个百分点。
这说明新关系头不是只记住 MolGrapher 风格，同时也表明单一固定阈值仍不适合直接作为
所有风格的部署默认。

## 决策

- 共享 dense-snap 检测顶点上的 relation 重训：组件 GO；
- 100 图容量门控：GO，relation-only F1 90.75%；
- MolGrapher 1k 泛化：GO，Edge F1 52.56% -> 62.70%；
- 跨字体保留性：GO，但 recall 有轻微回落；
- 替换稳定 v0.7.10 推理：NO-GO；
- 原因：vertex exact / Count exact 仍使 skeleton exact 为 0，尚未形成可交付整图提升。

下一步不再继续扩大 relation 训练。优先修复顶点集合的漏点、误点和 Count exact，随后
再用 v0.7.25 relation 进行完整 SDF benchmark。所有 relation 候选继续保持全点对，
不得重新引入键长阈值或长键预删除。
