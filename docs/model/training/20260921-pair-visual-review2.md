# 两条假边的原图核对：跨节点捷径与跨空白延伸

本轮只完成讨论中的第一步：查看两张固定训练图及附近真边，不执行第二步训练回放。
使用原PNG、同源layers真值和首轮initial/50步保存预测；不读取开发/封存测试逐图资料。
没有加载checkpoint、模型推理、参数更新、GPU使用或连键规则修改。

## 结论

两条假边都不能从“条带中有线状笔画”直接推导为合法连接，但视觉构型不同：

1. **4ef桥环：跨过两个明确打印的C，额外连接两个桥头。**
2. **08d：跨过NH附近空白，沿已有支链单键的方向错误延伸。**

这些是原图、标签和预测图之间可核对的对应关系，支持优先检查“直接连接与沿途笔画的区分”。
并不证明模型的内部归因，不意味着所有假边都属于这两类，也不构成修改架构或上线几何规则的依据。

## 图例与坐标

每张对照图从左至右为：未标记的原图裁剪、保存候选与假边、真实原子和连接。

- 红色虚线：新增确认假边，不是原图笔画。
- 青色框：按保存q1023坐标换算的近似pair采样范围（纵向4%–96%、横向±12像素）。
- 绿色：真实连接；`P`编号是历史预测候选槽，`T`编号是该图目标原子，二者不能混用。
- 下方横条是对原RGB像素进行的条带展开，仅用于查看文字、线和空白的相对位置。
  **不是模型的特征图、注意力或实际activation**；模型在冻结视觉特征上采样，感受野及量化也不同。
- 真边横条用同源目标锚点；假边横条用保存预测锚点。因此它们是视觉对照，不是受控模型实验。

## 1. 桥环中的多段连接被额外加上直通边

样本：`curr_4ef506af64e8f0b8__bond_short`。

![桥环假边对照](../../../outputs/audits/chemvector-pair-visual-review2-20260921/curr_4ef506af64e8f0b8__bond_short.png)

- 假边：`P15–P18`，目标端点对应`T34–T31`，概率 **0.351084 → 0.950123**。
- 原图中央可见两个`C`。中央真实路径为 **T34–T38–T39–T31**，三条SINGLE键，
  而不是T34直接连接T31。外侧另有等长拓扑路径；报告中的BFS最短路径选到外侧路径不代表中央路径不存在。
- 候选P41和P38落在这条长假边的条带内。展开的RGB里可以直接看到两个C和它们之间的短线，
  并不是一根普通单键的图案。
- 保存预测中的P15–P41、P41–P38、P38–P18在initial时已经超过0.85；新增的P15–P18是额外捷径，
  不是把原有预测链条删掉后的替代。因此“把整段塌缩成一条边”并不精确。

这里还有已有的文字/候选问题：P38保存OCR为`F`，对应图上下面的`C`；上面的C附近候选P41
保存为IMPLICIT，位置也偏离目标锚点。不能把这些候选邻接全部当成已确认的训练正标签。
两端桥头间非边的监督身份不受上述中间候选猜测影响。

OCR在两阶段冻结、pair头也不直接接收OCR字符串，因此不能解释成“这50步把OCR训坏了”。
本图initial本来就无法编译，假边是新增问题，不是首次无效的唯一原因。

## 2. NH与已有短键之间存在空白，却被错误接通

样本：`curr_08d02946e879406f__font_large`。

![NH假边对照](../../../outputs/audits/chemvector-pair-visual-review2-20260921/curr_08d02946e879406f__font_large.png)

- 假边：`P4–P6`，目标端点对应`T7(NH)–T14(C)`，概率 **0.069670 → 0.963315**。
- P12对应真实末端碳T16，它是T14左下方支链单键的末端，并不连接NH。
- 原图能看见NH到该末端之间的空白。假边条带的后一部分覆盖真实的 **T16–T14** 单键，
  但前一部分并没有把NH与这个支链接起来。
- 邻近真边对照：T14–T16确有单键；T7–T8也确有单键，是NH向左连至芳香环的那一条。
  对应预测P6–P12一直高置信（0.998083→0.999005）；P4–P10则由0.008782升至0.945508。
  说明这一局部同时存在真边恢复和假边新增，不能只说整块视觉都变差。
- T14原已有四个单键连接，额外接入NH导致五价碳，与保存的新增无效SDF一致。

## 应如何使用这一步结论

应保留两个不同的待验证机制：

- 是否把含中间原子的多段路径，当成两端可以额外直接相连的证据？
- 是否把候选连线的一部分与真实键重合，当成整段连接存在的证据？

不应直接加“条带里出现第三点就删边”或“像素不连续就删边”：候选可能错误，
合法文字原子的端点本来也会留白，真实键也可能邻近其他对象。
这次查看没有进行遮挡、特征干预或模型输出反事实，不能把几何重合描述成已经证实的模型机制。

下一步仍是讨论中的受限逐步诊断，确认这些输出何时被推高；本轮不执行，也不复用旧训练授权。
