# v0.9.51 非环芳香键一致性

> 状态：确定性编译规则 GO  
> 权重：沿用 v0.9.49 best，无训练  
> 数据：固定 internal_test 100  
> OCR/原子化学状态：Oracle，仅用于结构隔离

## 目标

验证 v0.9.50 的 26 个 `non-ring atom marked aromatic` 是否主要由非环 BondObject 被预测为
`AROMATIC` 引起。规则只允许将不属于任何拓扑环的芳香键降为其可见 `display_type`；普通键不变，
环内芳香键不变，也不增加或删除 Atom/BondObject。

## 运行

```bash
.venv-train/bin/python -m chemvector.shadow_chemscene_v02_oracle \
  --aromatic-consistency demote-noncycle \
  --output-dir outputs/evaluations/chemvector-v0951-aromatic-consistency-internal100
```

## 结果

| 指标 | v0.9.50 | v0.9.51 |

| SDF valid | 56% | 69% |
| 非立体 SDF exact | 30% | 36% |
| Chemical exact | 27% | 31% |
| non-ring aromatic invalid | 26 | 13 |

新增 6、回退 0。该规则 GO，但仍剩 13 个非环芳香原子、12 个 Kekulize 和 6 个价态失败。
