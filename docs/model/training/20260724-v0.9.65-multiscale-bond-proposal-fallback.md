# v0.9.65 多尺度 Bond proposal 无效回退

## 问题定位

v0.9.64 的 1,100 张 MR-TADF 主测试中，263 个合法错误包含 214 个漏键样本。全量逐层
审计进一步确认：

| 指标 | 全量 | 标准键长 | 长键 | 极端长键 |
|---|---:|---:|---:|---:|
| Atom proposal 完整覆盖 | 93.73% | 95.83% | 89.83% | 90.35% |
| Bond proposal 完整覆盖 | 80.82% | 94.96% | 88.14% | 32.02% |
| incidence 可监督完整覆盖 | 78.00% | 92.95% | 81.36% | 29.82% |

因此极端长键的主要错误发生在联合 MILP 之前：完整 BondObject 候选没有进入 192 个
proposal，后续 selector 和 incidence 无法恢复。

有效错误的互斥主归因是 AtomObject 输出/映射 120、缺失 BondObject 87、多余
BondObject 19、纯键级 14、incidence rewire 12、OCR/元素 4、其他 7。本轮使用 Oracle
原子化学状态，OCR 不是这些结构错误的来源。

## 多尺度 A/B

当前联合流水线一直使用旧单尺度 checkpoint：

`outputs/checkpoints/chemvector-v082-line-object-9k-5epoch/best.pt`

仓库已有但未接入联合路线的多尺度 checkpoint：

`outputs/checkpoints/chemvector-v082-multiscale-joint-9k-1epoch/best.pt`

只替换 Bond proposal 后，极端长键 proposal 完整覆盖从 32.02% 提到 43.42%，全量
联合对象/incidence exact surrogate 从 39.82% 提到 43.91%。但直接替换会让标准键长
SDF exact 从 68.49% 回退到 67.19%，因此不能覆盖原单尺度结果。

## 最终协议

v0.9.65 使用确定性的 invalid-only fallback：

1. 先执行 v0.9.64 单尺度 proposal 与四级解码；
2. 单尺度只要生成合法 SDF，就原样保留；
3. 只有四级解码全部 sanitize 失败时，才执行多尺度 Bond proposal；
4. 不比较真值、不按键长路由、不修改阈值；
5. MR-TADF 不进入训练或 checkpoint 选择。

该协议保证旧版 874 个合法输出零回退。

## 诊断协议修复

v0.9.65 在 sanitize 失败时保留失败前 ChemScene 与 compile diagnostics。最终结果目录中
1,100 个样本全部有 scene，后续可直接定位无效价态或 Kekule 失败对应的具体原子和键，
不再只保存空诊断 SDF。

## 下一步

下一阶段不继续按 MR-TADF 键长调门槛。优先做两个通用实验：

1. 对 Atom proposal 的 3-10px 近重复候选做集合级去重学习；
2. 对 invalid-only 场景验证 cycle-local aromatic consistency，减少剩余 95 个 Kekule
   失败，同时保持合法结果不变。
