# v0.9.78 稳定特征的多域 Proposal

## 目标

保留 v0.9.76 的跨风格 proposal 训练方向，同时避免破坏 set/incidence 已学习的 object feature
坐标系。初始化重新回到稳定的 v0.9.72，不继承 v0.9.76 的特征漂移。

## 冻结边界

Atom 冻结：

- `input_projection`；
- `context`。

Bond 冻结：

- 多尺度 `stride8_adapter`、`stride16_adapter`；
- `base.input_projection`；
- `base.context`。

只训练 Atom/Bond 的 heatmap、端点几何、计数、角色、键型和方向输出分支。这样
`object_features` 保持稳定，下游仍可使用原有语义空间。

## 数据与门控

仍使用 ChemVision、full-v0、MolGrapher 三域严格等量训练，每域计划 6,000 张，第一检查点
为 4,500 总样本。除 proposal recall 外，还必须检查冻结的旧 set head 不再出现 Bond exact
整体归零；否则说明 set head 对几何、score 或 type 输入同样过度敏感。

MR-TADF 和 USPTO 仍只用于最终外部测试。

输出：

`outputs/checkpoints/chemvector-v0978-stable-feature-multidomain-proposals-balanced18k/`

## 结果

4,500 总样本结果：

- MolGrapher Atom proposal recall：85.73% → 85.92%；
- MolGrapher Bond proposal recall：78.76% → 79.42%；
- ChemVision/full-v0 的 full exact 仍有 28.71%/37.15%，没有发生 v0.9.76 的接口崩溃；
- MolGrapher full exact 为 0.80%，未高于初始 1.00%。

因此本轮为 NO-GO，并在 5,400 总样本处停止。结论是稳定 object feature 足以保护旧后端，
但固定特征本身无法提供足够的 MolGrapher 风格信息。下一轮采用可学习特征加教师一致性约束，
在“可适配”和“接口稳定”之间连续控制，而不是全解冻或全冻结。
