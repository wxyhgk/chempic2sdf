# v0.7.11 MolGrapher 结构头插值门控

## 目的

MolGrapher Synthetic 10k 的混合训练显著提升了同域骨架识别，但直接覆盖完整
vertex/relation/stroke 小头后，在 USPTO 和 MR-TADF 上发生严重遗忘。本实验不继续
训练主干，而是在 v0.7.10 基线与 MolGrapher 适配 checkpoint 之间做受限权重插值。

## 固定输入

- 基线：`outputs/checkpoints/chemvector-v079-relation-all-pairs-9k/last.pt`
- 适配：`outputs/checkpoints/chemvector-v0711-molgrapher-relation-mixed-10k/last.pt`
- 只允许变化：`vertex_head.*`、`relation_head.*`、`stroke_head.*`
- 实际变化：28 个张量，238,856 个参数
- 输入画布：768 x 768
- USPTO 内容尺寸：548，沿用 v0.7.10 最优设置

## 候选

使用 `chemvector.interpolate_structure_heads` 生成 `alpha=0.10/0.25/0.50`。每个候选
依次评测 MolGrapher validation 1k、USPTO clean 前 200 和 MR-TADF 前 200。

## 门控

v0.7.10 在相同 200 样本上的基线为：

- USPTO：43 个有效 SDF，4 个化学完全一致
- MR-TADF：174 个有效 SDF，143 个化学完全一致

候选必须在保留两组旧域能力的同时，证明 MolGrapher 骨架能力有所吸收，否则不升版。

## 结果

| alpha | MolGrapher Oracle skeleton exact | MolGrapher detected skeleton exact | USPTO valid/exact | MR-TADF valid/exact |
|---:|---:|---:|---:|---:|
| 0.10 | 9.6% @ 0.4 | 0.7% @ 0.4 | 43 / 2 | 177 / 143 |
| 0.25 | 11.7% @ 0.4 | 0.9% @ 0.4 | 32 / 1 | 178 / 144 |
| 0.50 | 20.5% @ 0.6 | 1.4% @ 0.6 | 24 / 3 | 177 / 135 |

旧基线 MolGrapher Oracle/Detected skeleton exact 为 8.3%/0.5%（阈值 0.4）。
USPTO 门控为 43/4，MR-TADF 门控为 174/143。

三档均未同时通过两个旧域门控。`alpha=0.10` 虽保住 USPTO valid 和 MR-TADF
exact，但 USPTO exact 从 4 降至 2；更大的 alpha 遗忘更明显。因此停止继续搜索
插值系数，不升版，转入零初始化残差适配器实验。

> 最终状态：NO-GO
