# v0.8.10 Oracle 文字层 A/B

> 状态：数据均衡协议 GO，二维条件输入小幅 GO，完整分割主线暂缓  
> 输出：`outputs/checkpoints/chemvector-v0810-oracle-text-layer-10k`

## 目标

判断当前 OCR 的核心缺口究竟是文字/键线像素归属，还是字符串训练分布。所有实验使用
相同 train/validation、bbox、颜色概率、v0.8.8 初始化和 byte CTC，只改变输入。

四组输入：

1. `rgb`：原始 bbox；
2. `masked_rgb`：只保留真值文字 mask 内 RGB；
3. `rgb_text_mask`：RGB 加真值文字 mask 通道；
4. `rgb_text_mask_anchor`：再加入原子 anchor heatmap，并以垂直注意力替代高度均值。

真值 mask 只用于 Oracle probe，不进入正式推理。

## 采样修复

旧训练按数据流达到 crop limit 即停止，高频字符串支配结果。本轮先扫描 train split 的
exact-string 频次，按反平方根重复长尾标签，最大重复 8 次。validation 完整读取
5,012 个文字实例，并同时报告 micro、全部字符串 macro 和样本数至少 20 的 supported
macro。

## 结果

| 输入 | micro | macro | supported macro | modifier | false modifier |
|---|---:|---:|---:|---:|---:|
| RGB | 86.97% | 55.13% | 66.08% | 82.26% | 1.55% |
| masked RGB | 78.97% | 51.77% | 63.50% | 70.03% | 0.55% |
| RGB + text mask | 86.33% | 55.76% | 67.72% | 77.32% | 0.61% |
| RGB + mask + anchor + 2D attention | 87.13% | 57.77% | 69.43% | 80.62% | 1.19% |

关键标签：

| 输入 | N | NH | NH2 | N+ |
|---|---:|---:|---:|---:|
| RGB | 96.9% | 84.2% | 68.8% | 78.4% |
| RGB + mask + anchor + 2D attention | 97.6% | 85.7% | 84.4% | 76.1% |

均衡采样本身让 RGB 的长尾能力显著提高。Oracle mask、anchor 和二维注意力额外贡献
约 2.64pp 全字符串 macro、3.35pp supported macro，主要改善 `NH2`，但没有达到
预设的 10pp 机制门槛。纯 masked RGB 破坏预训练输入分布，明显回退。

## 决策

- exact-string balanced sampling 成为后续 OCR 的必需协议；
- 保留 RGB + mask + anchor 的二维输入作为后续候选；
- 暂不投入完整 text/bond 语义分割，因为 predicted mask 的收益只会低于 Oracle；
- 下一步先建设组合式开放字符串和真实核验 crop；
- 评测继续使用 macro、混淆矩阵和 actual predicted bbox，禁止只看 micro overall。
