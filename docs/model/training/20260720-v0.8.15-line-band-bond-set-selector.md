Oracle Junction 协议均保持不变。

## 复核

line-band reader 本身没有失效：validation 真/假候选 AUC 为 98.77%，真候选平均
edge 概率 97.98%，假候选为 9.27%。给定真实 Bond count 时，同一个 selector 的
严格拓扑可达 80.12%。主要失败来自 learned count 头，Count accuracy 仅 38.55%，
MAE 为 1.22。

固定使用既有 detector 阈值 0.25，并按 Junction pair 去重后，Count accuracy 可达
73.29%，selector 拓扑达到 71.49%。这进一步说明下一步不应继续扩大 count 分类头，
而应重新检查 Junction 的来源和 Bond endpoint 的对象语义。
