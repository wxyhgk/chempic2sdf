# v0.7.40 全候选邻接图去噪

## 目标

v0.7.39 证明候选边界校准有收益，但 9k/498 的 role vertex exact 只有 59.64%。
本轮不再调 Count 或阈值，而是让全部 256 个候选的 32,640 个无向点对参与两轮
node-edge-node 消息传递。没有最近邻截断、键长阈值或长键删除。

## 结构

冻结 v0.7.37 Group selector 和上游视觉模型，只训练约 309,981 个参数：

```text
全部候选节点 + 冻结 grounded edge logits
  -> 两轮 edge encoding / node aggregation
  -> 有界 REAL/NULL 节点残差
```

固定 100 图训练 5k 后，部署 exact 为 89%，Candidate Oracle 为 91%，通过
85.5% 容量门槛。

## 9k 结果

训练集 8,974 张，validation 498 张，15k 曝光。最佳 checkpoint 为 15k：

```text
selector role exact        58.03%
端到端 role exact          57.83%
strict skeleton exact      52.81%
匹配端点 edge recall       99.36%
>96px 条件 recall          95.44%
```

相对 v0.7.38 的 56.02%/51.00% 有小幅收益，但未达到 62% role exact 和 57%
skeleton exact 门槛。

## 强边证据消融

将 v0.7.38 宽线带 Bond Object 作为全部候选点对 teacher，500 张训练、100 张
validation 的 pilot 在完整 498 图上反而得到：

```text
role exact                 55.42%
strict skeleton exact      50.80%
```

因此瓶颈不是 edge logits 强度本身。强连线证据也会支持落在真实线段内部的假顶点；
只替换 edge reader 不能解决端点身份。
