# v0.8.33 Local-evidence Presence Selector

> 状态：容量 GO；formal safe-select GO；稳定推理未接入
> 日期：2026-07-21
> 基础 checkpoint：`chemvector-v0832-bond-group-query-ink-line-local-only-early4k/best.pt`
> 稳定推理：仍为 v0.7.10

## 目标

v0.8.32 已经把 collision holdout 的候选几何上限提高到 44.17%，但原始 presence 排序在
GT-known-count top-k 下只保留 9.71%。本轮验证：冻结 v0.8.32 的候选和端点几何后，能否
只靠局部视觉证据重新排序候选，减少“正确 refined candidate 已存在但被截断”的错误。

本实验只解决 ranking。它不训练完整分子 count、不修改 display/chemical type、不训练
OCR，也不接触 ChemScene/SDF 编译器。

## 模型

选择器只读取冻结 v0.8.32 已生成的部署特征，不读取任何 GT 字段：

- 每个端点的 `endpoint_local_features`：800 维，投影到 64 维；
- 每个端点的 `endpoint_ink_line_features`：64 维，共享编码；
- 两端编码使用 `mean` 和 `abs-diff` 组成无序对称表示；
- 拼接冻结的 192 维 BondObject hidden、基础/细化端点几何、base presence probability；
- display、chemical 和 direction softmax 只作为冻结 type prior 输入；
- 默认 `set_layers=0`，首轮使用逐候选 MLP，避免小数据下集合 Transformer 过拟合；
- 输出一个 presence residual，加到基础 `base_logits`。

residual 最后一层零初始化，因此 step 0 与 v0.8.32 presence logits 按位一致。选择器共
108,289 个参数，全部可训练；视觉编码器、Dense BondObject 和 v0.8.32 Group Query 共
55,631,351 个参数保持冻结。训练前后冻结 state hash 完全一致。

## 严格 Representable 标签

标签只用于训练 loss，不进入选择器特征。对每张图执行以下协议：

1. 用 refined endpoints 与 GT Bond 做无序端点比较；两个端点的最大欧氏误差都不超过
   `6 px` 才建立 compatible 边；
2. 在完整 compatible 图上做“最大匹配基数优先、总几何代价最小”的 Hungarian 匹配；
3. 同时兼容多个 GT 的候选如果成为 canonical winner，则只归入其匹配 GT；没有成为
   canonical 的跨 GT 模糊候选才从 loss mask 排除，不能强行标正或标负；
4. 每个匹配 GT 的 canonical winner 是该正组代表；同一 GT 的其他非模糊 6px 近候选
   加入同一正组，不作为普通负样本；
5. 没有 compatible GT 的有效候选成为独立负组；
6. 没有匹配候选的 GT 记为几何不可表示，不进入正标签或 `representable_count`；
7. loss 使用 canonical positive、negative max、exactly-one、representative 和 margin，
   cardinality weight 固定为 0。

这一区分防止候选池无法表示的 GT 反向污染 ranking，也防止多个视觉等价候选互相成为
矛盾正负样本。完整 GT count 从未作为训练目标。

是曝光不足，但只对 100 张训练图成立，不能直接外推为泛化结论。

## Checkpoint 选择 Bug

首个正式目录：

```text
outputs/checkpoints/chemvector-v0833-bond-group-presence-generalization-early4k/
```

训练本身有效，但旧 checkpoint selector 先按 collision 指标排序，未在更新 `best.pt`
之前执行 ordinary safety gate，因此错误选中 3,600 exposure：

- holdout collision known-count recall：26.21%；
- holdout cell exact：6.00%；
- ordinary image exact：58.03% -> 57.23%，回退 0.80pp，超过允许的 0.50pp；
- `go_checks.go=false`。

该目录和错误 checkpoint 独立保留，不覆盖、不删除，作为选择逻辑错误的审计产物。修复后
只有普通图 recall/exact 回退均不超过 0.5pp、candidate ceiling 不变的 checkpoint 才有
资格参与 collision 排序；随后从零以相同数据、顺序和 seed 重跑到独立 safe-select 目录。
