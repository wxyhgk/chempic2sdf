# Selector 冷启动 AdamW 核验与单一保留约束原型

## 决定

**原完整损失在实际学习率尺度的冷启动 AdamW 方向下，仍未给 `C#C` 两个被删正确端点升分。**
这次排除了“只因误读单位 SGD 方向才判断冲突”的解释，但不是历史训练退步的完整因果证明。
停止继续拆梯度、扫权重或扩大诊断图；只保留一个正例门槛保留原型，尚不接入训练。
默认模型仍为 initial。本轮没有新的准确率或 checkpoint。

## 固定协议与计算

- 原 4 图按既定顺序：`C#C`、`C#[13CH]`、`C#CC`、`CCC#N`，不替换样本或候选槽位。
- 旧完整分子控制取 9 月 15 日四图梯度审计中预先固定的前两张 **train** 图：
  `full_molecule_expansion:curr_d1248897c226b214__serif`、
  `full_molecule_expansion:curr_b7a85b1f6804b7df__font_small`。
  不是根据本轮预测或梯度挑选，不是开发/封存图片转训练。
- initial、eval、batch=1、冻结上游，只允许对 set_head 的 178,565 个参数求导。
  使用原完整 set loss，所有默认权重及门槛不变；atom selector 门槛为 `-0.25`。
- 冷启动 AdamW：LR `5e-6`、eps `1e-8`、weight decay `0`，空一二阶矩，selector-only norm clip `1`。
  每张小图独立计算首步方向，不累计、不平均；不代表历史 warm AdamW。

```text
g = gradient(original_full_set_loss)
c = min(1, 1 / (||g|| + 1e-6))
delta = -5e-6 * (c*g) / (abs(c*g) + 1e-8)
候选分数的局部线性变化 = J_candidate · delta
```

沿用已有 `cold_adamw_direction` 公式。FP32 autograd 梯度转 float64 后计算；
这不是实际 FP32 权重写入，也没有声称与有限步后的预测完全相同。
合成张量分别与 FP32、FP64 的真实 AdamW 首步做数值对照；**真实数据上不创建优化器**。
原单位 SGD 方向只用作逐候选复现检查，不拿两种方向的幅度作同单位比较。

旧图测量的是每个小图方向对旧图的 `J_old · delta_new`，不是旧图自己的下降方向。
预声明探查规则：全部 raw 正例、全部已保留负例、最高分负例、最接近门槛的负例；同分取最小槽位。
本轮规则产生 52 个正例、2 个负例，共 54 个旧图探针，每个分别检查 4 个小图方向。

## 结果

| 小图 | 正确候选降分 / 探查正确候选 | 最高分负例的线性分数变化 |
| --- | ---: | ---: |
| `C#C` | 2 / 2 | -0.019580 |
| `C#[13CH]` | 2 / 2 | -0.022829 |
| `C#CC` | 3 / 3 | -0.016560 |
| `CCC#N` | 2 / 4 | -0.010326 |
| 合计 | **9 / 11** | 不跨图求和 |

`C#C` 的局部估计尤其明确：

| 候选 | 初始 logit | `J·delta` | 线性估计 logit |
| --- | ---: | ---: | ---: |
| 错误 candidate 0，已保留 | -0.089200 | -0.019580 | -0.108780 |
| 正确端点 candidate 1，被删 | -0.624211 | -0.009484 | -0.633695 |
| 正确端点 candidate 2，被删 | -0.830390 | -0.003115 | -0.833505 |

错误候选降得更快，相对排序改善；但两个正确端点都进一步远离 `-0.25` 保留门槛。
同位素图已保留正确 candidate 2 从 `-0.039925` 线性下降约 `0.006742`，
仍在门槛上方，剩余余量约 `0.203333`。不能称它已被删掉。

两张旧图的交叉影响：

| 更新方向来源 | 旧图正确候选降分 / 52 | 一步线性估计正确→错误 | 保留正例最小剩余门槛余量 |
| --- | ---: | ---: | ---: |
| `C#C` | 52 / 52 | 0 | 0.842529 |
| `C#[13CH]` | 52 / 52 | 0 | 0.842758 |
| `C#CC` | 52 / 52 | 0 | 0.844357 |
| `CCC#N` | 48 / 52 | 0 | 0.845184 |

这是对旧能力的局部向下压力，不是已经发生回归。两张固定旧图的正例本来余量较大，
**没有覆盖紧贴门槛的旧正例**，因此零越界不能证明旧能力安全。
旧图最靠近门槛的负例初始为 `-0.329285`；负例是否危险须结合剩余余量，
不能用“所有负例必须每步下降”作为通用判据。
所有探针的一步线性估计都未改变筛选决策；未实际更新参数，不能报告救回图片数。

## 下一项：只实现一个隔离损失原型

新增 [隔离原型](../../../tools/selector_retention_prototype.py)，仅定义：

```text
L_keep = batch_mean(positive_mean(softplus(atom_threshold - atom_logit)))
L_proposed = L_original_full_set + 1.0 * L_keep
```

空正例图贡献零；padding 不参与。权重固定为 1，仅是待证伪的首个方案，不搜索。
原来的排序、正负例分类、count、bond 与 incidence 项全部保留。
它不是新发明的 threshold-aware 思路：生产代码已有 `_graph_exact_surrogate_loss`，
其 atom 部分也采用 signed-threshold softplus，只是本轮原目标中权重为零。
此次区别是只把正例保留单独按正例数归一化，不再次启用整个 atom/bond/incidence 最坏项。

已复核 [v0.9.57 的 graph-exact NO-GO](20260723-v0.9.57-graph-exact-surrogate.md)。
该历史结果不等于这个原型必败，但也不能包装成从未尝试过的全新方向。

**本轮只通过合成张量的函数契约测试，没有测得此原型在真实模型上有效。**
测试特意保留一个反例：负例的直接导数为零，仍可因共享参数而升分。
同样，直接要求正例升分不保证原完整目标加上它之后，AdamW 的实际方向就能满足全部约束。
这就是不能凭公式直接开大训练的原因。

不在此后继续增加纯梯度分解、阈值/权重扫描或一批备选 loss。下一次实证应是一项明确准入、
明确步数/时间、带回放和真实输出验收的有限更新试验；如果失败，否决这个原型，不自动续跑。

## 后续有限试验的边界（尚未授权或执行）

1. 新课程 v0.2 仍是 quarantine，身份核验不等于训练准入。本轮没有发布或改 split。
   先完成固定训练/开发划分及发布检查；不得把开发图直接用于优化。
2. 只考虑 selector 组件，从 initial 出发，其他模块/OCR/门槛固定。
   不再混合改变架构、课程比例和多个损失方案。
3. 旧完整分子保护清单沿用既有 headroom32，不按本轮结果挑样本。
   计划 SHA `2b5aedf18a4ab18613c19ca33a658a3471aaec2dff4cda73fa913ff5ce4d2aac`；
   报告 SHA `80787a19a7fbfb526a568de228e722f492068fd946cb77e5ef0942a80febaa68`。
   本轮仅核对历史文件绑定，没有重跑 32 图，更没有宣称其回归通过。
4. 验收必须包括两个端点一起保留、误选候选、键可达性、旧图救回/改错和最终图输出，
   不能只看平均 loss。固定诊断图不代表泛化准确率。
5. 训练预算和完整开发回归预算分开约定，不能挪用既往已结束的授权。
   800 张完整分子 CPU 回归是约半小时量级，不承诺塞进 60 秒诊断预算。

此前 presence-only 试训冻结 selector，故本次 selector 发现不能解释那次试训的退步。
