# 原始 full loss 配对对照：200 步早停，保留项有覆盖收益但仍不够

## 本轮结论

用户“开始下一步”确认了唯一的 original-full-loss-only 对照。
实际 **RTX 5090 单卡 14.383 秒、200 步**，在约定的 600 秒 / 400 步上限内，
因拟合完整端点到 200 步未改善而早停，正常完成结果保存。

**NO-GO。** 未续训、未启动第三个 loss 方案、未执行旧 944 图回归、未部署。
默认模型继续保持 initial。

新增保留项并非没有作用：在严格相同的前 200 步条件下，它保住/补回了更多目标端点；
去掉它虽减少了误保留，却进一步丢失正确端点。但两组都没能安全修好核心反例。
这限定于当前数据、种子、更新范围和预算，不是对自研架构的否定。

- 原 full set loss、匹配规则、6 px 半径、阈值、old/old/witness 循环全部不变。
- 唯一优化目标变化：新增 positive-retention 项系数 **1 → 0**。
- 原授权已消耗，本轮新增独立单次授权和同批用途扩展记录，不改历史数据准入或旧提案。
- 本轮未获完整 944 图回归授权；只有对照试训，没有自动后续回归。

更新前完成 122 张 initial 预测核对：指标/分数和语义 SDF 结果与上一轮完全一致。
冻结 raw/bond/label/batch 缓存、旧32图像/特征缓存、模型冻结部分及 OCR 哈希也完全一致。
200 次 batch key 逐步与上一轮同一步核对，保存记录独立复核前缀一致。

完整端点是目标原子覆盖，可达键是两个端点都能匹配；均不代表键类别、连接或 SDF 正确。

拟合26和旧32都参与更新，其数字不是独立识别准确率。

第100步也有等步证据：带保留项完整端点21/26，仅原loss17/26。

不为凑齐400步因果对照而越过既定停止条件。

## 核心反例与开发图

`C#C` 本轮第200步：错误槽0分数 -0.3243，正确槽1/2为 -0.7896/-0.9526。
固定阈值 -0.25 下三者都被拒绝；坏点去掉了，真端点也没留下。
其最弱正例－错误候选间隔由 initial -0.7327 改善到约 -0.6283，
但仍倒置且真端点离绝对保留阈值更远，不能说排序改善就是修复。

`C#[13CH]` 原本保留的正确槽2降到 -0.2773，被阈值丢弃；另一正确槽4为 -1.2436。
因此本轮也没通过核心正例保护。

本轮64开发图只能与本轮 initial 比较：

- 完整端点 **51 → 48 / 64**；完整且无多余点 **49 → 48 / 64**。
- 匹配原子 490 → 487 / 507；可达键 436 → 432 / 459。
- raw误保留17 → 15；selected多余点9 → 7。
- 没有测这64图的严格 SDF 准确率。

上一轮64图只保存了0/400步，没有200步，因此不能把本轮200步与上一轮400步终值
当作等步因果比较。报告的 `new64_equal_step_comparison` 明确为 null，没有补跑任何一组。

## 本轮几何证据补充：笔画与化学节点的混淆

新保存的冻结候选缓存与上一轮逐字节相同，所以可以把这些候选坐标对应到上一轮的选中槽，
不是假定不同CPU/GPU运行的槽号恰好相同。

1. `C#C` 正确槽1/2距目标约 **1.55 / 1.76 px**，原始候选中确实存在正确两端。
   错误槽0/3距最近目标约 **10.21 / 10.40 px**，原图显示它们落在三键上方外侧线条端头附近。
   这里有三个平行笔画，不是六个化学原子；要识别的是同一化学键的两个节点。
2. 上一轮 `CP(C)CCBr` 新增的错误槽5位于约 **(514.45,362.11)**，
   落在同源渲染 `r` 字形 bbox **(511,359,519,373)** 内，距目标原子锚点 **14.47 px**。
   这是 `Br` 标签中的字形区域，不是新增化学节点。
3. 上一轮另外两个新增错误槽距最近目标分别 **10.89 px、6.86 px**，
   都在固定6px匹配半径之外；没有据此扩大半径或改标签。

位置证据支持进一步区分“化学图节点”和“局部笔画候选”，
但不能从位置直接证明网络内部使用了哪种特征。
也不能据此删除所有落在文字区域的候选——正确文字原子同样需要保留。

## 后续边界

停止当前两种 selector loss 配方的自动延长，不加第三种系数、不继续扫阈值、也不直接全量训练。
下一阶段应利用已保存的几何和原始图，整理 **真图节点 / 多重键外侧笔画端头 / 字形内部伪点** 的
小型错误分类，再决定监督和候选表征是否需要改变。
本轮只给出定位证据，没有修改匹配、增加新规则或启动该下一阶段训练。

目前两真端点已在raw候选中，所以不能据这几个反例宣称“前端完全看不到原子”；
问题至少包含选择与语义区分，而不是仅靠更多端点保留或更强背景压制能解决。
