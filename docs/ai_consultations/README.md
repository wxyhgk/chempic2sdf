# AI 技术咨询档案

本目录记录 ChemPic2SDF 与其他 AI 系统进行的独立技术评审。它不是聊天记录堆放区，
而是用于追踪外部意见、项目决策和后续实验结果的工程档案。

## 记录范围

适合收录：

- 模型架构、训练协议和数据策略的独立评审；
- 针对明确实验结果的反方意见；
- 多个 AI 对同一问题的比较；
- 已采纳建议的后续验证结果；
- 被否决方案及否决证据。

不收录：

- 普通命令查询和无决策价值的短对话；
- API 密钥、代理认证信息或其他敏感配置；
- AI 的内部思考过程和终端噪声；
- 未经验证就写成项目事实的模型意见。

## 文件规则

文件名使用：

```text
YYYYMMDD-提供方-主题.md
```

例如：

```text
20260717-kimi-v0736-model-review.md
```

每份记录至少包含：

1. 咨询对象、日期、会话 ID 和对应项目版本；
2. 提供给 AI 的事实和硬约束；
3. AI 的主要判断；
4. 项目侧的采纳、保留和否决意见；
5. 可验证的后续实验及 GO/NO-GO 门槛；
6. 后续实验完成后的回填结果。

新记录从 [模板](TEMPLATE.md) 复制。AI 意见只作为假设来源，正式结论仍必须写入对应
训练档案，并由可复现实验支持。
