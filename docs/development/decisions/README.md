# 技术决策

每个重要决定单独保存 Markdown，说明背景、选择、证据、替代方案与重新考虑条件。
采用方案与效果验证分开：记录规范已采用，不代表模型方案已通过实验。

ID 格式为 `D-YYYYMMDD-01`，从 [模板](../templates/decision.md) 创建。
决策状态为 proposed/accepted/superseded/rejected。替代旧决定时，在旧记录追加新决定链接，
保留原始背景；日常小改动不必单独建立决策文件。
